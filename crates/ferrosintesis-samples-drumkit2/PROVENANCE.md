# Provenance — ferrosintesis-samples-drumkit2

The accent-cymbal half of the sampled drum kit: 48 mono 16-bit 44.1 kHz WAVs
(10.23 MiB), generated by `tools/ferrosintesis-samples/prepare_drumkit.py`
from two CC0 sources. The WAVs under `samples/` are **source, not build
output** — they are committed and embedded into the synth binary via
`include_bytes!`.

## Why this crate exists

It is a **packaging split, not a musical one.** The kit was originally one crate,
`ferrosintesis-samples-drumkit`, which packaged at **15.8 MiB compressed** — over
the crates.io **10 MiB** per-crate hard limit, so it could not be published at all.

Cymbals decay for seconds where drums decay in fractions of one, so the four
accent-cymbal banks held roughly half the bytes in a fifth of the banks. Moving
exactly those four splits ~20.5 MB into two ~10.5 MB halves (≈ 7.9 MiB packaged
each), with headroom on both sides and no change whatsoever to the audio.

Nothing here is re-recorded, re-cut or re-processed: these are the same files, from
the same sources, at the same pinned revisions, produced by the same script. A render
made against the split crates is **byte-identical** to one made before the split.

The ride, ride bell and the three hi-hats stayed in the core crate despite also being
cymbals — the seam was cut on file size, and those five are short enough to leave the
halves balanced. Do not read the crate boundary as a statement about the instrument.

## Sources (both pinned by commit SHA)

### 1. Virtuosity Drums — crash, sizzle crash, splash

- Repo: <https://github.com/sfzinstruments/virtuosity_drums>
- Pinned revision: `9f04cf9a734527edfbb0a4eee1f674e45bbf71bc` (master HEAD at
  fetch time, 2026-07-14)
- License: **CC0 1.0 Universal**, verified from the repo's own `LICENSE` file
  at the pinned revision (it is the verbatim Creative Commons legal code,
  beginning "Creative Commons Legal Code / CC0 1.0 Universal"). A verbatim
  copy ships in this crate as `LICENSE-CC0`.
- What it is: a contemporary jazz kit played with sticks by Austin McMahon,
  recorded at Virtuosity Musical Instruments, Boston, by Versilian Studios /
  Karoryfer Samples.
- Mic set used: **`mid`** — the balanced mono-friendly middle position, matching
  the core crate so the kit image stays coherent across the split.

### 2. Big Rusty Drums — the china (Virtuosity has none)

- Repo: <https://github.com/sfzinstruments/karoryfer.big-rusty-drums>
- Pinned revision: `f07ce00df34a46b6b08375be56fe116cf15782bc` (main HEAD at
  fetch time, 2026-07-14 — note this repo's default branch is `main`, not
  `master`)
- License: **CC0 1.0 Universal**, verified from the repo's own `LICENSE` file
  at the pinned revision — byte-identical to the Virtuosity `LICENSE`
  (same SHA-256), i.e. the same verbatim CC0 legal code shipped here as
  `LICENSE-CC0`.
- What used: the 18" china, stick articulation (`Samples/china_18/cn/`),
  **overhead (`oh`) mic** — the closest perspective match to Virtuosity's
  `mid` position (the `cl` close mic is much drier).

## Inventory

Velocity-layer splits (`hivel` bounds) and round-robin counts were **parsed
from the source SFZ mappings** (`Programs/mappings/mid/*.sfz` in Virtuosity,
`Programs/mappings/china_18/cn_oh.sfz` in Big Rusty), not guessed. A layer
covers `(previous hi + 1)..=hi` in MIDI velocity; the first starts at 0.

| Articulation | Files | Source stem | Vel layers (hivel) | RRs | Tail cap / fade |
|---|---|---|---|---|---|
| `crash` | 12 | `mid_crash_crash` | 3: ≤42, ≤85, ≤127 | 4 | 2.8 s / 0.35 s |
| `sizzle` (sizzle crash) | 12 | `mid_crash_sizzle` | 3: ≤42, ≤85, ≤127 | 4 | 2.8 s / 0.35 s |
| `splash` (hi-hat splash) | 4 | `mid_hh_splash` | 1: ≤127 (source has no layers) | 4 | 2.2 s / 0.35 s |
| `china` (18", stick) | 20 | `cn` (Big Rusty, `oh` mic) | 5: ≤25, ≤51, ≤76, ≤101, ≤127 | 4 | 2.2 s / 0.35 s |

Total: 48 files. File naming: `<articulation>_vl{L}_rr{R}.wav`, 1-based,
e.g. `crash_vl2_rr3.wav`. The `splash` files are named `splash_vl1_rr{R}.wav`
for uniformity even though the source has a single full-range layer.

All four banks have **true round robins** at the source — the adjacent-layer
pseudo-round-robin scheme described in the core crate's `PROVENANCE.md` applies
only to the snare, cross-stick and toms, none of which are here.

Notes:
- `splash` is Virtuosity's **hi-hat splash** (pedal-splash articulation), not
  a true splash cymbal — it is the nearest thing this kit has for GM 55.
- `sizzle` is reachable through the `Bank` API but is **not routed** by any GM
  channel-10 key in `ferrosintesis`. That is deliberate: the synth is a generic
  GM player and the bank is part of the public instrument, available to callers
  and to future kit work. Do not cull it for lack of an in-repo user.
- Virtuosity also has a flat ride (`flatride_ride`, `flatride_crash`) that was
  left out to keep the bank lean; it can be added by extending `BANKS` in
  `prepare_drumkit.py`.

## Processing (deterministic, mirrors `prepare.py`)

Per file: bit-exact FLAC decode (ffmpeg, `pcm_s24le`, native rate — ffmpeg is
tool-time only, the version does not affect the decoded PCM); stereo→mono
downmix (0.5/0.5); linear resample 48 kHz (Virtuosity) / passthrough 44.1 kHz
(Big Rusty) to 44.1 kHz; onset trim at 3% of peak with an 8 ms pre-pad; tail
cap per the table above with a squared fade-out; 2 ms fade-in; peak-normalize
to 0.9 (the bank-wide convention — per-layer natural loudness is discarded;
the synth applies velocity gain). Output: 16-bit mono WAV.

## Regenerating

`prepare_drumkit.py` writes the whole kit; the four banks below land here and
the rest land in `ferrosintesis-samples-drumkit`. After regenerating, refresh
both crates' embedded tables:

```powershell
python tools/ferrosintesis-samples/prepare_drumkit.py
python tools/ferrosintesis-samples/regen_samples_table.py crates/ferrosintesis-samples-drumkit
python tools/ferrosintesis-samples/regen_samples_table.py crates/ferrosintesis-samples-drumkit2
```
