# Provenance — ferrosintesis-samples-musescore-grand

| `musescoregrand_*` | 25 |

Grand-piano attack/body bank for the **GM 1 Bright Acoustic Piano alternate**
(CC0=2): a **dense single-velocity multisample** (one sample per distinct sampled
pitch across C2..C6+, ~every 2–3 semitones) of mono 16-bit 44.1 kHz WAVs.
Generated by `tools/ferrosintesis-samples/prepare.py` (`_bake_musescore_grand`)
from the MuseScore_General soundfont. The WAVs under `samples/` are **source, not
build output** — committed and embedded via `include_bytes!`.

## Source

**MuseScore_General.sf3** (S. Christian Collins, MIT), the "Grand Piano" preset.
The fuller MuseScore soundfont's grand — a warm-to-neutral GM grand, distinct from
the thinner "MS Basic" grand.

- URL: <https://ftp.osuosl.org/pub/musescore/soundfont/MuseScore_General/MuseScore_General.sf3>
  (39,900,972 bytes; SHA-256 pinned in `prepare.py` — the FTP publishes no checksum).
- License: **MIT** —
  <https://ftp.osuosl.org/pub/musescore/soundfont/MuseScore_General/MuseScore_General_License.md>.
  Copyright/acknowledgement notices (Collins; FluidR3/Frank Wen) retained in `NOTICE`.

## Selection & the single-velocity simplification

The preset is a velocity-layered multisample: "Piano MF-low/high" (vel ≤ 107) +
"Piano FF-low/high" (vel ≥ 108), each an SF3 instrument. To keep the extraction
tractable for an audition, this crate takes the **MF tier only**, one sample per
distinct `originalPitch` (`shdr[40]`, the trustworthy MIDI root) in MIDI 34..88.
Dynamics in the render come from the LA blend gain (velocity-scaled) and the
modeled voice, not from the sample layer — so this bank has no per-velocity strike
brightening. If it earns a place in the final ranking, the FF layer can be added.

Each SF3 sample is a self-contained Ogg-Vorbis stream in the `smpl` chunk
(byte-delimited by `shdr` start/end); decoded with ffmpeg.

## Processing (deterministic)

Per sample: slice the Ogg by byte offsets; ffmpeg → 16-bit PCM; `read_wav` decode
(→ mono); resample to 44.1 kHz if needed; `trim_to_onset` keeps the onset + **1.5 s**
of body (0.6 s fade-out), peak-normalized to 0.9; `measure_f0` (tight window around
`originalPitch`) records the root pinned in `musescoregrand_*` in
`crates/ferrosintesis/src/sampler.rs`. Output: 16-bit mono WAV.

## Regenerating

```
python tools/ferrosintesis-samples/prepare.py --only=musescoregrand
```

Needs `ffmpeg` on PATH (Ogg decode).
