# ferrosintesis-samples-rain

A single embedded real-rain ambience **loop** for
[ferrosintesis](https://github.com/0x4D44/ferrosintesis)'s GM 96 (FX 1 "rain") voice — a
seamless mono 16-bit 44.1 kHz texture. With the LA sample layer on it **replaces** the voice's
synthetic gated-noise wash (a real recording is a far better rain than any bandpass-noise
model), keeping the faint crystal sparkle on top; a modeled-only build keeps the pure synthetic
wash unchanged.

Recorded by the repository owner (2017) and dedicated **CC0 1.0** (public domain). Provenance +
regeneration steps in `PROVENANCE.md`. Consumers normally reach it through `ferrosintesis`.
