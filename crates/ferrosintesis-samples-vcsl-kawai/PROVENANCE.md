# Provenance — ferrosintesis-samples-vcsl-kawai

## Packaged family inventory

| Family | Files |
|--------|------:|
| `kawai_*` | 48 |

Grand-piano attack/body bank for the **GM 1 Bright Acoustic Piano default**
(no CC0 select needed): 48 mono 16-bit 44.1 kHz WAVs, 8 pitch zones (C2–C6) × 3 dynamics
(pp/mf/f) × 2 round robins. Generated by `tools/ferrosintesis-samples/prepare.py`
(family `kawai`) from the VCSL "Grand Piano, Kawai" sustain samples. The WAVs
under `samples/` are **source, not build output** — committed and embedded via
`include_bytes!`. Kept in its own crate for licence isolation and the crates.io cap.

## Source

**Versilian Community Sample Library (VCSL)** — "Grand Piano, Kawai" (player
perspective), by Versilian Studios / Sam Gossner. A darker, rounder vintage grand
than the bright Salamander C5 (GM 0 CC0=2 alternate).

- Repo: <https://github.com/sgossner/VCSL>
  (`Chordophones/Zithers/Grand Piano, Kawai/Sustains/`)
- Files: `GPiano_sus_<Note><Oct>_v<N>_rr1_Player.wav`, velocity layers v1..v4,
  single RR, 16-bit stereo PCM (downmixed to mono, requantized to 16-bit).
- License: **CC0 1.0 Universal** (public domain) —
  <https://github.com/sgossner/VCSL/blob/master/LICENSE>. No attribution
  obligation; `NOTICE` is a courtesy credit only.

## Selection — the octave-label trap

VCSL's Kawai file labels sit **one octave BELOW sounding pitch** (measured: label
`C2` sounds 131 Hz = C3; label `C4` sounds 525 Hz = C5; label `A#3` sounds 469 Hz =
A#4) — the same trap as the VCSL keyboard/ocarina, and unlike the Steinway B. So
each dest zone is named by its **MEASURED sounding pitch** and mapped to the source
file labelled one octave down:

| dest zone (sounds) | source label | dynamic → velocity (RR1, RR2) |
|---|---|---|
| C2 | C1 | pp→v1,v2 · mf→v2,v3 · f→v4,v3 |
| A2 | A1 | (same) |
| C3 | C2 | |
| A#3 | A#2 | |
| C4 | C3 | |
| A#4 | A#3 | |
| C5 | C4 | |
| C6 | C5 | |

Only pitches with a full v1..v4 layer set were chosen (the sampling is irregular),
giving 8 zones — the roots are pinned by measurement in the `kawai_*` zone tables in
`crates/ferrosintesis/src/sampler.rs`, never by the source labels.

## Processing (deterministic, `prepare.py` `kawai` family)

Per file: `read_wav` decode (16-bit stereo → mono 0.5/0.5); linear resample to
44.1 kHz (no-op); `trim_to_onset` cuts to the onset (3% of peak, 8 ms lead-in
pad), keeps **1.5 s** of body with a lead-bounded 2 ms fade-in and a 0.6 s squared
fade-out, peak-normalized to 0.9; `measure_f0` records the autocorrelation root.
Output: 16-bit mono WAV.

## Regenerating

```
python3 tools/ferrosintesis-samples/prepare.py --only=kawai
```

Pure stdlib (plain WAV, no ffmpeg).
