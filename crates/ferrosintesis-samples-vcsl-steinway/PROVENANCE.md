# Provenance — ferrosintesis-samples-vcsl-steinway

## Packaged family inventory

| Family | Files |
|--------|------:|
| `steinwayb_*` | 54 |

Grand-piano attack/body bank for a **GM 0 Acoustic Grand alternate** (CC0=3):
54 mono 16-bit 44.1 kHz WAVs, 9 pitch zones (C2–C6) × 3 dynamics
(pp/mf/f) × 2 round robins. Generated by `tools/ferrosintesis-samples/prepare.py`
(family `steinwayb`) from the VCSL "Grand Piano, Steinway B" close-mic samples.
The WAVs under `samples/` are **source, not build output** — committed and
embedded via `include_bytes!`.

Kept in its own crate so the CC0 dedication is isolated from the other banks'
licences and so `ferrosintesis-samples-core` stays under the crates.io 10 MiB cap.

## Source

**Versilian Community Sample Library (VCSL)** — "Grand Piano, Steinway B",
close mic, by Versilian Studios / Sam Gossner. A warm, intimate vintage
Steinway B — the tonal opposite of the bright Yamaha C5 Salamander grand
(GM 0 CC0=2).

- Repo: <https://github.com/sgossner/VCSL>
  (`Chordophones/Zithers/Grand Piano, Steinway B/Sus/`)
- Files: `JHPiano_Sus_Close_<Note><Oct>_vl<N>_rr1.wav`, whole-tone sampled
  (A#, C, D, E, F#, G# per octave), velocity layers vl2/vl3/vl4, single RR.
- Source format: **44.1 kHz, 24-bit, stereo, PCM** (downmixed to mono, kept at
  44.1 kHz, requantized to 16-bit by `prepare.py`).
- License: **CC0 1.0 Universal** (public domain) —
  <https://github.com/sgossner/VCSL/blob/master/LICENSE>. The README states:
  "you can do whatever you want with these sounds (even make commercial
  software), no royalties, no credit, no special terms." No attribution
  obligation; `NOTICE` is a courtesy credit only.

## Selection

- **Zones** C2, F#2, C3, F#3, C4, F#4, C5, F#5, C6 — the same C/G-ish spacing as
  the Salamander grand (F# is the nearest sampled pitch to each G). VCSL's
  Steinway labels are **true sounding pitch** (measured: C2 65.7, C4 262,
  C6 1050 Hz — it is NOT octave-mislabelled like the VCSL keyboard/ocarina).
- **Dynamics** pp → vl2, mf → vl3, f → vl4.
- **Round robins:** VCSL has one RR per note, so RR2 is an adjacent velocity
  layer (pp→vl3, mf→vl4, f→vl3). Each file is peak-normalized to 0.9, so RR1/RR2
  land at the same level and differ only in the natural harder/softer-strike
  timbre — real round-robin variation, defeating the machine-gun tell.

## Processing (deterministic, `prepare.py` `steinwayb` family)

Per file: `read_wav` decode (24-bit stereo → mono 0.5/0.5); linear resample to
44.1 kHz (no-op); `trim_to_onset` cuts to the onset (3% of peak, 8 ms lead-in
pad), keeps **1.5 s** of body (`KEEP_FAM['steinwayb']`) with a lead-bounded 2 ms
fade-in and a 0.6 s squared fade-out, peak-normalized to 0.9; `measure_f0`
records the autocorrelation root pinned in the `steinwayb_*` zone tables in
`crates/ferrosintesis/src/sampler.rs`. Output: 16-bit mono WAV.

## Regenerating

```
python tools/ferrosintesis-samples/prepare.py --only=steinwayb
```

Downloads the VCSL Steinway B files once (cached under the system temp dir), then
bakes. Pure stdlib (plain WAV, no ffmpeg).
