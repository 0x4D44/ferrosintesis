## Winter Guests

An original two-part instrumental (9:26 + 9:02) in the Mike Oldfield idiom
with two guest sorties made to belong rather than clash: **ABBA** (*The
Visitors*' cold sequenced arpeggios; *Super Trouper*'s stacked-thirds
choruses, off-beat piano octaves and the truck-driver gear change) and the
**Crash Test Dummies** (*Mmm Mmm Mmm Mmm*'s low wordless baritone hum). The
guests are movements sharing one DNA: a single Guest theme with three
machine-verified guises (low hum / ABBA chorus stack / Oldfield guitar), all
reducing to the skeleton `1 5 2 1 3 7 4 1`. A parallel-major arc — opens E
minor, closes E major — carried home by the ABBA gear change; the final hum
resolves the tonic Part One withholds. The humming is written in as lyric
metadata a MIDI player will display.

- Files: `Winter Guests/midi/01 - Winter Guests, Part One.mid` (9:26),
  `Winter Guests/midi/02 - Winter Guests, Part Two.mid` (9:02)
- Six movements with MIDI markers; timed maps in
  `Winter Guests/album_manifest.json`
- Docs: `Winter Guests/README.md` and `ALBUM.md`
- Regenerate/verify: `python build.py` / `python build.py --verify`
- Listen via [hollowsynth](hollowsynth/README.md) **v0.7** (its CC70 vowel
  morph, RPN bend-range/fine-tune, portamento, resonance, aftertouch and
  pedal features were built for this piece)

This is original material using Oldfield-vocabulary gestures; it quotes no
existing piece.

## The Signal Fire

An original single-track instrumental (16:52) crossing four corners of the
Oldfield catalogue — *Incantations Part IV*'s long guitar build, *TSDOE*
"Ascension"'s ambient-to-pulse ignition, *Tubular Bells III*'s bells-over-
four-on-the-floor climax, and *The Millennium Bell* "Mastermind"'s funk
engine. One bass riff in three rhythmic guises (4/4 funk, 10/8 additive,
augmented) and three themes composed over one ground so they stack in
counterpoint at the finale — both properties machine-verified by the
album's own oracles. Heavy continuous-controller writing: wah (CC74 LFO),
Leslie spin-up (CC1), violining swells (CC11), detuned double-tracking and
unison bends, pedalled piano (CC64), and a Morse-code beacon that gets
answered.

- File: `The Signal Fire/midi/01 - The Signal Fire.mid` (16:52)
- Six movements annotated with MIDI markers; timed map in
  `The Signal Fire/album_manifest.json`
- Docs: `The Signal Fire/README.md` and `ALBUM.md`
- Regenerate/verify: `python build.py` / `python build.py --verify`
- Listen via [hollowsynth](hollowsynth/README.md) **v0.6** (its CC1/CC64/
  CC74 features were built for this piece)

This is original material using Oldfield-vocabulary gestures; it quotes no
existing piece.

## Hollow Hill

An original two-part instrumental epic (~26:29) in the Mike Oldfield idiom,
drawing on Tubular Bells I–III, Amarok and The Songs of Distant Earth — a
13/8 additive-meter ostinato (3+3+3+2+2) in E dorian that returns across
both parts and is recast major for the finale, with an instrument-by-
instrument roll-call, ambient pools, a false ending, and a Morse-code joke
buried in the woodblock.

- Files: `Hollow Hill/midi/01 - Hollow Hill, Part One.mid` (13:56),
  `Hollow Hill/midi/02 - Hollow Hill, Part Two.mid` (12:34)
- Movements are annotated with MIDI markers; timed section maps live in
  `Hollow Hill/album_manifest.json`
- Forces: 16 GM channels — piano, glockenspiel, tubular bells, bass, organ,
  strings, choir, steel/nylon/clean/lead guitars, flute & whistle, fiddle,
  pad, crystal, timpani & mandolin, percussion
- Docs: `Hollow Hill/README.md` and `Hollow Hill/ALBUM.md` (movement tables)

This is original material using Oldfield-vocabulary gestures; it quotes no
existing piece.

Regenerate and verify with:

```powershell
python ".\Hollow Hill\build.py"
python ".\Hollow Hill\build.py" --verify
```

For listening, render the MIDI with [hollowsynth](hollowsynth/README.md) —
a zero-dependency Rust MIDI-to-WAV synthesizer voiced for this album
(modeled instruments plus LA-style sampled attacks on the solo voices).

## The Iron Tide

An original single-movement cinematic piece written in the Hans Zimmer idiom —
a long build from a quiet low-D pedal and sparse tolling piano, through a
gathering string ostinato, taiko-style percussion, and low-brass braams, to a
full-voice horn theme at the climax, closing on a bare open fifth.

- File: `midi/The Iron Tide.mid`
- Key: D minor, 4/4
- Length: 96 bars, ~3:33 (112 bpm, easing to 76 bpm in the coda)
- Form: intro (1-16), first build (17-40), theme distant (41-56), surge (57-64), climax (65-80), coda (81-96)
- Forces: piano, string ostinato, low strings, cello, horns, low brass, choir pad, percussion

This is original material using broad film-music vocabulary; it is not a copy
of any existing score.

Regenerate with:

```powershell
python .\the_iron_tide.py
```
