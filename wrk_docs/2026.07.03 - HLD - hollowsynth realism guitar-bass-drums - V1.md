# HLD — hollowsynth realism: recorded-instrument guitar, bass & drums (V1)

*Status: DRAFT (V1 synthesis). Target: `fable5/hollowsynth`. Evidence base:
`wrk_docs/2026.07.03 - CR - hollowsynth guitar-bass-drum realism review.md`
(41 verified findings). Findings cited inline, e.g. GTR-1, CYM-4.*

This V1 synthesises three independent drafts (simplest-viable, risk-first,
testability-first). The **risk-first spine** carries it — impact ÷ risk phasing,
every claim pinned to a `cargo test` oracle — grafted with simplest-viable's
explicit *non-goals-with-a-reason* discipline and testability-first's concrete
std-only oracle-helper API. Three blind spots that **all three drafts missed**
(stereo kit imaging, a compute budget, GM-routing verification) are added here in
§3.4, §5 and §6.

---

## 1. Scope & non-goals

### 1.1 Goal
Make **guitars, bass and drums** read as recorded instruments — close the
high-impact findings coherently, **evolving** hollowsynth, not rewriting it.

### 1.2 Success
The acceptance oracles in §5 pass (each fails on current `main`, passes after),
**all pre-existing tests still pass**, the deterministic seeded render stays
bit-reproducible, and per-family mix balance holds within ±2.5 dB of a committed
golden baseline. "Sounds better" is never the definition of done — a measured
centroid / band-energy / decay / pitch / choke / correlation delta is.

### 1.3 In scope
Rebuild the guitar/bass/drum **voice** models and the drum engine; extend shared
DSP (`dsp.rs`) and the engine signal path **only where a finding demands it** — a
guitar cabinet insert, a drum-room bus, a guitar sympathetic bus, per-piece drum
panning, and one new synth-bass voice.

### 1.4 Non-goals (deliberately NOT built — with the reason, per simplest-viable)
- **No rewrite** of the render loop, bus/FX chain, `reverb.rs`, `midi.rs`,
  `wav.rs`, or the `sampler.rs` LA mechanism — all *reused*.
- **No external crates** (std only). **No new env vars, no feature flags** — the
  one existing `samples: bool` is the only knob.
- **No migration / rollback / back-compat** — sandbox build.
- **+0 MB by default.** No `include_bytes!` additions in the main phases. Guitar/
  bass/drum onsets are impulsive transients a *seeded synth models better* than a
  fixed PCM one-shot (velocity-continuous, deterministic, no repitch). A bounded
  **≤ 2 MB** drum one-shot escalation is pre-designed (§6) but gated behind the
  existing `samples` flag and fired **only if** oracle 25 (kick beater) cannot be
  met synthetically.
- **Deferred as fragile / low-payoff** (residual risks §6, not in the main
  phases): high-gain *feedback bloom* (GTR-7#2, impact 2), unconditional *4×
  oversampling* (GTR-3#2 — the steep cabinet LP already kills the fizz), and
  *micro-timing humanisation* (see §3.4 — a real realism lever but arguably a
  composition-side concern; flagged for the review loop to rule in or out).

The whole design is six abstractions. If you can name them you hold it in your head.

## 2. Design overview

Six abstractions carry ~90% of the work; the rest is table/preset edits.

**A. The velocity→timbre law** — one formula applied at every plucked- and
drum-voice construction. Today velocity moves only amplitude — the single biggest
"sampled-at-one-dynamic" tell. `vn = vel/127` opens the excitation lowpass and
loop-damping cutoff for `Pluck`, and scales membrane start-pitch, glide, click
energy and decay for `Drum`. Closes **KS-2, GTR-1#2, BASS-2, DRM-2**. Highest
impact ÷ risk in the design — ~a dozen lines, no new state, tuning-safe.

**B. `Burst` — a parallel one-shot transient** (new ~15-line `dsp.rs` primitive):
a filtered, exponentially-decaying noise burst summed **in parallel** to a voice's
output, **never into a feedback loop**. One primitive supplies pick/finger attack
(GTR-2, BASS-7), slap thumb/pop (BASS-1), release thump (BASS-6) and palm chuff
(GTR-5). Its drum cousin is the extended `NoiseBand` (delayed `onset` + `swell`
envelope) that adds snare wire-engage (DRM-5) and crash bloom (CYM-2).

**C. The Cabinet** — replaces the lone 3.4 kHz lowpass in `Drive` with a 5-biquad
IIR speaker cab (low resonance + presence peak + ~24 dB/oct cliff), preceded by a
program-keyed pre-voicing peak and a DC-bias asymmetric clip. The clean-guitar
preset gets its own light cab. Closes **GTR-1, GTR-4, GTR-2#2, GTR-6** and, for
free, the fizz of GTR-3#2 (the steep cab LP *is* the decimation filter).

**D. The KS physics core** — shared `KsLoop`/`Pluck` upgrades: cubic-Lagrange
fractional tap (KS-5), triangle-displacement initial condition (KS-1),
energy-conserving polarization coupling (KS-4), release darkening (GTR-7), and
register-split wound-ness / optional dispersion allpass (KS-3, GTR-5#2). These are
the *risky* ones (loop stability at E1 = 41 Hz, retune clicks, re-levelling) so
they land **last**, each behind its own oracle.

**E. Ambience & imaging** — two reverb-style buses reusing tested `Reverb`/comb
code: a **drum room** (short `Reverb`, ch 9 only, pre-hall; DRM-7) and a **guitar
sympathetic** comb bank (open-string tuning, acoustic guitars only; GTR-3/KS-6) —
plus **per-piece drum panning** so the kit images across the stereo field instead
of as a mono point source (§3.4, the shared blind spot).

**F. `SynthBass`** — one genuinely new voice (saw + envelope-swept resonant LP)
for GM 38/39, which are wrongly modelled as acoustic plucked strings today
(BASS-4).

### 2.1 Signal path (edits marked ►)
```
NoteOn ─┬─ ch9  → drums::make(key,vel)          ► choke() live hats first (CYM-4)
        │                                        ► per-piece pan offset (§3.4)
        └─ mel  → voices::make(prog,key,vel,samples)
                     ► velocity→timbre law (A)
                     ► Burst onsets summed parallel (B)

per voice ─► ch_buf[ch]
  ch_buf ─► [Drive insert (prog 29|30): pre-voice → bias-tanh → CABINET (C)]
         ─► strip gain · expr · pan(+ ►drum per-piece offset) · Haas
            ├─► mix_l / mix_r
            ├─► send_rev (CC91, hp'd)                → hall Reverb
            ├─► send_cho / send_del                  → Chorus / PingPong
            ├─► send_sym  (piano)                    → Sympathetic
            ├─► send_sym_gtr (prog 24|25)   ►NEW     → GuitarSymp (GTR-3/KS-6)
            └─► send_room (ch9, no hp)      ►NEW     → drum_room Reverb (DRM-7, pre-hall)
  mix_l/mix_r ─► BusGlue ─► out
```
Nothing in the reverb/chorus/echo/glue math changes; new buses sum into `mix_*`
exactly like the existing ones. `Reverb` is already stereo (per-side early taps,
`combs_l`/`combs_r`), so the drum room returns a stereo room, not a mono blob.

### 2.2 Determinism invariant (holds across every change)
The velocity mapping keeps **exactly one** `rng.white()` in the `bright` line so
the per-note round-robin sequence stays byte-identical. All `Burst` noise draws
come from the voice's existing seeded `rng`. Two same-seed renders stay
bit-identical (oracle 35).

## 3. Per-family design

Presets gain fields, all defaulted to 0/none on families that don't use them:
`click, click_hp` (onset hardness), `attack_noise` (finger/fret), `stop_thump`
(release), `cab_lp` (clean-cab rolloff, 0 = none).

### 3.1 GUITAR

**G1 — Cabinet + amp voicing** (GTR-1, GTR-4, GTR-2#2; closes GTR-3#2).
`engine.rs::Drive` gains `voice: Biquad`, `cab: [Biquad;5]`, `bias: f32`,
`dc: f32` — all built at `sr*2.0` (existing 2× path):
- **Pre-voicing** (before gain/tanh): prog 30 `peak(650,0.9,-5)` (scooped chug);
  prog 29 `peak(800,0.8,+4)` (mid-push lead).
- **Asymmetry** (even harmonics): `bias = if prog==30 {0.55} else {0.4}`,
  `dc = bias.tanh()`; shape `(pre·voice·gain + bias).tanh() - dc` (constant
  DC-cancel → silence stays exactly 0, click-free).
- **Cabinet** (post-tanh, per sub-sample): `peak(100,1.2,+4)`, `peak(500,1.0,-3)`,
  `peak(2600,1.5,+5)`, `lowpass(4800,1.2)` → `lowpass(5200,0.7)`. The two cascaded
  LPs give the ~24 dB/oct cliff and **replace** the box-average decimator (take
  the cab-filtered sub-samples at base rate → tanh fizz killed, GTR-3#2 needs no
  4×). Trim `post` ≈ −2.5 dB to offset the boosts (prog 30 → ~0.22, prog 29 →
  ~0.32); pinned by oracle 34.
- **Routing:** `Drive` insert stays on **29|30 only**. Prog 28 (muted) and 31
  (harmonics) do **not** get channel distortion (fixes the double-distortion /
  clean-funk hazard) — their grit is contained in the preset (G4, G7).

**G2 — Clean-amp cab** (GTR-6). `CLEAN` preset: `body = [(200,1.0,+2),(2500,1.0,+3)]`
(feeds the existing per-voice body chain). Add `cab_lp: Option<OnePole>`—no, a
`Biquad::lowpass(4500,0.9,sr)` for CLEAN only (do **not** touch the shared
`out_lp` that BASS/MUTED depend on), processed right after the body chain. Static,
no clicks.

**G3 — Velocity→timbre** (KS-2, GTR-1#2 — the law, guitar half). In `Pluck::new`:
`vn = vel/127`; `bright = (p.bright*(0.65+0.55*vn)*(1.0+0.08*rng.white())).min(sr*0.45)`
(exactly one `rng.white()` preserves the round-robin sequence);
`pick_lp = (p.pick_lp*(0.5+0.9*vn)).max(400.0)` feeds the excitation `OnePole`.
`bright` flows unchanged into both `KsLoop::new` calls, so damper and `delay_for`
stay tuning-consistent.

**G4 — Pick attack & palm chuff** (GTR-2, GTR-5). `Pluck` gains `onset: Option<Burst>`.
Preset `click`/`click_hp`: STEEL/CLEAN ≈1.0 @1500 Hz, DRIVE 1.2, NYLON 0.5 @1000 Hz,
BASS/FRETLESS use the finger-noise variant, others 0. Triggered at level
`click·vel_amp(vel)` in `new`, summed into `y` **before** the body EQ so the click
knocks the body. MUTED (GTR-5): per-voice soft-clip `y=(y*2).tanh()/2` gated to the
preset; enrich `sub` with 2f/3f partials; shorten the sub ramp 220→~90 samples;
add a short chuff `Burst`. No channel distortion.

**G5 — Guitar sympathetic bus** (GTR-3, KS-6). `engine.rs::GuitarSymp`: 6 combs at
E2 A2 D3 G3 B3 E4 (82.41…329.63 Hz), each `DelayLine(sr/f)`, in-loop
`OnePole::lowpass(3400)`, feedback 0.85, `hp = Biquad::highpass(120,0.7)`, return
0.30, denormal flush `if x.abs()<1e-20 {0.0}`. Fed **only** by prog 24|25 at send
0.03 (`send_sym_gtr`). Restricted to true acoustics so driven electrics don't smear.

**G6 — Release darkening** (GTR-7). `KsLoop::set_bright(bright,f)` sets cutoff +
`retune(f)` (retune recomputes the damper-phase-compensated delay, pitch holds).
`Pluck` keeps `rel_bright_h/v`; while released, at control rate glide each toward a
floor `min(current, ~800/920)` — already-dark presets unaffected. Control-rate +
existing `glide_k` → no click.

**G7 — Prog 31 harmonics** (GTR-6#2). Split 31 into a `HARMONIC` preset:
node-biased excitation (`pos` at 1/2–1/4 so the comb nulls the fundamental),
glassy ~2 s t60, light grit at most, no heavy amp.

### 3.2 BASS

**B1 — Velocity→timbre** (BASS-2): same G3 formula; verify `pluck_pitch_a4`
tolerance at vel 30 and 120 (fundamental-only measurement → safe).

**B2 — Articulation split** (BASS-1, BASS-3, BASS-7). New presets in `make()`:
- `SLAP` (36/37): `pick_lp≈4500, bright≈3500, out_lp≈4000, pos≈0.12`, `click` high
  → thumb slap + near-bridge pop via `Burst` (highpass 1500, ~3 ms, linear-to-zero
  → no tail click), **parallel** to the string.
- `PICK` (34): `pick_lp≈2600, bright≈2200, pos≈0.15, out_lp≈2400` so the plectrum
  click survives.
- `UPRIGHT` (32): `t60≈2.4`, second body peak `(110,1.0,+3)`, woody attack noise.
- Fingered 33 stays on `BASS`. **Finger/fret noise** (BASS-7): preset
  `attack_noise` (FRETLESS 0.12, BASS 0.08, else 0) drives the `onset` `Burst` as a
  `bandpass(2000,0.8)` layer, gain `(attack_noise·(0.45+0.55·v)).min(0.5·v)` so soft
  fretless still exposes finger noise without it dominating.

**B3 — Stop thump** (BASS-6). Preset `stop_thump` (BASS/FRETLESS 0.15, else 0).
`Pluck` gets `stop: Option<Burst>` = `OnePole::lowpass(250)` low thud, ~60 ms t60,
armed by `note_off`, summed into `y` (rides amp/release, keeps the voice alive to
play out, then dies). Fires only on explicit `note_off`, not natural end.

**B4 — Synth bass** (BASS-4). New `voices::SynthBass` (NOT SawStack — no
amp-env-driven filter path): one `BlepSaw` (38); two detuned ±6–10 ¢ (39); optional
sub `Sine`; amp `Adsr` (fast A, mid D/S, short R); resonant `Biquad::lowpass(base,q)`
q≈3–6 whose cutoff is driven at control rate by a **separate filter `Adsr`**:
`cut = 300 + fenv·depth` (depth scales with velocity), `cut.clamp(80, sr*0.4)` via
`retune_lowpass` (state-preserving). No body EQ, no pickup comb, no tanh; own gain
calibration.

**B5 — Sub enrichment** (BASS-5). In `Pluck::new` randomise sub start phase
(`rng.white()*π`). In render, replace the pure add with a DC-free even-harmonic
shaper: `y += (s + 0.3*(s*s - 0.5)) * gain * sub_env` (`s²−0.5 = −½cos2x`, a clean
2nd harmonic, no DC). Keep the `t60*0.8` decay (no feedback coupling).

### 3.3 DRUMS

**D1 — Velocity→timbre** (DRM-2). In `make()`'s `d` closure, transform tables before
`Drum::new`: membrane start-freq `×(1+0.03·vn)`; glide `×(0.6+0.8·vn)`; decays
`×(0.85+0.30·vn)`; noise/click amp `×(0.5+0.5·vn²)` (floor 0.5 preserves ghost
notes). Cymbals keep their own `velnorm` handling.

**D2 — Membrane modes** (DRM-1, DRM-4). Toms 41/43/45/47/48/50: add two modes at
1.59×/2.14× the fundamental (amps 0.40/0.18), **same glide** on all modes (preserves
inharmonic ratios), trim per-drum gain ~8%. Snare 38/40:
`[(186,0.8,0.10,4),(280,0.35,0.08,2),(330,0.30,0.07,2),(430,0.18,0.05,2)]` with a
small shared down-glide.

**D3 — Kick beater point** (DRM-3). 35/36 second noise band
`(0.3·vn², 0.005, bandpass(3500,0.9))` — a real ~3.5 kHz "point" (bandpass, not a
second flat highpass correlated with band 1). Optional knuckle tone `(130,0.4·vn,0.01)`.

**D4 — Crash bloom + coloured/beating wash** (CYM-2, CYM-1). Extend `NoiseBand` with
`onset:u32, env:f32, atk:f32, floor:f32`; effective gain `= amp·(floor+(1−floor)·env)`,
`env` ramps 0→1 via `atk`, `amp` still decays. Crash shimmer bands: `floor≈0.5,
atk≈40–60 ms` → instant chick + swelling wash (no reverse-cymbal onset). Hats/rides:
`floor=1.0` (unaffected). **Wash coloration** (CYM-1): the highpass **plus** closely
spaced high-Q bandpass pairs (6000&6055, 8300&8380 Hz, Q≈60–100) fed the shared
`white` → overlapping ringdowns beat (~55–80 Hz shimmer). Closed hat keeps a plain
Q~6–12 bank.

**D5 — Snare wire engage** (DRM-5). `NoiseBand.onset` (delayed start): shell slap
(immediate, bandpass 1300) + wire sizzle (highpass 2800) + darker rattle tail
(highpass 1800, t60 0.35); the two wire bands `onset ≈ 1.5 ms`, life 0.5→0.6.
Exact-zero pre-onset amp + `>1e-5` guard → denormal-safe, click-free.

**D6 — Hat choke group** (CYM-4). `fn choke(&mut self){}` default on `trait Voice`;
impl on `Drum`: shrink every tone/noise decay to a ~10 ms t60 floor and cap `life`
to `t + 30 ms` (never below `self.t`). In `engine.rs` ch9 NoteOn, before spawning:
`if matches!(key,42|44|46) { for a in active where a.ch==9 && matches!(a.key,42|44|46)
{ a.voice.choke() } }`. No new field — `Active` already carries `key`.

**D7 — Cymbal voicing fixes** (CYM-3, CYM-5, CYM-6, CYM-7). Refactor `cymbal()`'s
~11 positional args into a small **`CymSpec` struct** (real simplification, not
another positional param) with added `click: Option<(amp,t60,hp)>` and `swell: bool`.
- Closed/pedal hat 42/44: `click Some((0.9,0.005,9000))` scaled by `velnorm` (CYM-3).
- Ride 51/59: `d()`-built — widened tone-t60 spread + a **guarded** ping band
  `(0.55·(0.4+0.6vn), 0.07, highpass 7500)` distinct from a quiet sustaining wash
  (CYM-5); ping self-terminates (RMS ≈ 0 after 0.3 s).
- Ride bell 53: dense `METAL_RATIOS` stack on base 1650 + sharp stick click
  (highpass 7000, 6 ms) + light wash — not two pure sines (CYM-6).
- China 52: dedicated trashy cymbal (base ~1400, compressed t60, aggressive bright
  noise, life ~1.0 s). Splash 55: split from crash 49 (base ~1600, t60 ~0.4/0.2,
  life ~0.6 s) (CYM-7).

**D8 — Strike-position dither** (DRM-6). In `Drum::new` draw one shared
`edge = rng.white()`; tilt partial amps anti-correlated (`tilt = 0.20·edge·(2·modal−1)`)
+ independent `0.12·rng.white()` per partial; noise bands `×(1+0.15·edge+0.10·rng.white())`,
all `.max(0.0)`. Hit-to-hit variation within bounds (no fundamental-starved outlier).

### 3.4 Kit imaging — the shared blind spot (all three drafts missed)

Even with every voice upgraded, the kit still images as a **mono point source**:
ch 9 sums into a single per-channel pan (default centre), and today drums have no
per-piece placement. A real recorded kit is spread — hats/ride to one side, toms
sweeping across, kick/snare centre, overheads/room wide. Mono placement is itself a
strong "programmed, not recorded" tell.

**D9 — Per-piece drum pan** (new). A tiny static `drum_pan(key) -> f32` table
(−1..+1, drummer's perspective): kick/snare ≈ 0; hats 42/44/46 ≈ −0.35; toms sweep
41→+0.1, 43/45→+0.25, 47/48→−0.15, 50→−0.35; ride 51/59 ≈ +0.4; crash 49 ≈ −0.5,
57 ≈ +0.5. Applied as a per-*voice* pan offset added to the ch-9 strip pan when a
drum voice renders — i.e. `Active` carries an optional `pan_off`, and the mix step
uses `(strip.pan + pan_off).clamp(0,1)` for ch 9. Keeps the existing equal-power
`theta` law and Haas untouched.

**D10 — Drum room bus** (DRM-7). `drum_room = Reverb::new(sr, 0.55, 0.55, wet*0.9)`
(comb fb 0.55 → <0.3 s decay). `send_room` accumulates **only** ch 9,
**un-highpassed** (kick keeps body) at fixed `ROOM_SEND≈0.35` (CC91-independent),
processed into `mix_*` **before** the hall. `Reverb` is already stereo, so the room
returns a decorrelated L/R image (verified by oracle 32b).

### 3.5 Shared KS core (guitar + bass)

**K1 — Cubic-Lagrange tap** (KS-5). Add `DelayLine::tap_cubic` (4-point, weights
sum to 1, FIR → no feedback instability, `.max(2.0)`). Use it **only in
`KsLoop::tick`**; leave the linear `tap` for chorus/echo/reverb/pickup/haas so no
bus output shifts.

**K2 — Triangle initial condition** (KS-1). Build `exc` as a normalised triangle
(ramp 0→1 over `[0,comb]`, 1→0 over `[comb,len]`), subtract mean (DC block), add
~0.12·noise through `pick_lp` for grit, keep `v/peak` scaling, then **RMS-match**
(target peak ~0.75×) so the higher-RMS triangle doesn't raise per-note loudness.

**K3 — Polarization coupling** (KS-4). Add `h_prev/v_prev` to `Pluck`;
skew-symmetric coupling `k=0.003`: `hc = horiz.tick(inject + k·v_prev)`,
`vc = vert.tick(0.7·inject − k·h_prev)` (note the minus). Matrix `[[0,k],[−k,0]]`
is skew-symmetric → pure-imaginary eigenvalues → energy sloshes, none created →
unconditionally stable even at long t60.

**K4 — Dispersion / inharmonicity** (KS-3, GTR-5#2) — two stages, cheap first:
- *Stage 1 (primary, near-zero risk):* register-split **wound-ness** — derive a
  wound factor from key (crossover ~G3 for guitar; whole range for BASS/FRETLESS),
  scale `bright` and skew `t60` so wound bass strings differ from plain treble.
  Pure arithmetic, no allpass.
- *Stage 2 (optional polish):* one 1st-order allpass `A(z)=(a+z⁻¹)/(1+a·z⁻¹)` per
  `KsLoop`, **negative** `a∈[−0.25,−0.05]` (partials stretch sharp, correcting the
  existing flat skew), `|a|` larger for low/wound strings, fixed for the note's
  life; `retune` recomputes loop delay after subtracting the allpass phase delay at
  `f`. Denormal-flushed.

## 5. Acceptance criteria (definition of done)

Each is a `cargo test` that **fails on `main`, passes after** the cited change,
numerical/structural (no ears).

**Shared std-only oracle helpers** (a `#[cfg(test)]` module — from
testability-first; **self-calibrated first**, oracle 0):
- `band_rms(seg, sr, f, q)` — `seg` through `Biquad::bandpass`/`highpass`, return RMS.
- `centroid(seg, sr)` — Goertzel magnitude at ~20 log-spaced bins 100 Hz–12 kHz;
  `Σf·|X| / Σ|X|`.
- `mag_at(seg, sr, f)` — single-bin Goertzel (cabinet response).
- `pitch_hz(seg, sr)` — existing zero-crossing counter.
- `rms(a,b)`, `t60_of(env)` — windowed RMS and decay-time from the RMS envelope.
- `inter_corr(l, r)` — normalised L/R cross-correlation (stereo-width oracle).

0. **Helper calibration** (guards the guards): on synthetic golden signals —
   `mag_at` of a pure 1 kHz sine peaks at 1 kHz and is ≥20 dB down at 2 kHz;
   `centroid` of white noise > `centroid` of a 200 Hz sine; `t60_of` of a known
   exponential recovers its decay within ±10%. Prevents a wrong DFT helper from
   silently passing/failing the 36 feature oracles.
1. **Velocity brightness** (KS-2/GTR-1#2/BASS-2): STEEL & BASS `centroid(ff) > 1.4·centroid(pp)` (bass 1.3×) at the same key.
2. **Velocity tuning-invariance**: `pluck_pitch_a4`-style check at vel 30 **and** 120 (±6 Hz).
3. **Cabinet response** (GTR-1): impulse through `Drive` (prog 30) — `mag_at(2600)−mag_at(1000) ≥ +3 dB`; `mag_at(6000)−mag_at(3000) ≤ −18 dB`; `mag_at(100)−mag_at(300) ≥ +2 dB`.
4. **Tube asymmetry** (GTR-2#2): `Drive` output DC < 1e-3; 2nd-harmonic energy > symmetric-tanh baseline.
5. **Pre-voicing** (GTR-4): prog 30 has lower `band_rms(600)`:`band_rms(2k)` than prog 29.
6. **Clean cab** (GTR-6): CLEAN `mag_at(2500)` +≥2 dB and `mag_at(8k) ≤ −12 dB` vs the old one-pole.
7. **Pick click** (GTR-2): `onset_energy(first 3 ms,>1.5k) / rms(50–80 ms) > 2.0`; NYLON ratio < STEEL.
8. **Slap transient** (BASS-1): SLAP(36) first-3 ms >3 kHz ≫ BASS(33); fundamental at E1 ≈ 41 Hz (±2 Hz).
9. **Finger noise** (BASS-7): FRETLESS onset >2 kHz exceeds a no-noise baseline, decays within ~8 ms.
10. **Stop thump** (BASS-6): after `note_off`, `band_rms(<300)` bump appears; natural-end run shows none.
11. **Sub shaper** (BASS-5): BASS sub tail contains 2f energy; DC ≈ 0; two same-seed renders differ in sub phase.
12. **Pick vs finger vs upright** (BASS-3): `centroid(PICK) > centroid(BASS)`; UPRIGHT shows `mag_at(110)` peak + shorter t60.
13. **Synth-bass class** (BASS-4): held SynthBass(38) RMS 0.2–0.8 s near-constant (ratio <1.3); filter env raises then lowers centroid; no 65 Hz body peak.
14. **Inharmonicity** (KS-3/GTR-5#2, Stage 2): low-E partial *n* sharp of *n·f* (n≥4) while fundamental in tune (±6 Hz).
15. **Coupling stability + life** (KS-4): coupled STEEL over 10 s finite, peak <1.5; envelope non-monotonic (secondary rise).
16. **Lagrange tap** (KS-5): high banjo treble `band_rms(>5k)` retention >15% over linear; `pluck_pitch_a4` + `pluck_bend_two_semitones` still pass.
17. **Triangle level** (KS-1): per-note RMS within ±1.5 dB of the pre-change baseline; harmonic rolloff ≈1/n²; first 64 samples byte-identical across same-seed renders.
18. **Release darkening** (GTR-7): `centroid(release 100–200 ms) < centroid(sustain)` by ≥20% for CLEAN; amplitude still decays.
19. **Guitar sympathetic** (GTR-3/KS-6): open-E chord with vs without the bus — sustained-tail (300–800 ms) RMS higher + beating envelope; bus silent for prog 30.
20. **Toms modal** (DRM-1): ≥3 partials near 1:1.59:2.14; peak within ±1 dB of baseline.
21. **Snare modes** (DRM-4): ≥4 head partials present.
22. **Kick beater** (DRM-3): first-2 ms >3.5 kHz scales with vel²; body sub present.
23. **Crash bloom** (CYM-2): argmax of the smoothed HF (>6 kHz) envelope > 20 ms; a stick chick exists at t=0; hats (floor=1) unchanged.
24. **Wash beating** (CYM-1): crash-wash AM component detectable at the designed 40–100 Hz beat rate (autocorrelation peak); flatness < threshold.
25. **Hat tick** (CYM-3): closed hat first-2 ms >9 kHz high, scales with velocity. *(Also gates the §6 sample escalation via the kick variant.)*
26. **Hat choke** (CYM-4): open-hat(46) then closed(42) at +20–100 ms → open-hat RMS < 5% within 30 ms of the choke.
27. **Ride ping** (CYM-5): a short (t60~0.07) >7.5 kHz transient over a longer wash; ping RMS ≈ 0 after 0.3 s.
28. **Ride bell** (CYM-6): key 53 ≥5 inharmonic partials + >7 kHz stick click.
29. **China/splash** (CYM-7): china(52) life <1.2 s; splash(55) life <0.7 s; crash(49) >3 s.
30. **Drum velocity timbre** (DRM-2): hard hit higher start-pitch, larger click ratio, longer decay than soft.
31. **Strike variation** (DRM-6): across repeated identical-key hits, variance of fundamental:overtone ratio > 0 and bounded.
32a. **Drum room** (DRM-7): a kick render shows early-reflection energy in 8–35 ms a dry render lacks; non-ch9 gets no room send.
32b. **Kit stereo width** (D9/D10, the blind-spot oracle): a hats+ride pattern renders with `inter_corr(L,R) < 0.9` and an L/R energy imbalance, vs ≈1.0 (mono) today; kick/snare stay centred.
33. **Snare wire engage** (DRM-5): wire-band energy ≈ 0 at t=0, rises after ~1.5 ms; shell slap present at t=0.
34. **Mix-balance guard** (cross-cutting): a fixed multi-family reference song's per-channel RMS within ±2.5 dB of a committed golden baseline; pre-normalise master peak within tolerance.
35. **Determinism**: two same-seed renders bit-identical.
36. **GM routing** (blind-spot oracle): a synthetic MIDI stream with real GM program-change bytes (24/25/28/29/31/32/34/36/38) spawns the intended voice/preset for each — proves `midi.rs`' raw-prog routing (0xC0, no −1) reaches SLAP/PICK/UPRIGHT/HARMONIC/SynthBass and that Drive is created only for 29/30.
37. **Regression**: `pluck_pitch_a4`, `pluck_bend_two_semitones`, `pluck_hammer_on_retunes`, `muted_dies_fast`, `bowed_scoop_settles`, `voices_decay_and_die`, `la_pitch_a4`, `la_level_continuity`, `glue_compresses_and_stays_sane` all still pass.
38. **Compute budget** (blind-spot oracle): rendering a fixed reference MIDI completes within a generous wall-clock ceiling (e.g. ≤ 3× a captured baseline) — a soft perf trip-wire so the cab cascade, resonator banks and two new buses don't silently blow up offline render time.

## 6. Residual risks & mitigations

| Risk | Where | Mitigation |
|---|---|---|
| KS instability at E1 (41 Hz), long t60 | K3/K4, BASS/DRIVE | `loop_gain = 10^(−3/(t60·f)) < 1`; skew-symmetric coupling adds no energy; allpass unity-magnitude. Oracle 15 asserts bounded 10 s peak. |
| tanh aliasing / fizz | G1 | Cascaded steep cab LP *is* the decimation filter → fizz killed at 2×. Escalate to 4× only if a spectral test finds inharmonic partials <16 kHz (GTR-3#2). |
| Retune clicks / denormals on new IIR loops | G5, K4 | State-preserving retunes; symp combs + allpass flush `<1e-20`; release-darken glides at control rate. |
| Triangle re-levelling | K2 | RMS-match to ~0.75× peak; oracle 17 bounds per-note RMS ±1.5 dB. |
| Mix balance / normalizer shift | all | Per-family gain trims (`Drive.post`, drum table gains, preset `amp`); oracle 34 golden-RMS guard is the trip-wire. |
| Mono-summed room collapses kit width | D10 | `Reverb` is already stereo (per-side early taps + `combs_l/r`); per-piece pan (D9) gives dry width; oracle 32b pins `inter_corr < 0.9`. |
| Compute cost of cab + banks + 2 buses | all | Offline render — not fatal; oracle 38 caps render time; cab runs only on 1–2 ch29/30 strips, symp/room are single shared buses. |
| Micro-timing left mono/quantised | §1.4 deferred | Flagged for the review loop. If ruled in: a deterministic ≤±3 ms per-note onset jitter + velocity-groove in `engine.rs`, seeded, with an oracle asserting non-uniform onset offsets. Held out of V1 because it is arguably a composition-side concern and touches event scheduling, not voicing. |
| Feedback bloom genuinely unstable | GTR-7#2 (deferred) | Not built. Impact 2 doesn't justify the risk now. |
| Sample-transient continuity/pitch | optional layer (deferred) | Use samples **only for unpitched drum one-shots** (no crossfade, no repitch → the two hardest LA risks vanish). ≤ 2 MB, behind `samples`, fired only if oracle 25's kick threshold can't be met synthetically. |
| New `SynthBass` surface | B4 | `cut ∈ [80, sr·0.4]`, q ≤ 6, no tanh; own gain calibration + oracles 13/34. |
| Choke plumbing through boxed `Voice` | D6 | Default no-op trait method; 10 ms fade floor, never truncate `life` below `self.t`. |

## 7. Phasing (each lands as a passing unit)

Ordered by **impact ÷ risk**; every phase independently shippable, gated by its oracles.

- **Phase 0 — Guards + helpers first.** Shared oracle helpers + calibration (oracle 0);
  golden mix-balance (34), determinism (35), GM routing (36), compute budget (38)
  against current `main`. Every later phase is measured against these fixed baselines.
- **Phase 1 — The velocity law (A).** G3/B1 (Pluck) + D1 (Drum). Oracles 1,2,30. Best ratio; ~a dozen lines.
- **Phase 2 — Drum table richness.** D2,D3,D8 + D7 ride-bell/china/splash. Oracles 20,21,22,28,29,31. Table/routing edits, near-zero risk.
- **Phase 3 — The Cabinet (C).** G1 then G2. Oracles 3,4,5,6. Biggest single realism gap (GTR-1); closes GTR-3#2 free.
- **Phase 4 — `Burst` + parallel transients (B).** `dsp.rs::Burst`; G4 pick/chuff, B2 slap/finger, B3 stop-thump; D4/D5 `NoiseBand` swell+onset, CYM-1 wash, CYM-3 tick, CYM-5 ping. Oracles 7–10,23,24,25,27,33.
- **Phase 5 — Ambience, imaging & synth bass (E/F).** D6 choke, D9 per-piece pan, D10 drum room, G5 guitar sympathetic, B4 `SynthBass`, B5 sub shaper. Oracles 11,13,19,26,32a,32b.
- **Phase 6 — KS physics core (D).** K1 `tap_cubic` → K2 triangle IC (re-level) → K3 coupling → G6 release darken → K4 Stage 1, then optionally Stage 2 allpass. Oracles 12,14,15,16,17,18. Riskiest → last, each behind its oracle.
- **Deferred / optional.** GTR-7#2 bloom, GTR-3#2 4× oversampling, G7 prog-31 node excitation refinement, micro-timing humanisation, and the ≤ 2 MB embedded drum one-shot layer — only if a measured gap justifies the added surface.

Re-run oracles 34–38 after every phase; a golden-RMS drift beyond ±2.5 dB or a
stereo-width/compute regression blocks the merge until re-trimmed.
