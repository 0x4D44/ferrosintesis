# 2026.07.07 — CR — HLD v0.7 reconciliation review (hollowsynth realism)

Evidence base for the HLD's **V4 revision** (`wrk_docs/2026.07.03 - HLD -
hollowsynth realism guitar-bass-drums.md`, §12). The signed-off design targeted
hollowsynth **v0.5**; `main` had moved to **v0.7** (v0.6: CC1 Leslie/vibrato, CC74
filter, CC64 sustain, `--solo`; v0.7: CC70 vowel morph, RPN 0/1, CC5/65 portamento,
CC71 resonance, channel aftertouch, CC66/67 pedals). Two decorrelated review tracks
ran on 2026-07-07 under Arthur's build instruction:

1. **Cross-family external review** — OpenAI Codex (gpt-5.5, reasoning xhigh,
   read-only sandbox) over the HLD + full v0.7 source. This closes the V3 sign-off
   caveat that the original "external" review was a same-family stand-in.
2. **Five-lens adversarial workflow** (Claude Fable 5) — lenses: code drift,
   v0.6/v0.7 feature interactions, DSP/math correctness, oracle implementability,
   repo doctrine. Every lens's findings were re-verified by two independent
   skeptics against the source; disagreements adjudicated at synthesis. (The first
   run died at 9/14 agents on a session limit; the completed results were salvaged
   from the journal and the run resumed from cache — findings below are the
   completed, fully-verified set.)

**Converged result: 2 critical, 24 major, 12 minor** — all resolved as document
edits in V4; no architectural change. Both tracks independently converged on the
same worst finding (the D9 ch-9 strip bypass), which is the point of running
decorrelated reviews.

Baseline verified green before review: 29/29 tests on v0.7.0 `main`.
