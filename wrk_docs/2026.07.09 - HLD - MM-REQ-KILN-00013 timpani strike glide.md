# MM-REQ-KILN-00013 - Timpani Strike Glide

- **Status:** DRAFT
- **Requirement:** `MM-REQ-KILN-00013`
- **Date:** 2026-07-09

## Confirmed Intent

Make GM 47 timpani sound like a struck kettle drum: a sharp attack that settles down in pitch, brightens with velocity, varies per strike, and keeps ringing after short note-offs.

## Scope

- Update only the hollowsynth GM 47 pitched timpani path.
- Add the named oracle `timpani_47_glides_brightens_and_rings_after_noteoff`.
- Update hollowsynth docs and version once with the implementation.
- Validate affected GM 47 albums and render containment.

## Out Of Scope

- Drum-channel toms and percussion key 47.
- Album composition changes.
- A broad rewrite of `Modal` or a new percussion engine.
- `MM-REQ-KILN-00008` and all other heavy reqs.

## Approach

Keep timpani on the existing `Modal` voice. It already has the right modal-decay shape, deterministic phase seeding, pitch-bend support, and lifecycle handling. Add a small optional modal pitch-settle hook that is disabled for every other modal instrument.

1. Extend `Modal` with an optional one-shot strike glide:
   - current multiplier starts above 1.0;
   - per-sample multiplier moves it down toward a floor of 1.0;
   - `with_strike_glide()` must immediately retune existing oscillators to the sharp start frequency;
   - `render()` must continue retuning while the strike glide is active, because unbent notes never call `set_pitch()`;
   - `apply_pitch()` uses `base_freq * bend * strike_glide`, so authored bend/RPN/aftertouch/portamento still works;
   - repeated `set_pitch()` calls must not reset the one-shot strike glide or double-apply it.
2. Add a `with_strike_glide(start_ratio, glide_oct_per_s, floor_ratio)` builder on `Modal`, used only by `timpani()`.
3. Revoice `timpani()` narrowly:
   - start about 2.0-2.2 semitones sharp and settle to written pitch within the first 140-170 ms;
   - add deterministic per-strike upper-mode amplitude jitter from a derived RNG seed, so the shared `Modal` phase/noise stream is not perturbed;
   - do not jitter the fundamental frequency, and bound any upper-mode frequency jitter to <= 0.5% so pitch stays musical;
   - scale upper mode amplitudes upward with velocity while preserving monotonic louder-is-louder behavior and roughly the current amplitude law;
   - lengthen the note-off release envelope enough that short notes ring. Target roughly 3.5-4.5 s for the extra release envelope, because it multiplies the already-decaying mode amplitudes; the modal partial T60s still control the audible drum decay.
4. Keep the mode table compact and bounded:
   - no extra oscillator family;
   - no random source beyond the existing per-voice seed;
   - no change to drum-channel membrane voices.
5. Clamp the strike-glide multiplier at exactly 1.0 when it reaches the floor, so settled pitch is `base_freq * bend` and `render()` can stop retuning once the one-shot glide is done.

This deliberately changes default GM 47 rendering. Source search found pitched GM 47 users in `fable5/Hollow Hill`, `fable5/The Burning Meridian`, and `fable5/The Ninth Bell`; implementation must re-check this list from current source before validation. Hollow Hill reuses the same channel as timpani -> mandolin -> timpani, so validation must include that program-change boundary.

## Acceptance Criteria

- `cargo test timpani_47_glides_brightens_and_rings_after_noteoff --manifest-path fable5/hollowsynth/Cargo.toml` proves:
  - render through `make(47, ...)`, not direct helper construction, and prove a timpani-specific signature; `kind() == "modal"` alone is insufficient because many programs are modal;
  - use keys 40 (E2) and 45 (A2), velocity 96, same seed, and fixed windows:
    - early pitch window: 25-70 ms, after the lowpass thump has mostly cleared the fundamental search band;
    - late pitch window: 180-320 ms;
    - body brightness window: 80-260 ms;
    - release-tail window: 300-650 ms after a 120 ms staccato gate;
  - use `peak_locate` only in a narrow fundamental search band `[0.95 * f0, 1.15 * f0]`, so upper modes cannot be mistaken for pitch;
  - early fundamental peak is at least 5% higher than late peak, while late peak is within 3% of written pitch;
  - hard velocity (120) has at least 1.3x the upper-mode/fundamental ratio of soft velocity (40) in the body window, where upper modes are measured by phase-invariant Goertzel magnitudes at `1.504*f0`, `1.742*f0`, and `2.0*f0`;
  - hard velocity body RMS is at least 4.0x soft velocity body RMS, and hard velocity peak stays below 8.0x soft velocity peak to catch loudness regressions and runaway attacks without compressing the existing velocity law;
  - two different seeds produce at least 8% difference in phase-invariant upper-mode balance while both keep the late fundamental within the written-pitch tolerance;
  - a note-off after a 120 ms staccato gate keeps a ringing tail: same-seed released tail RMS in 300-650 ms remains at least 65% of a held note's matched tail RMS and stays above `1e-4`;
  - repeated `set_pitch()` calls during the first 120 ms preserve the downward strike-settle shape and settle to the requested bent pitch, without resetting or multiplying the glide; if the private glide state remains accessible to the test module, assert directly that it clamps at 1.0 after settlement.
- Existing relevant guards still pass:
  - `gm_routing_pins_voice_kinds`;
  - `golden_mix_balance_holds`; first verify by inspection that the reference fixture still contains no pitched GM 47. Any fixture recapture after a GM47-only change is suspicious and must be explained as a shared-path bug fix, not as expected GM47 drift;
  - full hollowsynth `cargo test`.
- Add a small non-timpani modal canary test or equivalent assertions inside the named oracle:
  - piano 0, vibes 11, tubular bells 14, crystal 98, and kalimba 108 do not show the timpani strike-glide signature in the same early/late pitch windows where a stable fundamental exists. Full byte-identity for non-timpani modal programs is handled by baseline/new render validation;
  - the current implementation must be observed red before the fix. Expected red clauses: no early-to-late downward pitch settle, no phase-invariant seed balance variation, and staccato note-off tail too low against the held comparison.
- Baseline/new render validation:
  - render at least one non-GM47 full album and prove byte-identical output by binary hash/length;
  - render focused non-timpani modal stems or fixtures covering piano/bells/vibes/crystal/kalimba and prove byte-identical output;
  - render affected GM 47 solo stems for each affected album and record intentional change;
  - render a non-GM47 solo stem from each affected album and prove byte-identical output. Use solo stems for this containment proof because bus glue and shared effects can make a full affected mix differ outside the timpani channel by design;
  - for Hollow Hill, specifically inspect/render around the timpani -> mandolin -> timpani program-change boundaries on channel 15 to ensure the longer release does not create unintended mandolin-section tail bleed.
- Affected album source oracles are re-run where present:
  - `fable5/Hollow Hill`: `python build.py --verify`;
  - `fable5/The Burning Meridian`: `python build.py --verify`;
  - `fable5/The Ninth Bell`: `python build.py --verify`.
- Affected album render/audio checks:
  - `fable5/The Ninth Bell`: render the track and run `python analyze.py "audio/01 - The Ninth Bell.wav"` or the same analyzer against a temporary WAV path if supported; the scored silence tail checks must remain green;
  - `fable5/The Burning Meridian`: render at least one dense roll stem from channel 12 and record peak/headroom remains bounded;
  - `fable5/Hollow Hill`: render channel 15 around the part-one program-change boundary and record no unexpected tail bleed into the mandolin section.
- Final hollowsynth validation passes:
  - `cargo fmt --check`;

## Decision Log

- Reuse `Modal`: the missing behavior is strike dynamics around an already-modal voice, not a separate synthesis family.
- Optional modal hook, not global behavior: piano/bells/kalimba keep their existing pitch unless explicitly configured.
- Default-on GM 47 change: the requirement is about ordinary GM 47 timpani, and existing album users should benefit after sign-off.
- Render containment is mandatory because GM 47 is already authored in committed albums.
- Fundamental pitch jitter is rejected for pitched GM 47. Seed variation belongs in upper-mode amplitude/balance and phase, not in the written kettle pitch.
- The longer release envelope is intentionally near-open relative to the modal head ring. The actual audible tail still decays through the modal partial T60s; the envelope just avoids note-off choking it.

## Adversarial Review

Three internal reviewers inspected the draft HLD.

Surviving findings after refutation:

- The first draft under-specified the `Modal` lifecycle. `Modal::new()` creates oscillators at base frequency and `render()` does not retune today, so an optional strike glide must retune immediately and continue retuning while active.
- Pitch jitter was unbounded and copied too much from drum-channel prior art. Pitched GM 47 should keep the fundamental stable; any upper-mode frequency jitter must be tiny and bounded.
- The oracle was too loose. It now names keys, windows, search bands, phase-invariant upper-mode measurements, segmented note-off rendering, red-first expectations, and `set_pitch()` interaction.
- Routing cannot be proven by `kind() == "modal"` because many programs report that kind. The oracle must render through `make(47, ...)` and prove timpani-specific behavior.
- The velocity-brightness check also needs loudness and peak containment so timbre improvement does not mask a broken velocity law.
- The golden fixture has no pitched GM 47 program. A GM47-only change should leave it unchanged; fixture recapture is not expected.
- A shared `Modal` hook needs non-timpani modal canaries, not only one no-GM47 album render.
- Affected-album validation must cover all known pitched GM47 albums, The Ninth Bell render-side silence analyzer, Burning Meridian dense rolls/headroom, and Hollow Hill's timpani/mandolin channel reuse boundary.

## External Review

Claude Opus reviewed the folded HLD once in read-only plan mode.

Accepted items:

- The release-tail criterion and original 1.5-2.0 s target were numerically inconsistent. The design now targets a roughly 3.5-4.5 s extra release envelope while relying on modal partial decay for the audible tail.
- The original hard/soft peak cap accidentally required compressing the existing velocity law. The criteria now preserve a large monotonic loudness rise while bounding runaway peaks.
- The early pitch window could be confounded by the lowpass thump. It now starts at 25 ms.
- The glide parameters are now pinned tighter: 2.0-2.2 semitone start and 140-170 ms settle.
- Upper-mode jitter uses a derived RNG seed, and strike glide clamps exactly at 1.0 after settlement.
- Render containment is explicitly solo-stem based for affected albums because full-mix glue/effects can spread an intended timpani change.
- The golden-fixture claim must be verified by inspection before relying on it.

Rejected items:

- A mandatory direct private-state assertion on the glide multiplier is not required if rendered pitch proves the same behavior; the HLD keeps it as an optional stronger assertion when the test module can read the state cleanly.

## Residual Risks

- `peak_locate` can be fooled by inharmonic upper modes if the test window or search range is too wide. The oracle must search a narrow fundamental range and use late-settled windows.
- Default-on re-rendering changes existing timpani album moments by design. Sign-off covers that freeze break; validation proves the change stays confined to GM 47.
