# MM-REQ-KILN-00014 - Free Reed Organ Family

- **Status:** SIGNED-OFF (2026-07-09; auto-approved objective)
- **Requirement:** `MM-REQ-KILN-00014`
- **Date:** 2026-07-09

## Confirmed Intent

Make GM 20-23 render as free-reed instruments, not generic pipe/Hammond organs: reed organ/harmonium breathes, accordions have musette/bellows character, harmonica has breath/noise and a small onset scoop, and GM22 uses CC1 pitch vibrato instead of organ Leslie.

## Scope

- Update hollowsynth default-bank programs 20, 21, 22, and 23.
- Keep programs 16-19 as the existing organ family with Leslie semantics.
- Add a focused oracle named `reed_organ_accordion_harmonica_have_free_reed_character`.
- Update docs, version, and the req ledger after implementation.
- Validate Winter Guests because it uses GM20 harmonium.
- Validate RIVERWAKE because it uses GM21 accordion.

## Out Of Scope

- New sample assets.
- Reworking the reed engine for woodwinds 64-71.
- Changing album source or MIDI composition.
- Modifying alt-bank behavior.
- Fixing the pre-existing `altbank::tests::sawstack_v1_canary_frozen` trunk failure tracked in `scratchpad.md`.

## Approach

Reuse the existing `Organ` voice as the free-reed base instead of adding another oscillator family. It already supports sustained harmonic ranks, ADSR, tremulant control, pitch retune for bend/portamento/aftertouch, and deterministic pipe/rank scatter. Extend it only where free reeds differ.

1. Add narrow free-reed controls to `Organ`:
   - configurable key-click level, so GM20-23 can drop the Hammond click while programs 16-19 keep it;
   - sustained bellows/breath noise with its own filter and level, following the note envelope instead of decaying like chiff;
   - optional one-shot pitch scoop for harmonica, implemented like a small render-time multiplier composed with `bend`;
   - rank tables with close detuned unisons for 21/23 musette and cleaner paired ranks for 20/22.
2. Keep the normal organ programs unchanged:
   - programs 16/17/18/19 keep their current stops, click, chiff, drive, and Leslie behavior;
   - only 20-23 use the free-reed specs.
3. Engine CC1 routing:
   - introduce `organ_leslie_family(program)` or equivalent and make it **only** `16..=19`;
   - programs 20, 21, and 23 keep built-in free-reed tremolo/musette and do not respond to CC1 as Leslie;
   - default-bank GM22 is excluded from Leslie and takes authored CC1 through the existing pitch-vibrato `set_pitch()` path;
   - route GM22 CC1 by spawn-time/default-bank voice state, not program number alone, so alt-bank voices are not accidentally retuned;
   - reset/program-change logic must restore base tremulants only for true Leslie organs and must not leave stale Leslie state when changing `19 -> 22` or `22 -> 19`.
4. Keep the change default-on because the req is about ordinary GM programs. Existing committed GM20 usage is validated by rendering; no feature flag.

## Acceptance Criteria

- `$null | deltic timeout 240 cargo test reed_organ_accordion_harmonica_have_free_reed_character --manifest-path fable5/hollowsynth/Cargo.toml -- --nocapture` proves:
  - programs 20, 21, 22, and 23 render through `make()`;
  - GM16-19 direct voice renders are byte-identical before/after the free-reed change in a committed test fixture or temporary baseline render, proving the shared `Organ` defaults did not drift;
  - onset click uses fixed windows and normalized high-band energy:
    - click window: 0-8 ms;
    - body normalization window: 80-220 ms;
    - high band: >= 2.5 kHz via existing magnitude/band helpers;
    - GM20-23 high-band click/body ratio is at most 35% of GM19's ratio, while GM19 remains above a fixed floor so the comparison is meaningful;
  - GM20 bellows/noise floor:
    - stable-pitch window: 260-600 ms, `peak_locate` within `[0.97*f0, 1.03*f0]`;
    - residual-noise proxy: off-harmonic energy in bands halfway between harmonics 1-4, normalized by fundamental;
    - GM20 residual is at least 1.5x GM19 while late pitch stays within 2% of written pitch;
  - GM21 and GM23 musette:
    - render the same key/velocity/seed as GM20;
    - 200-900 ms envelope has a measurable low-rate AM component in the 3-8 Hz band at least 2x GM20's component;
    - body RMS stays within 0.6x-1.8x GM20 and peak stays below 2.5x GM20, so musette does not become a loudness-only pass;
  - GM22 harmonica:
    - early pitch window 15-55 ms starts at least 1.5% below late pitch, and late window 160-360 ms is within 2% of written pitch;
    - late residual breath/noise proxy is at least 1.3x GM20, measured in off-harmonic high bands and normalized by fundamental;
    - GM22 with bend + authored CC1 still composes as `written pitch * bend * vibrato * scoop`, where the scoop settles and does not reset on repeated `set_pitch()`.
- `$null | deltic timeout 240 cargo test gm22_cc1_is_harmonica_vibrato_not_leslie --manifest-path fable5/hollowsynth/Cargo.toml -- --nocapture` or an equivalent engine subtest proves:

  - GM22 authored CC1 produces pitch variation at least 2x the no-CC1 render in the late settled window, using `peak_locate`/short-window pitch samples;

  - GM20, GM21, and GM23 authored CC1 do not enter the Leslie ramp path;
  - program-change/reset edge cases are covered: CC1 before program change, `19 -> 22`, `22 -> 19`, GM reset, and a held GM22 note with active CC1;
  - alt-bank program 22, if reachable, is unchanged by default-bank harmonica CC1 routing, or the engine branch explicitly checks `!a.alt` for per-voice routing.
- Existing relevant guards still pass:
  - `cc1_leslie_spins_up_with_inertia` for GM19;
  - `modal_organ_pitch_controls_move_sustained_notes`;

## Decision Log

- Reuse `Organ` rather than adding `FreeReed`: the needed behavior is rank/noise/onset variation around the same sustained harmonic body and pitch-control lifecycle.
- Keep `kind() == "organ"` unless implementation pressure proves otherwise; program identity and audio oracles matter more than a new test-only label.
- Leslie routing is limited to GM16-19. GM20/21/23 have their own built-in free-reed motion and ignore CC1; default-bank GM22 gets engine-level pitch vibrato because harmonica players use pitch vibrato. A Hammond-style Leslie ramp is wrong for all four free-reed programs.
- Winter Guests gets render validation because it already uses GM20 harmonium, so this is an intentional re-render.
- RIVERWAKE gets targeted render validation because source inspection found committed GM21 accordion usage.

## Adversarial Review

Three independent reviewers inspected the draft HLD.

Surviving findings after cross-check:

- The first draft left GM21/GM23 CC1 routing undecided. The design now explicitly keeps Leslie semantics on GM16-19 only; GM20/21/23 do not use CC1 as Leslie, and default-bank GM22 uses pitch vibrato.
- The first draft used qualitative oracle language. The acceptance criteria now specify windows, bands, ratios, pitch tolerances, and RMS/peak containment.
- Shared `Organ` changes need direct GM16-19 regression proof. The design now requires byte-identical direct renders or an equivalent baseline fixture for GM16-19.
- GM22 CC1 routing has stateful edge cases. The design now requires program-change, reset, held-note, bend+scoop, and alt-bank/default-bank guards.
- Render containment alone is insufficient for Winter Guests. The design now requires a full Part One before/after render with analyzer pass and bounded peak/RMS deltas, plus targeted stem identity checks.

Rejected or bounded findings:

- A separate `FreeReed` type is not required up front. If `Organ` extension becomes awkward during implementation, a small wrapper remains acceptable, but the current plan keeps fewer moving parts and preserves existing pitch/control lifecycle.

## External Review

Claude Opus reviewed the folded HLD once in read-only plan mode.

Accepted items:

- The design missed RIVERWAKE's committed GM21 accordion use. Added targeted RIVERWAKE GM21 changed-stem validation plus a non-GM21 identity stem.
- The musette and scoop oracles need to stay resistant to level/envelope false positives. The HLD now keeps numeric windows/ratios and requires scoop composition with bend/CC1 in one test, not separate isolated checks.

Rejected or scoped items:

- The alt-bank program-22 guard and CC1 state matrix should stay cheap unit-test coverage, not a broad render-validation burden, because no committed album depends on alt-bank 22. The HLD keeps them in the focused engine oracle.

## Residual Risks

- Spectral free-reed oracles can accidentally measure pitch or level. The test should fix pitch, use narrow bands/windows, and compare against nearby controls.
- Any default-on GM20 change affects Winter Guests. Validation can prove containment and analyzer health, not musical taste.
