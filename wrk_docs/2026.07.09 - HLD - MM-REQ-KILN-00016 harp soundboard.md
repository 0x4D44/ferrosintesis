# MM-REQ-KILN-00016 Harp Soundboard HLD

Status: SIGNED-OFF

## Intent

GM 46 harp should sound like strings coupled to a resonant harp body, not a boxless guitar-family pluck with a guitar-scale wound-string crossover.

## Scope

- Add a body/soundboard EQ table to the `HARP` Pluck preset.
- Exempt `HARP` from the guitar key-split wound-string darkening law.
- Keep all other Pluck presets on their existing wound behavior.
- Update ferrosintesis docs and version metadata for the shipped synth change.
- Validate committed MIDI that uses GM 46.

Out of scope:

- A new harp synthesis engine.
- Harp pedal/glissando mechanics.
- Rebalancing all Pluck family presets.

## Current Code Read

- `PluckPreset` has `body: &'static [(f32, f32, f32)]`; `HARP.body` is currently empty.
- `Pluck::new` builds body filters from the preset table and applies them after pickup/grit/onset summing.
- `wound_factor(p.wound_all, key)` has two modes today: basses are wound full-range; everyone else uses a guitar key split around G3.
- `HARP.wound_all` inherits `false`, so harp bass notes are darkened by the guitar split.
- GM 46 dispatches through `Pluck::new(&HARP, ...)`.
- Committed MIDI scan found GM 46 in:
  - `albums/fable5/Hollow Hill/midi/02 - Hollow Hill, Part Two.mid`
  - `albums/fable5/The Burning Meridian/midi/01 - The Muster.mid`
  - `albums/fable5/The Burning Meridian/midi/02 - Lanterns on the Water.mid`
  - `albums/fable5/The Burning Meridian/midi/03 - Meridian.mid`
  - `albums/fable5/The Ninth Bell/midi/01 - The Ninth Bell.mid`
  - `demos/synth_feature_showcase/midi/05 - Atlas of Unbuilt Machines.mid`

## Approach

- Add `wound_key_split: bool` to `PluckPreset`.
  - Default `true` preserves current behavior for all existing presets.
  - `HARP` sets it to `false`.
  - `wound_factor` becomes `wound_factor(wound_all, wound_key_split, key)`, returning `0.0` when key-split winding is disabled and `wound_all` is not set.
- Add a modest harp soundboard table to `HARP.body`: `(90 Hz, Q 0.8, +3.5 dB)`, `(180 Hz, Q 0.9, +2.8 dB)`, `(400 Hz, Q 1.1, +1.8 dB)`. These are deliberately broader and less guitar-like than NYLON's existing 98/210/420 Hz body.
- Add `harp_46_has_soundboard_and_harp_wound_law`:
  - Structural checks: `HARP.body` contains modes in the expected low/warmth ranges; `HARP.wound_key_split` is false; guitar/bass wound behavior remains as before.
  - Audio checks use bass-register keys 45 and 52, both below the guitar split. Shipped `HARP` must lift the 90/180/400 Hz bands versus a same-seed bodyless clone. A same-preset old-guitar-split clone must measure darker by centroid/HF ratio versus the new harp; do not assert low-band direction without measuring it.
- Keep the existing `wound_strings_darker` test as a guitar/bass canary.

## Decision Log

- Preset flag instead of hard-coding `HARP`: accepted because it keeps the rule testable and avoids pointer/name checks inside `Pluck::new`.
- Default `wound_key_split: true`: accepted because it preserves all non-harp Pluck behavior unless a preset explicitly opts out.
- Body EQ only: accepted because the req asks for soundboard resonance, not a new harp model.
- No harp click/onset change: accepted for scope. The req asks for body resonance and wound-law exemption, and adding a click would be a separate attack-character change.
- Rerender committed listening outputs in this req: accepted under Arthur's batch-integration approval because the change intentionally affects existing GM46 album audio.

## Adversarial Review

Reviewer A finding: Adding a third wound mode could accidentally brighten non-harp presets.

Refutation check: inspected all preset construction: every preset uses `..DEFAULTS`, so defaulting `wound_key_split` to `true` preserves current behavior. The finding survives as an implementation constraint: only `HARP` should set the flag to `false`, and the acceptance test must keep guitar/bass wound canaries.

Reviewer B finding: A body EQ test can accidentally measure the string fundamental instead of the soundboard modes.

Refutation check: the body modes include 90/180/400 Hz, so a single note near those frequencies could confound the measurement. The finding survives. Mitigation: measure band ratios on two keys and compare `HARP` against a bodyless clone with the same no-wound law.

Reviewer C finding: Render blast radius is larger than Hollow Hill.

Refutation check: structured MIDI scan found six GM 46 files. The finding survives. Validation must include at least Hollow Hill, The Burning Meridian, The Ninth Bell, and showcase track 5 structural/render sanity.

## Survivors Folded Into Design

- Keep the new wound opt-out default-preserving and prove guitar/bass behavior stays intact.
- Use differential body tests against a bodyless harp clone to avoid confusing string pitch for soundboard EQ.
- Validate all discovered GM 46 MIDI users, not only Hollow Hill.

## Residual Risks

- Exact harp body EQ values are perceptual. The planned broad modes should be conservative, but later listening may tune them.
- Existing committed album audio that uses GM 46 will change by design.
