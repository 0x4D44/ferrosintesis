# HLD — hollowsynth alt-bank (GM Bank-Select alternate orchestral voicings)

**Status:** DRAFT v3 (adversarial review folded; **D3 resolved to Option A — restore `set_vib`** per Arthur; awaiting sign-off)
**Date:** 2026.07.09
**Worktree:** `D:/worktrees/midi-music/20260709-DEV-HUM-hollowsynth-altbank` (off origin/main 41e49d2)
**Crate:** `fable5/hollowsynth` (currently 0.9.0)

## 1. Goal / scope

Offer hollowsynth's **v0.9 orchestral voicings** — the strings, choir and bowed designs
that trunk's reqs-loop independently superseded during the v0.9 reconciliation — as a
**selectable alternate bank**, so a composer can A/B them against the current defaults and
use them for tonal variety. The voicings are resurrected verbatim from `v09-backup-pre-rebase`
(da72e32).

Selection is **GM Bank Select (CC0)**: a channel that has sent `CC0 != 0` gets the alt
voicings on its next note spawns; the default bank (`CC0 == 0`, i.e. never sent) is
**unchanged and byte-identical**. Same opt-in-seam family as kit-v2 (ch10 PC) and CC73 —
verified safe because **0 of 53 committed MIDIs send CC0/CC32** (both reviewers confirmed;
Riverwake's `b4 00` is a Set-Tempo VLQ, not a controller).

### In scope — the alt-remapped programs
`{40,41,42,43,44,45}` bowed, `{48,49,50,51}` strings, `{52,53,54}` choir. (13 programs. GM
46/47 — harp/timpani — and everything outside this set delegate to the default voice; the
label "40-54" is not literal.)

### Non-goals (explicit)
- **Program 55 (orchestra hit) is NOT banked.** Trunk's `orch_hit` is already byte-identical
  to da72e32's (verified — differs only in comments/`pub`), so an alt would equal the default:
  zero A/B value. 55 delegates to `voices::make`. (This also removes the only `Modal` cross-dep.)
- **No banking of 56-71 (brass/reeds), 80-87 (leads), 88-95 (pads), or anything else** —
  single implementation, nothing to A/B; those delegate to `voices::make`.
- **No CC32/LSB granularity, no multiple alt banks** — one alt bank keyed on `CC0 != 0`.
- **No .opus refresh, no album edits** — no committed album selects a bank.
- **No changes to the default voices or `voices::make`.** (Option A adds one defaulted
  `set_vib` trait method + a bank-gated engine branch — both inert on the default path.)

## 2. Success / acceptance criteria

- **AC1 — default byte-identity.** Every committed album (default bank) renders byte-identical
  to pre-change. Guaranteed *by construction*: `voices::make`, the spawn seed
  (`0x9E37 ^ voices_spawned*…`), and all shared state are untouched; `mod altbank` /
  `pub(crate)` widenings are inert. Asserted by a spawn-routing test (no CC0 → default voice)
  + the existing golden/canary suite staying green.
- **AC2 — bank gate is exact.** A channel that has sent `CC0 != 0` spawns the **alt** voice for
  the in-scope programs; `CC0 == 0` (or never sent) spawns the **default** voice. Engine test on
  the spawn path.
- **AC3 — faithful timbre.** The resurrected alt voices reproduce the v0.9 **self-contained
  character**, proven by porting da72e32's *self-contained* voice-level oracles (they render the
  voice directly, no engine, so they pass byte-for-byte against the vendored DSP):
  - strings — brightness rises with the note envelope (`st1_env_brightness_opens_the_tone`),
    synth-string identity (`st3_synth_strings_identity`), plus the `sawstack_v1_canary_frozen`
    fingerprint (its reference bytes carried across);
  - choir — consonant/breath onset + sectioned SATB scatter (`ch_o1`/`ch_o4`/`ch_o5`);
  - bowed — viola/cello/contrabass distinct body resonances (`bowed_bodies_differ`), pizz and
    tremolo behaviour.
  Under **Option A** (chosen), `set_vib` is restored, so the two da72e32 oracles that exercise it —
  `st2_section_vibrato_spreads_carrier` (strings) and `ch_o6_shimmer_blooms` (choir) — **port
  intact**, keeping full strings/choir vibrato coverage. The `sawstack_v1_canary_frozen` fingerprint
  is **re-pinned against the alt module** (not blindly carried), since it now shares trunk's DSP
  primitives (§8 Codex note).
- **AC4 — A/B is real.** For 42 (bowed cello), 48 (strings) and 52 (choir), the alt-bank render
  differs from the default-bank render by **band-energy ratio ≥ ~1.5 dB in the discriminating
  band** (concrete floors pinned from real renders at implementation; a positive lower bound,
  not `kind()` — strings/bowed share a family `kind()` string). 55 is *not* a target (it can't
  differ). Guards against accidentally wiring the alt bank to the default voice.
- **AC5 — latch + delegation + release.** `CC0 != 0` then `CC121` (reset-all-controllers) still
  spawns alt (bank is not a performance controller); `CC0 != 0` then `CC0 == 0` returns to the
  default voice (Codex §8); and an alt-bank channel playing a non-orchestral program (e.g. 0 piano)
  spawns the default voice (delegation path).
- **AC6 — gate green.** `cargo fmt --all --check`, `clippy --all-targets -- -D warnings`,
  `cargo test --release` all clean.

## 3. Approach

### 3.1 Engine seam (default path untouched; Option A adds a bank-gated CC1 branch)
- `Strip` gains `alt_bank: bool` (init `false`).
- `cc()` gains one arm: `0 => s.alt_bank = val != 0` (CC0 bank-MSB; non-zero = alt, program 0 =
  standard). Latched; **not** cleared by `reset_all_controllers` (GM-correct: RAC resets neither
  program nor bank).
- The NoteOn spawn (engine.rs:802, non-drum branch) picks the factory on the flag:
  ```rust
  let prog = self.strips[ci].program;
  Some(if self.strips[ci].alt_bank {
      altbank::make(prog, key, vel, sr, seed, self.opt.samples)
  } else {
      voices::make(prog, key, vel, sr, seed, self.opt.samples)
  })
  ```
  The `voices::make(...)` arm is byte-for-byte unchanged; `voices_spawned` still increments once.
- **`Active` gains `alt: bool`** (copied from `strip.alt_bank` at spawn). This is the correctness
  fix for Option A: the CC1-vibrato driver is chosen **per held voice**, not per current channel
  bank — so a mid-channel bank switch with overlapping held notes routes each note's vibrato
  correctly (a default note keeps trunk's `set_pitch`; an alt note keeps `set_vib`). (Found by the
  Codex external review, §8.)
- **Option A CC1 driver** (the `set_vib` fidelity, restoring da72e32 semantics): in the per-block
  CC1 apply loop (engine.rs:1165, the `else if vibrato_family(...)` arm), split the per-voice
  application so that, for the in-scope alt voices:
  - alt strings 48-51 → `set_vib(base + (ST_CC1_VIB_DEPTH - base) * m)` (per-layer decorrelated
    shimmer; `base = altbank::strings_vib_base(program)`), **not** `set_pitch`;
  - alt choir 52-54 → no CC1 vibrato (da72e32 gave choir none);
  - every default voice (and all non-48-54) → trunk's existing `set_pitch(bend*factor)` unchanged.
  Because the split branches on the per-voice `alt` flag and default voices take the identical
  `set_pitch` path with the identical `factor`, **a channel with no alt voices produces
  byte-identical output** — the default render is unchanged. Bend for the alt voices is maintained
  by the existing pitch-bend handler (as in da72e32, where 48-54 were out of `vibrato_family`),
  not this loop.

### 3.2 The `altbank` module (the bulk — a frozen, isolated resurrection)
`src/altbank.rs`, added via `mod altbank;` **in lib.rs**. It vendors, from da72e32, the
in-scope voicings and their private helpers:
- **SawStack** + `Layer`, `EnvBright`, `StackFilter`, `ChoirSection`, `ChoirExt`, `CHOIR2_*`
  consts, `reg_weight`, `vel_attack`.
- **strings()** (48-51: ST1 env-brightness on 48/49/51, static Solina 50).
- **choir_v2()** (52-54) — the distinctive ChoirExt consonant-onset / SATB-scatter choir, built
  at full depth (`amt = 1.0`). The near-trunk `choir()` factory is **not** resurrected (D4).
- **Bowed** + `bowed_body`/`bowed_voice`, `BODY_{VIOLIN,VIOLA,CELLO,CONTRABASS}`, `TREM_*`
  (program-44 tremolo), and the `PIZZ` `PluckPreset` (program 45 → `Pluck`; vendor `BODY_VIOLIN`
  and construct `PIZZ` without the private `DEFAULTS` spread — see §5).

`pub fn make(program, key, vel, sr, seed, samples) -> Box<dyn Voice>`:
- `40..=43` → `Bowed`, LA-sampler-wrapped when `samples` (faithful attack, as da72e32).
- `44` → `Bowed` (tremolo, unwrapped); `45` → `Pluck(&PIZZ)`.
- `48..=51` → `strings`; `52..=54` → `choir_v2(.., 1.0)`.
- **any other program** → `crate::voices::make(program, key, vel, sr, seed, samples)`.

Shared deps referenced (not vendored): `crate::dsp` primitives (curate imports — da72e32's
`BlepPulse` is trunk's `ReedPulse`; `polyblep` is private on trunk; the in-scope voices need
neither), `crate::voices::{Voice, Pluck, PluckPreset}`, `crate::sampler::{LaVoice, violin_bank}`.
All resurrected voices are plain owned data ⇒ auto-`Send` (satisfies trunk's `Voice: Send`).

### 3.3 Trait (Option A): one new defaulted method
`set_vib(&mut self, depth: f32)` is added to the `Voice` trait as a **defaulted no-op**
(`fn set_vib(&mut self, _depth: f32) {}`). Every existing voice keeps the default (inert); the
alt `SawStack` overrides it (restored from da72e32). No other trait change; the default path
never calls it (the §3.1 driver only calls `set_vib` on alt strings).

## 4. Decision log

- **D1 — selector = CC0 (bank MSB), `!= 0` means alt.** Simplest GM-standard bank select. One
  `bool` per channel — no enum, config, env var, or feature flag. CC32/LSB and multiple banks unused.
- **D2 — isolated module; default *path* untouched.** The load-bearing invariant is "no committed
  album sends `CC0 != 0`" (confirmed 0/53; implementer to re-confirm via the crate's `midi.rs`
  parser). Given that, every committed render is byte-identical by construction — the alt voicings
  can never perturb the default.
- **D3 — CC1 vibrato: Option A (full v0.9 fidelity), chosen by Arthur.** da72e32 kept
  strings/choir OUT of `vibrato_family` and drove strings' vibrato via `set_vib` (per-layer
  decorrelated shimmer, "not a coherent channel warble"); choir got no CC1. Trunk puts 48-54 IN
  `vibrato_family` (coherent `set_pitch` vibrato). Option A restores the v0.9 semantics for the
  alt bank exactly: a defaulted `set_vib` trait method (§3.3), the bank-gated CC1 driver (§3.1)
  that gives alt strings `set_vib` and alt choir no CC1, `ST_CC1_VIB_DEPTH` (0.012) and
  `strings_vib_base`, all reproducing da72e32. **Correctness (Codex, §8):** the driver keys on
  the **per-voice** `Active.alt` flag, not the current channel bank, so mixed-bank held notes are
  routed correctly. The two `set_vib` oracles (`st2_section_vibrato`, `ch_o6_shimmer`) port intact
  → full strings/choir vibrato coverage. Rejected alternative — Option C (drop `set_vib`, accept
  trunk's coherent CC1 vibrato): simpler but expression-*un*faithful; Arthur chose fidelity.
- **D4 — alt choir = `choir_v2`, not `choir()`.** The alt must be *distinctive*; da72e32's
  `choir()` ≈ trunk's formant choir, whereas `choir_v2` (ChoirExt onset + SATB scatter) is the
  genuinely different design. Resurrect only `choir_v2`, at `amt=1.0`.
- **D5 — keep the bowed LA-sampler wrap for 40-43** (faithful attack, as da72e32; 44/45 unwrapped).
- **D6 — alt make() delegates for every non-in-scope program** (single spawn branch; an alt-bank
  channel still renders its non-orchestral instruments correctly).

## 6. Testability

- **Voice oracles (ported, self-contained):** render each alt voice directly and assert its
  character (AC3) — the faithfulness proof, no engine needed. Verbatim resurrection is exactly
  what lets them pass byte-for-byte (Modal/sampler/DSP are behaviorally identical trunk-vs-da72e32).
- **A/B differ oracle (AC4):** render 42/48/52 via `altbank::make` and `voices::make`; assert the
  band-energy ratio floor — proves the alternate is real and not mis-wired to the default.
- **Engine tests (AC1/AC2/AC5):** no-CC0 → default voice; CC0 → alt; CC0-then-CC121 → still alt;
  alt-bank + piano → default. Drive via the event stream; probe by render divergence (not `kind()`).

## 7. Residual risks / open items

- **Two orchestral voicings to maintain** — intentional (the A/B is the point) and the alt copy
  is *frozen*, so this is stable duplication, not the "wrong abstraction" kind.
- **Held-note program dimension** — the §3.1 CC1 driver reads `strip.program` for a held voice
  (like trunk's existing loop), so a program-change mid-ring is bounded by the *pre-existing*
  "held notes follow current strip state" simplification. The new `Active.alt` flag fixes the
  *bank* dimension (Codex §8); the program dimension is inherited, not worsened.
- **Bend maintenance for alt strings/choir** — since they leave trunk's `set_pitch`-vibrato loop
  (Option A), verify at implementation that bend still reaches them via the pitch-bend handler
  (da72e32's arrangement; expected fine). A test asserts a bent alt-string note tracks pitch.
- **`sawstack_v1_canary_frozen`** — re-pin its reference bytes against the alt module rather than
  carrying da72e32's, since the alt SawStack now composes with trunk's (bit-identical) DSP
  primitives (Codex §8).
- *(Refuted, removed): the pizz-45 CC68 caveat — verified da72e32's `Pluck` already has
  `legato_to`, so the alt pizz behaves identically; no faithfulness gap.)*

## 8. External review (Codex gpt-5.5, one light pass — triaged)

  Fixed in §3.1/§4 D3. (This is why Option A is more than "~15 lines" — Codex was right.)
- **Frozen PIZZ default** — don't share trunk's `DEFAULTS` for the alt PIZZ; use local explicit
  fields so the alt stays frozen. Folded into §5.
- **Re-pin the canary fingerprint** against the alt module. Folded into AC3/§7.
- **Add `CC0 != 0` then `CC0 == 0` → default** test. Folded into AC5.
- **Pizz/legato caveat is stale** — verified: da72e32's `Pluck` has `legato_to`; caveat removed.
- Codex's own preference was Option C (simplicity); **Arthur chose A** (fidelity) — recorded as the
  rejected alternative in D3.
