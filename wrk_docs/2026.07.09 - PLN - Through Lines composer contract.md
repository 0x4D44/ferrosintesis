# 2026.07.09 — PLN — Through Lines composer contract

The working brief for every track-composer agent on *Through Lines*
(albums/fable5/Through Lines). Read alongside the track's section in
"2026.07.09 - HLD - Through Lines double album.md". The HLD says WHAT the
track is; this says HOW to deliver it.

## 1. What you own

Exactly ONE file: `movements/tNN_<stem>.py`. Replace the stub wholesale.
Everything else — engine.py, conductor.py, material.py, build.py, verify.py,
analyze.py, other tracks — is frozen to you.

Your module must expose:

| Attribute | Meaning |
|---|---|
| `NUMBER, TITLE, FILE, SEED` | must match `conductor.REGISTRY` exactly |
| `PART` | a `conductor.Part`: movement grid, tempo map, time sigs, keysigs, channels, program changes, extra markers |
| `BUILDERS` | one `build(sc)` callable per `PART.MOVEMENTS` entry, in order |
| `PROGRAM_WHITELIST` | every GM program the track may author (set[int]) |
| `CENTERED_CHANNELS` | channels whose CC10 must always be 64 (all sustained beds) |
| `NOTE_RANGES` | {ch: (lo, hi)} pitch clamps — low beds floored at 36 (C2) |
| `GAP_WHITELIST` | [(t0, t1)] beat spans where all-channel silence is scored |
| `BEND_EXEMPT` | channels holding a CONSTANT microtuning bend per movement (else bends must recentre at every movement boundary) |
| `DURATION_WINDOW` | (lo_s, hi_s) for the written file |
| `BOUNDS_WHITELIST` | [(ch, lo, hi)] documented sustain seam carry-overs |
| `def oracles(sc, info, spans)` | your track-specific oracles → `[(name, [failures])]` |
| `def audio_checks(ctx)` *(optional but expected for headline audio claims)* | render-side oracles, run after the WAV exists |

## 2. Method — oracle-first, non-negotiable

Write `oracles()` BEFORE the music; compose to pass. Every headline claim in
your HLD section must be a falsifiable oracle (the HLD lists them per track —
implement those, add more if your design makes further claims). Encode the
dramatic shape as inequalities on per-bar velocity sums (the `check_arc`
pattern from The Ninth Bell), and mirror the same contour in `audio_checks`
as per-bar RMS dB where the HLD demands it. A prose brief is unfalsifiable; a
contour of numbers is a target and a test.

Recurring material MUST be recomputed from material.py (fable cell, bridge
chorale, walker/dive/orbit, ledger theme, morse_rhythm) — never re-typed by
hand, never compared against another track.

## 3. Validation loop

```
python build.py --track N --check     # in-memory oracles while composing
python build.py --track N             # write midi/NN - Title.mid
python build.py --track N --verify    # file + all oracles for your track
```
Done = `--track N --verify` green (material check + all generic checks + your
oracles). Do not run the full-album `--verify` (other stubs are red by
design). Runtime discipline: your build must stay a few seconds, not minutes.

## 4. The shared verify.py generics (already enforced, design WITH them)

structure (grids match, note counts match, duration window) · programs
(whitelist) · pan (centred set) · ranges · gaps (>1.5-beat silence must be
whitelisted) · overlaps (same-pitch clamp) · bend hygiene (recentre or
exempt-constant) · movement bounds (write only inside your [t0, t1); seam
carry-overs whitelisted).

## 6. Hard disciplines (repo lessons — violations WILL be caught)

- Sustained beds: pan 64, always (Haas mono-collapse). Stereo width comes
  from panning TRANSIENT sources (bells, piano, mallets, timpani, arps).
- Low sustained lanes: floor at C2 (MIDI 36), centred.
- Velocity is not audibility: keep melodic material ≥ ~vel 40 unless scored
  as near-silence; your `audio_checks` must assert the headline dynamics on
  the RENDER, in dB, not just in velocities.
- Bends recentre at movement boundaries (or declare BEND_EXEMPT constants).
- >1.5-beat silences are scored decisions → GAP_WHITELIST.
- Seeded jitter means: change one movement and downstream jitter re-rolls —
  the assembly re-verify at album level will re-measure everything.
- Markers: name every movement/section (players + oracles navigate by them).
