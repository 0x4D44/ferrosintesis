# Code review: default solo bowed strings

**Date:** 2026-07-10

**Scope:** `origin/main...51a008f`, reviewed once under the `code-reviewer` workflow, followed by one quality-only simplicity/altitude pass. No critical finding required a targeted re-review.

## Summary

The implementation follows the signed architecture: one compact default-bank preset map, independent frozen-alt precedent, no new assets or dependencies, and behavior-first tests. Four acceptance/correctness gaps required changes. One optional abstraction was rejected as needless indirection.

## Required changes

1. **Issue — body-table length was a runtime assumption.** `Bowed::new` indexed three elements from a slice even though every supported body has exactly three modes. Fixed by typing every body as `[(f32, f32, f32); 3]` and `BowedPreset::body` as a reference to that array.
2. **Issue — default GM44 coverage did not prove velocity or reversal re-bites.** The voice contained the mechanisms, but the test only measured one AM rate. Added the exact velocity-law guard plus a behavioral residual-energy test around detected reversal events.
3. **Issue — the signed true-DC safety criterion was missing.** Added a four-pole 8 Hz settled-DC measurement with `DC RMS / signal RMS < 1e-3` for the sustained family.
4. **Issue — positive sample assertions would fail the later sample split's modeled-only gate.** The default build must prove GM40/110 layering, but a no-embedded-samples build must remain modeled. The test now detects generic sample availability through the piano positive control and asserts the correct branch without adding a feature flag here.

## Suggestions

- **Optional — consolidate the local audio-oracle helpers.** Skipped. They are short, test-only, and each keeps its measurement window beside the behavior it proves. A general helper would hide the important differences and create the wrong abstraction.

## Simplicity and altitude pass

- Removed redundant GM44 output autocorrelations for the velocity law after the output AM rate was already proven. The constructor-level rate guard is exact and materially faster.
- Made `Bowed::vib_val` test-only. After the invalid bow-noise coupling was removed, shipped code had no reason to retain that runtime field.
- Kept the intentional default/alt-bank data duplication: sharing would violate the frozen compatibility boundary.
- Kept one `Bowed` struct and one private preset map; no articulation hierarchy, trait, feature flag, allocation or dependency was introduced.
