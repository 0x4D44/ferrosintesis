# HLD — GM19 cathedral-organ reed rasp, driven by the swell (CC11)

**Date:** 2026-07-11
**Author:** Claude (lead) — hard reed-drive DSP + oracle design consulted from **Claude Fable 5**, verified-by-understanding and owned by the lead.
**Scope:** `crates/ferrosintesis` — `CathedralOrgan`/`RankPipe` (`voices.rs`), CC11→drive routing (`engine.rs`), audio oracles.
**Trigger:** user — "there's a raspy nature to a church organ when it's driven hard." User chose to drive it by **CC11 (the swell pedal)**.

## 1. Diagnosis (verified)

The ChorusReed is a sum of sine partials with no drive-dependent behaviour, so it can't snarl. Three concrete causes, not "sines are smooth" (a steady tone's waveform shape is inaudible — Ohm's phase law; only amplitude spectrum + modulation matter):
1. **Buried** — reed rank 9 at gain 0.18 sits ~12 dB under the 8′ principal (0.72). A real chorus reed *dominates* the full organ.
2. **Truncated** — `ORGAN_MAX_SOURCE_HARMONICS = 24` caps the reed's top partial at 24·f0 (~3.1 kHz at C3), so the 2–8 kHz "brass snarl" band is nearly empty for exactly the keys a chorus reed lives in. Rasp *is* largely dense unresolved partials in that band beating at f0-rate (auditory roughness).
3. **Noiseless** — a hard-blown reed has cycle-to-cycle jitter at the shallot (noise sidebands / "spit"); the wind-wander (0.15–2.5 Hz) is far too slow to supply it.

## 2. Mechanism: driven wavetable + reed lift + spit noise (NOT waveshaping)

**Load-bearing decision: harmonic intensification via a third table, not a `tanh` on the reed.** For a *periodic* single-pipe input a memoryless nonlinearity produces *only integer harmonics of f0* with modified amplitudes — i.e. it is exactly a table redraw. The only things time-domain waveshaping adds are (a) intermodulation between different sources sharing the shaper — *inauthentic*, since each real pipe is its own nonlinear oscillator and two chord notes' reeds do not IMD — and (b) aliasing (the reed already reaches ~19 kHz at high keys; any nonlinearity folds products down as fizz). A band-limited "driven" table gives all the wanted spectrum with **zero aliasing by construction** and near-zero CPU, and it reuses `RankPipe`'s existing speech→steady crossfade (add a third endpoint). A separate BLEP-saw voice was also rejected (can't share the pipe's phase accumulator → beats/combs, won't wander with its pipe).

Three coupled effects, gated by a smoothed `blend ∈ [0,1]` (drive), **on ChorusReed ranks (ids 9, 13) only** — not the plenum (bus/plenum shaping would IMD between chord notes = "fuzz pedal on a chord"; flues just get louder+sag, already modelled):

1. **Spectral hardening** — a `driven` table built in `regenerate_tables` for reed pipes: same `organ_anchor` shape, harder anchors (peak moved off H1 onto H2–H4; −4 dB/oct tail vs −6), extended to **48 harmonics** (`driven_harmonics = min(48, floor(max_hz/frequency))`, same alias law) to fill 2–8 kHz. Normalized to its *own* energy so the blend is **timbre-only** (loudness is the separate lift term). `next()`: `target = steady + (driven−steady)·blend`, then the existing speech crossfade wraps it. **No fixed-Hz formant** (would make table content depend on `frequency` at regen time → breaks the path-independence the `composes_pitch_pressure_and_tremulant` test pins); express any register shaping through key anchors only.
2. **Reed lift** — reed `drive_gain = 10^(LIFT_DB·blend/20)`, **LIFT_DB ≈ +6 [+5..+8]**, one more factor in the amp chain (reeds-forward when driven). ≈ +0.6 dB channel level at full drive (checked vs headroom).
3. **Spit noise** (per voice, in `render`): split the pipe sum into `flue_sum + reed_sum`; `spit = LP₂(BP(white))·reed_env·spit_gain` added before `norm`. BP ≈ 2.8 kHz Q≈0.7, LP 5 kHz (confines it below the anti-alias probe band), `reed_env` = OnePole|reed_sum| ~200–300 Hz (modulate by the *slow* envelope, not raw reed — else the noise band smears up to 12 kHz into the anti-fizz region), `spit_gain ∝ blend²`, level ≈ **−26 dB [−30..−22]** vs organ body. New independent `Rng` (event_seed ^ CONST), *not* drawn from `stable`/`chiff` (draw-order hazard). Whole block strictly `if drive > 0.0`.

**Wiring / invariants:**
- New trait method `set_organ_swell(&mut self, drive: f32)` (default no-op) — **separate from** `set_organ_pressure`/`retune` (retune triggers table regen; drive must *never* regen, and a separate setter leaves every existing call site/test textually untouched).
- Every drive path strictly branches on `drive > 0.0`; the `else` arm is today's code **verbatim** — that is the byte-identity guarantee.
- Composition: driven table read through the *same* phase accumulator → wander detunes/trims it identically; `retune()` untouched; blend never changes `harmonics`. Legacy CC0=1 voice ignores the setter (no-op) → byte-identical.
- No oversampling anywhere → render budget untouched.

## 3. Drive mapping from CC11 (opt-in)

```
expr  = smoothed (CC11/127)²                      // existing lane
drive = if !expr_authored { 0.0 }
        else { (((expr − T)/(1−T)).clamp(0,1)) ^ γ }
T = 0.25 [0.20..0.30],  γ = 1.6 [1.3..2.0],  max = 1.0
```
Threshold (not linear) because a chorus reed is on/off with registration and the snarl belongs to the *top* of the dynamic. T=0.25 in (squared) expr terms puts the knee at CC11≈64: ≤64 → smooth (pure gain as today), 96→0.25, 110→0.55, 127→1.0. **Opt-in**: add `expr_authored` (set in the CC11 arm, `engine.rs:1114`, like `breath_authored`; reset with the CC121 block); `expr` defaults to 1.0 so gating on value alone would snarl every silent channel. **Strictly CC11** — velocity would violate velocity-independence; wind-load would leak drive onto unauthored channels (breaks opt-in). Compute `drive` in the cathedral wind pass and call `set_organ_swell(drive)` beside `set_organ_pressure`.

## 4. Oracles (deterministic; box has no ears)

- **(a) rasp grows** (`cathedral_reed_rasp_grows_with_swell`): A1 `hfr = hp_rms(2 kHz)/rms` monotone up (hfr(64) ≤ 1.15×unauth = smooth; hfr(110/127) ≥ measured floors); `centroid(127) ≥ 1.2×unauth`. A2 `flatness(2k,8k)` rises by measured Δ — the "rasp ≠ brighter sine-stack" clause (fails a spit-less build). Seed-stability + chord smoke (`return_peak < 1.0`).
- **(b) not aliased** (`cathedral_reed_rasp_is_band_limited_not_aliased`): B1 off-lattice differential probe — Goertzel at `(2k+1)·f0/4` across 6–13 kHz, `offlat(127) ≤ offlat(unauth)·10^(3/20)` (a tanh-no-oversample build folds products here at −25..−40 dB → fails). B2 `band_rms(14–21 kHz)` barely grows. B3 bounds unit test (`frequency·driven_harmonics ≤ 0.45·sr`).
- **(c) byte-identity** (`cathedral_organ_without_cc11_matches_baseline_hash`): pinned `render_hash` of a no-CC11 GM19 song == the pre-edit 0.13.3 value; paired canary (same song + CC11=127) must **differ** (proves wired).

## 7. Implementation outcome (what actually shipped — 0.14.1)

**Shipped as designed:** the driven-table crossfade + reed lift + CC11-thresholded drive,
reed ranks only, opt-in via a new `expr_authored` flag, separate non-retuning
`set_organ_swell`. Chosen values: **LIFT_DB = +8** (top of Fable's range — measurably the
clearer snarl, and it only engages at the top of the swell), T = 0.25, γ = 1.6. Measured
(key 60, dry): hfr (>2 kHz band mass / rms) **0.277 → 0.278 → 0.304 → 0.378** at
unauthored/CC11-64/110/127; spectral centroid **1755 → 2843 Hz** (+62%). CC11 = 64 sits on
top of unauthored (the knee keeps a half-open swell smooth).

**Dropped after measurement — the spit noise (§2.3).** Calibration refuted it two ways:
(1) the dense *driven partials* dominate the 2–8 kHz flatness, so Fable's A2 "texture rises"
clause measured the wrong thing (flatness *falls* with drive — the added partials are tonal,
not noise); and (2) the spit is broadband and raises **off-lattice** energy 1.9×, which is
exactly the signal the anti-alias oracle uses to detect fizz — the spit made "authentic
breath" and "digital aliasing" indistinguishable to the test, for a −26 dB benefit
unverifiable on a deaf box. The **driven table alone is the authentic rasp**: dense partials
~262 Hz apart in the 6–12 kHz band beat within critical bands = auditory *roughness*, which
is physically what rasp is, and the wander makes them shimmer. Fable explicitly sanctioned
shipping without spit (delete the flatness clause). Spit is parked as a future option if a
listen wants more breath.

**Oracle correction — absolute, not differential, anti-alias.** Fable's B1 differential is
confounded here: the drive *legitimately* makes the reed's high partials louder, so their
Goertzel leakage + wander-smear into off-lattice slots grows with drive even with zero
aliasing (measured 1.66× without any spit). But the **absolute** off-lattice stays at
**−67 dB (unauthored) / −62 dB (full drive)** — a realistic tanh-without-oversampling reed
would fold products here at ~−25 dB. So B1 asserts an absolute floor (≤ −46 dB, ~15 dB
margin), and **B3** (the pipe-bounds test extended to `driven_harmonics·frequency ≤ 0.45·sr`,
exercised under a 4× bend) is the *structural* alias-free proof.

**Oracles (all green):** A `cathedral_reed_rasp_grows_with_swell` (hfr monotone up, cc64
smooth, hfr(127) ≥ 1.25× and centroid(127) ≥ 1.30× unauthored); B
`cathedral_reed_rasp_is_band_limited_not_aliased` + the bounds extension; C
`cathedral_organ_without_cc11_matches_baseline_hash` (pinned no-CC11 hash = the pre-feature
value `0x4e6545f5a7592108`, with a CC11=127 canary that must differ — proving the feature is
wired). **Byte-identity holds**: the no-drive path is branch-skipped, the driven table is
regenerated but never read at blend 0 and uses no RNG, and `render` reverted to the exact
original sum.

**Mix tests moved but stayed green without recalibration** (both author CC11=127 → full
drive): headroom `return_peak < 1.0` held with the +8 dB lift; the wet tail moved
−20.8 → −21.2 dB (still ≥ −22). They are now permanent full-drive integration coverage.
