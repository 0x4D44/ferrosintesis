## 1. Goal, scope, non-goals

**Goal (one line):** make GM 26–31 electric guitars read as *electric* — pickup-circuit
resonance, a two-stage amp with sag/compression, an e-bow-style sustainer for held
29/30 notes, and a 26/27 preset split — as a default-on timbre improvement with the
mandated render-diff and `listening/*.opus` refresh.

**In scope**
- A. Pickup RLC resonance in the `Pluck` voice (all electric presets).
- B. Split the shared CLEAN preset into JAZZ (26) and CLEAN (27). First-class

  today's album usage does not bound what gets proper support). The one-line
  re-route back to `&CLEAN` remains as a pure contingency if the JAZZ voice
  listens wrong, not as optional scope.
- C. Drive v2: two cascaded soft-clip stages with interstage voicing + a sag/sustain
  compressor, keeping the existing 2× oversampling and 5-biquad cab.
- D. Per-voice string sustainer (band-limited regeneration + hold latch) for
  DRIVE / DRIVE_LEAD, and the DRIVE_LEAD re-spec that retires its hot-amp hack.
- The render-diff inventory, refresh of affected committed `.opus`, one version bump.

**Non-goals (explicitly out)**

## 2. Diagnosis (why the current chain reads synthetic)

Current chain (verified at `bfd77a9`):
`Pluck` two-polarization KS (`voices.rs:1844`) → feedforward pickup-position comb
(`voices.rs:2130-2133`, delay = **2·pickup·period**, so the preset field is half the
physical sensing fraction) → body EQ → per-voice cab (CLEAN only) → summed per
channel → `Drive` insert for 29/30 only (`engine.rs:220-293`): HP90 → one
program-keyed peak → single biased tanh → DC block → 5-biquad cab → post gain.

The three gaps, in order of audibility:
1. **No pickup circuit.** The 2–5 kHz resonant lowpass of a magnetic pickup
   (RLC: resonant peak, then 12 dB/oct) is the defining "electric" color
   (Paiva/Pakarinen/Välimäki, JAES 2012). We model pickup *position* but not the coil.
2. **One static tanh, fixed gain, no gain recovery.** A real amp is cascaded stages
   plus power-supply sag: effective gain recovers as the note decays, holding it in
   saturation (compression sustain). `DRIVE_LEAD` (0.14.4) proved the effect by
   driving `amp: 1.5` into the tanh; v2 builds the honest mechanism and retires the hack.
3. **A KS loop is strictly dissipative** — no energy input after the pick. The
   in-loop damper is applied once per round trip (f trips/s), so its per-trip loss
   costs more per second at higher pitch AND falls differentially on harmonics —
   high notes shed the harmonics that carry their RMS almost immediately (the T16
   "wooden glockenspiel" verdict). Only regeneration holds a note.

Already right (keep): distortion on the *summed* channel buffer (power-chord
sub-octave intermodulation — Sullivan's topology), two-polarization decay,
velocity→timbre law, 2× oversampled nonlinearity with the cab as decimator.

## 3. Design

### A. Pickup RLC (voices.rs)

New `PluckPreset` field `pickup_rlc: (f32, f32)` — (resonance Hz, Q); `(0.0, 0.0)` =
absent, set in `DEFAULTS` so every `..DEFAULTS` preset is bit-identical. In `Pluck`,
build `Option<Biquad>` via `Biquad::lowpass(hz, q, sr)`; process immediately after
the position comb (string → position/aperture → coil circuit), before body EQ.
Indicative values (final constants tuned to the oracles):

| Preset | rlc Hz | Q | character |
|---|---|---|---|
| JAZZ (26) | 2400 | 1.1 | neck humbucker, tone rolled |
| CLEAN (27) | 4200 | 1.8 | single-coil + cable |
| MUTED (28) | 3000 | 1.2 | |
| DRIVE (default 29/30) | 3300 | 1.5 | pushed humbucker |
| DRIVE_LEAD (CC0 alt-bank only) | 3300 | 1.5 | |
| HARMONIC (31) | 3800 | 1.5 | |

Existing `out_lp` / `cab_lp` stay; the RLC's audible job is the resonant *peak*.
If CLEAN dulls, tune `rlc`/`out_lp` jointly against oracle V1 (velocity contrast),
which must stay green.

### B. Preset split 26/27 (voices.rs)

Today `26|27 => Pluck(&CLEAN)`. Split:
- **JAZZ (26), new preset:** from CLEAN — pos ≈ 0.30, **pickup ≈ 0.11** (the field is
  half the physical fraction — 0.11 senses at ~0.22 of string length, a neck
  position; document the ×2 convention at the field), rlc 2400/1.1, warmer body EQ
  (≈ (180, 1.0, +2.5), (700, 1.2, +1.5)), t60 ≈ 2.4, pick_lp ≈ 3500, click ≈ 1.2,
  cab_lp ≈ 3800.
- **CLEAN (27):** unchanged except the new rlc 4200/1.8 (`pickup` stays 0.12).
Routing `26 => &JAZZ`, `27 => &CLEAN`; oracle-36 `name` discriminants added.
Alt-bank 26/27 falls through to `voices::make` (altbank.rs:1057) — the split
propagates there, consistent with the timbre regime.

### C. Drive v2 (engine.rs)

Keep the struct, the insert point, the 2× path, and the 5-biquad cab. New chain per
2× sample:

```
HP90 → voicing EQ → ×g_sag → stage1 clip (g1, bias b1) → interstage tilt biquad
    → stage2 clip (g2, mild/no bias) → DC HP20 → cab ×5 → ×post
```

- **Clipper:** keep `tanh` referenced to its bias (`(x·g+b).tanh() − b.tanh()`).
- **Sag/sustain compressor** (temporal polarity matters — this is the corrected spec):
  envelope follower on |input| with **fast attack (≤ 1 ms)** and slow release
  (≈ 180 ms); `g_sag` eases toward `clamp(T / max(env, floor), 1.0, G_MAX)` with an
  **upward slew limit** (≤ +12 dB per ≈ 150 ms — that slew *is* the sag recovery) and
  no slew limit downward (an onset yanks it back toward 1 within the attack window).
  Idle: after ≈ 400 ms below `floor`, ease `g_sag` back to 1.0 so a fresh entrance
  never starts boosted. Result: pick transients pass at g_sag ≈ 1; as the note
  decays the gain recovers, holding saturation. `T` per program; `G_MAX ≈ 4`
  (+12 dB). The follower sees the summed channel: chords breathe together.
- **Program keying (indicative):** 30: g1 4.5 / b1 0.5, tilt peak(700, −4 dB),
  g2 3.0; 29: g1 2.5 / b1 0.35, tilt peak(1200, +2 dB), g2 2.0. `post` re-matched at
  **two operating points**: a loud reference phrase within ±1.5 dB of v1, and a
  decayed-tail/pp point whose lift (≤ +12 dB by construction) is measured and
  reported — G_MAX is the knob if the tail lift listens wrong.
- **Idle/denormal policy** (rev 3): the Drive persists for the channel's lifetime
  and otherwise filters silence forever through its recursive stages; after ≈ 400 ms
  below the follower floor, snap the follower and all Drive biquad states to zero
  when below an epsilon (denormal guard), and ease `g_sag` back to 1.0 so a fresh
  entrance never starts boosted.

### D. String sustainer (voices.rs) — band-limited regeneration with a hold latch

New `PluckPreset` field `sustain: f32` (0 = none): the fraction of the note's
reference level at which the string latches into a *hold* while the note is held.

- **Regeneration path: a band-limited, SATURATING driver** (rev 4): each `KsLoop`
  gains an optional resonant bandpass (`Biquad::bandpass` — constant 0 dB peak and
  zero phase at center; `retune_bandpass` already preserves state across retunes)
  centered on the loop's current fundamental. The loop input gains an additive
  feedback term `k_fb · softsat(bp(s), L)` alongside the existing `inject`, where
  `softsat` is a tanh-style limiter with knee `L = sustain × reference amplitude`.
  Off-center modes — DC, remote harmonics — see only the bandpass skirt. (Rev 2's
  scalar whole-loop gain is REJECTED — unstable at DC; rev 3's *linear* bandpassed
  feedback is REJECTED — a net gain of 1.002 at f0 grows exponentially with nothing
  to stop it.)
- **Equilibrium comes from the saturator, not a controller** (rev 4): `k_fb` is set
  so the *small-signal* net gain at f0 is deliberately slightly supercritical
  (`k_fb = 1.002 − loop_gain · |H_damp(f_center)|`, closed-form OnePole magnitude,
  recomputed on retune/set_bright, **per polarization loop**, minimum across glide
  endpoints, absolute cap `K_FB_MAX`). The f0 mode then grows until the driver
  saturates and its effective gain falls to exactly unity — the amplitude settles
  at a level set by `L`. This is the classical e-bow/sustainer stabilization
  (Sullivan 1990's feedback with a limiter): a memoryless nonlinearity provides the
  convergent equilibrium that switched gain control cannot.
- **Boundedness argument** (rev 4): every linear path is strictly sub-unity with the
  driver off — including the coupled two-polarization pair, whose per-step matrix
  [[a, k],[−k, a]] has |λ| = sqrt(a² + k_couple²) (discrete skew coupling is NOT
  energy-neutral; with k = 0.02 this demands a < 0.9998, satisfied since
  loop_gain·|H_damp| ≤ ~0.9995 — the build asserts this inequality in a unit test,
  and the "adds no energy" comment at `voices.rs:1818-1821` gets corrected). The
  only supercritical path runs through the saturator, whose output is hard-bounded
  by `k_fb·L` per sample — total system energy is bounded no matter how the
  constants are mis-tuned.
- **Latch (simplified, rev 4):** `k_fb = 0` until the observed envelope first
  *decays* to `sustain × reference`; then ramp `k_fb` to its clamped value over
  ≈ 60 ms and hold it there — no ease-down rule (the saturator regulates). The
  driver never engages during the attack and never attenuates the string. Observed
  signal: the raw string mix (`course_mix.0·hc + course_mix.1·vc`), before onset
  bursts (the click never enters the loops and must not enter the reference);
  envelope at CTRL rate; reference = windowed RMS over 100–200 ms post-onset.
- On `note_off`: `k_fb → 0` immediately (normal decay + release darkening; voice
  dies as today, env floor 2e-5).
- **Intended steady state (stated deliberately):** the hold is band-limited at the
  fundamental; upper harmonics decay naturally, and the channel Drive's tanh
  re-harmonizes the held tone — the e-bow-into-amp sound. Oracle V6(b) pins the
  post-Drive harmonic content so it can never silently degenerate to a naked sine
  in the render. (DRIVE_LEAD's bright 11000 additionally keeps the string itself
  harmonic-rich.)
- **Engagement:** `DRIVE sustain ≈ 0.35` (default 29/30), `DRIVE_LEAD sustain ≈ 0.6`
  (CC0 alt-bank opt-in — today authored only by Through Lines T16). Every other
  preset 0 ⇒ bit-identical (no bandpass allocated). No `Voice`-trait change, no
  engine change for this unit.

**DRIVE_LEAD post-v2 contract (re-spec, retiring the hack):** `t60: 8.0` (back to
DRIVE's), `amp: 0.7`, `bright: 11000` (kept — its proven harmonic-sustain lever),
`click: 1.3`, `sustain: 0.6`, rlc 3300/1.5. The AGC is *the* sustain mechanism;
the amp-1.5 tanh-pinning hack is retired. Without this re-spec the AGC would
regulate DRIVE_LEAD's near-unity-decay string *downward* toward 0.6×reference —
an attenuator, not a sustainer. Contract: DRIVE = default driven guitar, moderate
hold; DRIVE_LEAD = opt-in lead voice, stronger hold + gentler damper + softer pick.
T16's render changes (expected diff; it is the track this exists for).

  pitches whose harmonic lattices populate *both* comparison bands (≥ 3 harmonics

  amplitude 0.5, −30 dB over 2 s) through Drive with G_MAX = 4 vs G_MAX = 1

  1 dB over the first 30 ms (transients must pass at g_sag ≈ 1 — catches an

  sub-fundamental (< 0.5·f0) energy ≤ −40 dB rel f0; all samples finite.

## 7. Decision log

- **In-voice AGC sustainer over Sullivan channel feedback.** No engine→voice
  back-path, no `Voice`-trait change, per-voice stability trivially bounded.
  Howl/feedback-pitch deferred as character.
- **Band-limited regeneration over any whole-loop gain** (rev 3, external review):
  rev 1's scalar clamp couldn't hold above ~A4 (damper ignored); rev 2's
  damper-normalized clamp destabilized the DC mode (|H_damp(0)| = 1 while the
  excitation retains DC). A bandpassed feedback term at f0 keeps every other mode
  strictly contracting, and `retune_bandpass` already exists for click-free retunes.
- **One-way hold latch over a closed-loop AGC** (rev 3): a proportional AGC has no
  stable equilibrium (at env = target its requested gain is 1 and decay resumes) and
  would suppress the early note (both targets sit below the post-capture envelope).
  The latch has no bidirectional dynamics to tune and can never attenuate.
- **Saturating driver over switched gain control** (rev 4, targeted re-review): a
  linear driver at net 1.002 grows exponentially, and a latch that eases gain down
  past a threshold is switched feedback with no convergent equilibrium. A memoryless
  soft limiter in the feedback path is the classical fix (Sullivan 1990): the
  supercritical small-signal gain blooms the mode, saturation pins its amplitude at
  `L`, and the ease-down rule disappears entirely. It also hard-bounds energy input,
  which closes the discrete-skew-coupling gap (|λ| = sqrt(a² + k²) > a) that a
  per-loop linear clamp ignored.
- **Sine-into-tanh steady state stated as intended** (rev 2): the hold is
  band-limited at f0, the Drive re-harmonizes; V6(b) pins it. Actuating `bright`
  under the controller was considered and rejected: it retunes the loop every tick
  (via `set_bright`) and drags tuning/oracle complexity for a timbre the tanh
  already supplies.
- **Sag with fast-attack/slow-release + upward slew** (rev 2): the round-1
  `T/env` law had inverted temporal polarity (onset boost); the corrected law is
  the physical one (transients pass, gain recovers as the note decays).
- **DRIVE_LEAD re-specced, hack retired** (rev 2): without it the AGC attenuates the
  one voice built for sustain; three stacked sustain mechanisms collapse to one.
- **Keep tanh clippers; keep the 5-biquad cab**: oracle continuity; the weak links
  are the pickup and the static single stage. Ripple comb deferred.
- **Split 26/27 now, marked droppable** (rev 2): cheapest real variety; reversible
  by re-routing one match arm.
- **Default-on everywhere** (timbre regime); the sustainer engages only on held
  notes, so short-note textures shift least.
- **Sag follower on the summed channel**: real amps compress the sum.
- **GM 28 keeps no channel Drive** (GM semantics); GM 31 RLC-only (album-unused).
- **0.15.0 not 0.14.5**: new pub `PluckPreset` fields are API-breaking → 0.x minor
  slot (matches 0.9 brass / 0.12 course-fields precedent).
- **Real-world option space** (guitars × pickups × pedals) collapses per shipping
  modelers (Variax, MODO) to {pluck pos, pick force, string brightness/t60, damping,
  pickup pos, pickup resonance/Q, drive/voicing, cab} — v2 covers every axis with
  per-GM-program constants; no new user-facing surface.

## 8b. Amendments (as built — deviations from the signed-off rev 4)

Recorded during implementation; each was forced by measurement, none changes
the architecture:
1. **Proportional supercriticality** replaces the constant `1.002` net-gain
   target: `k = SUS_K_OVER (1.18) × the loop's per-trip deficit`. With a
   constant margin the saturator's equilibrium (a function of k/deficit) was
   pitch-dependent — E6 held ~4 dB hot while E5 was perfect. A constant RATIO
   pins the equilibrium at the same multiple of the knee everywhere. Two
   runtime-trim designs were tried first and rejected by measurement: trimming
   k lets a high note crash off the gain cliff (E6 decays −65 dB/s bare)
   faster than any safe trim chases; trimming the knee chased the
   two-polarization beat (1.17 s period).
2. **Reference window 20–80 ms**, not 100–200 ms: a bare E6 DRIVE pluck is
   *dead* by 100 ms, so the later window referenced the noise floor and made
   the hold level meaningless at exactly the pitch the feature exists for.
   The reference is now the note's spoken level.
3. **V6 bounds as measured**: hold expectation = `20·log10(sustain)` − 11.6 dB
   rel the spoken-level peak (the offset bundles crest-vs-RMS, the smoothed
   window-max envelope statistic, and the saturator equilibrium multiple),
