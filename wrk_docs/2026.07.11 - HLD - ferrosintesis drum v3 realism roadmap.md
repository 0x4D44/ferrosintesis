# HLD — ferrosintesis V3 drum realism: toms, snare, cymbals

Status: **PROPOSED** (Design-only). Answers Arthur's question "drum set 3 is the default
but the toms/snare still aren't good enough and the cymbals have room vs state-of-the-art
— how can we further improve them?" Nothing here is implemented; each item is a scoped,
oracle-backed proposal for Arthur to green-light (whole, in part, or reordered).

## How this was produced

A parallel analysis fanned out three code-grounded gap audits (toms, snare, cymbals against
`crates/ferrosintesis/src/drums.rs`) and three state-of-the-art surveys (membrane physical
modeling, snare-wire collision synthesis, nonlinear cymbal-plate synthesis), then synthesized
one roadmap. The single hardest item — the nonlinear cymbal energy cascade — was handed to a
Fable 5 specialist consult for a de-risked design plus a purpose-built property oracle (see
§Cymbals / P-C1). Every claim below was verified against the shipped code.

## The one-line answer

Each family has **one signature gap** that a listener's ear keys on, and all three are cheaply
fixable in the *envelope / statistics* domain — no PDE, no FFT, no new dependency:

| Family | The tell (why it still sounds synthetic) | The fix |
|---|---|---|
| **Snare** | the wire buzz is smooth, correlated filtered noise with a *periodic* 186 Hz AM whine under it | a chaotic, aperiodic **collision-grain gate** (PhISEM) — a crackle, not a wash |
| **Cymbal** | the spectrum only ever *darkens* from the strike; there is no **bloom** | a feed-forward **energy cascade** so highs *fill in* 40–80 ms after the hit |
| **Tom** | 3 pure sines + one mid pip reads as an 808, not wood — no body, no air | an **air-loaded 5–6 mode ladder + a shell/cavity body band** (spec'd in the v3 HLD, never shipped) |

**Do first (Tier 1):** snare grain (P-S1), cymbal bloom (P-C1/C2), tom body (P-T1). Each has
audit↔survey agreement and a decisive fail-first oracle. Full ranking in §Ranking.

## Ground rules every proposal obeys

- Lands on the **V3 arms only**; `Kit::V1`/`V2` stay byte-identical (their differential tests
  are the backstop).
- **Zero new dependencies**, pure per-sample math, no FFT/PDE.
- **Determinism preserved**: new constants are drawn at build in fixed order; any render-time
  randomness reuses the *existing shared `white` draw* (exactly how `Shimmer`/`WireRes` already
  do) — nothing is inserted into `self.rng`, so RNG-draw order is untouched and every golden /
  differential pin holds by construction.
- **Earless verification**: every "it's better" claim is a numeric oracle on the rendered mono
  buffer, using only the `testutil.rs` helper vocabulary, in fail-first + differential form,
  calibrated on a known-answer synthetic first.
- **Blast radius is real**: a timbre change is default-on and forces a render-diff inventory
  across every album MIDI + re-rendering the committed `listening/*.opus`. Noted per item.

## SNARE (keys 38/40)

### P-S1 — Replace the periodic 186 Hz slap-AM with a seeded PhISEM collision-grain gate ★ headline
The snare's single most defining sound, and the audit and the wire-synthesis survey name the
*same* defect and the *same* fix.

- **Gap closed.** Today the "wires" are three head-coupled bandpass clusters (`WireRes`) driven
  by smooth filtered noise, amplitude-modulated by a *periodic* half-wave 186 Hz slap
  (`drums.rs:298`: `1.0 + am_depth·head·max(0,sin(head_phase))`). Real snare wires are ~20 metal
  strands *intermittently colliding* with the resonant head — a chaotic, aperiodic rattle. The
  current model gives a filtered "shhhh" with a low periodic buzz-pitch under it, instead of a
  crackling "kssshh".
- **Mechanism.** Delete the periodic slap term. Multiply the `WireRes` sum by a **stochastic
  grain envelope** `g[n]`: with intensity `λ = head^0.4` (the already-computed `head_track`),
  each sample fire a grain when a seeded value `u < λ·rate_max` (`rate_max ≈ 0.3–0.6` →
  ~1–3k grains/s at full head, thinning to ~0 by ~120 ms as the head decays); on fire `e ← 1`,
  else `e *= dmul(~0.8 ms)`; gate `g = floor + (1−floor)·e`, `floor ≈ 0.15`. Keep a *mild*
  one-sided bias `rate ×(1 + 0.5·max(0,sin(head_phase)))` so grains cluster on the head's
  compression half — physical, and it preserves a whisper of head-sync **without** a spectral
  line. Derive `u` from the existing shared `white` (`u = white·0.5 + 0.5`) → **zero new RNG
  draws**. Recompute `WIRE_MAKEUP` (currently 2.9) for the analytically known mean-gate loss.
- **Cost.** ~4–6 flop + 1 compare/sample — *cheaper* than the `powf` it replaces. No polyphony threat.
- **Oracle (fail-first).** Solo key 38, vel 100, seed 7; HP-2800 copy of the sustain [20,120 ms].
  `env_autocorr_peak(seg, sr, 1/300, 1/120)` peak must fall **below 0.2** (current render fails —
  a strong ~186 Hz peak at lag ≈ 5.4 ms). Plus an impulsiveness rise: a new `crest_factor`/`kurtosis`
  helper over the wire band **> 1.3×** the smooth baseline (the *one* new testutil helper this
  roadmap needs — calibrate on synthetic Gaussian-noise-vs-click-train of known answer first).
  Level parity DR-O10 within ±2 dB; `|mean| < 1e-4` (no DC). **Note:** this *supersedes* the
  current DR-O8(b) oracle, which today *maximises* the 186 Hz line — it must be re-aimed to assert
  the line is now *absent*.
- **Blast radius.** 38/40 — the backbeat of essentially every drum-bearing album. Broad `.opus` refresh.
- **Size/risk.** **M.** Failure modes: one-sided bias too strong → the 186 Hz line returns (the
  autocorr oracle guards it); near-threshold gate chatter → zipper (smooth with a short one-pole
  on the gate). Ghost-note gating (soft hits self-thin below the fire rate) falls out for free.

### P-S2 — Model-only crack transient
- **Gap.** Weak modeled "crack" — a soft "thap" with no snap, exposed under `--no-samples`
  (the sample overlay masks it when samples are on).
- **Mechanism.** A few-sample HP (~4–6 kHz) noise burst at t=0, one short exponential env on the
  shared white, velocity-scaled. Build draws appended after existing snare draws.
- **Oracle.** `hp_rms(seg[0,3 ms], 5000) / rms(seg[10,40 ms])` rises vs current and scales
  monotonically across vel 40/80/120.
- **Blast radius.** 38/40. **Size/risk.** **S** (assert bounded, zero-mean — no click on silent channels).

### P-S3 — Resonant (bottom) head + shell air mode
- **Gap.** No resonant/bottom head or shell resonance → a mid-forward, bodyless snare.
- **Mechanism.** Add 1–2 higher-tuned resonant-head decaying sines + one low shell-air
  `Biquad::bandpass` (~200–450 Hz, Q 2–4, short t60) on the shared white. Once both exist, feed the
  P-S1 `λ` from the resonant-head envelope rather than the batter fundamental.
- **Oracle.** `spectral_band_rms(seg, sr, 200, 450)` over [0,50 ms] exceeds an adjacent control band
  by a set margin vs a no-body build.
- **Blast radius.** 38/40. **Size/risk.** **S–M** (keep the shell freq off the head-mode ladder or it honks).

### P-S4 — Bessel-correct head modes + beating pairs
- **Gap.** Sparse, non-Bessel head modes → the pitched component sounds static/electronic.
- **Mechanism.** Re-seat `SNARE_TONES` (186/280/330/430) on air-loaded ratios and split 2–3 modes
  into detuned pairs (fixed-Hz Δf table, like `CRASH_TWIN_DF_HZ`) so they beat.
- **Oracle.** `env_autocorr_peak` on a bandpass around the fundamental shows a 2–8 Hz beat absent
  today; re-satisfy DR-O10 level parity; hold the settled pitch fixed.
- **Blast radius.** 38/40. **Size/risk.** **S**.

*Rimshot is a new velocity-switched articulation, not a tuning tweak — deferred, needs a design decision.*

## TOMS (keys 41/43/45/47/48/50)

### P-T1 — Air-loaded mode ladder + shell/cavity body band ★ headline
The largest *design-intent-vs-shipped* gap: the v3 HLD §3 explicitly scoped "one or two
shell/body bands and slightly longer low-mode sustain," and it **was never shipped** — the tom
arms carry only a single stick bandpass (`drums.rs:1288–1315`).

- **Gap closed.** Toms are 3 modal sines at circular-membrane ratios 1 / 1.59 / 2.14
  (`tom_tones`, `drums.rs:543`) + one stick noise band. No shell body, no air-cavity resonance —
  a clean, hollow, organ-like "boop" with no wood and no air. Reads as an 808, not a drum.
- **Mechanism.** Replace the 3-mode table with a **5–6 mode ladder** on *air-loaded* ratios
  ≈ 1 / 1.5 / 2 / 2.4 / 2.9 (/3.5) (between the ideal membrane 1/1.59/2.14 and a timpani's
  2:3:4:5:6 — air loading flattens the high modes down), amps tapering ~1.0→0.12, per-mode t60
  shortening with frequency (extend the existing ×0.7,×0.5 taper). Add one wideband HP `NoiseBand`
  (HP ~1.2–2 kHz, t60 15–40 ms) as the unresolved-high-mode attack cloud. Add **one shell/cavity
  `Biquad::bandpass`** (Q 2–4) per key on the shared white: rack toms ~150–300 Hz, floor toms
  41/43 ~80–150 Hz, short t60 40–120 ms — this is the "body/wood". **Do NOT** copy the 32–48-mode
  MetalPlate approach: the ear resolves only ~5–7 membrane modes; 6 modes + a noise cloud is the
  target. If pushing past ~8 modes, switch toms from `Tone` (`phase.sin()` per sample) to the
  cheaper `dsp::Sine` rotation osc.
- **Cost.** ~+5 partials/voice + 1 biquad — negligible; toms don't stack as densely as rides.
- **Oracle (fail-first).** With glide disabled, `peak_locate`/`mag_at` at each predicted ratio →
  **≥5 distinct resolved peaks** in 100–1500 Hz, each > 5% of the fundamental (mirrors the ride-bell
  "≥4 inharmonic peaks" test; current fails at 3). `band_rms` in the 180–450 Hz shell window is
  non-trivial and finite vs a no-cavity build. Must still land settled pitch exactly on the table
  pitch (DR-O5 `peak_locate`) and must not collapse the per-strike `edge`/`jf`/`jd` variance.
- **Blast radius.** 41/43/45/47/48/50 — every tom-bearing album. Full inventory + `.opus` refresh.
- **Size/risk.** **M** (keep the cavity freq off the mode ladder or it honks).

### P-T2 — Broadband/HF attack transient
- **Gap.** Weak, narrow attack — a soft, dull onset with no stick snap (worst on floor toms).
- **Mechanism.** Add a short HP-passed click `NoiseBand` (like the cymbal `click` band) above the
  existing 900–1500 Hz mid burst.
- **Oracle.** `hp_rms(seg[0,10 ms], 3000) / rms(seg[50,150 ms])` rises vs current; finite, no click on silent channels.
- **Blast radius.** all toms. **Size/risk.** **S**.

### P-T3 — Two-head beating pair + non-rigid settle
- **Gap.** No beating; a rigid, ratio-locked pitch settle → a sterile, motionless ring.
- **Mechanism.** For the low 2–3 modes, emit a detuned resonant twin at `f+Δf` (fixed-Hz table,
  Δf 2–5 Hz on the fundamental), ~0.6× amp, ~1.4–1.6× t60. Interference gives the "wow" + a
  two-stage decay with no feedback. Keep Δf·t60 ≳ 1 so at least one beat completes on a short tom.
- **Oracle.** `env_autocorr_peak` around the fundamental shows a 2–8 Hz beat absent today;
  `t60_of` on [150,400 ms] > [0,80 ms] (two-stage decay).
- **Blast radius.** all toms. **Size/risk.** **S–M** (Δf too large → roughness; too small → no beat completes).

## CYMBALS (MetalPlate: crash 49/57, ride 51/59, china 52, splash 55)

The v3 HLD already flagged cymbals as "the most audible synthetic tell" and did them first; this
is the next layer. The residual gap is ~40% *missing bloom* + ~35% *modal density* + smaller bits.

### P-C1 — Energy-bucket cascade (the bloom) ★ headline, and the hard item
This is the item sent to the Fable specialist consult, because a wrong design here is expensive
to discover (a full re-render-diff across most albums) and the cheap oracles can green-light a
render that still sounds synthetic in three specific ways. The detailed, de-risked mechanism and
its multi-property oracle are in the dedicated subsection below.

- **Gap closed.** MetalPlate's ~40 modes decay *independently and linearly from t=0*
  (`mode.amp *= mode.decay`, `drums.rs:462`) — there is no cross-modal energy transfer, so the
  spectrum only ever darkens. A real crash *blooms*: energy injected into a few low modes migrates
  up into a dense high shimmer over 40–80 ms. Today's swell envelope on the wash fakes a level
  bump but not the low→high *spectral migration*.
- **Mechanism (outline; detail below).** Partition the modes into B≈4 contiguous log-frequency
  bands; drive each band's amplitude shape from a **feed-forward chain of leaky integrators** so
  high bands peak *after* the low band (a gamma/Erlang delay). Velocity enters via inter-band gain
  so a soft ride barely fills the top bands (a ping) while a hard crash blooms fully. It stays in
  the envelope domain, feed-forward — BIBO-stable, no DC, cannot self-oscillate.
- **P-C2 (fold in).** Also drive the wash HP band's swell env from cascade stage **c₂** (see the
  detail — amended from "top band" after the consult, because the wash is mid-weighted), so the
  shimmer migrates upward with the bloom. Near-zero extra cost.
- **Blast radius.** 49/51/52/55/57/59 — essentially every drum-bearing album. Broad refresh.
  Hats 42/44/46 and bell 53 (on the `Drum`/`cymbal()` path, *not* MetalPlate) must show **zero**
  diff — an unexpected hat diff is a bug.
- **Size/risk.** **M–L**. Failure modes and the property oracle: see the subsection below.

#### Detailed cascade design + property oracle (Fable consult, verified)

Designed by a Fable 5 specialist consult; verified against the shipped code and owned here. The
consult refuted three parts of the naive sketch — each refutation backed by a concrete failure
argument, summarized inline below.

**Structure.** Per hit at build, tag each mode with a band index `b ∈ {0,1,2,3}` from its
(jittered) frequency against fixed edges **1.5 / 4 / 8 kHz** (crash 49 spans 650–14 000 Hz).
Per render sample (extending `MetalPlate::render`, `drums.rs:454`):

```
// 3 cascade stages, unit-step driven, one shared per-hit `atk`:
c0 += atk*(1.0 - c0);  c1 += atk*(c0 - c1);  c2 += atk*(c1 - c2);
// band multipliers (m0 == 1.0 always — the low band is pure legacy):
m1 = f1 + D1*c0;  m2 = f2 + D2*c1;  m3 = f3 + D3*c2;
// mode loop UNCHANGED except accumulate per band (mode gets a u8 band index):
acc[mode.band] += mode.osc.next() * mode.amp;   // mode.amp *= mode.decay stays EXACTLY as today
// once per band, with per-band micro-AM am_b:
s += acc0 + acc1*m1*am1 + acc2*m2*am2 + acc3*m3*am3;
```

`atk = 1 − exp(−1/(τ·sr))` (i.e. `OnePole::lowpass(1/(2πτ), sr)`), τ per §profile.

- **Refutation 1 — the band envelope MULTIPLIES the intrinsic decay; it does not own the
  amplitude.** If `m_b` *replaced* `mode.amp *= mode.decay`, the tail would inherit the chain's
  slowest pole: to keep the crash gong ringing (t60_low 1.35 s → env T ≈ 195 ms) the drive would
  need τ ≈ 195 ms, and then the 8–14 kHz modes ring with t60 ≈ 1.35 s instead of ≈ 0.43 s — five
  extra seconds of sizzle; make τ short and the gong dies in ~100 ms. Ownership also quantizes 44
  graded decays into 4 band rates and breaks `choke()` (which clamps `mode.decay`, `:492`).
  Multiplicative form: `m_b` is a pure ≥0, ≤1, monotone-rising multiplier; past ~250 ms every `c`
  has settled so `m_b` is *constant* and the tail is the legacy render scaled per band — which is
  what keeps flatness / sine-tail / t60 / choke guards structurally valid.
- **Refutation 2 — drive with a unit step, not a decaying excitation.** The intrinsic per-mode
  decays already carry the energy loss; the cascade only shapes the *rise*. A step gives each
  stage the closed form `c_n(t) = 1 − e^{−t/τ}·Σ_{k<n}(t/τ)^k/k!`, making the peak arithmetic exact.

**Time constants + peak arithmetic (crash 49).** The measured envelope is the *product*
`e^{−t/T_b}·(f_b + D_b·c(t))`. Band-center intrinsic constants from the existing t60 law
(`t60(frac)=0.22+1.13·(1−frac)^0.7`, `T=t60/6.908`): T₁≈142 ms, T₂≈101 ms, T₃≈**62 ms**. With
**τ=15.1 ms** (vel 120) the product peaks land at B1≈28 ms, B2≈45 ms, B3≈51 ms; the wash-follow
(below) peaks ~60 ms. So the measured 6–12 kHz peak is ≈50–70 ms — inside the 40–80 ms target —
and the pitched partials arrive ~10 ms *ahead* of the noise wash (bronze-first, noise-second).
**Constraint surfaced:** because T₃ is only 62 ms, the top-band floor **f₃ must be ≤ ~0.12** or
the fast intrinsic decay makes the product monotone-decreasing (no bloom). Physically right — the
instant HF of a real crash is contact noise, which the wash/click already provide.

- **Refutation 3 — one smoothstep velocity gate, not a per-stage power law** (which would make the
  top band ∝ velnorm^{3p}, wrong at either end). Compute once per hit:
  `s = clamp01((velnorm−0.25)/0.75); g = s²(3−2s)` → g(127)=1.00, **g(100)=0.80, g(64)=0.27,
  g(40)=0.021**. Then per band `D_b = (1−f_b)·g^{b/3}` (higher bands need harder hits — the FvK
  amplitude signature) and `τ = 21 − 6g` ms (harder = faster *and* fuller). Because
  `f_b + D_b ≤ 1` always, `m_b ∈ [f_b, 1]` by construction: no overshoot, no makeup gain, no peak risk.

**Per-key profile (new `MetalSpec` fields):**

| key | floors f₁,f₂,f₃ | depth scale | τ law (ms) | note |
|---|---|---|---|---|
| crash 49/57 | 0.40, 0.18, 0.10 | ×1.0 | 21−6g | full bloom |
| china 52 | 0.35, 0.15, 0.10 | ×1.0 | 13−4g | thinner plate → faster; top peak ≈ 31 ms |
| splash 55 | 0.40, 0.20, 0.12 | ×1.0 | 10−3g | ≈ 24 ms; small plate |
| ride 51/59 | **0.92, 0.88, 0.85** | **×0.15** | 21−6g | m₃ rises ≤ 0.998 → **+1.4 dB max even at vel 127** |

**The ride cannot become a small crash by construction, not by tuning:** its floors leave ≤1.4 dB
of headroom at *any* velocity, and the smoothstep gate zeroes what little there is below vel ~50.
Swell stays `false`, wash untouched.

**No back-reaction (verified call).** Parity doesn't need it: since `m_b ≤ 1` the bloom is an early
*deficit* that fills to parity — it never adds energy over legacy, so there is nothing to net off
(predicted vel-100 delta ≈ **−0.2 dB**, wash dominates [0,1 s] RMS). The low-reservoir depletion a
back-reaction would model is masked by the wash exactly when it occurs, and it is precisely
pathology (b)'s doorway. If ever added, the only safe form is "feedback may only increase damping,
never gain" (`decay_eff = decay·(1 − k·c₂)`, k bounded so `t60_low_eff ≥ 0.85·t60_low`) — a v2 knob,
not v1.

**Density coexistence (amends P-C3): pairs, not triplets; the low band keeps legacy density.**
Discreteness is set by *center* spacing, beating by cluster size ≥ 2 — a third partial per center
costs 33% of the center budget for marginal roughness. The low band must stay dense outright: the
strongest-line ≤ 0.45 tail guard lives on the 700–1500 Hz lines, and thinning 12 lines to ~5 pushes
`a_max/√(Σa²)` past 0.5 — breaking our own guard. Allocation keeps total partials = legacy counts
(crash: 12 singles < 1.5 kHz + 16 paired centers = 44 partials), so partial cost is zero. Each paired
center emits two partials at `f·(1 ± Δ/2f)`, independent phases, equal total power to the two legacy
modes it replaces (parity by construction). Detune `Δf = 4.5 + 0.0011·f Hz, ×(1 + 0.25·white)` →
beats 6 Hz @ 1.5 kHz to 20 Hz @ 14 kHz. Micro-AM: per band b∈{1,2,3} one `OnePole::lowpass` on the
**shared** white (zero new draws), cutoffs 30/45/60 Hz, depth 0.12, clamp [0.5, 1.5]. Bloom (one
monotone rise), beats (5–20 Hz) and micro-AM (≤60 Hz) are three multiplicative envelopes at
separated rates that don't fight.

**Wash-follow (amends P-C2): drive the crash wash swell from c₂, not c₃** (the wash HP corner is
~2.2 kHz — mid-weighted): `env = floor_w + (1−floor_w)·c₂`, `floor_w = 1 − 0.55·g^0.8`. Intended,
audible behavior change to document: a *soft* crash's wash no longer swells (that is the linear-regime
physics). Ride/china/splash washes untouched.

**Invariant accounting.** Determinism: all new constants resolved in `MetalPlate::new` with a
fixed, velocity-independent build-draw count; render adds **zero** RNG draws (micro-AM reuses the
shared white) and no reordering → byte-identical per seed. (Build draws *do* change because pairing
restructures the loop → all V3/Brush cymbal renders change — the intended default-on timbre
improvement; V1 fingerprint freeze can't move, MetalPlate is V3/Brush-only.) Choke: provably safe
(clamped `mode.decay` falls 60 dB/10 ms; `m_b` rises at most +20 dB/50 ms → net ≈ −40 dB/10 ms).
DC/NaN: convex combinations of [0,1] inputs → bounded; lowest carrier 650 Hz with ≤60 Hz sidebands →
nothing near DC. Cost: ≈ 30 constant ops/sample/voice on top of the ~400-op 44-partial loop →
**≈ +8%**, partial counts unchanged → inside +15% and the 1.75× dense-pattern guard.

**Property oracle (14 checks).** All on mono `render_drum_kit(key, vel, 4.0, Kit::V3)`, seed 7.
Trajectory machinery (test-local, built only on `spectral_band_rms`): `E(t;lo,hi)` = spectral band
RMS over 25 ms windows, 5 ms hop, [0,300 ms], 3-tap smoothed; **peak-time = center of the FIRST
window reaching ≥0.90·max** (first-crossing, not argmax — the wash plateau wobbles ±9% under 25 ms
noise stats and argmax would wander). Bands: crash LOW 650–1400, HI 6000–12000. Thresholds marked °
are provisional — print-then-pin against the synthetics, repo style.

- *Bloom* (crash 49, vel 120): **BLOOM-1** t_pk(LOW) ≤ 12 ms. **BLOOM-2** t_pk(HI) ∈ [20,90] ms
  (china [12,70], splash [10,60]). **BLOOM-3** t_pk(HI) − t_pk(LOW) ≥ 15 ms *and*
  E_HI([2,15] ms) ≤ 0.7°·E_HI(peak) (stops a t≈0 click spike from faking it). **BLOOM-4**
  `spectral_centroid(seg[40..90 ms],800,13000) ≥ 1.18°×` the [5..30 ms] centroid (brightening);
  **BLOOM-4b** the [250..400 ms] centroid < the [40..90 ms] centroid (then darkens — guards a
  stuck-bright bug).
- *Velocity / ride articulation* (pathology c): **VEL-1** bloom_gain ≝ E_HI([40,85])/E_HI([5,20]):
  crash vel 120 ≥ 1.6°, crash vel 40 ≤ 1.25°, and gain(120) ≥ 1.5·gain(40). **RIDE-1** ride vel 90
  & 120: bloom_gain ≤ 1.2 and |t_pk(HI)−t_pk(LOW)| ≤ 10 ms. **RIDE-2** ping preserved:
  `hp_rms(seg[0..30 ms],5000) ≥ 0.8°×` the printed current value.
- *Gong survives + contamination canary* (pathology b): **GONG-1** crash vel 120,
  `drop_dB = 20·log10(E_LOW([80,105])/E_LOW([580,605]))`; `|drop_new − drop_golden| ≤ 1.5 dB`. B0
  is untouched by design, so any drift here means the bloom leaked into the low band — stop and look.
- *Density is bronze, not chord+shhh* (pathology a — deliberately not flatness-only): **DENS-1**
  line prominence `mag_at(w,f*)/spectral_band_rms(w, f*/1.12, f*·1.12) ≤ 0.55°` in the bloom window
  (f* = `peak_locate(w,2000,9000)`). **DENS-2** `env_autocorr_peak(seg[0.3..1.2 s], 1/22, 1/9)` peak
  ∈ [0.05°, 0.45°] (twins alive, no runaway single beat) — **note** this helper detrends at 15 Hz
  (`testutil.rs:201`), so it only sees the 9–22 Hz beats that live in the mid/high centers; if wash
  dilution makes it mushy, use the in-repo `twin_beat_cv` pattern (DR-O4, `drums.rs:2091`) instead —
  a deliberate, established-machinery deviation from the base vocabulary. **DENS-3** sub-band
  `flatness ≥ 0.18` in each of (1000–2500), (2500–6000), (6000–12000) over both [0.5,1.5] s and the
  bloom window (denies the guard a one-wide-band escape hatch).
- *Safety/parity:* `|mean| < 1e-3`, finite, peak ≤ 1.1× current; `rms(seg[..1 s])` within ±3 dB of
  current per changed key at vel 100.
- *Known-answer synthetics, built FIRST to calibrate the estimator:* **SYN-A** (positive: a hand-built
  low-decay + Erlang-3 high-migration spectrum → must report the bloom, fixes the ±10 ms window bias),
  **SYN-B** (negative: pure decays from t=0 = the legacy shape → all bloom checks must FAIL, and must
  also fail on the *current build's* crash — the real fail-first), **SYN-C** (density: a 6-sine chord
  must fail DENS-1/DENS-2-upper; a 16-pair field must pass — pins the ° thresholds).

**Tripwires (stop and re-escalate).** The load-bearing ones: (1) if t_pk(HI) < 15 ms, T₃ is shorter
than derived or f₃ crept up — lower f₃ toward 0.08 / raise τ; **but if it takes f₃ < 0.05 to pass,
the multiplicative model is fighting the t60 law — stop; the right-layer fix is a longer top-band
t60_high, which changes the tail and re-opens the tail guards — a design decision, not a knob.**
(3) parity fails high >+3 dB → some band's `f_b + D_b > 1` (structurally impossible unless the depth
law was edited without the floor law). (5) RIDE-1 creeps > 1.2 after crash retuning → a shared
constant leaked between profiles (depth/floor/τ must be per-key). (9) GONG-1 drifts at all → B0 was
touched → stop-the-line contamination bug, not a threshold to loosen. Full list (10) in the consult
record.

**Two residual risks to carry into the build:** the ° thresholds are predictions — pin them via
SYN-A/B/C and printed current values before asserting; and the soft-crash-wash-no-longer-swelling
change (§wash-follow) is audible and intended — *listen once* before the asset refresh, since no
oracle here scores "does a soft crash still sound like a crash."

### P-C3 — Modal-density fakes: detuned twins + per-band micro-AM
~35% of the cymbal gap — nearly as large as the bloom, and needed so C1's bloom reads as *bronze*,
not as louder noise.

- **Gap closed.** MetalPlate's log-spaced modes have only ±1.8% per-hit scatter (`drums.rs:393`)
  and no dense beating; the pitched sheen is thin and the whole crash "breathes" together instead
  of shimmering like a living surface.
- **Mechanism.** (a) Split MetalPlate's mid/high modes into **detuned pairs** — pairs, *not*
  triplets, and the low band stays legacy-dense to protect the strongest-line tail guard (full
  allocation + the Δf law in the cascade detail below). *(Note: the existing `CRASH_TWIN_DF_HZ` table
  lives on the legacy `cymbal()` path, which V3 crash no longer uses — this attaches to MetalPlate's
  own mode generation at `drums.rs:388–405`, not that table.)* (b) **Per-band micro-AM**: multiply
  each band by `(1 + m·n_b)` where `n_b` is a slow one-pole-lowpassed copy of the **shared white**
  (zero new draws — same trick as `Shimmer`). Modestly lift `tone_amp`.
- **Cost.** Twins are linear in partial count (respect the 48 cap — reject the physically-honest
  ~300-mode approach; at ~8-voice polyphony it busts the timing guard). Micro-AM: B one-poles + 1 mul/mode.
- **Oracle.** Beat depth (std/mean of a band-limited sustain envelope) is **nonzero but bounded
  < 0.5** (beating, not tremolo). Must stay *inside* the anti-sine-tail guards: `flatness ≥ 0.18`
  and narrow-line dominance ≤ 0.45. **Caveat:** `flatness` samples only 24 log bins and can pass
  while the ear still hears discreteness — the crest/beat check is load-bearing here; don't trust
  flatness alone. (This coupling is *why* C1+C3 are treated as one system in the Fable brief.)
- **Blast radius.** same keys. **Size/risk.** **M** (risk: resurrecting a singable pitched tail —
  bounded by the flatness/narrow-line oracles).

### P-C4 — Amplitude-dependent pitch glide (frequency hardening)
- **Gap.** Subtle — a real crash's modes sit sharp at loud onset and glide down as it decays.
- **Mechanism.** Track energy `E(t)` (band-0 strike env), retune `f_i = f_i0·(1 + β·E)`,
  β ≈ 0.02–0.04, via `Sine::set_freq` every K≈64 samples (phase-continuous). Clamp `f < 0.49·sr`.
- **Cost.** ~1.4 transcendental/sample. Cheap.
- **Oracle.** `peak_locate` a strong low mode in [0,20 ms] vs [300,400 ms]: `f_early > f_late` by
  10–80 cents, total < 1 semitone.
- **Blast radius.** same keys. **Size/risk.** **S**.

## Ranking

**Tier 1 — highest leverage, do first** (biggest cut in the synthetic-vs-SoA gap per unit risk;
each has audit↔survey agreement and a decisive fail-first oracle):
1. **P-S1 PhISEM snare grain** — the snare's signature defect, cheaper than the `powf` it replaces,
   zero-new-draw determinism, the crispest oracle of the lot. Do first.
2. **P-C1 + P-C2 cymbal bloom cascade** — the biggest single slice (~40%) of the cymbal gap,
   +~15% cost, unconditionally stable in feed-forward form. Highest leverage but hardest to get
   *right* — start the design early (Fable), ship carefully.
3. **P-T1 tom air-loaded ladder + shell body** — the largest intent-vs-shipped gap; turns an 808
   into a drum; cheap.

**Tier 2 — worthwhile** (clear wins, modest cost; several are needed to make Tier 1 land fully):
4. **P-C3 cymbal density (twins + micro-AM)** — ~35% of the cymbal gap; without it C1's bloom is
   just brighter noise. Pair with C1 in practice; ranked lower only for its risk against the
   anti-sine-tail oracles.
5. **P-T2 tom HF attack** — trivial, restores the stick snap.
6. **P-S2 model-only crack** — matters for `--no-samples` parity; cheap.
7. **P-T3 / P-S4 two-head beating pairs (toms + snare)** — the "alive" cue; cheap, low risk.
8. **P-S3 snare resonant head + shell** — body the crack currently lacks.
9. **P-C4 cymbal amplitude glide** — subtle but honest; cheap.

**Tier 3 — diminishing returns / skip** (with reasons):
- Energy-driven tom glide rework — toms already glide/settle convincingly; risks the DR2 oracles
  for a subtle gain.
- Longer low-mode tom sustain — fold into P-T1's t60 taper, not its own broad-blast-radius task.
- Cymbal log→linear mode redistribution — perturbs every mode, stresses the flatness/level oracles
  for moderate audibility; fold into P-C3 calibration.
- Per-band Shimmer split, ride-bell/china enrichment, cymbal attack — low album exposure and/or
  sample-masked.
- Snare rimshot — a new *articulation*; needs a design decision (defer, discuss).
- Everything in the surveys' "skip" lists — full FvK/FDTD plates, modal coupling tensors, hundreds
  of live oscillators, waveguide meshes, Hunt–Crossley wire banks, commuted convolution,
  sympathetic cross-drum buzz. Out on cost / zero-dep / architecture grounds. This whole roadmap
  is the cheap envelope-domain truncation of exactly those methods.

## Delivery notes (when a tier is built)

- One version bump per integrated task (shipped-code change), not per proposal.
- Each timbre change: run the render-diff inventory (baseline binary in a throwaway worktree vs
  the change) across every `render_opus.py::ALBUMS` MIDI; the *expected* diff set defines which
  `listening/*.opus` to refresh; any *unexpected* diff (a piano-only album changing, a hat/bell
  diff from a MetalPlate-only change, DC on a silent channel) is a bug — investigate before commit.
- The new `crest_factor`/`kurtosis` testutil helper (P-S1) is the only shared-infra addition;
  calibrate it oracle-0 style before any feature oracle trusts it.
