# PLN — loudness normalization overhaul (per-track LUFS + true-peak limit)

**Decision (Arthur, 2026-07-13):** replace per-track *peak* normalization with per-track
**loudness** normalization to **−18 LUFS** and a **−1 dBTP** true-peak ceiling; flatten
the album arc, emit R128 tags (optional-but-cheap); re-render the whole catalog and ship
opus for the 5 currently-missing albums in the same pass. Loudness fix only (the hot/
clipping raw synth is a noted follow-up, not this task).

Evidence: `wrk_docs/2026.07.13 - CR - raw render loudness measurement.md` + `raw_loudness.csv`.

## Target design
Replace `offline::normalize_to_i16(&samples, stats.peak, 0.891)` (main.rs:128) with:
1. Measure integrated loudness **I** (BS.1770-4) of the raw f32 buffer.
2. `gain = −18 − I` (dB), applied as a scalar.
3. True-peak limit the result to **−1.0 dBTP** (only the overshoot; median 2 dB, few tracks).
4. TPDF dither to i16 (reuse existing dither).

A scalar gain preserves every within-track composed arc and every `analyze.py` *ratio*
check. Only the few high-crest tracks get gentle transient limiting.

## Ordered green units (each: compiles + scoped test passes, then commit)

**U1 — `crates/ferrosintesis/src/loudness.rs`: BS.1770-4 K-weighting + integrated LUFS.**
- Stage-1 high-shelf + stage-2 RLB high-pass biquads (bilinear-transform coeffs at the
  render rate, 44100). Mean-square, channel-summed (L=R=1.0), 400 ms blocks / 100 ms hop,
  absolute gate −70 LUFS, relative gate −10 LU.
- **Oracle (EBU Tech 3341):** 1 kHz sine at −23 dBFS → −23.0 LUFS ±0.1; and a
  differential check vs the committed `raw_loudness.csv` ffmpeg values on ≥5 real renders,
  agree < 0.5 LU. Fixed-signal test needs no audio files.

**U2 — true-peak meter (BS.1770 Annex 2): 4× polyphase-FIR oversample, max |x|.**
- Oracle: a signal whose inter-sample peak exceeds its sample peak (e.g. a 0 dBFS tone
  near Nyquist) reads > 0 dBTP; a DC/low tone reads ≈ sample peak.

**U3 — true-peak lookahead limiter → ceiling.**
- Short lookahead (~1.5 ms), fast attack, ~80 ms release; gain-reduction envelope so
  output true-peak ≤ ceiling. Must be unity (no pumping) on material already under ceiling.
- Oracle: overshooting input → output TP ≤ ceiling + 0.1 dB; under-ceiling input →
  bit-near-identical (steady-state GR ≈ 0).

**U4 — `normalize_loudness(samples, sr, target, ceiling) -> Vec<i16>` + wire into CLI.**
- Compose U1–U3 + dither. Replace the main.rs:128 call. Keep a `--peak-normalize`
  escape hatch for A/B (legacy path stays available, off by default).
- Oracle: gain=0 + ceiling high ⇒ pure-scalar path bit-identical to the old scalar (proves
  the new path adds nothing but the intended gain/limit).

**U5 — `render_opus.py`: R128 tags.**
- After render, tag `R128_TRACK_GAIN` and `R128_ALBUM_GAIN` (Q7.8, ref −23 LUFS) via
  `--comment`. With a −18 bake both ≈ −5 dB, so track/album player modes agree. Cheap.

**U6 — full catalog re-render + docs + one version bump.**
- `python render_opus.py` regenerates all `listening/*.opus` incl. the 5 missing albums
  (Big Weather, Bright Matter, VIGIL, RIVERWAKE, The Long Turning). Commit per-album.
- Re-base `analyze.py` absolute-dBFS assumptions where they now measure differently
  (Bright Matter's dead `peak<0.42` / `peak>=0.99997`, and any album asserting absolute
  level); keep every `build.py --verify` green — **do not weaken oracles** (fork if green
  needs weakening).
- Bump `crates/ferrosintesis/Cargo.toml` once (minor: 0.15.3 → 0.16.0, new feature) +
  Cargo.lock. Fix `README.md` (five missing→zero; fable5 is twelve albums) and the
  `CLAUDE.md:171` MIDI-only line.
