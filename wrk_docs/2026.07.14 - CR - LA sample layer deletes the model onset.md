# Investigation — the LA sample layer deletes the model's onset

**Date:** 2026.07.14
**By:** Claude Opus 4.8 (lead)
**Trigger:** flagged during the weak-voices diagnosis; Arthur asked for an investigation + a
before/after A/B before any change. This is NOT integrated — evidence for a decision.

## The claim, verified

`LaVoice::render` (crates/ferrosintesis/src/sampler.rs:846) is a REPLACEMENT crossfade: it
fades the modeled voice in from ZERO over `[0, fade_end]` while the recorded sample fades out
over `[fade_start, fade_end]`, so the sample is meant to OWN the attack and hand over to the
model. The stated intent (sampler.rs:782) is that "the model's own (weaker) onset is masked by
the real one."

The problem: the replacement sample plays at `self.gain` (LA_* constants, 0.25–0.55), which is
calibrated for the SUSTAIN blend — it is far too quiet to carry the energy the model onset had.
So the model onset is deleted and only a fraction is put back.

**Measured** (attack-to-sustain RMS ratio, samples ON ÷ samples OFF — 1.0 would mean the layer
preserves the onset; <1 means it eats it):

```
GM071 Clarinet    0.085   <-- keeps 8% of its attack
GM060 Fr Horn     0.173
GM057 Trombone    0.191
GM068 Oboe        0.192
GM040 Violin      0.188
GM073 Flute       0.226
GM056 Trumpet     0.229
GM043 Contrabass  0.246
GM000 Piano       0.418
GM048 Strings     0.451
GM042 Cello       0.566
GM024 Nylon gtr   0.741
```

Every sampled program loses 26–91% of its onset. The layer whose entire purpose is to SUPPLY a
better transient is, net, deleting one. This affects the WHOLE catalogue (all 15 sampled
programs, every album that uses them) — which is exactly why it needs Arthur's ear, not an
agent's decision: "more attack" is a taste call, and it moves every render.

## Candidate fix (one line)

Floor the model's onset fade instead of zeroing it — keep the model's own onset and let the
sample add real transient character on top, rather than replace it:

```rust
// sampler.rs:846
let mut s = self.buf[i] * (MODEL_FLOOR + (1.0 - MODEL_FLOOR) * smooth(t as f32 / self.fade_end as f32));
```

with `MODEL_FLOOR ≈ 0.6`. At `t ≥ fade_end` the scale is 1.0, so the SUSTAIN is unchanged (no
tonal shift); only the attack window is affected. Measured retention with the floor:

```
clarinet 0.085 -> 0.591    fr horn 0.173 -> 0.523    contrabass 0.246 -> 0.618
trombone 0.191 -> 0.536    violin  0.188 -> 0.641    piano      0.418 -> 0.700
```

i.e. the onset is largely restored (retention 0.52–1.0) without touching the sustain.

## Open question / tripwire

`MODEL_FLOOR` is one global constant, but the right value may differ by family (a piano's
percussive onset wants more model than a slow bowed string). If 0.6 helps some and hurts others,
promote it to a per-`LA_*` field. Start global; split only if the ear demands it.
