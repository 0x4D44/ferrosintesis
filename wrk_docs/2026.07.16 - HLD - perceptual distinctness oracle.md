# HLD — a perceptual distinctness metric for the anti-clone oracle

- **Date:** 2026-07-16
- **Author:** Fable 5 (on-call consultant), commissioned + owned by the round-3 voice-quality lead (Claude Opus 4.8).
- **Task mode:** Design-only. Implementation + ownership stay with the lead; this HLD is the durable capture of the consult.
- **Target:** `crates/ferrosintesis/src/testutil.rs` — the `distinctness` module (the anti-clone matrix).
- **Verification status:** the load-bearing measurement (§1) is being re-run by the lead on HEAD before any code is built on it. `CAL` = a designed starting value the calibration pass must confirm; `hypothesis` = reasoned but unverified.

## 0. Why this consult happened

The round-3 plan's Wave-0 reform was "flip the distinctness matrix to samples-on, use a sustain window, and drop the raw-MAX aggregation, then re-calibrate EPS." The independent review (C2) flagged that this rests on an *unproven* assumption: that an `(aggregator, EPS)` pair exists that keeps the good families green while flagging the GM4/5 near-clone. Fable was asked to settle it — hard, high-leverage, hard-to-verify-cheaply — and to return explained reasoning **plus** a machine-checkable oracle.

**It settled it by measurement, and the answer is: the assumption is false as stated.** The matrix's *ordering* is wrong, not its threshold — so no threshold/aggregator tweak on the current features can work. The feature set must change.

**Three of the four perceived clones score higher than at least seven ear-accepted pairs.** No `EPS` can separate them; dropping MAX cannot either, because the feature vector `[centroid, flatness, odd/even, HF-fraction, h2/h1]` carries **zero temporal information** — no envelope, no attack, no modulation — which is most of what the ear uses for instrument identity. The redesign changes *what is measured* first, then aggregation, then threshold.

## 2. The metric

### 2.1 Rendering protocol — measure what the ear gets
- `make(program, key, VEL=100, SR=44100, SEED=7, samples=true)` into a **3.0 s** buffer, no note-off.
- Module gated `#[cfg(all(test, feature = "embedded-samples"))]` **plus** a runtime `assert!(embedded_samples_available())` — a silent samples-off run measures a different instrument and invalidates every threshold.
- **Probe keys {48, 72}**, aggregated by **mean, not max** (a real difference persists across register; a one-key fluke must not certify distinctness).
- **Five windows** from one render: W1 [0.02,0.12], W2 [0.12,0.45], W3 [0.45,0.90], W4 [0.90,1.70], W5 [1.70,2.80] s. The 0.90 boundary sits just past the largest LA `fade_end` (piano 0.85 s) so **W4/W5 are model-owned for every wrapped program** and W1 is sample-owned. Straddling windows are safe because every feature is computed on the audible **sum** (owner-attribution only bites metrics that assign a window to a layer). Guard with tripwire T7.
- **Two protocol views, one render:** SHORT = {W1,W2}, LONG = {W1..W5}. Pair score `S = 0.4·S_short + 0.6·S_long`. The SHORT view is what keeps the GM0/3 verdict honest: their tails genuinely diverge (the model's wide detune beats after the fade), but a listener on normal material mostly hears the shared onset and reports "same." A pair must differ *where the music lives*, not only in second three of a held note.

### 2.2 Features — 7 perceptual dimensions (anti-correlation: one physical knob earns credit on one axis)
Each dimension yields **one** bounded pair-distance; per member, `δ = |a−b|/JND` (absolute-scale members: dB, log2, log-rate) or `δ = (|a−b|/(|a|+|b|+floor))/JND` (ratio members); `d_i` = mean of its members' δ. All JNDs are `CAL`.

| dim | weight | contents | why |
|---|---|---|---|
| **D1 envelope** | 0.15 | attack time to 90% peak (log10); decay slope dB/s; sustain dB = `20log10(rms(W5)/rms(0.05–0.30))` (LONG); envelope roughness = std/mean of 10 ms env over [0.9,2.8] (LONG) | instrument *class* is largely envelope (struck vs blown vs bowed); absent today. Roughness catches tremolo/beating as a temporal fact. |
| **D2 tilt** | 0.05 | \|Δlog2 centroid\|; HF-fraction >3 kHz | brightness is EQ, not identity (GM0→GM1 is exactly this). Log2 is scale-free. **Deliberately low weight.** |
| **D3 tilt-removed harmonic shape** | 0.12 | `h_k` k=1..10, Goertzel **peak-searched ±4% around k·f0** (fixes off-grid EP partials at 1.997/3.010/2.82/4.18), dB rel loudest, floor −35 dB, subtract the LS line in (log2 k, dB); distance = ΔdB-residual RMS, per-k significance-weighted | "spectral shape that survives an EQ change" — formant/drawbar/reed structure. Subsumes h2/h1. |
| **D4 noise/tonality** | 0.09 | flatness(500–9000); harmonic-fraction = Σhₖ power/total; log kurtosis | breathiness, grain, inharmonic share |
| **D5 modulation** | 0.12 | AM: `env_autocorr_peak_detrend` on the **f0-bandpassed** signal (Q≈8), lags 0.08–1.2 s (0.83–12 Hz) → depth, and (if both depths>0.25) \|Δlog2 rate\|; FM: `fm_mod_rate` 3–9 Hz depth. SHORT: omit (too few cycles) | tremolo, Leslie, vibrato, **unison beating**. Measuring AM on the f0 *band* is the anti-flange defence: true detuned-unison beating makes periodic f0-band AM; a static comb (flange) makes tilt but **no** AM. |
| **D6 onset** | 0.12 | over [0,0.12]: log2 centroid; HF-fraction; flatness; onset-energy share = rms(0–0.12)/rms(0–2.8) | the attack is where the ear decides what an instrument *is*. Pairs sharing an LA zone score ≈0 here (honest — forces them to earn distinctness elsewhere). |
| **D7 band-spectrogram gestalt** | **0.35** | 16 log-spaced bands 100 Hz→10 kHz (`band_rms`, Q≈3.5 — O(N), not `spectral_band_rms`) × the protocol's windows → cell dB rel loudest cell; drop cells where **both** < −40 dB; `d7 = Σ w_cell·\|ΔdB_cell\|`, `w_cell` = pair-max linear-power share | the workhorse: *where the energy is and how it moves*. **Energy weighting is load-bearing:** GM4/5's real partial differences are −10..−20 dB and short-lived → low-weight cells → small d7; sax 64/65's formant/register differences move the *loudest* cells → large d7. This is the audibility weighting the current metric lacks. |

### 2.3 Aggregation — saturating bounded-influence sum
```
S_proto = Σ_i  W_i · min(d_i, 2.0)        // W = [.15,.05,.12,.09,.12,.12,.35], Σ=1
S_key   = 0.4·S_short + 0.6·S_long
S(a,b)  = mean over probe keys of S_key    // NOT max
```
- `min(d_i, 2)` caps any one dimension at `2·W_i` — a saturated brightness axis contributes ≤0.10, so GM0/1 cannot pass on tilt alone. The *sum* rewards breadth (genuinely different instruments differ moderately on several dimensions at once). This is a Huber-style bounded-influence estimator.
- Rejected alternatives, with reasons: **L2/RMS** still lets one axis dominate and double-counts correlated features; **hard k-of-n** is the binary-saturation special case but adds cliff-edge flakiness; **Mahalanobis / family-z-scoring** — 8 members give no covariance, and family-relative normalization couples a pair's score to unrelated members (fixing GM2 would move GM4/5); the correlation problem it would solve is handled structurally by the dimension grouping. **Byte-identical ⇒ exactly 0** at every stage.

### 2.4 Threshold — set by controls, then frozen
- **NEG (must score < BAR on HEAD):** (0,1), (0,3), (4,5), (29,30).
- **POS (must score ≥ MARGIN_P = 1.3·BAR):** the tightest ear-accepted pairs (64,65), (40,44), (16,23), (17,21), (83,87), (48,49), (11,12). *(caveat (40,41) — §6.)*
- Procedure (once, then freeze): implement → run `print_perceptual_matrix` on HEAD → require the gap `1.25·max(NEG) ≤ BAR ≤ min(POS)/1.3` non-empty → freeze BAR at the geometric mean (hypothesis: 0.30–0.40). If empty: one documented weight/JND revision with a physical diagnosis, re-run once; if still empty, that pair is ear-adjudicated (§6). **Do NOT iterate weights to green** — that is how green-but-wrong oracles are born.

## 3. Oracle spec (machine-checkable)
A **new** `perceptual_distinctness` module *alongside* the existing `distinctness` matrix (do not delete it — it keeps a different job: a model-preset-layer tripwire that catches byte-level arm collapse regardless of sample masking; document its blind spot in its header). Six tests:
1. `every_gm_family_sounds_free_of_unexpected_clones` — within-family pairs `score ≥ BAR` unless ALLOW'd. **Fail-first check:** empty ALLOW must fail on exactly (0,1),(0,3),(4,5),(29,30) and nothing else — that observation *is* the RED-on-HEAD deliverable; commit with those four `Collapse` entries (the repo's existing stage idiom).
2. `allowlisted_perceived_clones_are_still_clones` — every `Collapse` entry `score < BAR`; the moment a voice fix lands this fails and forces the entry's deletion (the mechanical GREEN transition).
3. `perceptual_bar_is_calibrated` — every POS pair `score ≥ MARGIN_P` (the no-false-alarm side + drift alarm).
4. `byte_identical_arms_score_zero` — `score(29,30) < 1e-6` while the shared DRIVE arm exists.
5. `metric_is_a_premetric` — `score(a,a)==0`, symmetry, all features finite (catches NaN/denormal/asymmetric-formula bugs).
6. `sample_layer_engaged_at_probe_keys` — for each LA-wrapped program (0,1,3,24,40,41,42,43,48,49,56..61,68..71,72,73,110): samples-on vs -off differ in W1 RMS by >0.5 dB at ≥1 probe key (guards `LaVoice::wrap`'s silent bare-model fallback when a repitch leaves the 0.5–2.05 zone window).

Plus `print_perceptual_matrix` (`#[ignore]`) printing each pair's `S`, its 7 per-dim distances, and the control tables. **Reused helpers already in testutil.rs:** `band_rms`, `env_autocorr_peak_detrend`, `fm_mod_rate`, `peak_locate`, `t60_of`, `kurtosis`. **Cost:** ~256 renders × 3.0 s ≈ 4.3× today's audio-seconds → est. 15–40 s debug (acceptable for `cargo test --workspace`; if not, cut D7 to 12 bands before cutting keys/windows).

## 4. Tripwires (stop and re-escalate)
- **T1** wrong-path: test 6 fails or module compiles with samples unavailable → everything downstream invalid.
- **T2** GM4/5 lands above BAR (closest call): the *one* sanctioned lever is D7's weighting exponent (power→power^1.5 share) or JND 2.5→3 dB, with POS re-checked in the same run; else ear-adjudicate.
- **T3** single-salient-cue legit pairs max near `2·(W5+bits)≈0.3` → any non-ALLOW pair in **[0.8·BAR, BAR)** triggers a one-time ear A/B, never a threshold nudge. (40,44) is the likeliest first.
- **T4** GM3-fix false credit: if the honky rebuild earns green via D2/D7 with `d5≈0`, the dual-read is flanging not beating → **reject the fix, not the metric.** Beat rate scales with f0 (≈0.9 Hz key48 — marginal; 3.7 Hz key72 — solid), so key 72 is the load-bearing beat probe.
- **T5** frozen-bar drift: tests 2/3 pin both sides; a trip on untouched pairs → investigate before committing, recalibrate only deliberately.
- **T6** D7 band blur (Q≈3.5) under-credits a static-detune-only pair (no beat) → ear-adjudicate if one appears.
- **T7** window-ownership: add a one-line test `every LA fade.1 < 0.90` — a future fade retune past 0.90 silently re-owns W4.

## 5. Compatibility with per-voice "is it really X" checks
The per-(program,key) `Passport` is a reusable timbre identity card: absolute range assertions on its fields express class identity (church organ: sustain ≈0 dB, low flatness, slow attack; nylon: attack <15 ms; strings: FM depth 4–7 Hz). The second complaint family becomes cheap follow-on oracles over the same protocol — subject to the limit below.

## 6. Honest limits (where a human ear is unavoidable)
1. The metric orders *amount* of audible difference; it cannot judge whether a difference is the *kind* that changes instrument identity — salience weights are heuristics. Minimized human protocol: for any dead-zone (T3) or calibration-overlap pair, render both at keys 48/60/72 (~1.5 s), Arthur answers same/different **once**, recorded as `ALLOW … Why::EarAccepted("date: <one line>")` or as a voice-fix requirement. One listen per adjudicated pair, ever.
2. **(40,41) is a suspect positive control** — GM41 is `Bowed(41)` in the *violin* bank (viola proxy); samples-on, its onset is byte-shared with GM40. The new metric may legitimately flag it — likely a true positive the old metric missed, not a false alarm — but only the ear can rule. Adjudicate before treating it as a calibration anchor. (Same class: 48/49, 72/73 shared banks — the lead's C1 finding.)
3. Absolute realism ("does GM40 sound like a violin") is not pairwise; passport ranges encode class, not realism — listening-session territory.
4. Ear-time observations from the HEAD run, outside this deliverable: GM 58/60 = 0.187 (tuba vs french horn, surprisingly tight); GM 16/17 = 0.161 (organ family's tightest).

## 7. Two-tier refinement *(addendum — supersedes the single-BAR threshold of §2.3–2.4)*

A second consult pass proved, with **two feature-space inversions**, that a *single* global (aggregator, threshold)
**cannot** simultaneously keep the good families green, red GM4/5, and correctly call the shared-bank pairs:

1. **Onset-credit inversion.** GM4/5 are **model-only** (no LA wrap) so their onsets differ and D6 credits them; GM72/73
   **share** the flute bank (`flute_bank()`, no program arg) so D6 = 0. Under one metric the perceived-clone 4/5 can
   out-score the maybe-distinct 72/73 on onset alone — a wrong *ordering* no threshold fixes.
2. **Modulation inversion.** GM0/3 (piano detune-beat) and GM40/44 (string tremolo) differ from their siblings through
   the *same* numeric measurement (f0-band AM, D5); the ear calls one a clone and one distinct. The features carry no
   instrument-context token to separate them — **irreducible on this feature set.**

**The two-tier resolution** (objective, self-maintaining — no hardcoded pair labels):

- **Classify each pair at test time:** `is_shared_onset(a,b) := rms(W1_a − W1_b)/rms(W1_a) < 0.02 at BOTH probe keys`
  — byte-identical sampled onsets drive this ~0. Auto-reclassifies if a voice later gets its own bank.
- **Tier 1 — independent-onset pairs** (brass 56-63, reed 64-71, EP 4/5, drive 29/30…): the **full** 7-dimension
  metric vs **BAR_full**. Preserves the `epsilon_is_calibrated_on_the_good_families` intent (good families keep their
  genuine onset differences).
- **Tier 2 — shared-onset pairs** (0/1, 0/3, 40/41, 48/49, 72/73…): credit **only the model-owned tail** (W3–W5) on a
  restricted set — **keep D1 envelope, D3 harmonic-shape, D4 noise; drop D6 onset, D2 tilt, and D5 modulation from
  credit** — vs **BAR_tail**. Asks the correct question: *given identical onsets, does the model inject a real
  instrument difference in the sustain?*
- **Dropping D5 from Tier-2 credit is the key lever:** it reds GM0/3 (whose tail differs almost only via detune-beat)
  AND **imposes a voice-design requirement** — a shared-onset pair earns distinctness only through envelope/harmonic/
  noise character, never detune or tremolo alone. So the honky-tonk fix *must* be a genuine brighter/harder/shorter
  tack-piano timbre, not a detuned grand. The metric drives the correct fix instead of rubber-stamping a cosmetic one.
- **Per-tier calibration:** NEG_full={4/5, 29/30}, NEG_tail={0/1, 0/3}; POS_full={64/65, 16/23, 17/21, 83/87, 11/12,
  brass/reed mins}; **POS_tail anchored on nothing** — 48/49 and 72/73 are *reported, not asserted*, until one ear
  A/B confirms each direction.
- **The three shared-bank pairs are contingent controls, not anchors:** each is legit-distinct **iff** the model
  injects a nameable tail difference. Expected calls: **40/41 = probable defect** (viola is a repitched-violin proxy →
  reds → fix the viola body/formant, don't relax the metric); **48/49** legit iff a real attack/swell-time (D1) gap;
  **72/73** legit via recorder's purer/breathier D3+D4. **40/44** (model-only tremolo strings) is the residual honest
  limit — distinct only by modulation → an `ALLOW … Why::EarAccepted` entry with one recorded human verdict.
- **New tripwires:** **T8** — a nominally shared-bank pair that *fails* `is_shared_onset` = silent bare-model fallback
  (repitch outside `LaVoice`'s 0.5–2.05 zone) → investigate routing, don't reclassify. **T9** — if calibration finds
  0/3 out-scores 72/73 *even after* dropping D5, the tier split has failed for shared-onset pairs → the whole family
  becomes ear-adjudicated (report it; never tune weights to hide it). Plus test `onset_tier_classification_is_stable`
  freezing which pairs are shared vs independent, so a future bank change can't silently move a pair between tiers.

**Honest limit, sharpened:** numeric features cannot separate a shared-onset *modulation-only clone* (0/3) from a
shared-onset *modulation-only distinct instrument* (40/44). The two-tier design shrinks the ear-dependent set to
exactly that class — a bounded handful (40/41, 48/49, 72/73, 40/44, and 4/5 if it under-reds), one same/different
listen each, carried by the oracle thereafter.
