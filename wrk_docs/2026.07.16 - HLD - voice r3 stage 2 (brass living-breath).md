# HLD — Voice R3 Stage 2: brass living-breath (GM 56–60)

**Status: SELF-APPROVED** (adversarial + Codex reviews folded in — see §9)
**Author:** Claude (Opus) · **Date:** 2026.07.16 · **Effort:** M · **New samples:** no

## 1. Problem
Round-3 audition feedback on natural brass: *"attacks good, holds synthetic."* Root cause
(measured, roadmap PLN on trunk): the **sustain is frozen**. With no authored CC/aftertouch
(every committed album MIDI authors none), all timbre drivers are constant during the hold —
`bloom`=1.0, `pressure`=1.0, `growl`=0, `bite` decayed. The radiated spectrum does not move:
centroid p5–p95 wander **2–13 Hz** (under one FFT bin) vs SC-55's **88–191 Hz** (7–75× less);
RMS ripple **0.1–0.4 dB** vs SC-55's **0.5–4 dB**. Solo naturals additionally have **no
vibrato** (`BR_DEFAULTS.vib=(0,0,0)`). A perfectly periodic held waveform is the textbook
"synthetic" tell — precisely why the LA+rasp *attacks* are praised and the *holds* are not
(LA is onset-only).

## 2. Goal & non-goals
**Goal:** make the **solo natural-brass** sustain (56–60) *breathe* — a shallow, living,
aperiodic wander of the whole timbre — moving the centroid wander off the frozen floor
toward SC-55's band, without an audible LFO "wobble" and **without touching the praised
attack**.

**Non-goals (explicit):**
- **Section 61** — excluded (see §4.2 / review F1): its 5 players share one `l`, so a single
  breath would pump the whole unison coherently; it is also already alive (5-player detune +
  its own 5 Hz vibrato + onset scatter) and was never measured as frozen.
- **Synth brass 62/63** — deliberately synthetic; must render **bit-identical**.
- Secondary spectral-balance miss (h2–h5 ~17 dB weak vs real). Bigger/riskier body-EQ;
  **parked** — liveness first (roadmap judges it recovers most of the perception).
- **Pitch** — left to the existing per-player `Drift` (~2.6-cent random walk); folding breath
  into pitch would risk a coherent pitch+timbre wobble and add a knob. Revisit only if the
  prototype sounds pitch-static.
- Any new CC/controller semantics (default-on timbre improvement, not a controller feature).

## 3. Reference philosophy (Arthur's decision)
**Physical realism, SC-55-anchored.** SC-55 is the clean measurement anchor; the target is
physical plausibility. Real brass breath/embouchure micro-variation is a **stochastic**
(not periodic) drift that moves brightness, drive, and level *together*. The modulator is
therefore aperiodic noise, not an LFO, landing the measured wander inside SC-55's band.

## 4. Approach
`l` (the BR2 loudness scalar, `control_tick` voices.rs:9215) is the single scalar that drives
the whole brass timbre: lip cutoff `fc`, shaper index `kws`, the BR12 rasp `cascade_amt`, and
the radiated `out_lp` corner (`out_base·2^(out_oct·bright)`, out_oct=4.2 — **very** sensitive).
Modulating `l` is the one-point intervention that makes the whole spectrum wander coherently.

### 4.1 The living-breath signal — smooth value noise (not sines)
`breath_val ∈ [-1,1]`, **zero-mean, aperiodic**, from a small `BreathNoise` generator:
sample-and-hold random targets in [-1,1] (drawn from a **throwaway rng** seeded `seed^SALT`),
smoothstep-interpolated across ~`BR_BREATH_HOLD_S`-second segments. Dominant timescale ~2.3 Hz
(**below** the ~4 Hz fluctuation-strength peak — the "shaking" band that plagued the Stage-1
flues), but with a spread, non-repeating spectrum — genuinely *living*, not a tremolo.

- **Why noise, not two sines (review F/#6).** Real breath is stochastic. Two incommensurate
  sines still leave two narrow modulation lines whose 0.8 Hz beat, once per-note rate-jitter
  is applied, can drift to a ~0.37 Hz slow-swell tell (depth pulsing to zero once per beat).
  Value noise is aperiodic by construction — it dissolves the wobble/beat/swell failure mode
  at the root, is a better breath model, and gives clean depth semantics (value bounded to
  [-1,1] ⇒ `breath_depth` *is* the max fractional L excursion). Codex explicitly recommended
  "smoothly interpolated random targets."
- **Deterministic, no `self.rng` draw (review F6).** `BreathNoise` owns its rng; the breath is
  advanced every control tick regardless of depth, and `self.rng`'s stream (saw phase, vib,
  breath NOISE line 9376, chiff) is untouched. So a breath-on vs breath-off render differs by
  **only** the deterministic multiply — the differential oracle and existing determinism hold.

### 4.2 Fold-in, self-gating, and attack ramp
`breath_depth: f32` field, set in `Brass::new()`:
`breath_depth = if oversample && spec.players == 1 { BR_BREATH_DEPTH } else { 0.0 }`
⇒ exactly the **solo naturals 56–60** (single-player, oversampled). Section 61 (players=5) and
synth 62/63 (not oversampled) get 0.

In `control_tick`, after base `l` and *before* the `.min(1.3)` clamp:
```
let ramp   = smoothstep(BR_BREATH_RAMP.0, BR_BREATH_RAMP.1, self.t as f32 / self.sr);
let breathe = 1.0 + self.breath_depth * ramp * self.breath.next();   // ramp=0 pre-onset ⇒ ×1.0 exact
let l = (base_l * breathe).min(1.3);
```
- **Attack stays bit-identical (review #4).** `ramp = 0` for t < `BR_BREATH_RAMP.0` (~150 ms),
  so `breathe = 1.0` *exactly* (0·x=0) through the whole onset+bloom — the praised attack is
  untouched, and the breath emerges only as the note settles. Oracle-guarded (§5).
- **Self-gating, no hot-path branch.** Synth/section (`breath_depth=0`) ⇒ `breathe=1.0` ⇒ `l`
  unmodulated. Synth is *also* structurally inert to `l` (k-span 0, no out_lp, brassiness 0,
  not oversample) — unchanged twice over. Oracle-guarded.
- **Clamp headroom (review F4).** At sustain `base_l ≤ ~1.0` (vn=1, bloom=1, press=1, bite=0)
  with a 1.3 clamp ⇒ ≥0.3 headroom ≫ the ≤0.035 breath, so the multiply never clips
  asymmetrically today. Invariant commented at the fold-in; revisit if depth is raised or CC11
  is ever authored.

### 4.3 Constants (first-cut; depth is the one ear-tunable knob)
```
const BR_BREATH_DEPTH: f32 = 0.025;       // fractional L modulation (calibrated — see below)
const BR_BREATH_HOLD_S: f32 = 0.22;       // value-noise segment (dominant ~2.3 Hz, sub-4 Hz)
const BR_BREATH_RAMP: (f32,f32) = (0.15,0.40); // breath fades in after the onset (attack bit-exact)
const BR_BREATH_SALT: u32 = 0x8BEA_7401;  // throwaway-rng seed offset (no self.rng draw)
```
**Calibrated to 0.025** by the build-iteration re-measure (0.06 would overshoot — the out_oct=4.2
corner gives ±~3 semitones of cutoff swing there; reviews #2/#3): at 0.035 the sustain centroid
wander measured **172 Hz** (top of SC-55's 88–191 band), at **0.025** it measures **123.5 Hz**
(central) vs a **3.6 Hz** frozen baseline — a 34× differential, RMS ripple 0.32 dB (no tremolo).
Arthur's ear signs off the final depth + the wobble question. Per-preset outliers to watch at
the A/B: **muted trumpet 59** (breath's out_lp swing sits under the mute's +7 dB 1600 Hz peak →
amplified) and tuba 58 (brassiness 0.35, darker chain). One global depth for Stage 2; per-preset
scaling is a follow-up only if the A/B diverges.

## 5. Testability & oracles (tests-first)
Isolation strategy (review #3/F4): **`render_brass` renders FROZEN** (`breath_depth=0`), so the
~16 existing static-timbre oracles (BR-O1…O16) keep testing their invariant property free of
breath-phase flake — correct unit isolation, since the breath is an orthogonal axis with its
own oracle. Production (breath-on) is validated by the render-diff inventory + the new oracles
+ Arthur's ear. Directly-constructed differential oracles (BR-O5 growl, BR-O7 section) keep
breath on — robust (common-mode / different band); force `=0` only if one flakes.

New oracles:
- **O-LIVE `brass_sustain_breathes_off_the_frozen_hold`** — the money oracle (measures the
  *complaint*: centroid motion, not level). Slide `spectral_centroid` (window 2048, hop 1024)
  over the sustain [0.5,1.9] s of a trumpet C4 mf render; take **p5–p95 spread (Hz)**. Compare
  a breathing render vs a frozen (`breath_depth=0`) render, same seed. Assert: `frozen_wander <
  FROZEN_CEIL` (baseline is frozen) **and** `live_wander ≥ K·frozen_wander` (K≈4) **and**
  `FLOOR ≤ live_wander ≤ CEIL` (in-band, not a wild wobble — CEIL sized off SC-55's top).
  Plus a **tremolo ceiling**: sustain short-time RMS ripple stays below a small bound (the
  breath must move *timbre*, not become a level tremolo), and `live` is all-finite / peak-bounded.
  Floor/ceil pinned from the implementation's measured frozen baseline + the SC-55 88–191 Hz
  band.
- **O-SCOPE `brass_living_breath_scope_and_inertness`** — blast-radius guard. (a) Constructor
  gate: `breath_depth>0` for 56 & 60 (solo naturals), `==0` for 61/62/63. (b) Structural
  inertness: forcing `breath_depth = BR_BREATH_DEPTH` on synth **62 AND 63** renders
  bit-identical to `=0` (proves `l` is dead for synth even if wired on later — review F5/#7).
- **O-BREATHNOISE `breath_noise_is_bounded_zero_mean_aperiodic`** — unit-test the generator
  directly: value ∈ [-1,1], mean ≈ 0 over many samples, and not periodic (no exact repeat /
  autocorrelation not pinned to a single lag).

## 7. Decision log
- **D1 — Modulate `l`, not each driver.** One fold-in makes fc/kws/cascade/out_lp wander
  coherently; minimal and physically faithful.
- **D2 — Value noise, not sines.** Aperiodic by construction ⇒ no beat/slow-swell wobble tell;
  better breath model; clean depth semantics. (Supersedes the roadmap's "reuse the sine
  primitive" — the review showed periodic sines carry a residual wobble risk we can't cheaply
  self-detect.)
- **D3 — Solo naturals 56–60 only** (`oversample && players==1`). Excludes the section
  (coherent-pump) and synth; API-free (no BrassSpec field).
- **D4 — Throwaway rng.** Keeps `self.rng` aligned so the differential oracle + determinism hold.
- **D5 — Ramp the breath in after the onset.** Attack bit-identical; breath emerges in the hold.
- **D6 — Self-gate via `breath_depth` field.** No hot-path branch; doubles as the oracle's
  frozen-reference knob (testability by design).
- **D7 — Centroid-wander oracle, not envelope-AM.** Measures the actual complaint (timbre
  motion); envelope-AM demoted to a tremolo ceiling.
- **D8 — `render_brass` frozen.** Isolates the ~16 static-timbre oracles from the new axis.
- **D9 — Park pitch + secondary spectral balance.** Liveness first; both are separate slices.

## 8. Risks
- **Wobble / slow-swell (aesthetic) — primary residual.** Mitigated by aperiodic value noise +
  sub-4 Hz + shallow depth + the centroid ceiling; final sign-off is Arthur's A/B (must include
  muted trumpet 59 and horn 60).
- **Depth calibration.** First-cut 0.035; one build-iteration re-measure + ear. 59/58 are the
  expected outliers.
- **Existing-oracle churn.** Small; fixed by `breath_depth=0` isolation, never by weakening.
- **Render-diff contamination.** Guarded by O-SCOPE + the inventory; throwaway-rng + solo-gate
  keep synth-brass, section, and non-brass provably untouched.

## 9. Reviews (STEP 3 adversarial ×2 + STEP 4 Codex external — findings & resolutions)
Two independent adversarial reviewers (DSP/oracle-validity; blast-radius/simplicity) + Codex
(gpt-5.6-sol, xhigh, different model family). Strong convergence. Adopted:
- **[CRITICAL, all three] O-LIVE measured amplitude AM, not centroid** — the intervention
  modulates timbre, not level (`sum·amp·e`, fixed `e`); an envelope-AM oracle false-passes a
  tremolo and could false-fail a good wander (amplitude AM ≈ the frozen floor). → **Rewrote
  O-LIVE as a centroid-wander p5–p95 differential** (reusing `spectral_centroid`), floor+ceiling,
  envelope-AM demoted to a tremolo ceiling. (D7)
- **[MAJOR, Codex#5 + F1] Section 61 coherent pump** — 5 players share one `l`. → **Excluded 61;
  solo naturals only.** (D3, §2)
- **[HIGH, Codex#4] Breath touched the praised attack** (random phase from tick 0). → **Ramp-in
  after the onset**, first 150 ms bit-identical, oracle-guarded. (D5)
- **[MED, Codex#6 + F7/F8-noise] Two sines still periodic** (0.8 Hz beat → 0.37 Hz swell under
  jitter). → **Value noise.** (D2)
- **[MAJOR, F4/#3] Zero-mean does not protect ratio oracles** (nonlinear `l→timbre`; windows <
  the 1.25 s beat) — highest-risk existing oracle BR-O3 (the-waa, 70 ms window at 0.30–0.37 s).
  → **`render_brass` frozen** isolates all static-timbre oracles; treat breaks as possible
  regressions. (D8, §6)
- **[MINOR, F4/#3] Clamp asymmetry near l=1.3** → headroom checked + invariant commented. (§4.2)
- **[NIT, F5/#7] Test synth 62 AND 63** → O-SCOPE covers both.
- **[calibration, F2/F3/#2] Depth 0.06 likely overshoots; 59/58 outliers** → first-cut lowered
  to 0.035; A/B must cover muted trumpet + horn. (§4.3, §6.3)
Not adopted: per-preset depth field on `BrassSpec` (F3) — a breaking struct change; the
`players==1` solo-gate delivers the needed scope API-free (F6). One knob for Stage 2.
