## 1. Problem & why the fork
The choir vowels (GM52 aah / GM53 ooh / GM54 synth-voice, a `ChoirV2` voice) are "hollow/synthetic":
a **parallel** bandpass formant bank leaves a deep inter-formant notch (GM52 aah h3 measures −25 dB
dry, worse in-mix, vs SC-55 −14) and is uniformly ~700 Hz too bright (aah centroid 1667 vs SC-55 940;
GM54 inverted — brightest at 2129 vs SC-55's darkest 568). The cheap-fix reviews proved Q-widen +
glottal tilt can't fill the notch (it's the parallel bank's structural valley, not just a ~5 dB phase
zero) and the tilt worsens it. **Arthur directed the fork.** A prototype confirms the cure:

**A Klatt all-pole SERIES CASCADE** of the 3 vowel formants (each a unity-DC 2-pole resonator, output
of one feeding the next) MULTIPLIES into a connected vocal-tract envelope with **no inter-formant
zeros** — measured (prototype, dry, dB re f0 / centroid Hz):

| GM / key | metric | baseline | **cascade** | SC-55 |
|---|---|---|---|---|
| 52 aah k60 | h3 (notch) | −24.9 | **−14.7** | −14.4 |
| 52 aah k60 | centroid | 1667 | **847** | 940 |
| 53 ooh k60 | h3 | −31.8 | **−30.4** (stays dark) | −37.9 |
| 54 k60 | centroid | 2129 | **930** | 568 |

It fills the notch, matches brightness, keeps dark vowels dark (signed residues failed all three), and
is **RNG-neutral** (no-env render bit-identical to baseline — the cascade draws no rng). Unity-DC
resonators pass the fundamental → the `chest` crutch becomes largely redundant (bonus for CH2-O4).

## 2. Goal & non-goals
**Goal:** replace the parallel vowel-formant bank with a 3-resonator cascade and **retune** GM52/53/54
to SC-55 — aah/eh notch filled (h3 ≈ −14/−16 at keys 60/55), centroids matched (aah ~940, ooh ~800,
GM54 ~570, the darkest), vowel identity + ordering preserved. **GM54-only.**
**Non-goals:** the singer's-formant cluster + chest branch (stay **parallel**-added — only the 3 vowel
formants become a cascade); any other voice (choir-scoped; `ChoirV2` has its own rng → RNG-neutral);
per-register formant TABLES (a single per-vowel table is the target; if it can't match both registers,
that is the escalation trigger, see §8).

## 3. Reference (SC-55-anchored, prototype-validated)
aah centroid ~940 (notch h3 ~−14); ooh ~800 (dark, h3 stays ~−38); GM54 ~570 (the DARKEST, ordering
GM54 < ooh ≤ aah). Notch valley (fixed ~780 Hz band) −14/−16 dB at keys 60/55, two-sided (not hollow,
not overshot-bright).

## 4. Approach
1. **New primitive** `dsp.rs`: `Biquad::resonator(freq, q, sr)` + `retune_resonator` — an all-pole
   unity-DC 2-pole (`r = exp(-π·(freq/q)/sr)`, `a1 = -2r·cosθ`, `a2 = r²`, `b0 = 1+a1+a2`, `b1=b2=0`).
   ~20 lines, mirrors the existing `Biquad::bandpass`/`peak` builders.
2. **`Ch2Tract`** (voices.rs:5887): `bands[0..3]` (vowel) built as **resonators**; `bands[3..5]`
   (singer's cluster) stay `bandpass` (parallel).
3. **Render** (voices.rs:6141-6146): the vowel path becomes a **cascade** —
   `let mut vy = x; for k in 0..3 { vy = tr.bands[k].process(vy); } y += vy * vowel_out;` — the
   singer's-formant loop (6144-6146) + chest (6154) stay parallel-added, unchanged.
4. **`control_tick`** (6094-6097): retune the 3 resonators (same `fscat`, same cadence) via
   `retune_resonator`.
5. **RETUNE (the real work):** per-vowel formant freqs + Qs so the cascade delivers SC-55's centroid +
   notch + vowel identity; `vgains` collapse to a single per-vowel **output trim** (`vowel_out`, no
   longer per-formant); recalibrate `CH2_AMP` (the cascade changes overall gain); **reduce/remove the
   `chest` branch** (the cascade passes the fundamental). Calibrate by an eprintln sweep + re-measure
   at **keys 60 + 55** for all 3 programs vs SC-55 (centroid + notch + ordering).

## 7. Decision log
- **D1 — Series cascade, not signed residues** — the prototype proves the cascade reaches SC-55 on all
  three metrics where signed residues fills only ~40% and HARMS the ooh vowel.
- **D2 — Only the 3 vowel formants cascade; singer's-formant + chest stay parallel** — the cluster is
  a genuine parallel resonance; the cascade's unity-DC fundamental makes chest largely redundant (trim it).
- **D3 — `vgains` → single per-vowel output trim** — per-formant parallel gains are meaningless in a
  cascade; identity/brightness now come from formant freqs + Qs.
- **D4 — New CH2-O7 notch oracle, two-sided + fixed-frequency + SC-55-anchored** (−14, not MU-80's −22).

## 8. Risks
- **Retune intractability — the primary risk.** A single per-vowel formant table must match SC-55's
  centroid + notch + ordering at BOTH registers for 3 vowels, AND keep eh(GM54) distinct from aah(GM52)
  (the prototype had them too close at 930/847) without re-introducing brightness (the upper-bound O7
  guards it). If a single table can't (needs per-register interpolation — a bigger subsystem), **STOP +
  escalate** rather than ship per-register tables unreviewed. Calibration is delegated to a measurement
  sweep; I own the final coefficients.
- **Oracle re-pin integrity** — re-derive every moved threshold from SC-55/MU-80, never the prototype
  render; if a recal can only pass by weakening the discrimination, STOP.
- **Broadest blast radius of the four slices** — the default sound of every 52/53/54 note changes;
  render-diff + Arthur's ear are the gates (the most ear-dependent voice, now with the biggest change).
