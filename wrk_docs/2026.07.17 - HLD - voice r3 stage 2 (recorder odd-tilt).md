# HLD — Voice R3 Stage 2: recorder even/odd inversion (GM74)

**Status: SELF-APPROVED** (2 adversarial + Codex folded in — §9; direction roadmap-sanctioned,
degree needs Arthur's ear) · **Author:** Claude (Opus) · 2026.07.17 · Effort: S–M · Samples: no

## 1. Problem
The GM74 recorder (a `Wind` additive-bank voice; `RECORDER.harm[6]` = h2..h7 re h1 IS the
spectrum, voices.rs:6692) is **even-dominant** (`[0.16,0.08,0.02,0,0,0]`: h2>h3>h4, dead after h4).
Real SC-55 is **odd-tilted**: overtone even/odd (h1 excluded) ferro **2–3×** vs SC-55 **~0.3**,
h3 the dominant overtone, an odd ladder to ~h10. Inversion ~7–10×. The round-3 roadmap (Arthur-
approved) flags this and the defect-encoding oracle that hard-asserts `h2 >= h3`.

**Physics note (corrected — reviews):** a recorder is an **OPEN** pipe (window + open foot →
all harmonics; the odd-only instrument is the clarinet reed). The odd-tilt is the SC-55 patch's
JET/VOICING property, not a bore class. So this is a **SC-55-anchored tonal match**, NOT "make it
a stopped pipe." The round-2 even-rich choice (voices.rs:6688) is reversed per the roadmap + SC-55.

## 2. Goal & non-goals
**Goal:** rewrite `RECORDER.harm` so the delivered spectrum matches SC-55's odd-tilt — h3 the
dominant overtone, evens suppressed but PRESENT, an audible h5 ladder — on **GM74 only**, without
tripping the velocity-tilt (WD-O6b) or flue-pressure (FLUE) oracles.
**Non-goals:** the other 7 winds (byte-identical — `harm` is per-preset; the spawn draws a phase
per slot *unconditionally* (voices.rs:6952), so populating h5/h7 shifts no rng — verified by both
reviewers); the **h8–h10 extension** (DEFERRED — growing `[Sine;7]` adds an rng draw per slot for
EVERY wind → breaks byte-identity + the WD-O5 seam; SC-55 h8–h10 are −50…−75 dB, below the render
floor once h5/h7 carry the ladder).

## 3. Reference (SC-55-anchored, probe key 78, dB re f0)
h2 ≈ −41, **h3 ≈ −29** (dominant), h4 ≈ −47, h5 ≈ −46, h6 ≈ −59, h7 ≈ −52. Overtone even/odd ≈ 0.3.
Linear: h2≈0.009, h3≈0.036, h4≈0.005, h5≈0.005, h6≈0.001, h7≈0.0025. (Register varies — the low
register wants a stronger h5; a single fixed table is a documented global compromise, Arthur's ear.)

## 4. Approach — rewrite `RECORDER.harm` to the SC-55 per-harmonic dB
Replace `[0.16,0.08,0.02,0,0,0]`. **Calibrate to the per-harmonic SC-55 dB (NOT the aggregate
ratio** — the aggregate-matched first cut over-brightened h5/h7 by ~18 dB, reviews). Start
`[0.009, 0.036, 0.005, 0.005, 0.001, 0.0025]` (≈ SC-55), render, measure the h1..h7 Hann-DFT dB
vector at **two keys (78 + 65)**, and tune each weight to SC-55, subject to two **HARD gate
constraints** (measured every sweep step):
- **WD-O6b velocity tilt ≤ 1.25** (key 65). Moving weight h2→h3 raises the ff/pp tilt ratio
  structurally (h3 scales `bright³` vs h2 `bright²`); the SC-55-faithful h3-dominance sits ~1.24
  — TIGHT. Budget a ≤~1.22 target with margin. **If SC-55-faithful tuning pushes it > 1.25, the
  lever is decoupling the upper-partial velocity law (out of scope) → STOP + escalate to Arthur.**
- **FLUE_PRESSURE rise ≥ 1.22** (RECORDER, voices.rs:19934). Odd-tilt's h5/h7 raise the soft-
  velocity centroid floor → can compress the rise. **Gate on the measured rise staying ≥ 1.22 with
  the 1.22 target UNCHANGED — never lower it** (that would be a weakening). Calibrating h5/h7 toward
  SC-55 (moderate, not hot) relieves this. If it can't hold, STOP + escalate.

`harm` is per-preset by value (voices.rs:6984) → recorder-scoped by construction.

## 5. Testability & oracles (tests-first)
- **Replace the defect-encoding oracle** `wd_recorder_is_an_open_pipe_not_a_sine` (19311, asserts
  `h2>=0.14` + `h2>=h3`) → **`wd_recorder_matches_sc55_odd_tilt`**, measured with a **Hann-windowed
  DFT** (NOT the leakage-prone rectangular `mag_at`/`centroid` — codebase lesson 2026.07.14; SC-55's
  −46 dB h5 sits under the rectangular leakage floor but is measurable under Hann). Two-sided,
  leakage-robust, fail-first on the current even-dominant spectrum, no degenerate pass:
  1. **`h3 >= max(h2,h4,h5,h6,h7)`** — h3 is the single loudest overtone (kills the wrong-even defect;
     leakage-robust; current h2>h3 fails).
  2. **odd/even overtone band-energy `(h3+h5+h7) >= 2.5·(h2+h4+h6)`** — aggregate odd dominance
     (SC-55 ≈ 2.9, a cited margin; current ≈ 0.33 fails).
  3. **`h5 >= 0.4·h3`** — the ladder is audibly alive past h4 (kills the degenerate single-h3 pass;
     current h5≈0 fails; floor set above the Hann leakage floor).
  4. **`h2 < fl_h2` AND `h2 <= h3`** — evens present but below the flute (purer pipe) and not dominant
     (not a clarinet). (Keeps the round-2 "purer than flute" intent; inverts only the h2≥h3 clause.)
- **Re-verify (never weaken):** WD-O6b ≤1.25 (19632) + FLUE ≥1.22 (19934) are the §4 HARD gates
  (pass with targets UNCHANGED, or escalate). WD-O11 loudness ±4 dB vs flute (19877) + WD-O5 breath
  [0.006,0.016] (19463) — low risk (RMS/breath-fraction, h1-dominated), re-check. WD-O8 chiff is a
  differential → harm-independent, unaffected.
