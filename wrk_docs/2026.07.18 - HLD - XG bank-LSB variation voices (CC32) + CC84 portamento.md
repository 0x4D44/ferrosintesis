# HLD — XG bank-LSB variation voices (CC32) + CC84 portamento control

**Status: SELF-APPROVED**
(2 adversarial reviewers → folded reuse-over-new-voices, no module, no `bank_msb` field,
model-vs-model oracles. Codex external → verified the MSB gate, refined CC84 consumption,
refuted the "drop 2 voices" recommendation (defined banks). No critical findings; no fork.)
Date: 2026-07-18
Task: `task/20260718-TSK-HUM-cc84-portamento-and-cc32-bank-lsb`
Author: Claude Opus 4.8 (1M)

## Goal (one line)

Honor XG bank-select LSB (CC32) so a channel selecting a *defined* XG variation voice
renders that voice, and honor CC84 (portamento control); undefined banks keep falling
back to base GM (already correct).

## Background / evidence (from the official XG voice map)

Read the Yamaha PLG100-XG voice list (PyMuPDF). The max defined XG normal-voice LSB bank
is **101**. For the Incantations Part IV reference file:
- **LSB 112/113/115/117 do not exist** → 11 channel-programs fall back to base GM. XG
  does the same, so **ferrosintesis is already correct** for these; modeling them would
  make us *diverge* from a real XG synth (wrong).
- **LSB 3, 19, 41, 45, 65, 96, 98 are real banks.** Eight of the file's channels hit
  defined variation cells (verified against the raw table rows):

| Base (GM prog) | LSB | XG variation | Character vs base |
|---|---|---|---|
| Nylon Guitar (24) | 96 | **Ukulele** | distinct — small bright short nylon |
| Taiko (116) | 96 | **Gran Cassa** | distinct — orchestral bass drum |
| Banjo (105) | 98 | **Oud** | distinct — warm fretless Arabic lute |
| Strings (48) | 3 | Slow Strings | slow-attack strings |
| Atmosphere (99) | 19 | Hollow Release | hollow-timbre pad |
| Dist. Guitar (30) | 41 | Feedback Gtr 2 | sustaining/feedback lead |
| Fingered Bass (33) | 45 | Fingered Bass 2 | 2nd fingered bass |
| Synth Strings 1 (50) | 65 | Str5 | synth-string variant |

CC84 (portamento control): used 6× on ch10 only; the file sends no CC5/CC65, so glides
fall to the 5 ms default (≈ instant) — an inaudible change *to this file*, but a real
correctness fix for the general player.

## Scope

**In**
- Track CC32 (bank LSB) per channel; a variation dispatch keyed on `(program, bank_lsb)`
  that returns a variation voice when one is defined, else `None` → base `voices::make`.
- Model the **8 defined variations** above (preset/param variants of existing primitives).
- CC84 portamento control (one-shot explicit glide source, honoring `porta_time`).

**Out (non-goals)**
- Undefined banks (112/113/115/117) — keep base-GM fallback (correct; modeling = wrong).
- Full XG voice coverage (~480 voices) — future increments; the dispatch is a table, so
  adding more is a table entry + a preset.
- XG bank *MSB* variations (SFX MSB=64 etc.), XG effect SysEx — separate/existing scope.
- Exact XG timbre match — best-effort modeled approximations (this box has no ears; the
  subtle variations 4–8 are modeled from the voice *name* semantics + numeric checks).

## Approach

### CC32 infrastructure (revised per review — no `bank_msb` field, no new module)
- `Strip.bank_lsb: u8` (set by the CC32 handler; persists across RAC, matching XG bank
  semantics — only a new CC32 changes it). There is **no** `bank_msb` field today and we
  add none: CC0 is already tracked as `alt_bank`/`alt_bank_value`.
- **Dispatch reuses the existing non-drum / non-alt-bank `else` branch** in `note_on`
  (~engine.rs:1536, the current `voices::make(prog, …)`). Structurally, `!is_drum`
  already excludes XG MSB=127 (via `xg_drum`) and `!alt_bank` excludes MSB∈{1,2} — so
  MSB=0 is implied with no new field. The branch becomes:
  `voices::make_variation(prog, bank_lsb, key, vel, sr, seed, samples).unwrap_or_else(|| voices::make(prog, key, vel, sr, seed, samples))`
  — same `seed` either way, so an undefined pair (`None`) is bit-identical to today.
- **`voices::make_variation(program, bank_lsb, …) -> Option<Box<dyn Voice>>`** lives in
  `voices.rs` (NOT a new `variations.rs` module — the reused voices `strings`,
  `synth_strings`, `membrane_drum`, `Fx`/`FX_ATMOSPHERE` are private to `voices.rs`; a
  sibling module would force `pub(crate)` exposure for no gain). A `match (program,
  bank_lsb)` returning the defined variations; `None` otherwise. Extensible table.

### The variation voices (mostly REUSE — the core insight from review)
1. **Ukulele** `(24,96)` — new `UKULELE` `PluckPreset` from `NYLON`: shorter `t60`,
   brighter `bright`/`pick_lp`, smaller body (higher body modes).
2. **Oud** `(105,98)` — new `OUD` `PluckPreset` from `NYLON` (a wooden bowl, warmer than
   nylon), using the existing **course params** (`course_detune`/`course_t60`/
   `course_bright`/`course_mix`/`course_couple`, the v0.12 dulcimer voicing) for the
   double-course shimmer. NOT from `BANJO` (banjo's identity is its drumhead `membrane`).
3. **Gran Cassa** `(116,96)` — a new `membrane_drum(...)` call beside `taiko_drum`
   (lower/longer/softer transient). `membrane_drum` already pitch-tracks (`f=key_freq(key)`),
   so a pitched bass drum on a melodic channel is exactly how base 116 already behaves.
4. **Slow Strings** `(48,3)` — **reuse the existing slow-attack path**: `strings()` already
   branches `slow = program == 49` (attack 0.45, darker cutoff). Dispatch `(48,3)` to that
   voicing. No new preset.
5. **Feedback Gtr 2** `(30,41)` — **reuse `DRIVE_LEAD`** (the sustaining driven-guitar
   preset already used by the CC0 alt-bank 29/30 lead; its differs-from-base oracle
   `driven_main_and_alt_banks_diverge` already exists). Nearly free.
6. **Hollow Release** `(99,19)` — new `FxSpec` const beside `FX_ATMOSPHERE` with a
   **longer release only** (verifiable via `t60_of` on the tail). Drop the invented
   "hollow filter" (no clean oracle, unverifiable direction).
7. **Fingered Bass 2** `(33,45)` — MINIMAL `BASS` variant. Review caveat (folded): do NOT
   make it "brighter" — that contradicts the deliberately-muffled flatwound `BASS`
   ("McCartney flat strings"). Model a small, measurable, non-contradicting delta (e.g. a
   touch more attack transient / slightly different decay). XG's own Bass2 is barely
   distinct, so this stays subtle.
8. **Str5** `(50,65)` — MINIMAL `synth_strings` variant (a modest detune/width change —
   the name-plausible axis for a synth-string variation), measurably distinct, no bold
   invented timbre.

> Weak-voice note (folded from review): #7/#8 are the two the review recommended dropping
> as "invented". Kept per Arthur's "all 8" choice but modeled minimally and non-
> contradicting; surfaced in the checkpoint summary so Arthur can drop them if he prefers
> base-GM fallback there.

### CC84 portamento control
- `Strip.porta_control: Option<u8>` — set by the CC84 handler to the source key; cleared
  by `reset_all_controllers` (for consistency with `porta_on`/`last_freq`).
- `note_on`: `take()` the pending source **after** the bagpipe/legato/tremolo-restrike
  early-returns (~engine.rs:1479) but **before** the `let s = &self.strips[ci]` borrow
  (E0502): `let porta_ctrl = self.strips[ci].porta_control.take();`. This consumes it only
  when a fresh voice actually spawns (Codex — not on the early-return paths). Unlike
  `porta_from`, it needs no early capture (its source is the explicit `key_freq(src)`, not
  `last_freq`). Glide source = `porta_ctrl.map(key_freq)` (glides regardless of `porta_on`,
  correct MIDI CC84 semantics), else `porta_on ? porta_from : None`. Reuse the existing
  `(semis, k)` machinery + `porta_time`.

### File impact
- `crates/ferrosintesis/src/engine.rs` — `Strip.bank_lsb` + CC32 handler; the one-line
  dispatch change in the `note_on` `else` branch; `Strip.porta_control` + CC84 handler +

- `crates/ferrosintesis/src/voices.rs` — `make_variation` table; `UKULELE`/`OUD` presets;

- Tests in `voices.rs`/`engine.rs`; a synthetic per-variation MIDI check.

## Acceptance criteria
1. **Dispatch (unit).** A note with CC32=96 + program 24 spawns the Ukulele voice, not
   the base nylon; CC32=113 (undefined) + program 24 spawns the base nylon (fallback);
   CC32=0 is unchanged. Same for each of the 8 pairs → their variation; each *undefined*
   file LSB → base voice.
2. **Each variation differs from its base** in the named, measurable direction —
   **model-vs-model** (render the variation's preset vs the base preset, both `--no-samples`,
   the existing preset-vs-preset test precedent; NOT variation-vs-sampled-base):
   - Ukulele: `centroid(UKULELE) > centroid(NYLON)` AND `t60_of(UKULELE) < t60_of(NYLON)`.
   - Oud: `centroid(OUD) < centroid(NYLON)` (warmer — vs NYLON, its real base, not banjo).
   - Gran Cassa: `centroid < taiko` AND `t60_of > taiko`.
   - Slow Strings: longer attack rise than base 48 (add/promote an attack-rise metric —
     `rise_to_090_s` currently lives in altbank tests, not `testutil`; promote it).
   - Feedback Gtr 2: longer sustain than `DRIVE` (the existing `driven_*_diverge` oracle).
   - Hollow Release: longer tail `t60_of` than base 99.
   - Fingered Bass 2 / Str5: a measurable, non-noise delta from base (if it cannot be made
     to exceed seed/velocity noise cleanly, that voice falls back to base — see weak-voice
     note; do not assert a flaky oracle).
3. **CC84 (unit).** A `CC84=src → NoteOn` glides from `key_freq(src)` even without CC65;
   consumed once (a following NoteOn with no CC84 does not glide).
4. **Byte-identical albums.** Render-diff over all albums: **0 diffs** (no album sends
   CC32≠0 into a defined-variation program, and CC84 is authored-only). Confirm.
5. `cargo fmt --check`, `clippy --workspace -D warnings`, `cargo test --workspace` green.

## Decision log
- **Dispatch on `(program, LSB)` with base-GM fallback** mirrors XG exactly: undefined
  (program, LSB) → base voice. Never invent a voice for an undefined bank.
- **Gate variations on `bank_msb == 0`** (XG normal voices) so CC0-alt-bank and drums are
  untouched; `bank_lsb` alone never triggers alt-bank behavior.
- **Model, don't sample** — consistent with ferrosintesis's zero-dependency modeled
  ethos; each variation is a preset/param variant of an existing primitive where possible.
- **Subtle variations (4–8) are best-effort from the voice name** (no ears here); the
  acceptance oracle checks they move in the *named* direction, not that they match XG
  exactly. The 3 distinct instruments (Uke/GranCassa/Oud) are the high-value core.
- **CC84 separate commit** — orthogonal to CC32; bundled because Arthur requested it.
- **Reuse over new voices (review)** — 5 of the 8 reuse existing primitives/presets/paths
  (Slow Strings = `strings(49)` slow path; Feedback Gtr 2 = `DRIVE_LEAD`; Gran Cassa =
  `membrane_drum`; Oud/Uke = `NYLON`-derived presets). This collapses the change from an
  "8-voice module" to a dispatch table + ~3 presets in `voices.rs`.
- **No `variations.rs` module** — the reused voices are private to `voices.rs`; a sibling
  module would force `pub(crate)` exposure. `make_variation` lives in `voices.rs`.
- **Weak voices (#7 Fingered Bass 2, #8 Str5)** — review recommended dropping them as
  invented/unverifiable (and #7's "brighter" would contradict authored intent). Kept per
  Arthur's "all 8", modeled minimally and non-contradicting, with a real oracle or else
  base-GM fallback. Flagged in the checkpoint summary for Arthur's call.
- **Gate variations on the `!alt_bank` branch, not a `bank_msb` gate** — no duplicate CC0
  state; CC0=1/2 (alt bank) correctly wins over CC32 (XG variations are MSB=0).
- **MSB-gate correctness (verified vs Codex #2):** the CC0 handler sets `alt_bank =
  (val != 0)` for every nonzero MSB except 127 (→ `xg_drum`→drums). So the
  `!is_drum && !alt_bank` branch is entered **only when MSB=0**. An XG SFX bank (MSB=64) →
  `alt_bank=true` → routed to `altbank::make` (→ base GM), never to the variation table.
  No misdispatch.
- **Bank applies immediately, not latched at the next Program Change (Codex #1):** strict
  MIDI commits bank select on the following PC, but ferrosintesis's existing
  `alt_bank`/`xg_drum` already apply immediately, and real XG files order CC0→CC32→PC→notes
  (so it's equivalent in practice). Reading live `bank_lsb` at note-on matches the existing
  convention; latching would be inconsistent. Accepted.
- **Keep Fingered Bass 2 + Str5 as minimal deltas (Codex refutes the drop):** they are
  *defined* XG banks, so base-GM fallback would falsely treat them as undefined; a small
  measurable delta is structurally more faithful. Modeled minimally/non-contradicting.
- **`make_variation` must be RNG-pure (Codex #4):** no extra RNG draw beyond the voice's
  own `seed`, so the `None` (undefined) path and the base path stay bit-identical; the
  album render-diff is the empirical confirmation.
- **Hollow Release is longer-release-only (accepted limitation):** the "hollow" spectral
  character the name implies is unverifiable without ears/reference, so the model asserts
  only the release-length change; documented as loose.

## Residual risks
- Subtle variations may end up close to base GM (acceptable — that's what they are).
- Timbre fidelity is unverifiable by ear here; oracles check direction only.
- Large change (8 voices) — drive implementation voice-by-voice (loop) if it outgrows one
  context; each voice lands green + committed before the next.
