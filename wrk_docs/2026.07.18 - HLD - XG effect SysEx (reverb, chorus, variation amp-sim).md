## Approach

### Parser (midi.rs) — two low-level typed events, engine holds all semantics (GS "dumb parser" idiom)
- XG System On (`43 1n 4C 00 00 7E 00`) AND GM System On (universal `7E … 09 01`) → `EvKind::XgReset`
  (reset the XgEffects block only).
- XG Effect1 param (`43 1n 4C 02 01 <lo> <d0> [d1]`) → `EvKind::XgEffectParam { addr_lo: u8, data:
  [u8;2], len: u8 }` (len 1 or 2). Non-Effect1 XG addresses stay ignored, as today. (Rejected: a
  semantic EvKind per parameter = enum explosion; "accumulate the whole block" = the block has no end
  marker, so it needs fragile cross-message buffering.)

### Engine — an `XgEffects` state block (engine-global, not per-strip)
Holds the pending variation config (type msb/lsb, connection, part, drive, dry/wet) + the immutable
base wet captured from `opt.wet`. Defaults: variation part = 127 (off) → no insert; reverb/chorus at
current. `XgEffectParam` updates the relevant field; the variation is (re)resolved after each update
(idempotent, so t=0 event order is irrelevant):
- **Reverb Type** (`addr_lo 0x00`, data=[msb,lsb]): `(01,00)` Hall 1 → `Reverb::reconfigure(HALL1_ROOM,
  HALL1_DAMP)` on `self.reverb` ONLY (not cathedral/drum_room); else no-op. Return offset (`0x0C`)
  parsed-and-ignored.
- **Chorus Type** (`addr_lo 0x20`): `(41,00)` Chorus 1 → `self.chorus.reconfigure(CHORUS1_*)` (params
  bounded to the 40 ms delay line); else no-op. Return offset (`0x2C`) parsed-and-ignored.
- **Variation** (`addr_lo 0x40` type; `0x42` Param1=Drive; `0x54` Param10=Dry/Wet; `0x5A` connection;
  `0x5B` part): resolve → if type is Amp Sim AND connection==INSERTION AND part<64 →
  `strips[part].xg_insert = Some(Drive::amp_sim(sr, drive))`; else clear all `xg_insert`.

### The variation insert — REPLACE, Dry/Wet at the apply site (the load-bearing folded fix)
- The XG Amp Simulator models the **amp+cabinet** stage — the same physical thing as the strip-level
  `Drive`, NOT the guitar voice. So on the target channel the insert **replaces** the program `drive`
  (the driven *voice* model is untouched), avoiding two amp/cabinets in series (a dark, double-LPF,
  over-compressed result). New `Strip.xg_insert: Option<Drive>`, DISTINCT from `drive`.
- Apply site (engine.rs:2362, currently `if let Some(d)=&mut strip.drive { d.process(buf) }`) becomes:
  `if let Some(xg)=&mut strip.xg_insert { <dry/wet-blended xg.process> } else if let Some(d)=&mut
  strip.drive { d.process(buf) }`.
- **Dry/Wet blend at the apply site, at BASE rate** (outside `Drive::process`'s internal 2×): copy the
  dry block, `xg.process(buf)` (100% wet), then `buf[i] = dry*(1-w) + buf[i]*w`, `w = (drywet-1)/126`.
  `Drive::process` stays **byte-for-byte unchanged** (strongest inertness guarantee).
- `program_change` / `needs_drive` rebuild / `rederive_program_defaults` touch ONLY `s.drive`, never
  `xg_insert`; the `DRIVEN_GUITAR_VOICE_LIMIT` stealing is gated on `needs_drive(program)` which
  `xg_insert` never sets — so the insert can't be clobbered by the t=0 Prog-29 change, isn't
  double-processed, and doesn't change voice spawning. Do NOT fold the XG channel into `needs_drive`.

### `Drive` reuse (engine.rs:275) — no change to `Drive::process`
- The `program` field is DSP-irrelevant (`chain`/`process` never read it). Factor the shared field
  construction (`pre` HPF, `dcb`, `cab`, `prev`) into a private `Drive::from_stages(...)`; both
  `new(program)` and a new `amp_sim(sr, drive_0_127)` call it. `amp_sim` derives the two gain stages
  from XG Drive and reuses `cab_biquads`. NO dry/wet field inside `Drive` (blend is at the apply site).

### Reconfigure primitives
- `Reverb::reconfigure(&mut self, room, damp)` (reverb.rs): loop the 16 combs setting `feedback=room`,
  `damp=damp`. Alloc-free, no stale artifact (Freeverb models room by feedback gain, not delay length;
  buffer lengths + predelay + early taps unchanged). **Predelay is NOT reconfigurable in place** (baked
  at construction) → dropped from the mapping; keep the current 24 ms (oracle 39 pins it anyway).
- `Chorus::reconfigure(...)`: set LFO rate/depth/feedback; assert `base+depth ≤ 40 ms` (the line
  length) — Chorus 1 fits.

### Reset semantics
`XgReset` (from XG or GM System On) resets the `XgEffects` block to defaults ONLY:
`Reverb::reconfigure(0.86, 0.35)`, chorus back to current, and clear every `strips[*].xg_insert`. It
MUST NOT route through `hard_reset` (`*self = Self::new`) and MUST NOT touch `opt`, voices, or timing.
RAC (CC121) does not touch XG effects (they are global, not per-channel controllers). Byte-inert for
albums (0 send System On).

### File impact
- `midi.rs` — XG/GM System On + XG Effect1 recognition → `XgReset` / `XgEffectParam`.
- `reverb.rs` — `Reverb::reconfigure(room, damp)`.
- `engine.rs` — `XgEffects` state; `Strip.xg_insert`; `Drive::from_stages` + `Drive::amp_sim`; the
  apply-site replace + base-rate dry/wet blend; `Chorus::reconfigure`; the two EvKind handlers + reset.

## Decision log
- **Byte-identity default-to-current** — the spine; empirically 0/109 albums carry any SysEx, seed is
  spawn-counter-based → provably inert; render-diff is the proof.
- **REPLACE, not stack (folded)** — the XG Amp Sim is the amp+cab stage = the strip `Drive`, not the
  voice; replacing keeps program-29's driven voice, honors the single authored amp, and avoids two
  5-biquad cabinets in series. Idiomatic (authored-overrides-default, like `chorus_authored`).
- **Separate `xg_insert` slot, apply-site precedence over `drive` (folded)** — makes the t=0
  Prog-29-vs-SysEx order irrelevant and keeps `needs_drive`/voice-stealing untouched.
- **Dry/Wet blended at the apply site, `Drive::process` unchanged (folded)** — no blend/inertness
  reasoning inside the shared program-drive path; the blend sits at base rate outside the 2× (the
  `mid` samples inside `process` are discarded, so an inside-blend would be wrong anyway).
- **Cut return-scaling (folded)** — returns are unity here, AND `opt.wet` is construction-only; scaling
  it does nothing offline and, if forced, corrupts hall+cathedral+drum_room and leaks across the
  realtime engine's `hard_reset` (`live.rs` persistent `opt`). Parse-and-ignore returns; if ever
  needed, add `Reverb::set_wet` + a base-wet scalar targeting the hall only.
- **Cut type tables + system bus (folded)** — two-arm Hall1/Chorus1 match; INSERTION only. Minimal
  correct surface for what the file sends; still extensible via more match arms.
- **`Drive::from_stages` builder; program field is DSP-irrelevant (folded)** — a param-driven
  `amp_sim` constructor doesn't tangle the program-29/30 branch.
- **Reconfigure in place, drop predelay (folded)** — Freeverb room=feedback so room/damp are runtime
  fields; predelay is construction-baked, so it's not remapped (current 24 ms kept).
- **Reset only the XgEffects block (folded)** — never `hard_reset`, never mutate `opt`; voices/timing
  untouched.
