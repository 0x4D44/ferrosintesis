# PLN — GM0 acoustic-grand alternate banks (audition)

## Goal
Arthur finds the current GM0 grand (Salamander Grand Piano V3, bright Yamaha C5)
unsatisfying. Wire a curated set of alternative free/redistributable grand-piano
sample banks as **permanent CC0-selectable alternates** for GM0, render each on a
diagnostic torture-test MIDI **and** the opening of Tubular Bells, so Arthur can
audition and rank them (best→worst). The winning order becomes the final CC0
bank assignment.

Decisions (Arthur, 2026.07.18):
- **Permanent shipped alt-banks** (not a throwaway dev harness).
- **Curated grands + anchors** roster (no near-duplicates, no uprights).
- **Torture-test + real track**, the real track = *first few bars of Tubular Bells*.

## Mechanism (how a GM0 alternate is selected)
The synth already dispatches CC0 (Bank Select MSB) alternate voicings:
- `engine.rs`: a channel's `CC0 != 0` sets `Strip.alt_bank` + `alt_bank_value`;
  voice spawn then calls `altbank::make(program, alt_bank_value, key, vel, sr, seed, samples)`
  (engine.rs ~1484) instead of `voices::make`. The real `samples` flag is passed
  through, so an alt-bank GM0 voice DOES get its sample layer.
- `altbank::make` (altbank.rs ~1014) already switches on `bank` per program
  (GM19 bank 2 = cathedral; GM14 bank 2 = gong). GM0 currently falls through to
  `voices::make`.

**Design:** GM0 **bank 0** = current Salamander (unchanged anchor). GM0 **bank
1..N** = each candidate, built through the SAME model + LA blend as the default,
so the audition varies only the *recording*.

- `voices.rs`: added `pub fn acoustic_grand_with_bank(bank, key, vel, sr, seed, samples)`
  — builds `acoustic_piano` + wraps with `LA_PIANO` gain/fade + `LaFx::default()`.
  The default GM0 path (`make`, program 0) now routes through it with `grand_bank`;
  behaviour-preserving (verified: 17 la_/piano/grand oracles pass; render-diff still
  owed before integration). DONE.
- `altbank.rs`: add a `0 => match bank { 1 => <cand1>_bank, 2 => ..., _ => voices::make(0..) }`
  arm calling `acoustic_grand_with_bank(<cand>_bank(vel, seed&1==0), ...)`. TODO.

## Per-candidate build (repeat for each bank)
1. `prepare.py`: add fetch (SHA-pinned) + bake path. Per zone MEASURE the root
   (`measure_f0`) — lessons_learnt warns of 2f-dominant / octave-mislabelled sources.
   Bake to 9 pitch zones (~minor thirds C2..C6) × 3 dynamics (pp/mf/f) × 2 RR,
   onset + ~1.5 s body, peak-normalized 0.9, 16-bit mono 44.1k (matches grand).
2. New crate `ferrosintesis-samples-<name>` (template = `-grand`): Cargo.toml,
   src/lib.rs (`SAMPLES` array, `FILE_COUNT`, `get`, inventory+bytes tests),
   samples/*.wav, NOTICE (attribution for CC-BY), PROVENANCE.md, README.md, and
   `.gitignore` `!crates/<name>/samples/*.wav` (else the WAVs are gitignored and the
   crate fails to build from a clean checkout — lessons_learnt).
3. `sampler.rs`: `<name>_pp/mf/f (+rr2)` zone tables + `pub fn <name>_bank(vel, rr2)`.
   Wire `.or_else(|| ferrosintesis_samples_<name>::get(name))` into `embedded_wav`.
4. `ferrosintesis/Cargo.toml`: add the crate dep + the `embedded-samples` feature list.
5. `altbank.rs`: add the bank number → `<name>_bank` arm.

## Audition render
- Tooling in `tools/gm0-audition/` (dev-only, stdlib Python): DONE.
  - `make_torture_midi.py` → `gm0-torture.mid` (register sweep / dynamic ladder /
    chromatic run / sustained chord / repeated note / cadence — all channel 0).
  - `prep_audition.py in.mid -o out.mid --bank N --channel 0 [--max-seconds S]` →
    injects CC0=N on ch0 (skips when N=0) + trims to the first S s (tempo-aware).
- Render matrix: for each bank {0, model, 1..N} render (a) the torture MIDI, and
  (b) Tubular Bells opening (~30 s) with `--solo 0` (piano isolated) for the
  cleanest A/B — the opening is not solo piano in this GM arrangement. Encode to
  opus (or wav) with clear names. Renders are gitignored build output.
- Reference MIDIs live in the (untracked) `test-corpus/` — only in the main clone,
  so reference the main-clone path when rendering:
  `D:/language/midi-music/test-corpus/reference-midi/mike-oldfield/01-tubular-bells-part-one.mid`.
