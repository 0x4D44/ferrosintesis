## The uniform design (no new synthesis architecture)

Every one of the nine wraps its **existing model** in `LaVoice::wrap` (or
`wrap_fx`), exactly as GM 24 nylon / 6 harpsichord / 40 violin already do:
`[0,fade_start)` sample owns the onset; one sum-to-one crossfade; model owns the
sustain. This is a **timbre improvement = default-on** per the synth-change
policy — controllers untouched, no CC gating. It therefore REQUIRES the
render-diff inventory (see Validation).

Per instrument the work is four edits:
1. **`tools/ferrosintesis-samples/prepare.py`** — add the source (URLs/zones) and
   a bake call; print measured roots.
2. **`crates/<asset-crate>/samples/*.wav`** — the generated mono 16-bit 44.1 kHz WAVs (committed source).
3. **`crates/ferrosintesis/src/sampler.rs`** — a `Zone` bank fn with the MEASURED
   roots + a `pub fn <inst>_bank()`; add to `prewarm()`.
4. **`crates/ferrosintesis/src/voices.rs`** — `LA_<INST>: (gain,fade)` constant +
   wrap the model in the relevant `make()` arm.

### Bake strategy — all `trim_to_onset`, per-family `keep_s`

- **Plucked/struck (harp, timpani, sitar, banjo):** onset + early ring, `keep_s`
  ~0.9 s (mirrors nylon/harpsichord `LA_GUITAR`/`LA_HARPSICHORD`). Model carries
  the bendable/decaying tail.
- **Winds (recorder, ocarina, pan flute, blown bottle, shakuhachi):** onset
  ~0.6 s (mirrors flute `LA_FLUTE`). Model carries the sustained body/vibrato.
- Do NOT use `_bake_clavinet_note` (full decaying looped note) — that is the
  clavinet's *replace-the-model* strategy; here the model stays and only the
  onset is sampled.

### Source-fetch reuse (prepare.py)

- **VCSL (harp/timpani/recorder/ocarina):** mirror `HARPSICHORD_URLS` — a
  `dest→source-label` zone table + a per-file raw-GitHub URL at `VCSL_REV`
  (`prepare.py:188-210`). Fetch via `ensure_source`/`fetch`, `read_wav` downmixes
  stereo→mono, `trim_to_onset` (`prepare.py:672`), `measure_f0` (`:638`) prints roots.
  **Roots MUST be measured, not assumed** — VCSL labels can sit an octave off
  (the harpsichord lesson). Print them; hardcode the printed values in sampler.rs.
- **MS Basic SF3 (sitar/pan flute/blown bottle/shakuhachi):** generalize
  `_clavinet_zones(sf3)` (`prepare.py:820`) to take a **preset number** arg
  (currently hardcoded to GM7). Reuse `ensure_musescore_sf3` (`:808`), slice each
  zone's Ogg by byte offset, decode with ffmpeg, then `trim_to_onset` (NOT the
  clavinet decay bake). `h[40]` = originalPitch = trustworthy root (sample NAME
  octave is +1). Preset 104 zones already verified: 8 zones E3–G6.
  **Iteration 5 must first dump presets 75/76/77 to confirm they exist + zones**
  (MS Basic is a complete GM set, so expected present; if a preset is absent,
  that is a fork — stop and report, do not substitute silently).
- **ganjo (banjo):** NEW source. Repo `github.com/sfzinstruments/ganjo`, folder
  `Common/`, files `Banjo_Common - <note>[_n].wav`, CC0. Pin a commit SHA (pick
  the current `master` HEAD SHA at implementation time and record it), fetch the
  chosen ~8-zone subset by raw URL, probe bit-depth/SR/channels on first download
  (undocumented upstream), `trim_to_onset`.

## Crate placement (decision)

`-orchestral` is at 9.7 MiB (cap ≈10 MiB), so new samples need new crates:
- **NEW CC0 crate `ferrosintesis-samples-orchestral2`** — harp, timpani, recorder,
  ocarina, banjo (all CC0). Est. ~5 MiB, one crate under cap. Mirror the
  `-gong`/`-grand` crate skeleton (`Cargo.toml`, `src/lib.rs` `get()` +
  `include_bytes!`, `samples/`). CC0 needs no NOTICE (courtesy credit fine).
- **MS Basic MIT content → existing `ferrosintesis-samples-clavinet` crate.**
  Rationale: identical provenance/license (MS Basic, MIT) and its `NOTICE`
  already carries the FluidR3/Cowgill/Collins/Wen chain that covers sitar + pipes.
  Adds ~2.3 MiB to a 1.6 MiB crate → ~4 MiB, well under cap. (Alternative: a new
  `-musescore` crate. Chose reuse to avoid an extra published crate + publish-order
  pin. The crate stays named `-clavinet` but now holds all MS-Basic-derived onsets;
  document this in its README/PROVENANCE.)
- **Publish order** (forced by `=0.1.0` pins): asset crates before `ferrosintesis`.
  Add `orchestral2` to `sampler.rs`'s `embedded_wav()` fallthrough chain and the
  `ferrosintesis` Cargo deps + `embedded-samples` feature.

**This crate naming is reversible pre-publish and is NOT a blocking fork.** If
Arthur dislikes `-orchestral2`, rename before the (separate, human-gated) publish.
