## 2. Design throughline A — sampled onset becomes the default

Every target today is a pure model in `voices::make` (`crates/ferrosintesis/src/voices.rs`):

| GM | Current model | Line |
|----|--------------|------|
| 8 | `bell(… CELESTA …)` | 11113 |
| 10 | `bell(… MUSICBOX …)` | 11158 |
| 11 | `bell(… VIBES …).with_amp_trem(motor)` | 11169 |
| 14 | `bell(… TUBULAR …)` | 11229 |
| 15 | `Pluck::new(&DULCIMER)` | 11240 |
| 4 | `bell(… …)` (raised-bell EP) | ~11100 |
| 32 | `Pluck::new(&UPRIGHT)` | 11312 |
| 33 | `Pluck::new(&BASS)` | 11313 |
| 34 | `Pluck::new(&PICK)` | 11315 |
| 35 | `Pluck::new(&FRETLESS)` | 11318 |

The change per program is the **exact** shape already used for GM 9/12/13 and 42/43 — wrap the *unchanged* model in a sample onset, guarded by `if samples`:

```rust
N => {
    let model = Box::new(<existing model ctor, verbatim>);
    if samples {
        let (gain, fade) = LA_<NAME>;
        crate::sampler::LaVoice::wrap(model, crate::sampler::<name>_bank(), key, vel, sr, gain, fade)
    } else {
        model
    }
}
```

**Invariant:** the `else` branch is byte-identical to today, so `--no-samples` renders are unchanged and `non_guitar_la_render_is_pinned`-style oracles hold. Use plain `wrap` (not `wrap_var`) for all of these — `wrap_var` detunes the wrapped model ±6c (lessons_learnt 2026-07-19) and is guitar-only by design; the perc/bass onsets want the jitter-free constructor, matching contrabass (`voices.rs:11350`).

## 3. Design throughline B — the pre-sampling model preserved as the `CC0 ≠ 0` alt

**Mechanism (unchanged):** the engine sets `Strip.alt_bank = (CC0 != 0)` per channel; when true, voices route through `altbank::make` instead of `voices::make` (`altbank.rs:1017`). `altbank::make` matches specific programs and **delegates everything else to `voices::make`**.

**The precedent this reuses verbatim:** brass `56..=61` and guitars `24..=25` already sit in `altbank::make` purely to force the sample layer OFF so "the default bank's sampled attack layer must not reach alt-bank channels" (`altbank.rs:1110, 1118`):

```rust
56..=61 => crate::voices::make(program, key, vel, sr, seed, false),
24..=25 => crate::voices::make(program, key, vel, sr, seed, false),
```

**So the model-to-alt directive is one arm per newly-sampled program**, added to `altbank::make`:

```rust
4 | 8 | 10 | 11 | 14 | 15 | 32..=35 => crate::voices::make(program, key, vel, sr, seed, false),
```

- `CC0 = 0` (default) → `voices::make(…, samples=true)` → **new sampled voice**.
- `CC0 ≠ 0` → this arm → `voices::make(…, samples=false)` → **pure pre-sampling model** = today's exact default sound.

**No new frozen voice code is needed** (unlike the v0.9 orchestral resurrection): the "original" *is* `voices::make` with `samples=false`, and adding a sample layer never touches that path. This also preserves byte-identity for any existing `CC0 ≠ 0` channel on these programs (today they fall through to `voices::make(…, samples)` which, with no sample layer yet, already yields the model; the explicit arm keeps that true after the layer lands).

**Model-only programs (GM 5, 38, 39) get no alt arm** — their default is already the model; `CC0 ≠ 0` correctly falls through to the same model. GM 36/37 get no arm until slap is built.

**Oracle:** one test — `sampled_programs_preserve_pure_model_at_cc0_alt` — asserting `altbank::make(p, 1, …)` renders bit-identical to `voices::make(p, …, false)` for each `p` in the set (extends the existing `altbank_guitars_skip_sample_layer` pattern).

## 4. Per-program recipe (5 mechanical steps)

For each program (mirrors the batch-1 marimba unit end-to-end):

1. **prepare.py** — add a `_<NAME>_ZONES` table + a source map entry, route the family to its crate in the `CRATE`/package map (`prepare.py:800`), run `python tools/ferrosintesis-samples/prepare.py`, read the **printed measured roots**.
2. **Asset crate** — the baked mono/16-bit/44.1k WAVs land in `crates/ferrosintesis-samples-<crate>/samples/`; add `!crates/<crate>/samples/*.wav` to `.gitignore` for any *new* crate (else `git add` commits the crate without its bytes — lessons_learnt 2026-07-18).
3. **sampler.rs** — add `fn <name>() -> &'static [Zone]` with the `bank!` macro + the measured roots, and `pub fn <name>_bank(...) -> &'static [Zone]` (velocity split only where the source has layers — vibraphone/tubular are single-layer; basses may have v1/v3 like contrabass).
4. **voices.rs** — wrap the model per §2; add the `LA_<NAME>: (f32, (f32,f32))` gain/fade constant near the other `LA_*` consts.
5. **altbank.rs** — add the program to the `voices::make(…, false)` alt arm per §3.

Then oracles (§7) + the render-diff inventory.

## 5. Sourcing, crate & license routing

**License tiers** (round-3 §7.1): Tier-1 CC0 → default embedded crate, no obligation; Tier-2 plain CC-BY → default crate **+ a `NOTICE`**; NC / SA-NC / GPL / Sampling-Plus / redistribution-silent → **rejected** (2026-07-16 scope cap). MIT (MS Basic) is treated as Tier-2-equivalent — attribution via NOTICE, already precedented by the `-musescore` crate.

**Crate routing:**
- **CC0, already-pinned:** vibraphone/tubular → `-orchestral2` (VCSL, commit `c1ea7bcc…`); acoustic-pizz bass → `-strings` (VSCO, commit `440300901…`, sibling of the vendored contrabass).
- **MIT, already-pinned:** celesta → `-musescore` (MS Basic SF3, commit `d307a2bd…`, `_bake_sf_onset` path — same as sitar/pipe onsets), with its existing NOTICE extended.
- **CC0, new pins:** music box (BigSoundBank) and electric bass (FreePats RBX) → **new crates** `-perc2` and `-bass` (keeps `-orchestral2` under the ~10 MiB crates.io cap; onset-only WAVs are ~50 KB each, so a family is a few MB).
- **CC-BY, new pins:** Rhodes (tim.kahn) + hammered dulcimer (iternetcone) → **one new crate** `ferrosintesis-samples-ccby` carrying a **`NOTICE`** crediting *tim.kahn (Freesound pack 3957, CC BY 4.0)* and *iternetcone (Freesound pack 19445, CC BY 4.0)*. This is the repo's **first CC-BY melodic bank** — the NOTICE is the whole obligation.

**Pinning discipline (the round-3 error we must not repeat):** the license lives at the **primary source**, not an aggregator. jRhodes is the cautionary tale — its own LICENSE reads *"License for samples: CC BY-NC"* (the CC0 covers only SFZ/control files), so it is **rejected**. Freesound sources are **per-sound licensed** and **auth-gated**: confirm each embedded sound's license at download, then **vendor the files into the crate** (CC-BY/CC0 both permit byte redistribution) — the stable pin is the sound ID + immutability, not a commit SHA.

## 7. Verification (per unit)

- **`--no-samples` byte-identity** — the model path is untouched; pin with the existing `non_guitar_la_render_is_pinned` family.
- **Root-measurement sanity** — read prepare.py's printed roots; watch the 2f-dominant / octave-label traps (lessons_learnt 2026-07-18) — measure, never assume (celesta/vibes are bell-bright; confirm each zone's dominant partial).
- **`la_level_continuity`** — the onset must not click or over/under-shoot the model body at the crossfade.
- **`class_identity_ranges_hold` (MM-BUG-KILN-00006)** — confirm each newly-sampled program stays in its correct perceptual class (struck perc = DECAY; bass = plucked-decay); the onset must not flip the class axis.
- **Alt-bank oracle** — §3, `sampled_programs_preserve_pure_model_at_cc0_alt`.
- **Render-diff inventory** — baseline binary from the rebased-onto tip (NOT a fresh `origin/main` — the multi-agent drift trap, lessons_learnt 2026-07-19); expected diffs = only albums using that program; **any unexpected diff (a piano-only album moving, DC on a silent channel) is a bug**, investigate before commit.
- **Ear-in-the-loop stays out of the gate** — the numeric oracles define "done" for landing; timbre/realism is Arthur's audition, not a machine check ("this box has no ears").
