# 2026.07.21 — HLD — M-CAL v2 tooling implementation (probe + trajectory meter + guards)

<!-- STATUS: SELF-APPROVED (Claude Opus 4.8, 2026-07-21) — lean flow: adversarial (Fable+Claude) + Codex reviewed -->

Implements the *tooling* half of `2026.07.21 - HLD - M-CAL v2 envelope-guarded metric.md`
(the metric design, Arthur-agreed and heavily reviewed). Pins the concrete implementation and
takes it through the lean review + checkpoint. **Revised twice by review:** the attack/body
window scheme became a peak-normalised **trajectory** guard (adversarial: Fable+Claude), then
gained a short-note exclusion, a stricter per-key rule, and a BusGlue precondition (Codex
external). See Decision log and Surviving findings.

## Scope

**In:** three deterministic, testable tools that make the guarded percussive derivation
runnable — `mkprobe.py` (register-band probe), `calmeter.rs` (emit the per-note momentary-block
**trajectory**), `derive_trims.py` (all shape/level policy). Validated by unit tests + a
re-meter of the existing `ferro_full.wav` + a small fresh SC-55 differential.

**Out (ear-gated downstream, per metric-HLD §6):** the 6 timbre bugs (00031–00036), the bass
voice-gain fix (00016), and *applying* any re-derived trims / re-rendering albums. Deriving
final numbers is gated on the timbre bugs; this increment builds + proves the machinery and
produces a **provisional** (informational, not-applied) derivation.

**Non-goals:** no psychoacoustic (sones) model; **no crate/public-API change and no version
bump** — all changes are dev-only tooling + tests. (Lone exception that would force a bump: if
empirical check shows BusGlue is NOT inert for probe notes and a `with_bus_glue(false)`
calibration flag is needed — see Preconditions. Verify before assuming.)

## Success / acceptance criteria

- **A1 — probe.** `mkprobe.py <set>` transposes the 6-pitch-class set into each family's
  register; stride/hop invariants still assert; GM32–39 basses land in the sampled bank.
- **A2 — meter.** `calmeter.rs` emits the onset-relative momentary-block series `b0..bK` per
  note (plus `max_m`). A pure `onset_blocks()` helper is unit-tested on a synthetic series:
  returns exactly the blocks whose 400 ms body is inside the window, indexed from the true
  onset (warmup blocks dropped).
- **A3 — guards.** `derive_trims.py` (a) parses the TSV **by header name**; (b) retains
  per-`(program,key,velocity)` trajectories; (c) marks a key **unmetrable** when either
  engine's block 1 is floored (note confined to the first 400 ms block — sub-hop, unresolvable);
  (d) else computes peak-normalised `shape_dev`; (e) excludes a program when **> 1 key** is
  unmetrable-or-mismatched (`shape_dev > 3 dB`); (f) pitch-tilt guard on per-key peak-level
  spread > 6 dB; (g) anchor-free velocity guard; (h) paired-difference anchor
  `median_cohort(F_peak − S_peak)` over a size-asserted sustained cohort. `--selftest` asserts
  each on synthetic tables — including a *matched medium one-shot* kept and a *sub-hop* pair
  excluded (not mis-trimmed).
- **A4 — end-to-end (pipeline proof, caveated).** Re-metering `ferro_full.wav` reproduces the
  metric HLD's envelopes (GM28 collapses to floor mid-note; GM33 decays across the hold). With
  a small fresh SC-55 render the shape/short-note guards exclude GM28/33 and pitch-tilt excludes
  GM107. The numeric trims are **provisional** (BusGlue/fallback caveats below), so A4 proves
  the *pipeline runs and the guards fire*, not the final values. If the SC-55 render can't run
  in-session, A4's differential half is a documented residual.
- **A5 — hygiene.** `cargo fmt --check`; `cargo clippy -p ferrosintesis-cli --examples
  -D warnings`; `cargo test -p ferrosintesis-cli --examples`; `python derive_trims.py
  --selftest` — all green; no version bump.

## Calibration-render preconditions (Codex #1)

The differential is only valid if the ferro render chain is **linear** where we meter, because
the SC-55 (emulator) render has no equivalent post-stage:

- **BusGlue must be inert.** `engine.rs:~915` compresses above 0.32 (−9.9 dBFS) with a 15 ms
  attack / 250 ms release, then saturates. If a probe note crosses that, ferro's trajectory is
  compressor-shaped (spurious `shape_dev`) and the dB `SHIPPED[p]` back-out is no longer exact.
  The probe plays **single** notes at CC7=100, which likely stay below 0.32 — but **verify
  empirically** (peak-inspect the ferro probe render). If notes cross it: lower the probe CC7
  until inert (no library change), or, only if that fails, add a `with_bus_glue(false)`
  calibration Options flag (the one change that would need a minor bump). This is the single
  precondition that makes *both* the shape guard and the level back-out valid.

## Approach

### 1. Probe register bands (`mkprobe.py`)

Base `KEYS = C3 F3 A#3 D#4 G#4 C#5` — 6 pitch classes evenly spaced round the circle over 2
octaves (load-bearing: de-biases `nearest()`'s C-clustered roots; avoids out-of-idiom extremes).
Candidate-1 metered all 128 programs at this fixed set, so basses sat two octaves high and
GM33's 10/12 pitches fell to the fallback model. **Fix:** a per-family semitone offset on the
whole set, preserving its shape but centring the register:

| Family (GM) | offset | span | note |
|---|---|---|---|
| Bass 32–39 | −24 | C1–C#3 | all 6 keys in the finger-bass bank (roots E1–D2, ×0.5–2.05 ⇒ E0–D3). C1=32.7 Hz sits below the RLB knee (~38 Hz) → overtone-weighted, 1/6 keys, median-robust; commented. |
| Pipe 72–79 | +12 | C4–C#6 | flute/piccolo register |
| Percussive 112–115 | +12 | C4–C#6 | tinkle-bell/agogo/steel-drum/woodblock |
| Percussive 116–119 | 0 | C3–C#5 | taiko/tom/synth-drum are low membrane drums; +12 is out of idiom (F3) |
| all others | 0 | C3–C#5 | base set |

Offsets are coarse and musical, **not** sampler zone-roots (replicating the zone table in
Python is brittle duplication). **Limitation (Codex #4):** heterogeneous families still
mismeasure some programs — GM10 music-box (bank E5+) reads the model at C3–C#5; GM76
blown-bottle (+12, loop root G3) exceeds its ×2.05 limit above ~G4. A fallback path that
happens to be level- *and* envelope-matched slips the per-key guards, so the guard is **not**
a reliable fallback backstop. Trims for heterogeneous-family programs (esp. ChromPerc, some
Pipe) are therefore emitted **low-confidence/flagged**. The proper fix is a **ground-truthed
sampled/fallback table** emitted by an in-crate `#[cfg(test)]` helper (which *can* read the
private zones + step cutoff — no public-API change, no bump) — deferred to the trustworthy
(post-timbre-bug) derivation. This increment keeps family offsets + honest flagging.

The plan TSV already records per-note key and calmeter reads keys from it, so the fix is a
`FAMILY_OFFSET` table + one transpose line in `build()`; no meter change.

### 2. Trajectory meter (`calmeter.rs`)

calmeter already computes the full 400 ms momentary series per note (`momentary_lufs`) and keeps
only the max. **Emit the series.** For each note print the onset-relative momentary levels
`b0..bK` (K≈8 for the 1.2 s window / 100 ms hop), index 0 = first block at/after the true onset
(after the `first_valid` filter-warmup discard), so `bj` is comparable across engines. Keep
`max_m` and `sounded` for compat. Pull the onset-relative selection into a pure
`fn onset_blocks(m: &[f32], first_valid: usize, last_valid: i64) -> Vec<f32>`, unit-tested (A2).
No sub-400 ms primitive, no library change; the shape policy moves to Python.

### 3. Guards + paired anchor (`derive_trims.py`)

`load()` parses **by header name** (Claude #1 — new columns must not shift the `sounded` flag)
and retains `(program,key,velocity) → {traj:[b0..bK], sounded}` (per-key, Claude #2). All policy
is top-level pure functions taking table args, callable from `main()` and `--selftest`
(Claude #4); the shipped trim is backed out through a **single** peak accessor (Claude #7).

Per key, join ferro & SC at the same `(program,key,vel)`:

- **Short-note (unmetrable) test (Codex #3).** If *either* engine's block 1 is floored
  (`b1 < peak − 40 dB` — the note is confined to the first 400 ms block, i.e. shorter than the
  100 ms hop), the 400 ms meter cannot resolve its level or distinguish matched from mismatched
  duration → mark the key **unmetrable** (`shape_dev = +inf`). This correctly refuses GM28
  palm-mute (46 ms) and the sub-hop pair Codex flagged, instead of mis-trimming them.
- **Trajectory shape.** Else peak-normalise each engine's trajectory (`fn(j)=bj−max_k bk`, ≤0),
  floor each at −40 dB rel-peak, `shape_dev = max_j |ferro_norm(j) − sc_norm(j)|` over blocks
  present in both. This is anchor/level-independent by construction (own-peak normalisation
  removes the common offset). GM33 → ~7 dB (F2 dissolved); a *matched medium* one-shot (≥2
  non-floor blocks that track) → ~0 → kept and trimmed on the peak difference.

Per program:
- **Shape/short-note guard (Codex #2):** exclude when **> 1 key** is unmetrable or has
  `shape_dev > 3 dB` (median would mask a 2-register mismatch; > 1 tolerates a single flukey
  key). Route excluded programs to the voice-fix list with the reason + failing keys.
- **Pitch-tilt guard:** exclude when `max_k(D_peak) − min_k(D_peak) > 6 dB` (GM107 koto ~13 dB;
  also surfaces residual per-key fallback as level tilt).
- **Velocity guard (F6):** anchor-free `|[F_peak(110)−F_peak(72)] − [S_peak(110)−S_peak(72)]|
  > 3 dB`.

**Level + paired anchor.** For a non-guarded program, `F_peak(p) = median over clean keys of
max_j bj` (ferro, `SHIPPED[p]` backed out via the single accessor); likewise `S_peak(p)`.
`D_p = (F_peak − S_peak) − anchor`, `anchor = median_cohort(F_peak(q) − S_peak(q))` over vetted,
non-guarded **sustained** programs (paired median, HLD §4). `trim = 0 if |D_p|<1 else
clamp(round(−0.70·D_p), ±6)`. Assert the cohort ≥ a minimum; print its members + its own median
`shape_dev` as a ≈0 sanity diagnostic (F7). Keep the sustained cross-check gate and additionally
report which sustained programs the new guards exclude.

## Build deltas (as-built — found during implementation/validation)

Two refinements the real ferro/SC-55 guardcheck differential forced (unit-tested + committed):

- **Shape guard is over the BODY (b2..bK) at SHAPE_DB=12, not the whole trajectory at 3 dB.**
  The first run excluded the entire sustained cohort: ferro's ensemble *decays* ~8 dB across the
  hold while SC-55 sustains flat, and attack ramps differ — a 3 dB threshold on a 9-block
  max-deviation flags gentle differences as catastrophes. Measuring shape over the held body only
  (excluding the legitimate attack ramp) and setting the threshold in the observed bimodal gap
  (gentle ≤~7 dB vs the GM28 collapse ~38 dB) fixes it. The A3 statement "shape_dev > 3 dB" is
  superseded by SHAPE_DB=12 over the body.
- **Anchor is `median(RENDERED ferro − SC)` over the cohort, not backed-out.** Backing `SHIPPED`
  out of the cohort un-does the frozen-good calibration that defines the frame, biasing every
  percussive trim by ~median(shipped) ≈ +3 dB. The shipped trim is subtracted once, explicitly,
  in `D_p = g − SHIPPED[p] − anchor` (`g` = rendered gap). This also makes the cross-check
  meaningful (the metric reproduces the shipped sustained trims within 1.5 dB).
