## Confirmed findings

### CR-1 — Fast bank switches can retrigger the old instrument

- **Severity:** Medium
- **Confidence:** High
- **Where:**
  `D:\worktrees\midi-music\20260724-REV-CLA@KILN-code-review-163715\crates\ferrosintesis\src\engine.rs:1833`;
  `:2482`; `:2640`; `:2811`
- **Tracked as:** new Open bug `MM-BUG-KILN-00087`.
- **Problem:** the ≤100 ms same-key retrigger lookup matches channel, key,
  program, and only the boolean CC0-alt state. It does not retain or compare
  spawn-time CC32 LSB, ignores the raw CC0 alternate-bank value, and runs
  before current melodic/drum routing is computed. A steel→mandolin bank
  change can therefore retrigger steel and return before mandolin dispatch;
  the reverse transition can replay mandolin while steel is selected.
- **Concrete fix:** retain the complete spawn-time routing identity on
  `Active`, compare it with the current strip before retriggering, and add
  both-direction CC32, nonzero-CC0, and melodic/drum boundary regressions.
- **Effort:** Small–Medium.

### CR-2 — Mandolin round-robin phase has two unsynchronised owners

- **Severity:** Medium
- **Confidence:** High
- **Where:**
  `D:\worktrees\midi-music\20260724-REV-CLA@KILN-code-review-163715\crates\ferrosintesis\src\engine.rs:2491`;
  `:2565`;
  `D:\worktrees\midi-music\20260724-REV-CLA@KILN-code-review-163715\crates\ferrosintesis\src\sampler.rs:3377`;
  `D:\worktrees\midi-music\20260724-REV-CLA@KILN-code-review-163715\crates\ferrosintesis-samples-mandolin\PROVENANCE.md:44`
- **Tracked as:** new Open bug `MM-BUG-KILN-00088`.
- **Problem:** fresh spawns advance the engine's `pitched_rr`, while fast
  retriggers rotate only the live `LaVoice` and return before advancing the
  engine counter. A take-0/take-1 fast pair followed by a gap therefore starts
  the next fresh phrase on take 1 again, producing down/up/up instead of the
  promised ordered down/up/down sequence. The same engine counter also
  advances for unrelated non-alt melodic voices, so base steel can perturb the
  next mandolin take.
- **Concrete fix:** establish one bank-scoped phase as the source of truth,
  advance it exactly once for every accepted mandolin stroke, and add an
  engine-level phrase-boundary oracle plus unrelated-bank controls.
- **Effort:** Small–Medium.
