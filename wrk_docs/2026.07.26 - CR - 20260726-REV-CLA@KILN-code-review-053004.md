### CR-2 — Realtime prewarm leaves the companion PCM cache cold

- **Severity:** High
- **Confidence:** High
- **Where:**
  `D:\worktrees\midi-music\20260726-REV-CLA@KILN-code-review-053004\crates\ferrosintesis\src\live.rs:211`;
  `D:\worktrees\midi-music\20260726-REV-CLA@KILN-code-review-053004\crates\ferrosintesis\src\sampler.rs:2814`;

- **Tracked as:** `MM-BUG-KILN-00125`
- **Problem:** prewarm touches only a core `RIDE` take. The companion crate owns a

  hook, and add a realtime regression that proves a companion key initializes no
  cache after prewarm.
- **Effort:** Small–Medium.

## Test-coverage assessment

The crate-local tests bind the current disk filename set to the embedded table,
derive every take from the eleven bank descriptors, validate ordered velocity
ceilings, pin aggregate bytes, check RIFF/WAVE signatures, and decode the entire
cache on first PCM access.

Two gaps materially enabled confirmed defects:

1. no static or no-network oracle checks the generator's per-crate output
   partition;
2. prewarm coverage explicitly treats the drum-kit cache as one external
   mechanism and cannot enumerate the companion crate's private second cache.

The semantic duration/RMS/peak loop at
`D:\worktrees\midi-music\20260726-REV-CLA@KILN-code-review-053004\crates\ferrosintesis-samples-drumkit\src\lib.rs:913`
omits `RIDE_BELL`, `HH_OPEN`, and `HH_PEDAL`. This remains report-only test debt:
all current files still decode through the shared cache and no current audio-shape
defect was established.

## Not reported as defects

- **Invalid public `Bank` descriptors — hardening only.** Public fields allow an
  external caller to construct empty velocity layers or zero round robins, and
  `layer_for_velocity()` then panics or underflows. Every shipped static descriptor
  satisfies the invariant and the crate's tests cover them. A validated constructor
  is sensible API hardening, but no current ferrosintesis route can create the bad
  state.
- **Malformed-WAV parser panic — trusted-input boundary.** `decode_wav()` assumes
  the private embedded table contains valid committed WAVs. It is not exposed as a
  decoder for caller-controlled bytes, and the current inventory decodes through
  cache initialization.
- **Duplicate or missing current payload — refuted.** The 140 disk/table filename
  sets match exactly and all 140 SHA-256 values are distinct.
- **Per-file source SHA-256 pin — not promoted.** Exact commit-addressed GitHub URLs,
  HTTPS, and the per-revision cache path prevent ordinary upstream drift. A separate
  digest manifest would harden against a locally poisoned cache or compromised
  endpoint, but this pass established no altered current source or package payload.
- **Unused `SNARE_OFF` — by design.** It is a public bank without a current GM key,
  not dead code; generic-player policy forbids treating in-repo routing counts as the
  instrument's reachability contract.
