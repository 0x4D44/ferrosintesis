## 2. The unattended drain fixes fine — it has nowhere to land

**This is where my own first draft was wrong. I framed it as "switching the fix model to Codex

**All 11 unattended runs produced a fix and marked the bug Fixed. Trunk held them 2–18 seconds

02:14:02  e77cd30  hold(MM-BUG-KILN-00038): fix owner branch      <- 15 s later

### Three reasons the model explanation fails

1. **Codex was already the fixer *before* the change.** Co-author trailers on the daytime fixes
   that landed 21/21 read `GPT-5 Codex`, `OpenAI Codex` and `OpenAI GPT-5.6-Sol` (`bd72fe7`,

2. **There is no "before" to collapse from.** Across the *entire repo history*, `git log --all`

   pre-change bug carries `Owner: deltic:manual` and the body *"Deltic manual fix landed via
   `deltic bugs land`."*; every post-change one carries `Owner: deltic:gpt-5.5` and *"Deltic

   **`21 gate=manual` and nothing else — `gate=auto` has never once appeared.** A human running
   `deltic bugs land` simply does not invoke a hold path, so "0 holds pre-change" measures the
   absence of that path, not a 100 % success rate.
