## Confirmed findings

### CR-1 — The overlap oracle misses whole-file and event-order ambiguity

- **Severity:** Medium
- **Confidence:** High
- **Where:**
  `crates/render-catalog/tests/album_midi_overlaps.rs:42-47,92-114,141-155`
- **Tracked as:** `MM-BUG-CRUCIBLE-00008`
- **Effort:** Medium

`track_overlaps` resets its maps for every `MTrk`, so format-1 overlaps split
across tracks sum to zero. It also discards event order by retaining ticks only;
a same-tick note-on serialized before the matching note-off passes the strict
`end > next_start` comparison. Finally, unequal on/off counts skip the key, so
`on@0, on@10, off@20` returns zero despite a real overlap.

The cross-track concern is not theoretical model disagreement. The production
parser collects every track into one `raw` event list and sorts that merged list
at `crates/ferrosintesis/src/midi.rs:238-245,423-432`.

**Concrete fix:** replace per-track positional tick pairs with one file-wide,
ordered event-state machine. Add adversarial positive controls for cross-track
overlap, both same-tick orderings, unequal counts, and a clean repeated note.

### CR-2 — Discovery silently drops filesystem enumeration errors

- **Severity:** Medium
- **Confidence:** High
- **Where:** `crates/render-catalog/src/main.rs:480-503,590-599`
- **Tracked as:** `MM-BUG-CRUCIBLE-00009`
- **Effort:** Small–Medium

`sorted_midis` flattens both `read_dir` and entry errors. The recursive ownership
scan silently returns on a directory-open error and flattens entry errors. Lyrics
validation repeats the entry-error suppression. If readable siblings remain,
both sides of the ownership comparison can omit the same inaccessible entry and
the command can report a smaller catalog as complete.

**Concrete fix:** return `Result` from both walkers, propagate every directory and
entry error with path context, and replace I/O `flatten()` calls. Test through an
injected reader that yields one entry plus one error.

### CR-3 — A nonzero encoder preflight passes

- **Severity:** Medium
- **Confidence:** High
- **Where:** `crates/render-catalog/src/main.rs:759-763`, with the consequence at
  `:695-721,834-859`
- **Tracked as:** `MM-BUG-CRUCIBLE-00010`
- **Effort:** Small

The preflight asks only whether `ropusenc --version` spawned. A process that exits
nonzero still returns `Ok(Output)`, so it passes. Each worker then synthesizes a
full normalized WAV before the real encoder fails, and the queue continues across
the remaining selection.

**Concrete fix:** require `status.success()`, report a bounded stderr tail, and
prove with a fake nonzero `--version` encoder that synthesis never starts.

### CR-4 — Encoder waits have no deadline

- **Severity:** Medium
- **Confidence:** High
- **Where:** `crates/render-catalog/src/main.rs:714,761,829-868`
- **Tracked as:** `MM-BUG-CRUCIBLE-00011`
- **Effort:** Medium

Both preflight and per-track encoding use blocking `Command::output()` without a
deadline. A stuck preflight blocks the run before discovery. A stuck encode holds
its large WAV and prevents scoped worker joining forever.

**Concrete fix:** share a bounded child-process helper that kills and waits on
timeout. Derive or configure a generous track-aware deadline. A fake encoder that
never exits must prove bounded failure, child reaping, and WAV cleanup.

## Needs re-verification — held, not reported as defects

- **Final Opus failure atomicity:** `crates/render-catalog/src/main.rs:684-724`
  gives `ropusenc` the final path and validates only exit success plus existence.
  The caller does not itself preserve a previous file or reject empty/stale output.
  Confirming actual truncation/partial-write behavior requires reading or running
  the external `ropusenc`, which this pass deliberately did neither. This remains
  unverified and was not filed.
- **Captured encoder output growth:** `Command::output()` buffers stdout/stderr,
  but this pass did not establish that the real encoder emits output proportional
  to track duration. Not filed.

## Not reported (why)

- **Shell injection:** refuted. `ropusenc_argv` creates distinct arguments and
  `Command::args` invokes no shell (`main.rs:360-391,714`).
- **`--only-list` path escape:** refuted. User strings only select paths already
  discovered under the catalog (`main.rs:775-799`).
- **Symlink and non-UTF-8 cases as security findings:** refuted as framed. They
  can create local robustness or filename-collision failures, but this tool runs
  repository code over a trusted checkout; no separate attacker-controlled
  filesystem boundary was established.
- **Worker success-tally gap:** valid but already recorded as CR-9 in
  `wrk_docs/2026.07.18 - CR - overnight review pass (ferrosintesis core).md`.
  Normal per-track panics are caught, so it remains defensive and was not duplicated.
- **Every equal-tick handoff is ambiguous:** refuted. Off-before-on is clean;
  on-before-off is the missed case because serialized order matters.
- **Catalog metadata derivation:** `ALBUMS` is hand-maintained, but no current
  mismatch or authoritative replacement source was established. That is not enough
  evidence for a defect or a Draft requirement.
- **Sidecar validation test quality:** the test at `main.rs:1064-1079` does not
  prove validation remains before rendering. This is a real coverage weakness, but
  no current behavior failure was found, so it stays in this report rather than the
  bug or requirement ledger.
