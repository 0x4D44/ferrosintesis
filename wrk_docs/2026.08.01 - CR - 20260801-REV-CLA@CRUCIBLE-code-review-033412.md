## Scope and method

The assigned primary scope was exactly `crates/ferrosintesis-samples-bass/`. The review
read every file in that directory, all thirteen WAV headers and PCM boundaries, and only
the generator, consumer, packaging, and tests needed to check concrete claims.

Seven independent reviewers covered correctness, security, performance/scale, reliability,
maintainability, test coverage, and devil's advocacy. The lead then re-read every cited
path and checked the bug ledger for duplicates. Candidate findings were classified as
confirmed, refuted, or unverified. No reviewer was skipped or rate-limited.

This pass did not run the application, generators, tests, builds, audio renders, listening
checks, or the exploratory-test harness.

## Confirmed findings

### Medium — Warm caches ignore selected archive-member changes

- **Confidence:** High
- **Location:**
  `D:\worktrees\ferrosintesis\20260801-REV-CLA@CRUCIBLE-code-review-033412\tools\ferrosintesis-samples\prepare.py:1378`
  and `:1459`
- **Tracked as:** `MM-BUG-CRUCIBLE-00019`
- **Problem:** the manifest binds the archive pin, destination names, and cached hashes,
  but not the destination-to-archive-member mapping. A value-only recipe correction under
  the same destination and pin is ignored on warm machines, while clean machines apply it.
- **Concrete fix:** version the manifest, bind the exact mapping or its canonical digest,
  require equality, and add a mapping-value-only invalidation regression.
- **Effort:** Small.

### Medium — A new archive pin can attest a stale extracted member

- **Confidence:** High
- **Location:**
  `D:\worktrees\ferrosintesis\20260801-REV-CLA@CRUCIBLE-code-review-033412\tools\ferrosintesis-samples\prepare.py:1431`
  through `:1487`
- **Tracked as:** `MM-BUG-CRUCIBLE-00020`
- **Problem:** 7z extracts into a persistent directory without clearing or staging it.
  When a new pinned archive omits a selected member, the old path can survive, be copied,
  and receive a fresh manifest under the new pin.
- **Concrete fix:** extract into a fresh temporary directory, validate the complete selected
  set there, stage publication, and add a stale-leftover negative control.
- **Effort:** Small–Medium.

### Medium — Six bass assets inject a note-on discontinuity

- **Confidence:** High for the waveform defect; audibility unverified
- **Location:**
  `D:\worktrees\ferrosintesis\20260801-REV-CLA@CRUCIBLE-code-review-033412\tools\ferrosintesis-samples\prepare.py:2052`,
  `D:\worktrees\ferrosintesis\20260801-REV-CLA@CRUCIBLE-code-review-033412\crates\ferrosintesis\src\sampler.rs:3814`,

  `D:\worktrees\ferrosintesis\20260801-REV-CLA@CRUCIBLE-code-review-033412\crates\ferrosintesis\src\voices.rs:10499`
- **Tracked as:** `MM-BUG-CRUCIBLE-00021`
- **Problem:** onset-at-frame-zero sources get no de-click fade. Six committed assets begin

  both transient preservation and the silence-to-first-frame step across the whole bank.
- **Effort:** Small.

## Not reported

- **The 0.908-second WAVs are oversized for a 150 ms overlay — refuted.** Supported
  24-semitone pitch bend multiplies the sample read step. At the bass admission ceiling,
  a 150 ms output window can consume about 0.801 seconds of source, so most of the file is
  reachable rather than dead weight.
- **Missing `fingerbass_D#2.wav` — refuted.** The generator deliberately selects six
  whole-tone-spaced finger zones through D2; the consumer documents that exact bank.
- **Linear `get()` lookup is a scale defect — refuted.** Thirteen entries are searched
  only during one-time bank initialization; voices borrow the cached zones.
- **Filename/root metadata needs a new requirement — deduplicated.** The generator still
  prints measured roots while the runtime repeats them manually, but prior bass and grand
  reviews already record the per-file digest/root manifest remedy.
