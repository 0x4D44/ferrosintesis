## Confirmed prevention debt

### RD-1 — Mandolin payload identity and measured roots have no single authoritative manifest

- **Severity:** Low prevention gap; no current wrong payload or root
- **Confidence:** High
- **Location:** `crates/ferrosintesis-samples-mandolin/src/lib.rs:190-223`; `crates/ferrosintesis-samples-mandolin/PROVENANCE.md:31-42`; `crates/ferrosintesis/src/sampler.rs:2728-2816,6698-6775`; `tools/ferrosintesis-samples/gen_crate_lib.py:165-213`
- **Gap:** The crate pins the filename set, aggregate size, RIFF/WAVE signatures, and lookup results, but not each filename's exact baked payload. Its generator emits a pairwise duplicate-payload guard only for crates with aliases. The sampler separately hand-copies all 40 measured roots. Its oracle checks range, fretboard intervals, and cross-take agreement, but a coherent in-range shift of all four roots in one zone can pass. A same-size WAV swap or duplicated round-robin payload can likewise pass the mandatory static guards. All current bytes and roots are correct; this is prevention debt, not a current defect.
- **Concrete fix:** Commit one authoritative manifest containing filename, measured root, baked SHA-256, and round-robin identity. Generate or validate both `SAMPLES` and the sampler zone tables from it. Always emit the physical-payload uniqueness guard, not only when aliases exist. Include negative controls for a same-size swap, a duplicated take, and a coherent four-root shift.
- **Effort:** Medium.
- **Prior evidence:** The 2026-07-24 mandolin review recorded the same filename-to-payload/root-binding blind spot as report-only debt, and linked the cross-family form in the CC-BY review. This pass did not mint a second requirement blindly.
