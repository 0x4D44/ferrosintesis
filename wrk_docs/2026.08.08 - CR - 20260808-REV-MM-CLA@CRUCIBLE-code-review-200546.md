## Confirmed defects

### Low — The runtime can never reach 1.15 seconds of every embedded WAV

- **Confidence:** High
- **Where:** `crates/ferrosintesis-samples-clavinet/src/lib.rs:14`;
  `crates/ferrosintesis/src/sampler.rs:5517` and
  `crates/ferrosintesis/src/sampler.rs:5671`
- **Tracking:** ready to file; `deltic bugs new` could not allocate an ID
- **Problem:** each file carries 70,560 frames. The loop finder permits starts
  only through 0.34 seconds and lengths only through 0.11 seconds, so every
  selected loop ends by 0.45 seconds (19,845 frames). `sample_at` wraps every
  subsequent read modulo that loop. It cannot read frames after the selected
  loop end.
- **Impact:** 50,715 unreachable frames remain per zone. Across eleven zones,
  that is 1,115,730 embedded PCM bytes plus 2,231,460 decoded `f32` heap bytes.
  The loop-search setup also prepares samples beyond any possible candidate.
- **Concrete fix:** truncate after a proved-safe interpolation guard beyond the
  maximum selected loop without adding a fade that changes candidate samples.
  Narrow the loop-search working range. Add a differential oracle proving the
  pre/post voice is bit-exact across every root plus representative sample rates
  and pitch bends. Update the size and provenance claims.
- **Effort:** Small/medium.

### Low — The generated legal pointer breaks twelve published rustdoc headers

- **Confidence:** High
- **Where:** `crates/ferrosintesis-samples-clavinet/src/lib.rs:6-7`;
  generator at `tools/ferrosintesis-samples/gen_crate_lib.py:40`; guard at
  `tools/ferrosintesis-samples/test_prepare.py:3042`
- **Tracking:** ready to file; `deltic bugs new` could not allocate an ID
- **Problem:** the generated line starts with the isolated sentence
  `` `ferrosintesis`. Licence/provenance: ... ``. It is grammatical only when
  the preceding generated line ends with “through”. Clavinet's hand-written
  paragraph already finishes the sentence and names both documents, so published
  rustdoc renders an orphaned one-word sentence and repeats the pointer.
- **Extent:** a source census found the same orphaned continuation in twelve
  hand-written sample-crate headers: bottle, clavinet, core, drumkit, drumkit2,
  fretnoise, gong, grand, musescore, orchestral2, sax, and strings. The existing
  test requires the fragment verbatim but does not inspect its surrounding
  sentence, so it enforces the defect.
- **Concrete fix:** make the legal/provenance pointer a complete standalone
  sentence, update the twelve hand-written headers, and add an adversarial fixture
  whose preceding paragraph is already complete.
- **Effort:** Small.

## Draft-worthy structural debt

### Derive the clavinet package inventory and runtime zone map from one manifest

- **Confidence:** High
- **Where:** package table at
  `crates/ferrosintesis-samples-clavinet/src/lib.rs:11`; generator output at
  `tools/ferrosintesis-samples/prepare.py:4422`; runtime roots at
  `crates/ferrosintesis/src/sampler.rs:5586`
- **Tracking:** ready to capture as a Draft requirement; allocation was not
  attempted after the clone-wide allocator failed closed.
- **Statement:** the system must derive or mechanically compare each clavinet
  filename, measured root, and payload identity across the generator, published
  asset crate, and runtime zone map.
- **Why:** all three current inventories agree, but they are maintained
  independently. A rebake can package a renamed or added zone while the runtime
  still requests the old name, producing a setup panic or an unused asset.
- **Suggested flow:** Heavy; **priority:** Could; **effort:** Medium.

## Test and packaging gaps retained as report-only

- **Per-file identity and strict PCM fields:** `src/lib.rs:78-119` pins the
  filename set, aggregate size, RIFF/WAVE signatures, and lookup behavior. It
  does not bind each same-sized payload to its filename or validate chunk bounds,
  PCM encoding, channels, and sample rate. This is already recorded in
  `wrk_docs/2026.07.25 - CR - 20260725-REV-CLA@KILN-code-review-235852.md:53`;
  no duplicate requirement was raised.
- **Published archive contents:** `Cargo.toml:10` correctly includes
  `samples/**`, `NOTICE`, and `PROVENANCE.md`, but checkout-based tests do not
  prove the generated crate archive contains them. No present omission was found.
- **Generator coverage:** no focused fixture pins the eleven SF3 roots or the
  clavinet bake contract. The runtime hold, loop-seam, attack, release, routing,
  and prewarm oracles substantially reduce the current risk.
- **Copyable recipe:** packaged provenance explains the pin and pipeline but does
  not give the scoped `--only=clavinet` plus inventory/runtime refresh sequence.
  `MM-BUG-KILN-00142` already records that this is an owner judgment, not an
  established defect.
