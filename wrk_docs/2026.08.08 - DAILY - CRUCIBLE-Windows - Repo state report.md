Four tracks × 32 contiguous programs = the full 0–127 melodic range.

**What is genuinely verified.** I checked the coverage oracle rather than trusting the prose, and it is
stronger than `VALIDATION.md` claims:

- `verify.py:169` — `missing_programs = sorted(set(range(128)) - heard)`.
- `heard` derives from `engine.py:1064`, which counts a program only where `program_notes[program] > 0`;
  that counter increments solely in the `note_on` branch at `engine.py:1019-1020`, keyed on the program
  active when the note-on lands. So it counts **sounding notes, not Program Change events**.
- `verify.py:80-96` adds per-track floors — minimum note-on counts (4 or 24) and minimum sounding beats
  (1.0 or 8.0) — explicitly rejecting thin or brief coverage.
- The build contract rebuilds twice and requires byte-identical output, and compares the committed `.mid`
  and manifest against the in-memory rebuild before any musical oracle runs.

That is a well-built structural oracle. I did not run it; I read it.

**What is not verified.** The gap is entirely on the audio side:

- No `analyze.py`. Of 22 album `build.py` bundles in the repo, 11 have an `analyze.py`; this one does not.
- `VALIDATION.md:29` states the render measurements use "TimGM6mb through FluidSynth, not Ferrosintesis"
  and "do not validate Ferrosintesis timbre, samples, bank variants, physical models or effect semantics".
- `albums/gpt5-6/Every Voice Forward/README.md:45-51` gives ferrosintesis render *instructions*, not a
  render *result*.
- No mention of the album in `wrk_docs/`, `wrk_journals/`, or `reqs/`.

I had a fresh-context skeptic try to refute all of the above, including whether another album already
covers 0–127 and whether the oracle is weaker than it looks. It refuted nothing. The nearest miss it found
is `albums/gpt5-6/Bright Matter/verify.py:56`, which is a restricting whitelist — the opposite check.

**Why this matters beyond one album.** CLAUDE.md warns repeatedly that an in-repo usage census is a fact
about our albums, not about the synth, and that GM programs no album reaches are still part of the public
instrument. This album collapses that gap: it authors essentially the whole instrument. A single
ferrosintesis render of five tracks now exercises every melodic program, every percussion key, four bank
variants and thirteen controller lanes. Nothing else in the repo buys that much coverage for that little
work. Whatever it surfaces — silent programs, DC, level outliers, bank-select misses — is a real finding
about the synth.
