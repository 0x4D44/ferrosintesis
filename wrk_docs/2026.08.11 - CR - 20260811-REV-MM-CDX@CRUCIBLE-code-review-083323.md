## Confirmed finding

### Low — failed PCM lookups initialize and retain the full core cache

- **Confidence:** High
- **Where:** `D:\worktrees\ferrosintesis\20260811-REV-MM-CDX@CRUCIBLE-code-review-083323\crates\ferrosintesis-samples-drumkit\src\lib.rs:751`; package-wide initializer at `D:\worktrees\ferrosintesis\20260811-REV-MM-CDX@CRUCIBLE-code-review-083323\crates\ferrosintesis-samples-drumkit\src\lib.rs:780`; corrected companion implementation at `D:\worktrees\ferrosintesis\20260811-REV-MM-CDX@CRUCIBLE-code-review-083323\crates\ferrosintesis-samples-drumkit2\src\lib.rs:226`
- **Problem:** `pcm(name)` calls `decoded_samples()` before its fallible name search. `pcm_by_index(index)` likewise initializes before checking bounds. A missing name or invalid index therefore decodes and permanently retains all 128 takes before returning `None`.
- **Impact:** a typo, probe, or invalid diagnostic index pays the package's complete conversion and roughly 9.63 MB PCM residency cost. Normal synth NoteOn routing uses valid indices and explicit prewarming, so this is a public API miss-path defect rather than a normal render-path failure. Exact time and peak RSS are unverified.
- **Concrete fix:** resolve the name or validate the index first, then call `decoded_samples()` only for a valid take. Preserve eager package-wide decoding for valid lookups and `prewarm()`.
- **Regression oracle:** port the companion crate's pristine-process test at `D:\worktrees\ferrosintesis\20260811-REV-MM-CDX@CRUCIBLE-code-review-083323\crates\ferrosintesis-samples-drumkit2\src\lib.rs:401`. Both miss forms must leave `pcm_cache_initializations()` at zero; a following valid lookup must initialize it exactly once.
- **Effort:** Small
- **Tracking:** `MM-BUG-CRUCIBLE-00023`

Closed `MM-BUG-KILN-00174` is not a deduplication match because its fix and
regression cover only `ferrosintesis-samples-drumkit2`; the core crate still has
the pre-fix ordering. The required `deltic bugs --open --json` query found no
Open records on the supplied baseline. Its internal origin refresh could not
write this worktree's read-only `FETCH_HEAD`, so the command honestly reported
`origin-stale`; no explicit fetch was run.

## Not reported

- **Private RIFF parser hardening — refuted as a current defect.** `decode_wav()` consumes only compile-time first-party assets. All current files have valid checked extents and canonical PCM headers. Fallible parsing and adversarial malformed fixtures would improve defense in depth, but no shipped malformed payload or caller-controlled path exists.
- **Raw plus decoded payload residency — intentional.** The crate exposes raw WAV bytes and decoded PCM, and `prewarm()` explicitly initializes the complete cache away from realtime work. Removing one representation is an API/size tradeoff, not a correctness finding.
- **Cold valid first hit — intentional contract.** Without `prewarm()`, a valid first take initializes the whole cache. The docs say to prewarm away from a realtime thread, and the synth prewarms both drum packages.
- **Per-file processed-output digest manifest — not a current defect.** Current files, generated inventory, package inventory, and aggregate bytes agree. A cryptographic artifact manifest would be supply-chain hardening, not evidence of altered output.
- **Removal of `SNARE_OFF` and `CRASH_SIZZLE` — refuted.** Arthur approved the removal in `D:\worktrees\ferrosintesis\20260811-REV-MM-CDX@CRUCIBLE-code-review-083323\wrk_journals\2026.07.29 - JRN - approved scratchpad decisions.md:25`. Commit `bbf122d` landed before the first real crates.io release dated 2026-07-30, so it did not break an already-published API. Current routing and inventories contain no stale references.
- **Descriptor parity gap — already tracked.** Draft `MM-REQ-KILN-00176` covers the structural oracle. Current generator and Rust values agree.
- **Semantic audio sweep omissions — report-only test debt.** The duration/peak/RMS loop omits `RIDE_BELL`, `HH_OPEN`, and `HH_PEDAL`. Static inspection found no malformed current asset, so the missing negative oracle is not itself a shipped defect.
