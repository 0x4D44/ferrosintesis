## Test gaps that let these escape

- Realtime tests cap active voices but never feed more than the pending-command budget.
- Parser robustness tests cover truncated VLQs and one maximum delta, not a complete
  overlong VLQ or cumulative tick overflow.
- The only extreme sample-rate test exercises WAV-length preflight, not echo allocation,
  direct buffered render, or realtime construction.
- The GS reset oracle sends Program Change after reset, reconstructing the state it should
  be checking.
- Normalizer tests either need gain first or stay under the ceiling. Scratch parity uses the
  buffered implementation with the same early exit as its oracle.
- No public normalization test rejects NaN or infinity before touching output.

Each bug record names a focused negative control. Per repository policy, every new test
must be demonstrated red against the current implementation before its fix is accepted.

## Not reported

- Per-NoteOn allocations remain an accepted soft-realtime constraint recorded in closed
  MM-BUG-KILN-00092. The unbounded command queue is different: it has no capacity limit and
  no bounded callback workload.
- Offline event placement at 64-frame block boundaries is a documented residual of closed
  MM-BUG-KILN-00078, not a new finding.
- The embedded sampler's malformed-RIFF panic is not runtime caller input; the publish-time
  validator gap is already MM-BUG-KILN-00195.
- Consolidating live and SMF parsers was refuted: their framing differs and their modeled
  SysEx recognizer is already shared.
- A proposed full Roland GS Reset implementation was refuted as outside the documented
  scope. MM-BUG-CRUCIBLE-00030 is narrower: the routing effect already modeled must leave
  its own derived state coherent.
- The performance lens observed controller events that scan active voices. Without a
  measured deadline breach or a stronger complexity argument, that remains unverified and
  is not reported as a defect.
