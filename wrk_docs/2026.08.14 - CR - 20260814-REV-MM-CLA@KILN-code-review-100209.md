  whitelist; `inventory_matches_packaged_wavs` (`src/lib.rs:205`) derives the
  expected set from the filesystem, so hand-list drift and duplicate names are

  915–922, `cello_bank` p/f at 1062–1085). `exercise_every_public_bank`

  velocity 0–127 and calls `pizzbass_bank()` (`sampler.rs:6164`), so both
  velocity layers decode under `cargo test --workspace` — the 2026.07.26
  "default tests miss alternate banks" lesson does not bite here.
- **Format claims:** the crate-level claim "mono 16-bit 44.1 kHz" is enforced at
  decode by `parse_wav` (`sampler.rs:56-82`, hard assert `channels == 1 && sr ==
  44100 && bits == 16`), which the exercise sweep forces over every zone. Direct
  fmt-chunk inspection was not run this pass (script execution unavailable in
  this mode) — the claim is verified by reading the enforcement path, not by
  executing it; the workspace suite runs it at integration.
- **Source pins:** README rev `6fd75fb` == `BIGCAT_REV`
  (`tools/ferrosintesis-samples/prepare.py:346`); README/PROVENANCE rev
  `44030090…` == `VSCO_REV` (`prepare.py:35`). The regeneration selector
  `--only=cellosolo,dbass,pizzbass` matches the packaged families exactly and is
  itself guarded by `regeneration_selector_errors`
