## Actionable findings

### Low — the cold-cache regression can still escape process isolation

- **Confidence:** High; independently confirmed by a skeptic from the exact control flow and adversarial schedule
- **Tracked as:** `MM-BUG-KILN-00202`
- **Evidence:** `D:\worktrees\ferrosintesis\20260816-REV-MM-CDX@KILN-code-review-075555\crates\ferrosintesis-samples-drumkit2\src\lib.rs:414` treats an inherited `FERRO_DRUMKIT2_PCM_MISS_PROBE` plus one cold-cache snapshot as proof that the test is already its child. If another libtest thread initializes `PCM_CACHE` after that snapshot, assertions at lines 432-438 become schedule-dependent in the shared parent process.
- **Concrete impact:** a correct `pcm` miss implementation can fail its regression under parallel test order, or the test can pass without proving pristine-process isolation. Closed `MM-BUG-CRUCIBLE-00035` fixed the already-warm inherited-marker case, not this cold-at-snapshot race.
- **Concrete fix:** move the assertions to a separate ignored child test and always re-exec that exact child with `--ignored --exact --test-threads=1`, requiring explicit evidence it ran. Add an inherited-marker, initially-cold, concurrent-warmer regression.
- **Effort:** Small

### Low — the accent-cymbal audio oracle admits silent and click-only assets

- **Confidence:** High; independently confirmed with two source-level counterexamples
- **Tracked as:** `MM-BUG-KILN-00203`
- **Evidence:** `D:\worktrees\ferrosintesis\20260816-REV-MM-CDX@KILN-code-review-075555\crates\ferrosintesis-samples-drumkit2\src\lib.rs:455` validates only `CRASH` and `CHINA`, omitting routed `SPLASH`. Lines 467-468 require only one sample above 16,000 for the covered banks. The remaining tests require headers, names, sizes, resolvable indices, and nonempty PCM, not meaningful signal energy.
- **Concrete impact:** same-length zeroed splash PCM stays green while GM key 55 becomes silent. A same-length crash/china payload containing one sample at 16,001 also stays green while becoming a click.
- **Concrete fix:** validate every bank through one duration table, including `SPLASH`; apply the generator-normalized peak range and an RMS floor to every take. Add silent-splash and single-impulse negative controls.
- **Effort:** Small
