# Code review — `crates/ferrosintesis-samples-headroom/`

Read-only review of the assigned Headroom/Intimate Piano asset crate at the fresh
Deltic-supplied `origin/main` baseline. The pass inspected source, manifest,
packaged documentation, provenance, aliases, all 45 asset headers/hashes, direct
runtime lookups, recent WAV-to-FLAC history, and only the regeneration code needed
to establish the crate's contracts. It did not fetch, run the app, tests, decoder,
generators, rendering, packaging, or the exploratory-test harness.

## Confirmed findings

### Low — package documentation still describes WAV payloads after FLAC migration

- **Confidence:** High.
- **Evidence:**
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-004326\crates\ferrosintesis-samples-headroom\README.md:8`
  says 54 WAVs are embedded. `PROVENANCE.md:10` describes 45 unique WAVs, and
  `NOTICE:4` calls the embedded payloads WAVs. The actual table at
  `src\lib.rs:15` contains 45 FLAC files; `src\lib.rs:198` adds nine `.wav`
  logical aliases that return canonical FLAC bytes.
- **Impact:** Package users and auditors receive the wrong physical inventory and
  container contract. A consumer trusting the alias suffix can also mistake returned
  FLAC bytes for RIFF/WAV.
- **Concrete fix:** Update README, provenance, and notice together to distinguish
  45 physical FLACs from 54 logical names; derive a documentation guard from the
  actual inventory and alias table.
- **Effort:** Small.
- **Tracked:** `MM-BUG-KILN-00247`.

### Low — documented regeneration writes unconsumed WAVs and leaves FLAC stale

- **Confidence:** High.
- **Evidence:**
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-004326\crates\ferrosintesis-samples-headroom\README.md:15`
  and `PROVENANCE.md:63` publish `prepare.py --only=headroom` as the regeneration
  command. `tools\ferrosintesis-samples\prepare.py:689` collapses 54 logical
  sources to 45 physical names, all `.wav` at `prepare.py:780`; the loop writes
  those WAVs at `prepare.py:5733`. The validator at `prepare.py:5402` ignores FLAC.
- **Impact:** The command adds 45 WAVs beside 45 old FLACs, leaves runtime on the
  stale FLAC bank, and makes the 45-file inventory test see 90 physical assets.
- **Concrete fix:** Make the scoped recipe own verified final FLAC conversion and
  inventory/alias refresh, and reject mixed containers before publication.
- **Effort:** Medium.
- **Tracked:** `MM-BUG-KILN-00248`.

## Durable design debt

### Draft requirement — publish the Headroom bank failure-atomically

`tools\ferrosintesis-samples\prepare.py:5733` writes bank files one by one, while
`prepare.py:4247` protects only each individual file. A late failure can therefore
leave a partial generated overlay. Adversarial review rejected this as a current
runtime defect because the active command already targets the wrong extension and
the runtime FLAC bank remains unchanged. The structural failure mode is real and
actionable, so `MM-REQ-KILN-00249` records the staged, validated, all-or-nothing
publication contract and failure-injection oracle. Proposed effort: Medium; Heavy
flow.

## Not reported as new findings

- **Refuted:** Current runtime Headroom lookups are mismatched. Every sampler key at
  `crates\ferrosintesis\src\sampler.rs:1447` names an embedded FLAC, and the loud
  RR2 accessor deliberately reuses the medium RR2 bank at `sampler.rs:1532`.
- **Refuted:** The committed physical bank contains duplicates, missing payloads, or
  non-FLAC files. Static inspection found 45 files, 45 unique SHA-256 values, FLAC
  magic on all, and the exact 2,460,740-byte aggregate pinned in `src\lib.rs:231`.
- **Refuted:** Linear `get()` lookup is a meaningful performance or denial-of-service
  risk. It is bounded to 45 payloads plus nine aliases and runs during one-time bank
  initialization, not per audio frame.
- **Refuted:** The package omits attribution. `Cargo.toml:10` ships README, NOTICE,
  and provenance; those documents retain Bengt Nilsson, the instrument name, SFZ
  mapping credit, CC BY 4.0, and the pinned upstream revision.
- **Unverified:** FLAC decode correctness, PCM identity, MD5 enforcement, and rendered
  audio equivalence. This pass intentionally did not run the decoder, app, tests, or
  exploratory harness. Open `MM-BUG-KILN-00232` through `00236` already track known
  decoder defects outside this crate.
