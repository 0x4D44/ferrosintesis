  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-014426\crates\ferrosintesis-samples-honkytonk\src\lib.rs:12-57`.
- **Impact:** the documents promise WAV payloads, while exact-name lookup exposes

### 2. Documented regeneration leaves the embedded FLAC bank stale

- **Severity:** Low
- **Confidence:** High
- **Location:**
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-014426\crates\ferrosintesis-samples-honkytonk\README.md:14-15`,
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-014426\crates\ferrosintesis-samples-honkytonk\PROVENANCE.md:48-54`,
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-014426\tools\ferrosintesis-samples\prepare.py:4787-4818,5402-5429`, and
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-014426\crates\ferrosintesis-samples-honkytonk\src\lib.rs:70-84`.
- **Impact:** `prepare.py --only=honkytonk` writes nine WAVs beside the nine
  committed FLACs. Runtime continues using stale FLACs, while the inventory test
  sees 18 files against `FILE_COUNT = 9`.
- **Concrete fix:** stage and verify final FLAC outputs, publish the bank as one
  unit, reject mixed containers before writing, refresh the generated table, and
  add a FLAC-only-tree negative regression.
- **Effort:** Medium.
- **Tracked as:** `MM-BUG-KILN-00251`.

### 3. Shared FLAC migration tool is not failure-atomic as documented

- **Severity:** Low
- **Confidence:** High
- **Location:**
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-014426\tools\ferrosintesis-samples\to_flac.py:19-24,153-177`.
- **Impact:** the tool deletes each source WAV before later conversions finish.
  A late failure can leave a converted prefix and an unconverted suffix, despite
  the promise that failure deletes nothing. This is latent tooling risk; the
  current Honkytonk bank is a clean nine-FLAC set.
- **Concrete fix:** stage and verify every output for a bank before publishing any;
  clean failed staging and add a late-failure negative control.
- **Effort:** Medium.
- **Tracked as:** `MM-BUG-KILN-00252`.
