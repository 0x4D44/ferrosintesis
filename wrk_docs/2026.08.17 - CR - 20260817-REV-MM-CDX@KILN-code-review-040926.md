### 1. Required bottle-routing regression still names the removed WAV

- **Severity:** Medium.
- **Confidence:** High.
- **Location:**
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-040926\tools\ferrosintesis-samples\test_prepare.py:2742`,
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-040926\tools\ferrosintesis-samples\test_prepare.py:2761`, and
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-040926\.deltic-integrate.toml:59`.
- **Evidence:** `packaged_in()` checks an exact physical path, but the regression
  asks for `bottle_C6.wav`. The package now contains only `bottle_C6.flac`, so the
  assertion receives an empty set. The same unittest discovery is mandatory in
  both the workspace and fallback integration gates.
- **Impact:** the committed required Python gate is deterministically red before

- **Concrete fix:** derive the key from the current crate inventory or update it to
  `bottle_C6.flac`; add a negative control proving a container migration cannot
  silently invalidate the routing oracle.
- **Effort:** Small.
- **Tracked as:** `MM-BUG-KILN-00257`.

### 3. Documented regeneration leaves the active FLAC bank stale

- **Severity:** Low.
- **Confidence:** High.
- **Location:**
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-040926\crates\ferrosintesis-samples-musescore\PROVENANCE.md:7`,
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-040926\tools\ferrosintesis-samples\prepare.py:4528`,
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-040926\tools\ferrosintesis-samples\prepare.py:4561`, and
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-040926\tools\ferrosintesis-samples\prepare.py:5419`.
- **Evidence:** the published six-family command calls `_bake_sf_onset`, which
  validates and writes 36 WAVs. The package and direct runtime consumers use only
  the 36 FLAC names, while the stale-output guard ignores FLAC files.
- **Impact:** following the documented recipe adds 36 unconsumed WAVs beside 36
  unchanged FLACs, leaves playback stale, and makes the crate inventory see 72
  assets against `FILE_COUNT = 36`.
- **Concrete fix:** stage, encode, and verify the final FLAC set; reject mixed
  containers before publication; replace the active bank and refresh its generated
  inventory. Add a negative fixture starting from the current FLAC-only tree.
- **Effort:** Medium.
- **Tracked as:** `MM-BUG-KILN-00259`.

### 4. Onset regeneration is atomic per file, not per family bank

- **Severity:** Low.
- **Confidence:** High.
- **Location:**
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-040926\tools\ferrosintesis-samples\prepare.py:4247` and
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-040926\tools\ferrosintesis-samples\prepare.py:4544`.
- **Evidence:** `_bake_sf_onset` publishes each completed zone directly inside its
  loop. `write_wav_mono` protects one replacement with a `.part` file but supplies
  no family-level staging, exact-inventory check, or rollback.
- **Impact:** a late decode, transform, measurement, or write failure leaves an
  already-replaced prefix beside the prior suffix. Correcting the FLAC target alone
  would still permit a valid-looking mixed-generation bank.
- **Concrete fix:** produce each selected family in empty staging, validate all
  final-format assets, then publish with rollback. Add late-transform and failed-
  replacement negative controls that preserve the prior bank byte-for-byte.
- **Effort:** Medium.
- **Tracked as:** `MM-BUG-KILN-00260`.

### 5. Concurrent onset regenerations race fixed shared intermediates

- **Severity:** Low.
- **Confidence:** High.
- **Location:**
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-040926\tools\ferrosintesis-samples\prepare.py:4545`,
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-040926\tools\ferrosintesis-samples\prepare.py:5647`, and
  `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-040926\tools\ferrosintesis-samples\prepare.py:5687`.
- **Evidence:** every worktree shares one revision-keyed system-temp directory.
  Same-family calls truncate fixed Ogg names, overwrite fixed WAV names with
  `ffmpeg -y`, then immediately read those shared files.
- **Impact:** overlapping runs can consume a peer's partial/replaced intermediate
  or fail spuriously. The authenticated SF3 cache is not the race.
- **Concrete fix:** use process-unique decode directories or serialize mutable
  intermediates under a lock. Add a two-process overlap regression.
- **Effort:** Small-Medium.
- **Tracked as:** `MM-BUG-KILN-00261`.
