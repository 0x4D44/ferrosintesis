### CR-1 — public raw-asset API promises WAV while exposing FLAC

- **Severity:** Low
- **Confidence:** High
- **Where:** `D:\worktrees\ferrosintesis\20260817-REV-MM-CDX@KILN-code-review-121745\crates\ferrosintesis-samples-drumkit\src\lib.rs:561`; public lookup docs at `:726` and `:740`; package prose at `README.md:3` and `PROVENANCE.md:18`
- **Tracking:** Open `MM-BUG-KILN-00282`
- **Problem:** all 128 exact keys and payloads are FLAC, but public Rustdoc and package documents still promise `.wav` names and WAV bytes. A documented `.wav` lookup returns `None`; `Bank::wav()` returns `fLaC` bytes.

- **Effort:** Small.

- **Severity:** Low
- **Confidence:** High for the control-flow defect; execution unverified

## Tracked design requirement

Draft `MM-REQ-KILN-00286` requires an end-to-end, non-self-referential oracle for
core drum-kit payload identity and runtime mapping. Current tests compare labels
and cache views derived from the same hand-written table; a same-family
`include_bytes!` path swap can preserve those assertions. No current payload swap
or corrupt asset was found, so this is tracked as verification debt rather than a
defect.

## Not reported as defects

- **Current runtime routing failure — refuted.** The sampler prewarms both drum packages and consumes `Bank::pcm`; current names, offsets, and registered banks agree statically.
- **Current mixed inventory — refuted.** The clean assigned package has 128 FLACs and no WAVs. Mixing is the deterministic result of the stale regeneration command, not current tree state.
- **Production cache miss still eagerly decodes — refuted.** `pcm` and `pcm_by_index` validate before calling `decoded_samples`.
- **All-bank eager cache is a leak — refuted.** It is bounded, process-lifetime, documented behavior with an explicit off-realtime-thread `prewarm` contract. Timing and RSS were not measured.
- **Malformed RIFF is externally exploitable — refuted for this crate.** The RIFF walker is private and receives compile-time embedded bytes. Shared FLAC malformed-input limits are tracked separately and were not re-reviewed here.
- **Current payload corruption — refuted.** No mismatch was established. The ability of a future path swap to evade self-referential checks became Draft `MM-REQ-KILN-00286`.
- **`Bank::wav` lacks direct coverage — folded into CR-1.** A full key/container contract regression is the actionable repair, not a fifth ticket.
