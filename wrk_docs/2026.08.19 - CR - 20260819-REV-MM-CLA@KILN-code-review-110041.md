  (`crates\ferrosintesis\src\sampler.rs:71-82`) dispatches on the `fLaC` magic;
  `ferrosintesis_flac::decode_mono16`

  the same invariants the RIFF branch asserts — so the earlier worry that the FLAC branch
  skipped the sample-rate check is refuted inside the decoder.

  (`sampler.rs:3120-3126`) and by `exercise_every_lazy_cache` (`sampler.rs:6099`) — the
  MM-BUG-KILN-00073 gap stays closed for this bank.
