## New defects

### MM-BUG-CRU-00048 — failed mandolin bake can publish a mixed generation

- **Severity:** Low
- **Confidence:** High
- **Sites:**
  `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-124001\tools\ferrosintesis-samples\prepare.py:4372`,
  `:4412`, and `:5904-5944`
- **Failure:** the bake writes each new logical WAV into the live package, then converts,
  replaces, and removes files individually. A late failure leaves a mixture of new WAVs,
  new FLACs, and old FLACs instead of preserving the prior bank.
- **Concrete fix:** generate and validate all 40 final FLACs in empty staging, then publish
  the bank with rollback. Inject a late transform failure and a late replacement failure;
  each must preserve the old bank byte-for-byte.
- **Effort:** Medium

This does not duplicate `MM-BUG-KILN-00245`, whose observation and requested proof are
explicitly the separate 54-file grand bank.

### MM-BUG-CRU-00049 — concurrent bakes race a host-global mandolin source directory

- **Severity:** Low
- **Confidence:** High
- **Sites:**
  `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-124001\tools\ferrosintesis-samples\prepare.py:1681`,
  `:5719`, and `:5911`
- **Failure:** every worktree copies committed mandolin cuts into the same fixed system-temp
  names with non-atomic `shutil.copyfile`, then immediately reads them. Concurrent runs can
  see truncation or consume a peer worktree's source revision.
- **Concrete fix:** read the committed sources directly, or use per-run staging/locking
  with atomic publication. Add a two-process overlap using different source bytes and prove
  neither run fails or consumes its peer's input.
- **Effort:** Small-Medium

The analogous MuseScore races in `MM-BUG-KILN-00221`, `00256`, and `00261` use different
directories and functions; none exercises this path.

### MM-BUG-CRU-00050 — provenance names a retired physical WAV package path

- **Severity:** Low
- **Confidence:** High
- **Sites:**
  `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-124001\crates\ferrosintesis-samples-mandolin\PROVENANCE.md:18-20`
  and
  `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-124001\tools\ferrosintesis-samples\gen_crate_lib.py:2`
- **Failure:** provenance says physical `samples/*.wav` is the baked output, while the
  package ships only `.flac`; the generator docstring likewise says it reads only WAV.
  Logical/source `.wav` names are intentional, so the missing distinction invites either
  a broken path or an equally wrong blanket rename.
- **Concrete fix:** explicitly distinguish logical/source WAV names from packaged FLAC
  paths, and make the generator docstring container-neutral. Preserve genuine source and
  checksum-table `.wav` references.
- **Effort:** Small

This is a residual outside `MM-BUG-CRUCIBLE-00044`'s explicit list. That bug correctly
calls mandolin's public `get()` documentation container-neutral.

## Confirmed findings already tracked

### MM-BUG-CRUCIBLE-00040 — payload/name assertion is self-referential

- **Severity:** Medium
- **Confidence:** High
- **Site:**
  `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-124001\crates\ferrosintesis-samples-mandolin\src\lib.rs:195-221`
- **Failure:** the name test never opens a payload, and `get(name) == Some(bytes)` compares
  a tuple with data returned from that same tuple. Swapping two `include_bytes!` targets
  preserves names, aggregate size, magic, and the assertion while routing recordings under
  the wrong identities.
- **Concrete fix:** compare every embedded slice with an independent
  `fs::read(samples_dir.join(name))`. Prove the assertion by transposing two targets and
  observing it fail before restoring them.
- **Effort:** Small

### MM-BUG-CRUCIBLE-00039 — compressed-size pin depends on the host ffmpeg build

- **Severity:** Medium
- **Confidence:** High
- **Sites:**
  `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-124001\crates\ferrosintesis-samples-mandolin\src\lib.rs:190-215`
  and
  `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-124001\tools\ferrosintesis-samples\prepare.py:4335`
- **Failure:** a bit-identical PCM rebake can change compressed bytes with another ffmpeg
  build, turning the mechanically regenerated aggregate into a false failure.
- **Concrete fix:** pin decoded PCM identity and structural FLAC properties, or pin the
  encoder only if container-byte identity is required.
- **Effort:** Small-Medium

### MM-BUG-CRUCIBLE-00045 — FLAC-only bank's assertion still accepts RIFF

- **Severity:** Low
- **Confidence:** High
- **Site:**
  `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-124001\crates\ferrosintesis-samples-mandolin\src\lib.rs:211-220`
- **Failure:** the migrated mandolin bank accepts either RIFF or FLAC magic. Reintroducing
  WAV can stay green once the aggregate is mechanically refreshed, hiding binary growth.
- **Concrete fix:** derive each bank's required container and assert extension/magic
  agreement, with only the intentional B1-upright RIFF exception.
- **Effort:** Small

### MM-BUG-KILN-00232 — FLAC total sample count drives an enormous allocation

- **Severity:** Medium
- **Confidence:** High
- **Site:**
  `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-124001\crates\ferrosintesis-flac\src\lib.rs:334-379`
- **Failure:** a tiny FLAC can declare up to `2^36-1` samples and drive an infallible
  `Vec::with_capacity` before frame validation. Mandolin prewarm reaches this decoder, but
  the defect belongs to the shared decoder and is already open.
- **Concrete fix:** bound supported decoded size, reserve fallibly, reject an overflowing
  frame before pushing, and hash PCM incrementally.
- **Effort:** Small-Medium
