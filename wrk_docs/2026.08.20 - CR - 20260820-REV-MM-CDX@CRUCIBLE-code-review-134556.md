## Confirmed findings

### CR-1 — Exact compressed-byte pin makes a valid FLAC re-encode fail

- **Severity:** Medium
- **Confidence:** High
- **Where:** `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-134556\crates\ferrosintesis-samples-rain\src\lib.rs:34` and `:53-57`
- **Tracking:** Open `MM-BUG-CRUCIBLE-00039`; no duplicate filed
- **Problem:** the test pins the FLAC container to exactly 289,199 bytes. The committed
  file contains `Lavf62.12.101` as both its VORBIS vendor and encoder comment. The shared
  conversion path uses whichever `ffmpeg` is on `PATH`, so an otherwise bit-identical
  re-encode can change container metadata and fail an unexplained integer assertion.
- **Concrete fix:** choose and enforce one contract: emit encoder-independent container
  bytes, pin the encoder explicitly, or replace compressed-size identity with a decoded-PCM
  identity check. Name the encoder in any resulting failure.
- **Effort:** Small–Medium.

### CR-2 — The payload lookup assertion proves itself, not the packaged asset

- **Severity:** Medium
- **Confidence:** High
- **Where:** `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-134556\crates\ferrosintesis-samples-rain\src\lib.rs:53-64`
- **Tracking:** Open `MM-BUG-CRUCIBLE-00040`; no duplicate filed
- **Problem:** the loop takes both `name` and `bytes` from `SAMPLES`, then asks `get(name)`
  to return the same tuple's bytes. That assertion can only agree with itself. The name
  inventory and aggregate byte count do not bind the intended recording, so a same-sized
  substituted FLAC remains green. The current asset is not shown to be substituted.
- **Concrete fix:** generate a per-entry comparison between the embedded bytes and
  `fs::read(samples_dir.join(name))`, then bind the intended decoded PCM independently.
- **Effort:** Small for the generator-wide file binding; Medium for full PCM identity.

### CR-3 — The local format oracle accepts a return to RIFF/WAV

- **Severity:** Low
- **Confidence:** High
- **Where:** `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-134556\crates\ferrosintesis-samples-rain\src\lib.rs:59-62`
- **Tracking:** Open `MM-BUG-CRUCIBLE-00045`; no duplicate filed
- **Problem:** the package has been FLAC-only since 2026-08-16, but the assertion accepts
  either RIFF/WAV or FLAC. A regression to the former 405,764-byte WAV payload would pass
  once the generated size pin was refreshed, undoing the binary-size purpose of the
  migration without a targeted diagnostic.
- **Concrete fix:** derive the expected container from the packaged inventory and require
  FLAC for migrated banks, with the documented B1 custom-chunk exception kept explicit.
- **Effort:** Small, shared across the generated asset crates.
