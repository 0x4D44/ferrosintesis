## Confirmed findings

### 1. Low — packaged Kawai docs promise a WAV, Python-only rebake — `MM-BUG-CRU-00051`

- **Confidence:** High.
- **Where:** `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-153056\crates\ferrosintesis-samples-vcsl-kawai\README.md:7`; `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-153056\crates\ferrosintesis-samples-vcsl-kawai\PROVENANCE.md:9`; `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-153056\tools\ferrosintesis-samples\prepare.py:5669`
- **Problem:** README and provenance call the physical bank WAV, call the output WAV,
  and say the scoped command needs no ffmpeg. The crate ships only FLAC, and `main()`
  refuses every normal bake before selector processing when ffmpeg is absent.
- **Impact:** a maintainer following the packaged recipe fails on an undocumented
  prerequisite; package readers receive the wrong container and output contract.
- **Concrete fix:** distinguish upstream/logical WAV names from packaged FLAC, document
  ffmpeg, and derive a packaged-document guard from the live publisher. Coordinate the
  separately tracked NOTICE sentence through `MM-BUG-CRUCIBLE-00042`.
- **Effort:** Small.

### 2. Low — realtime prewarm memory guidance still assumes embedded PCM16 — `MM-BUG-CRU-00052`

- **Confidence:** High.
- **Where:** `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-153056\crates\ferrosintesis\src\live.rs:301`; decoder output at `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-153056\crates\ferrosintesis\src\sampler.rs:71`.
- **Problem:** the API says ordinary banks retain about twice their embedded bytes. Kawai
  now embeds 1,733,440 compressed bytes but retains 8,512,256 bytes of f32 PCM when fully
  prewarmed, a 4.91× ratio.
- **Impact:** callers planning a realtime process from the public guidance can materially
  under-budget resident memory; Kawai alone exceeds the stated estimate by 5,045,376 bytes.
- **Concrete fix:** document four bytes per decoded mono frame and treat the FLAC
  compression ratio as variable, or derive a current whole-bank estimate from STREAMINFO.
- **Effort:** Small.

### 3. Low — Kawai regeneration can expose a partial mixed bank — existing `MM-BUG-CRU-00048`

- **Confidence:** High.
- **Where:** `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-153056\tools\ferrosintesis-samples\prepare.py:4372`; publisher at `prepare.py:4412`; Kawai generic write path at `prepare.py:5910`.
- **Problem:** logical WAVs are written into the live bank one at a time, then converted,
  replaced, and removed one at a time. A late transform or encode failure leaves a mix of
  old FLACs, new FLACs, and unconverted WAVs.
- **Impact:** the failed command has already destroyed whole-bank generation coherence,
  even though a rerun can repair the directory and later inventory checks fail loudly.
- **Concrete fix:** stage and validate the complete final FLAC bank, then publish it with
  rollback. Open `MM-BUG-CRU-00048` names Mandolin but owns this same shared helper and
  failure mode, so no Kawai twin was minted.
- **Effort:** Medium in the shared publisher.

### 4. Low debt — Kawai selector boundaries lack an exact oracle — existing Draft `MM-REQ-KILN-00164`

- **Confidence:** High.
- **Where:** `D:\worktrees\ferrosintesis\20260820-REV-MM-CDX@CRUCIBLE-code-review-153056\crates\ferrosintesis\src\sampler.rs:1431`; representative-only exercise at `sampler.rs:6012`; alias identity test at `sampler.rs:7510`.
- **Problem:** no test pins both RR values at velocity boundaries 0/51/52/95/96/127.
  Existing initialization tests discard the returned bank, so a shifted boundary or a
  selector that always returns one table can stay green.
- **Impact:** this is prevention debt, not evidence of current misrouting; current source
  routes all six arms as documented.
- **Concrete fix:** include a table-driven selector/bank-identity oracle in Draft
  `MM-REQ-KILN-00164`'s Gate-1 acceptance criteria. The 2026-08-16 Kawai review already
  routed this exact gap there, so no duplicate requirement was minted.
- **Effort:** Small within the existing verifier.
