# 2026.07.06 - JRN - Winter Guests build

Task: a two-part (~9 min each) Oldfield-idiom piece with guest sorties —
ABBA (*The Visitors* cold arps; *Super Trouper* stacked choruses + gear
change) and Crash Test Dummies (the low wordless hum) — plus hollowsynth
v0.7. Worktree `20260706-DEV-HUM-winter-guests-album-and-hollowsynth-v0-7`.

## Decisions

- **Arthur's choices**: title *Winter Guests*; two parts ~9 min each
  (cold half / warm half); all three v0.7 feature tiers.
- **Anti-pastiche architecture**: the guest styles are movements sharing
  one DNA — a single Guest theme with three machine-verified guises (hum /
  ABBA chorus stack / Oldfield guitar), all reducing to the strong-beat
  skeleton [1 5 2 1 3 7 4 1]. Parallel-major frame: opens E minor, closes
  E major; ABBA gear change D→E at Part Two beat 320 is what carries the
  piece home.
- **Chorus ground redesigned at the oracle**: first draft (I V ii IV |
  vi V IV I) put the stack's third-above on a minor 2nd against the IV
  root at bar 4. Reharmonized to I V ii vi | I V IV I — the stack then
  passes with ZERO snapping. The oracle shaped the harmony before a note
  was placed, same as The Signal Fire.
- Verse-2 hum harmony (aeolian) does need one arranger's snap (F# vs G
  at bar 6) — `snap_to_chord` is part of the material, and the oracle
  verifies the snapped result.
- New oracles: tri-guise skeleton identity, hummable range (14 semis,
  cap 16), chord-tone downbeats over BOTH grounds, stack clash check
  ({1,6,11} forbidden vs roots), gear-change ceiling, RPN-aware bend
  hygiene (range 12 only in P1 M3), vowel/pedal/portamento inventories,
  lyric + keysig meta presence.

## Build mechanics

- Same pipeline as The Signal Fire: roadmap HLD + material.py written
  centrally (passed first try), then phase-1 workflow (hollowsynth v0.7
  Rust ∥ two-track Python scaffold), then six movement writers, then the
  adversarial verification fan-out.
- v0.7 features: CC70 choir vowel morph (mm/oo/ah/eh), RPN 0 bend range +
  RPN 1 fine-tune, CC5/65 portamento, CC71 resonance, channel aftertouch,
  CC66 sostenuto, CC67 una corda, lyric/keysig metas. Every feature uses
  the v0.6 "authored channel" opt-in pattern; back-compat gate = byte-
  identical renders of Hollow Hill AND The Signal Fire.

## Phase 2 done + adversarial verification

- The six-composer fan-out succeeded (all files written, 201-494 lines
  each) but the workflow reported failure: the StructuredOutput report
  step hit its retry cap on Opus for all six (a reporting failure, not a
  work failure — 1.1M tokens of real composition landed). Verified the
  work myself: build + all 28 oracles (14/part) PASS; P1 9:26 / 4618
  notes, P2 9:02 / 12631 notes; both renders clean (0 clicks, no
  silence). Committed as 4d70803.
- Lesson reinforced: on Opus, heavy compose/surgery agents should return
  PLAIN TEXT, not a schema — the structured-output emission is the fragile
  step. Verify agents (lighter) tolerate the schema fine.
- Adversarial 4-lens review (code / MIDI-binary / audio-stems / musical):
  no critical/major-broken output. Confirmed positives by measurement:
  gear change is an exact +2-semi lift at P2 320 (E-major keysig present),
  the -12 whammy dive renders as a clean octave sweep, CC70 mm vs ah moves
  the choir spectrum, the M5 stack really sounds all three guises at once,
  fine-tune double-track splits L/R.
- Findings -> surgery (in flight):
  * [major, audio] The Humming collapses -5.6 dB in mono (choir leans on
    the decorrelating quadrature chorus bus). Root cause is a SHARED synth
    effect, so fixing the synth risks the other albums un-auditionably;
    chose the correct-layer fix instead — get choir width from PANNING
    (mono-safe) and cut the chorus send in that movement. Target < 2 dB.
  * [major, music] The final chord was a bare E-B fifth — the parallel-
    major payoff lost its major third. Add G# to the closing sonority.
  * [major, music] M3 Footsteps was one flat 2.5-min crescendo — cut a
    breakdown at ~672-704.
  * [minor] M5 apotheosis register-crowded (8 chans in 2 octaves) — spread
    bells up / hum down. Humming verse-1 steel too busy — thin it.
  * [minor, code] snap_to_chord predicate was a no-op on the chorus stack
    (only caught downbeat-starting notes) — fix the net (oracle stays
    green since the stack is already clean). HLD spec drifts (CHORUS_GROUND
    wording, ch2 P2 role) reconciled to the code.
