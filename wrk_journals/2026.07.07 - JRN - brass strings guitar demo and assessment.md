## Headline finding (code + measured)

`voices::make` (src/voices.rs:1909-2038) has **no match arm for GM programs
55–71**. Orchestra hit (55), all **brass (56–63)** and all **reeds/saxes
(64–71)** fall through `_ => Pluck::new(&STEEL, …)` — a plucked steel-string
guitar. So hollowsynth has *no brass and no woodwind/reed voice at all*.

Empirically proven with a solo-stem "sustain ratio" (RMS late / RMS early of
a held note; ~1 = sustains, «1 = decayed like a pluck):

| voice (held note)        | sustain ratio | verdict          |
|--------------------------|--------------:|------------------|
| strings ch0 (SawStack)   | 1.38          | holds (swells)   |
| violin ch1 (Bowed)       | 1.11          | holds            |
| choir ch3 (SawStack+fmt) | 1.22          | holds            |
| **brass prog 61**        | **0.01**      | decays = PLUCK   |
| **oboe prog 68**         | **0.00**      | decays = PLUCK   |

A held trumpet/oboe note evaporates in a fraction of a second.

## Voice-family map (as built, v0.8.0)

- 0–7 piano (Modal + LA), 8–15 bells, 16–23 organ (additive drawbar)
- 24–31 guitar (Pluck / extended KS + cabinet), 32–39 bass (Pluck + SynthBass)
- 40–45 solo bowed strings (Bowed + LA) — **all 6 share violin body
  resonances**; pizzicato(45) rings as a sustained bow; tremolo(44) has no trem
- 46 harp, 47 timpani
- 48–51 string ensemble (SawStack: 5 detuned saws → static LP)
- 52–54 choir (SawStack + morphing formant "mm-ah")
- **55–71 UNMODELED → steel pluck fallback**
- 72–79 winds (Wind model + LA), 80–95 pads (SawStack + sweep), 96–103 crystal,
  104–107 banjo
