## Build

Split programs 12 and 13 out of the `11..=13 => VIBES` route. Added dedicated
`MARIMBA` and `XYLOPHONE` modal tables, plus a small `wood_bar` wrapper that
key-scales the decay times before calling the existing `bell()` constructor.
Marimba gets a lower band-passed mallet click; xylophone gets a shorter decay
and a stronger 1:3 partial. Updated the README modal table and bumped
hollowsynth from 0.8.2 to 0.8.3.

Post-rebase update: rebased the branch onto `origin/main` at `c0cd5cd` after the
hollowsynth realtime API landed. The implementation commit is now
`0efd750575902f455c10eb93f7ea2957253c75f6`, and the package version is now
`0.8.4` because trunk already carried `0.8.3`.

The first adversarial reviewer found that the initial oracle did not prove the
key-scaling across pitches and did not isolate the click filter from modal
partials. Strengthened it to render low/high keys and to check the impulse
response of the exact bandpass filters used by the click path.
