# 2026.07.09 - JRN - GM112-119 synthesis design

Goal from Arthur: design and then, after explicit sign-off only, implement
high-quality default-on synthesis for GM 112-119. These are the remaining
melodic percussion GM programs currently falling through to the steel-guitar
fallback.

Scope confirmed in one line: replace the GM112-119 steel-pluck fallback with
program-specific modeled voices for Tinkle Bell, Agogo, Steel Drums, Woodblock,
Taiko Drum, Melodic Tom, Synth Drum, and Reverse Cymbal.

Read the repo instructions and lessons. Relevant constraints:

- Work in this task worktree, not the main clone.
- Design doc and journal live under `wrk_docs/` and `wrk_journals/`.
- Stop at the sign-off gate before implementation.
- Use real numeric audio oracles; this repo has no ears.

Code context:

- `voices::make` routes 120-127 to `SfxNoise`, 104-111 to modeled/pluck/reed
  voices, and then falls through to `Pluck::new(&STEEL, ...)`, so 112-119 are
  currently wrong.
- `Modal` already supports deterministic modal partials, strike noise, note-off
  release, pitch bend, and a strike pitch-glide hook.
- `bell()` / `wood_bar()` cover struck pitched idiophones.
- `drums.rs` contains useful acoustic patterns for membranes/cymbals, but its
  builders are private and channel-10-specific. Reusing the ideas in `voices.rs`
  is cleaner than making drum internals public.
- `Reverse Cymbal` is the only program that needs a new non-modal one-shot
  voice because it needs a crescendo envelope.

Draft design direction:

- Keep all new melodic-program work in `voices.rs`.
- Add small modal helpers and tables for 112-118.
- Add one `ReverseCymbal` voice for 119.
- Extend routing/readme/tests. No feature flag, no opt-in seam.

Adversarial design review:

- Two reviewers inspected the HLD. I did a local third pass.
- Surviving findings:
  - require per-program audio signatures, not only family-level signatures;
  - specify fixed oracle keys/windows/search bounds/tolerances;
  - avoid centroid-only brightness checks;
  - add existing-album blast-radius validation for this default-on `voices.rs`
    change;
  - add short-note lifecycle tests so melodic-channel note-off does not choke
    struck/effect voices.
- Refuted findings:
  - Reverse Cymbal may be intentionally pitch-agnostic; the main semantic oracle
    should be the reverse swell, not key sensitivity;
  - the HLD already guards against premature helper abstraction.
