## Intent (one line)

Add a GM Bank-Select alt bank that resurrects the v0.9 strings/choir/bowed/orch-hit
voicings (the ones trunk's reqs-loop independently superseded) on the old SawStack, as
an isolated code path selectable per channel — default bank unchanged and byte-identical,
a channel selecting the alt bank gets those voicings — for A/B and tonal variety.

Source of the voicings: `v09-backup-pre-rebase` (da72e32).

## STEP 1 — UNDERSTAND (facts gathered)

  (Bank Select). So every committed album stays on the default bank → byte-identical.
  (Same opt-in seam family as kit-v2 / CC73.)

  - engine `cc()` (engine.rs:869) — match on CC num; **CC0 unhandled** → add a case.
    Bindings: `s = &mut self.strips[ch]`, `val` raw, `v = val/127`.
  - engine NoteOn spawn (engine.rs:799-810): `if ch==9 { drums::make } else { voices::make }`.
  - Voice trait (voices.rs:29): render, note_off, released, set_pitch, legato_to,
    set_trem, set_vowel, set_breath, choke, kind(test).
- **Planned engine change (minimal):** `Strip.alt_bank: bool` (default false); `cc()`
  case `0 => s.alt_bank = val != 0`; spawn else-branch picks `altbank::make` vs
  `voices::make` on `self.strips[ci].alt_bank`. Default path (`voices::make`) UNCHANGED →
  byte-identity by construction.
- **da72e32 orchestral voicing inventory (helper):** the resurrection set (line ranges in
  the da72e32 ref) is SawStack + Layer/EnvBright/StackFilter/ChoirSection/ChoirExt (1443-1666,
  1982-2013), strings() 1774-1872, choir_v2() 2015-2147, Bowed 2359-2534 (+ bodies 604-650,
  tremolo consts 2351-2357, PIZZ 651-670), OrchHit 3624-3762. Cross-deps beyond dsp
  primitives: `Modal` (orch-hit thump), `Pluck`+`PluckPreset` (pizz 45), `sampler::{LaVoice,
  violin_bank}` (bowed 40-43 wrap), `vel_attack`, `reg_weight`, `t60_mul`, CTRL const, TAU.
- **Engine-dependency analysis (the key finding):** EVERY voice's timbral character is
  SELF-CONTAINED (env_bright reads the voice's own Adsr; ChoirExt onset/SATB scatter run from
  internal state; bowed bodies + bow-pressure track the own envelope; orch-hit envelope is
  hand-rolled internal). The ONLY engine-CC dependency in the whole set is strings/choir
  **`set_vib`** (CC1 section-vibrato DEEPENING) — and it only deepens an already-self-contained
  per-layer wobble. `set_vib` is the ONE method not in trunk's trait.
- **DECISION: drop `set_vib`** → no trait change, pure voice-swap. Alt strings keep their
  constructed vibrato + trunk's shared CC1 pitch-vibrato (48-54 are in trunk's vibrato_family);
  they lose only the marginal CC1 depth-deepen. Also drop `strings_vib_base` (its restore
  target) and `choir()` (unused — alt 52-54 uses the distinctive choir_v2, not the ~trunk
  formant choir()).

## STEP 3 — ADVERSARIAL REVIEW (2 reviewers, cross-refuted; all survivors below)

Two decorrelated lenses (correctness/isolation + simplicity/scope). Core isolation +
byte-identity claims held up under both (seed is bank-independent; Modal/sampler/DSP
behaviorally unchanged trunk-vs-da72e32; Send satisfied; CC0 gate correct; 0/53 MIDIs send
CC0 — Riverwake `b4 00` is a tempo VLQ, false positive). Survivors folded into HLD v2:

- **S1 (MAJOR, verified): drop program 55.** Trunk's `orch_hit` == da72e32's modulo
  comments+`pub` (I diffed 2320-2456 vs 3624-3762). Banking 55 = zero A/B value (alt==default),
  and it self-refutes AC4. Dropping it removes the `Modal` cross-dep, the orch vendoring, and
  its oracle. Alt scope is now **40-54** (bowed 40-45, strings 48-51, choir 52-54); 46/47/55 delegate.
- **S2 (MAJOR, verified): D3 vibrato was dishonest.** da72e32 `vibrato_family` EXCLUDES 48-54
  (strings used `set_vib` decorrelated; choir got no CC1); trunk INCLUDES 48-54. So the
  resurrected strings/choir get trunk's *coherent* CC1 pitch-vibrato, not v0.9's. RESOLUTION:
  option **C (timbre-faithful)** — the alt bank swaps TIMBRE (env_bright/ChoirExt/bodies, all
  self-contained + faithful) and keeps trunk's shared CC1 expression; documented honestly, inert
  for committed albums. Full vibrato fidelity (restore set_vib) offered to Arthur at sign-off.
- **S3 (MAJOR): AC3 over-claimed.** Two da72e32 oracles use `set_vib` (`st2_section_vibrato`,
  `ch_o6_shimmer_blooms` — a CHOIR oracle). They don't port verbatim; drop/rewrite them, and
  acknowledge the choir's reduced vibrato-oracle coverage. The 4 headline oracles (st1 env-bright,
  choir SATB/onset, bowed_bodies_differ, [orch-hit dropped]) port clean.
- **S4 (MAJOR): AC4 untestable-as-stated.** No metric/threshold; can't use kind() (strings/bowed
  share a family name). Fix: concrete band-energy metric + per-family floor on 42/48/52 (not 55).
- **S5: missing ACs** — CC121-after-CC0 latch persistence; alt_bank + non-orchestral program → default.
- **S6: oracle port is its own ~15-oracle block** (+ helpers + the frozen sawstack_v1 canary
  reference bytes must carry across) — budget it in §5, not a "+tests" parenthetical.
- **S7: widen/vendor list** — structs Modal/Pluck/PluckPreset are `pub`, but `Modal::new`,
  `Pluck::new`, and the `DEFAULTS` const are private → `pub(crate)`; PIZZ needs `BODY_VIOLIN`

  square `BlepPulse`); `polyblep` is private on trunk — don't copy the import list verbatim.
- **S8: minor** — §1 "40-55" not literal (46/47 delegate); `mod altbank;` in **lib.rs** not

No finding was refuted; two independent lenses converged. HLD updated to v2.
