## Intent (one line)

Add a GM Bank-Select alt bank that resurrects the v0.9 strings/choir/bowed/orch-hit
voicings (the ones trunk's reqs-loop independently superseded) on the old SawStack, as
an isolated code path selectable per channel — default bank unchanged and byte-identical,
a channel selecting the alt bank gets those voicings — for A/B and tonal variety.

Source of the voicings: `v09-backup-pre-rebase` (da72e32).

  - engine `cc()` (engine.rs:869) — match on CC num; **CC0 unhandled** → add a case.
    Bindings: `s = &mut self.strips[ch]`, `val` raw, `v = val/127`.
  - engine NoteOn spawn (engine.rs:799-810): `if ch==9 { drums::make } else { voices::make }`.
  - Voice trait (voices.rs:29): render, note_off, released, set_pitch, legato_to,
    set_trem, set_vowel, set_breath, choke, kind(test).
- **Planned engine change (minimal):** `Strip.alt_bank: bool` (default false); `cc()`
  case `0 => s.alt_bank = val != 0`; spawn else-branch picks `altbank::make` vs
  `voices::make` on `self.strips[ci].alt_bank`. Default path (`voices::make`) UNCHANGED →
  byte-identity by construction.
- **da72e32 orchestral voicing inventory (helper):** the resurrection set (line ranges in
  the da72e32 ref) is SawStack + Layer/EnvBright/StackFilter/ChoirSection/ChoirExt (1443-1666,
  1982-2013), strings() 1774-1872, choir_v2() 2015-2147, Bowed 2359-2534 (+ bodies 604-650,
  tremolo consts 2351-2357, PIZZ 651-670), OrchHit 3624-3762. Cross-deps beyond dsp
  primitives: `Modal` (orch-hit thump), `Pluck`+`PluckPreset` (pizz 45), `sampler::{LaVoice,
  violin_bank}` (bowed 40-43 wrap), `vel_attack`, `reg_weight`, `t60_mul`, CTRL const, TAU.
- **Engine-dependency analysis (the key finding):** EVERY voice's timbral character is
  SELF-CONTAINED (env_bright reads the voice's own Adsr; ChoirExt onset/SATB scatter run from
  internal state; bowed bodies + bow-pressure track the own envelope; orch-hit envelope is
  hand-rolled internal). The ONLY engine-CC dependency in the whole set is strings/choir
  **`set_vib`** (CC1 section-vibrato DEEPENING) — and it only deepens an already-self-contained
  per-layer wobble. `set_vib` is the ONE method not in trunk's trait.

  constructed vibrato + trunk's shared CC1 pitch-vibrato (48-54 are in trunk's vibrato_family);
  they lose only the marginal CC1 depth-deepen. Also drop `strings_vib_base` (its restore
  target) and `choir()` (unused — alt 52-54 uses the distinctive choir_v2, not the ~trunk
  formant choir()).
