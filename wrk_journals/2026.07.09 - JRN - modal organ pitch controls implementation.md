# 2026.07.09 - JRN - modal organ pitch controls implementation

## Context

Arthur approved the HLD compatibility fork for `MM-REQ-KILN-00008`: waive
byte-identity for the 13 existing tracks that already authored Modal/Organ pitch
controls, and keep every other `render_opus.py::ALBUMS` render byte-identical.

## Work

- Added the failing engine-level oracle
  `modal_organ_pitch_controls_move_sustained_notes`.
- Implemented phase-continuous `set_pitch` for `Modal` by storing each mode's
  nominal frequency and temporarily muting, not deleting, modes that bend above
  the band guard.
- Implemented phase-continuous `set_pitch` for `Organ` by storing each pipe's
  stop ratio and retuning `base_f * ratio * bend`.
- Added Modal programs to `aftertouch_family`; left organ CC1 as Leslie/tremulant
  control only.
- Bumped hollowsynth to `0.8.13` before integration; after rebasing over trunk's
  v0.9.0 work, resolved the final shipped version to `0.9.1`.

## Validation

- New oracle failed on trunk before the implementation: Modal Crystal stayed near
  445 Hz after a requested +1 semitone bend.
- Focused controller tests passed:
  `rpn_bend_range_and_fine_tune`,
  `portamento_glides_from_previous_pitch`,
  `aftertouch_swells_gain_and_vibrato`,
  `cc1_leslie_spins_up_with_inertia`,
  `modal_organ_pitch_controls_move_sustained_notes`.
- Full crate tests passed after the integration rebase: 153 passed, 4 ignored.
- `cargo clippy --all-targets -- -D warnings` passed.
- `cargo fmt --check` passed.
- `cargo build --release` passed.
- Old/new render comparison passed: 40 non-waived MIDI files byte-identical; 13
  waived files changed, with no clipping and RMS deltas within the approved sanity
  bound.
- Reran the render comparison after rebasing over v0.9.0: current `origin/main`
  v0.9.0 (`41e49d2`) vs branch v0.9.1 still passed 40/40 non-waived
  byte-identical and 13/13 waived sanity checks.
