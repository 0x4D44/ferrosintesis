# Atlas of Becoming MIDI collection

## Objective

Build fourteen original advanced MIDI pieces in one new reproducible album directory:
three AquaTheater/*The Fine Line*-inspired tracks, five specified concept/reference
tracks, one fast original spy-film score, and five free-choice tracks.

## Live pointers

- Worktree: `D:\worktrees\midi-music\20260710-DEV-CDX-compose-advanced-original-midi-collectio`
- Album: `albums/codex/Atlas of Becoming/`
- Branch: `task/20260710-DEV-CDX-compose-advanced-original-midi-collectio`
- Shared engine: `engine.py`; shared musical vocabulary: `tracks/common.py`.
- Score-side gate: `python build.py --verify` from the album directory.
- Render-side gate: render matching WAV stems, then `python analyze.py <wav-directory>`.

## Decisions

- The named copyrighted works contribute only broad form, pacing, colour, and dramatic
  function. Every melody, harmony, riff, and arrangement is original.
- The album uses independent track modules over one deterministic standard-library MIDI
  engine. This gives parallel authors separate files and keeps rebuilds byte-exact.
- Each track declares named sections, changing tempo/meter, a recurring feature span,
  expressive controllers, and track-specific density/channel thresholds.
- The GPT history ends at GPT-5.5, the current public flagship. GPT-5.6 is described only
  as preview and is not encoded as a released milestone.
- The user requested MIDI, so the album will ship MIDI source/assets without committed
  Opus listening copies. Disposable WAV renders still receive audio-side checks.
