# 2026.07.10 — JRN — port superseded v0.11 branch voices onto the 0.11.0 trunk (ferrosintesis 0.12.0)

## What happened

The superseded branch commit 216da4a (kept on `backup/pre-integration`) carried a
fully-tested v0.11 feature set — GM 112-119 percussion, GM 15 dulcimer, GM 14
gong alt-bank, ch-10 brush kit — that trunk's independent "realism batch"
(v0.11.0: its own default 112-119 voices, Kit V3, sampled attack layers)
overtook. This task PORTED the branch work onto trunk as one coherent change,
under the new policy: controller features stay inert-unless-authored,
instrument improvements may be default-on.

## The port, piece by piece

- **Alt-bank percussion set B (controller feature, CC0-gated).** The branch's
  eight 112-119 voices renamed `_b` (`tinkle_bell_b`/`agogo_b`/`steel_drum_b`/
  `woodblock_b` in voices.rs; `taiko_b`/`melodic_tom_b`/`synth_drum_b`/
  `reverse_cymbal_b` + `RevCymB` in drums.rs) and wired ONLY in `altbank::make`
  (arms `112..=119`). Trunk's default-bank 112-119 voices and tests untouched.
  The 23 numeric oracles moved to altbank.rs as `altbank_b1xx_*`, rendering
  through the alt factory; the dispatch oracle now proves bank B differs from
  the default bank per program (the branch compared against the old STEEL
  catch-all, which no longer exists).
- **Gong alt-bank on GM 14.** `voices::tam_tam` + Modal `ModeBloom` (bloom
  branch OUTSIDE the per-sample loop; `None` path token-identical) + altbank
  `14 =>` arm + G1-G4 oracles verbatim; G5 authored-only test in engine.rs.
- **Dulcimer GM 15 (default-on timbre).** `PluckPreset` gained
  `course_detune/course_t60/course_bright/course_mix/course_couple`; DEFAULTS
  carry the exact old literals (1.0013/0.42/1.15/(0.74,0.26)/K_COUPLE) so all
  existing presets are bit-identical — proven by the render report below.
  altbank's PIZZ (deliberately not sharing DEFAULTS) got explicit old-literal
  fields. Trunk's `14 | 15` arm split: 14 keeps tubular bells verbatim,
  15 → `Pluck::new(&DULCIMER,…)`; fx_profile row `15 => (0.10, 0.0)`.
- **Brush kit grafted onto the V3 world.** `Kit::Brush` added; ch-9 Program
  Change selector: `prog == 40 → Brush`, anything else → V3 (trunk semantics —
  the showcase demo's prog 8 stays V3). Brush keys 35-46 intercept before the
  key match; unmapped keys fall through to V3 (metal-plate crashes/rides
  included) and keep the V3 sample overlays. Every lib-side `kit ==`/`!=`
  comparison rewritten as an exhaustive match so the compiler flags future kit
  variants; V1/V2 became truly test-only constructions and carry
  `#[cfg_attr(not(test), allow(dead_code))]`.
- Version 0.11.0 → 0.12.0 (both crates + path-dep pin + Cargo.lock); README
  gained the CC0 alt-bank paragraph (gong + set B), dulcimer 15 in the Pluck
  row, and the brush-kit sentence in the Drums row.

## Surprises / decisions

- The branch's brush fingerprint table survived UNCHANGED — trunk's only edit
  to the shared `Drum` core since the fork was the negative-glide (open cuica)
  extension, inert for the brush voices' positive/zero glides. No
  recalibration needed.
- Branch fx_profile rows for 112/114/119 and the aftertouch 112..=114 family
  extension were NOT ported: on trunk those programs are the default-bank
  voices (which own their sends/behaviour and must stay frozen); bank B simply
  inherits the program-keyed profiles.
- The committed Through Lines album ALREADY authors prog-40 brush (tracks 1,
  5, 11, 12), CC0 alt bank (8, 13) and GM 15 dulcimer (14) — it was composed
  against this synth work, so those renders changing is the point.
