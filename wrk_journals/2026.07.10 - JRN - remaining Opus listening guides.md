# 2026.07.10 — Remaining Opus listening guides

Arthur asked for the motivation, timestamped instrumentation, and showcased MIDI
effects added to Atlas of Becoming's Opus tags to be extended across the other
committed listening files.

## Scope and sources

- Added 59 exact-MIDI-stem UTF-8 sidecars across 14 albums: the ten earlier Fable 5
  releases, Through Lines, The Spark, Hours After Rain, and Synth Feature Showcase.
  Together with Atlas of Becoming, all 73 committed Opus files now have guides.
- Used each album's committed briefs, manifests, build sources, journals, and MIDI
  event data as the primary evidence. Local session history recovered Arthur's
  original briefs for The Ninth Bell, The Signal Fire, and Winter Guests where that
  intent was clearer than the surviving album notes.
- Left VIGIL, RIVERWAKE, and The Long Turning alone because they remain deliberately
  MIDI-only and have no committed Opus listening copies.

## Accuracy decisions

- Described formal markers separately from the first audible note when those times
  differ. Instrument entrances were checked against note-on events rather than just
  program changes or track names.
- Distinguished authored controller automation from renderer defaults. The guides do
  not claim a MIDI effect merely because a GM program's synth voice supplies one.
- Cross-checked the guides against the MIDI a second time. This corrected several
  initial overclaims, including default echo presented as CC94, inactive program
  changes presented as audible entrances, and channel-pressure steps presented as
  individual swells.

## Verification

- The focused Python suite passed all six tests. Its corpus assertion now requires one
  well-shaped sidecar for every MIDI that has a committed Opus counterpart.
- The 13 album `build.py --verify` checks passed. The Iron Tide, which has no build
  script, matched a byte-exact in-memory reconstruction of its committed MIDI.
- A locked release build of ferrosintesis 0.12.0 passed before rendering. All 59
  requested tracks then rendered successfully with the release binary.
- A packet-level Ogg parser confirmed exactly one `LYRICS` comment in every one of the
  73 committed Opus files and an exact Unicode match to its source sidecar.
- `ropusdec` fully decoded all 73 listening files. A path-set check confirmed that only
  the intended 59 non-Atlas Opus assets changed.
