1. **Oracle-first.** Write the fail-first / differential oracle, run it, OBSERVE it fail
   on the current V3 render (proving it detects the defect), THEN implement, THEN observe
   it pass. Calibrate any new detector on a known-answer synthetic FIRST (SYN-A/B/C for
   the cymbal; a gaussian-vs-click-train for the snare crest/kurtosis helper).
2. **Determinism.** Render-time randomness reuses the ONE shared `white` draw
   (`drums.rs` MetalPlate:464, Drum:267) — never insert a draw into `self.rng`, never
   reorder. Build-time draws for new state go AFTER all existing draws on that path. V1
   and V2 stay BYTE-IDENTICAL — only the V3/Brush arms change. The determinism guard
   (`testutil::guards::determinism_bit_identical`) and the V1 fingerprint freezes must
   stay green untouched.

   When a unit moves the ch-9 solo render beyond the golden tolerance (±2.5 dB RMS / ±20%
   centroid), that is EXPECTED (drum sound is intentionally changing): re-capture GOLDEN
   (`$null | cargo test -p ferrosintesis print_golden_fixture -- --ignored --nocapture`),
   paste the new ch-9 row + `GOLDEN_MASTER_PEAK` into `testutil.rs`, in the SAME commit,
   with the reason in the commit message. Do NOT weaken any assertion to pass — if green
   needs weakening, that's a fork (a): stop and report.

   task branch. End messages with a `Co-Authored-By: Claude Opus 4.8 (1M context)

   workspace gate is for the finalize phase.
