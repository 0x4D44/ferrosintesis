## Brief (Arthur, 2026-07-11)

10 upbeat, catchy rock/pop tracks for ferrosintesis, composed by Fable 5:
- melodic bass guitar; drum solos with drums spread across the stereo stage
- layered complex choral vocals; distorted/overdriven guitars; piano parts
- builds and drops; clear verse / pre-chorus / chorus / middle-8 song forms
- orchestral elements entering as pieces build (strings, brass, timpani)
- advanced MIDI features for realism; introspective slow passages allowed
- must sound great on ferrosintesis specifically

Process: lean (≤2–3 helper agents per step), design → adversarial review →
Codex external review → auto-approved sign-off → implement → code review →
validate. Design doc in wrk_docs/.
