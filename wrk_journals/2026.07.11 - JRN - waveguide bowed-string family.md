## The arc so far

- Arthur reported the **GM43 contrabass** "low buzzing." Root cause: the shared
  subtractive `Bowed` voice (saw → static body EQ), voiced for a violin, collapses
  into a **"transformer hum"** at ~65 Hz.
- Iterated a fix over several ear-in-the-loop rounds (I can't hear — Arthur is the
  oracle): subtractive re-EQ → "still hums"; a **bowed-string waveguide** (delay-line
  string + stick-slip friction) → "better but synthesised"; added bolted-on grit →
  "brushes on top"; **integrated the grit into the friction** → good; then **LA
  synthesis** — a real cello-section arco (`celens`) sampled attack over the
  waveguide sustain → the winner. Bite tuned to 0.29 by ear.
- **Multi-agent collision:** while I worked, a **Codex** effort landed on trunk
  (`386290f` deepen default solo bowed strings, `6c7d70f` bound contrabass low end,
  `5449617` tests) — the *same problem*, solved with **per-program body-EQ presets**
  on the saw model, plus a **samples-into-crates** split (`bd9a85c`).
- **A/B (Fault Lines, Arthur's ear):** the waveguide+LA contrabass **won** over the
  trunk Codex contrabass.

  `cello_bank` LA (LA_CELLO gain 0.30). GM41/44 stay on `Bowed` pending Stage 3.
- **Tuning bug found + fixed (the real Stage-2 story).** Shipping the cello tripped
  `default_bowed_pitch_range_and_legato`: GM42 A4 rendered **−50 cents flat**. Not an
  artifact — peak-locate and autocorrelation agree, model-only == sampled. Cause:
  `set_freq` subtracted only **1 sample** of loop latency, but the in-loop reflection
  filter + structural read/write add **~3.8**; a near-constant sample offset → cents
  flat scales with pitch (fine in bass, wrecking in treble). The contrabass shares the
  loop and is *equally* detuned in samples — it only passed because its test keys top
  at E4 (−36c, under the 45c gate).

    → within **±3.7 cents** C2–D5 (A4 −50 → −1.6). Contrabass keeps **1.0** → GM43
    byte-identical to Stage 1 (proven by render-diff). Contrabass re-tune deferred as a
    separate ear-gated change (would re-render 32 GM43 tracks; its residual flatness is
    small + it's locked/approved).
- **Tests:** re-spec'd `default_bowed_articulations_and_sample_routing` — GM42 now

## Gotchas hit

- Trunk moved twice mid-session (`3c8e7ee` → `8118570`); re-check `origin/main` before
  integrate. The bowed family is actively worked by the fleet — the HLD + claimed
  branch are the collision signal.
- `deltic timeout bash -c '... python ...'` loses PATH (python not found) and eats the
  loop var — call `deltic timeout python …` directly instead of via a nested `bash -c`.
- **Waveguide pitch is measurement-robust but the voice detunes with pitch** — a fixed
  ~3.8-sample loop latency (in-loop filter + read/write) that `sr/f − 1` under-subtracts.
  Cheap to miss: it's inaudible in the bass (where the contrabass lives) and only shows
  up as the register climbs. Any new waveguide voice needs its `loop_comp` set from a
  quick single-note pitch sweep (autocorrelation), not assumed.
- **`render_opus.py --only-list` (track-level) vs the lyrics validator** — the validator
  was scoped to the render *subset*, so a partial refresh flagged every not-selected
  sidecar in a touched album as an orphan. Validate sidecars repo-wide, render the subset.
