# Portable canaries and approved cleanups

## Scope

Implemented the decisions from the 2026-07-12 scratchpad review:

- replace stored raw-render fingerprints with portable audio signatures;
- centralise control-rate LFO construction without changing renders;
- cap unreleased driven-guitar voices at eight per channel;
- order CC0 bank select before same-tick program changes in both copied album engines;
- make Big Weather's fixed-meter verifier assumptions explicit and testable.

## Decisions

- A portable render signature measures body RMS, spectral centroid, and the
  late/early RMS ratio. Its shared tolerances are ±0.15 dB, ±2%, and ±0.30 dB.
  Calibration tests prove each component catches a change just outside its limit.
- Same-run identity/distinctness tests compare rendered buffers directly. No raw
  f32 hash helper or stored raw hash remains.
- The guitar limit counts unreleased GM 29/30 voices together per MIDI channel.
  Spawning a ninth releases the oldest, clearing sustain and sostenuto deferrals.
- CC0 uses event priority 0; Program Change remains priority 1; ordinary CCs
  remain priority 2. Nine Through Lines MIDI files changed only in event order.
- A meter declaration is a change only when its effective numerator/denominator
  differs from the preceding declaration. Changes exactly at a checked span's
  boundaries are valid; effective changes strictly inside fail clearly.

## Verification

- `cargo test --workspace`: green (348 library tests passed, 8 ignored; sample-pack
  tests also green).
- `cargo test --release --workspace`: green with the same results, proving the
  former optimisation-profile-sensitive pins are gone.
- `cargo clippy --workspace --all-targets -- -D warnings`: green.
- Big Weather and Through Lines focused `unittest` suites: green.
- `python build.py --check`: green for both albums.
- `python build.py --verify`: green for all 16 Through Lines tracks after
  regenerating tracks 03, 05, 07, 08, 10, 11, 13, 15, and 16.
- Mandatory baseline/candidate inventory: all 104 MIDI files listed by
  `render_opus.py::all_midis()` produced byte-identical WAVs.
- Candidate rendering of each of the nine old/new Through Lines MIDI pairs also
  produced byte-identical WAVs. No listening Opus refresh is needed.

An independent read-only review found no functional defects. It identified the
last same-run FNV helper, a stale comment, and redundant meter declarations as
cleanup gaps; all three were corrected and their focused tests re-run green.
