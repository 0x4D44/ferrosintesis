# 2026.07.13 — JRN — stop committing rendered opus; add `build.py`

## Task

Arthur: the committed rendered audio has bloated the repo. Remove the `.opus` files
from git (and from future clones), and make one build command produce synth + CLI +
all rendered opus.

## What the investigation found

- `.git` = **5.9 GB**; live tree = 569 MB. `.opus` = **3,135 MiB across 650 blobs**
  (~93 % of tracked bytes) — the 81 live tracks re-rendered and re-committed ~8× (the
  documented "`render_opus.py` rewrites `listening/*.opus` in place" pattern, each
  re-render committed).
- All 81 tracked opus live under `listening/`; `listening/README.md` is the only
  non-opus tracked file there (kept).
- No other audio is tracked beyond opus + the 202 sample-bank `.wav`
  (`crates/ferrosintesis-samples-*/samples/`), which are synth **source** — must be
  preserved. `.mid` (8 MiB) is committed source of truth for every album.
- Blast radius for a history rewrite: 5 worktrees + 3 local task branches + 3 remote
  feature branches. This is a live multi-agent repo.

## Decisions (agreed with Arthur)

1. **Full purge** — opus out of tree + history + git-ignored; audio is render-on-demand.
   Accepted tradeoff: loses "listen without a toolchain".
2. **Repo-root `build.py`** as the one command (not `cargo build` via `build.rs` — a
   build script runs before the binary exists, can't render, would need ropusenc, and
   would write 340 MB into the tree on every compile).
3. **Prep now, purge when quiescent** — the safe, reversible half lands on this task
   branch now; the destructive history rewrite + force-push is a documented runbook
   Arthur runs when in-flight branches have landed (a force-push rewrite orphans them).

## Done this task (safe half, on the task branch)

- `.gitignore`: added `*.opus` alongside `*.wav` under "reproducible build output"
  (sample-bank WAV negations untouched).
- `git rm --cached` all 81 opus (kept on disk; `listening/README.md` retained).
- New `build.py`: `cargo build --release -p ferrosintesis-cli` then `render_opus.py`;
  flags `--album`, `--jobs`, `--skip-build`, `--no-render`.
- Doc reconciliation (opus no longer committed): root `README.md`, root `CLAUDE.md`
  (pipeline, layout, worktree-warning box, rendering section, synth-change policy,
  album-anatomy table, gitignore paragraph), `listening/README.md`, `render_opus.py`
  docstring, and 16 per-album/demo READMEs (fanned out via a workflow, MIDI-committed
  claims preserved).
- Runbook: `wrk_docs/2026.07.13 - PLN - purge committed opus from git history.md` —
  mirror-clone + `git filter-repo --path-glob '*.opus' --invert-paths` + verify +
  `push --force --mirror` + re-sync every clone. (`git-filter-repo` is installed as a
  Python module here, not a git subcommand — the runbook locates it dynamically.)

## Verification

- `python build.py --album "Tuxedo Noir"`: built the release CLI (7.85s) and rendered
  a 2.4 MB opus; exit 0. Rendered opus correctly git-ignored (absent from `git status`).
- No Rust source touched → **no ferrosintesis version bump** (Cargo crate unchanged;
  `build.py`/docs/`.gitignore`/opus-removal are non-crate/dev-tooling changes).
