# 2026.07.14 — JRN — GM sound-effects family 120-127 rework

## Brief

GM 120-127 all rendered through ONE struct (`SfxNoise`): a band-passed
white-noise burst, gains 0.06-0.16, exponential decay from sample 0 on a fixed
t60, culled at amp < 1e-5 — no sustain segment at all, key-hold length ignored.
Measured against a piano at equal velocity the eight programs sat 24-39 dB
under it, i.e. inaudible after the whole-file peak-normalise. The test
`gm_sfx_120_127_are_toneless_noise_fallbacks` PINNED that behaviour (all eight
bit-identical across keys, rms < 0.08, flatness > 0.18).

## What was done

Baseline measurement first (new ignored calibration printer
`print_sfx_baseline`): piano(0) key 60 vel 100 → peak 0.8185, rms(0-0.5 s)
0.2991; every SFX held-window rms(1.5-2.0 s) = 0.0000; gunshot peak/piano
0.087.

Per program (all in `crates/ferrosintesis/src/voices.rs`, new block between
`SfxNoise` and `Modal`):

| GM | voice | fate | design |
|----|-------|------|--------|
| 120 fret | `SfxNoise` | UNCHANGED, bit-frozen | squeak transient is right as-is |
| 121 breath | `SfxBreath` | sustained | white noise through 2 formant bandpasses (500/Q2, 1400/Q2.2) + hiss bp(4200/Q0.8), 0.12 s soft onset, hold, release t60 0.30 |
| 122 seashore | `SfxSeashore` | sustained | surf wash bp(600/Q0.45)→LP(1000/Q0.7) + spray bp(3800/Q0.6), both riding a 0.09 Hz swell (spray follows swell², breaking at the crest), release t60 1.2 |
| 123 bird | `SfxBird` | one-shot | 4 upward FM chirps on a fixed 0.16 s grid, 60 ms exponential sweep 2.5→4.6 kHz (×1.85), 38 Hz trill, trapezoid envelope, ±6 % seeded per-chirp pitch jitter |
| 124 telephone | `SfxTelephone` | cadenced (repeats while held) | 440+480 Hz sines under a 20 Hz striker warble, ring 0.9 s / pause 0.45 s, note-off damps t60 0.15 |
| 125 helicopter | `SfxHelicopter` | sustained | rotor bp(330/Q0.5) + thump LP(140) chopped by an 11 Hz squared raised-sine gate, faint unmodulated turbine bp(2500), release t60 0.4 |
| 126 applause | `SfxApplause` | sustained | two interleaved `GrainGate` clap trains (150/s t60 10 ms + 210/s t60 8 ms) through clap bandpasses (2400/Q0.8, 3100/Q0.9), release t60 0.6 |
| 127 gunshot | `SfxGunshot` | one-shot | broadband crack (raw white ×4.1, t60 15 ms — peak ≈ 3.3× the piano's) into a LP(400) boom t60 0.30 |

Shared `SfxEnv` (attack-hold-release: one-pole rise while held, exponential t60
release after note-off) drives the four sustained voices. All seven new voices
ignore the written key and draw all randomness from the seeded `Rng`, so
equal-seed renders stay bit-identical — the old test's key-invariance clause is
kept for all eight in `gm_sfx_120_127_ignore_written_pitch`.

Dispatch: the `120..=127 => SfxNoise` arm became eight arms; `SfxNoise`'s
per-program constant table trimmed to 120 + default (121-127 rows dead).

## Surprises / gotchas

- `spectral_band_rms` is Hann-windowed; comparing it against raw `rms()` bakes
  in the window's power factor (~0.61) and silently deflates a "band fraction"
  — the bird tonality clause had to be recut as in-band vs out-of-band
  (both spectral, consistent units).
- `testutil::centroid` weights 20 log bins by magnitude, so an amplitude taper
  inside the measurement window drags the centroid: the bird chirp's original
  sin(πu) envelope suppressed exactly the sweep's top end and read
  2635→3095 (×1.17). A trapezoid envelope (8 ms/12 ms edges, flat body) plus a
  ×1.85 sweep fixed it honestly (chirps do hold level while sweeping).
- A single Q 0.45 bandpass has 6 dB/oct skirts — the seashore "low wash" leaked
  enough 2.5-8 kHz that it rivalled the deliberate spray (0.063 vs 0.068).
  Cascading LP(1000/Q0.7) after the wash makes the lows genuinely dominate.
- `env_autocorr_peak`'s default 15 Hz detrend would eat an 11 Hz chop — the
  helicopter oracle uses `env_autocorr_peak_detrend(…, 4.0)` per the alt-bank
  bowed-tremolo precedent.
- render-diff on Windows: pass BOTH binaries as absolute Windows paths
  (CreateProcess neither resolves Git-Bash `/tmp/...` nor a forward-slash
  relative path), and budget well over 600 s — 99 album MIDIs × 2 renders.
