# 2026.07.14 — JRN — drum kit internal rebalance (hats up, ride/crash down, forward)

**Task:** Arthur, using ferrosintesis as a general GM player, heard the drums as "far
back / too quiet" across tracks (incl. an external "Hey Jude"). Build. Branch:
`task/20260714-DEV-HUM-drum-kit-internal-balance-hats-up-ride-d` off clean trunk (0.19.1).

## The diagnosis journey (several wrong turns)

The complaint drifted through four hypotheses; measurement settled each:
1. **"Drums far back" → reverb?** Dried the drum sends (a separate, unpushed branch). Didn't
   fix it — the drums weren't wet-distant.
2. **"Not prominent" → bus level?** A flat drum-bus gain is **absorbed**: the −18 LUFS
   normalize pulls the whole mix back (a +6.8 dB / 2.2× probe moved the delivered master
   ~0.4 dB RMS), and the −1 dBTP limiter clamps the now-peak-driving drum transients (drum
   true-peak 0.6 → 5.8 dBTP at 2.2×). Arthur confirmed 1.0× and 2.2× sounded identical.
3. **→ drum-bus compressor?** Built one (DrumGlue, on the unpushed branch); still "not right"
   — because it amplified the *broken* balance.
4. **→ internal kit balance.** Arthur's ear: "snare/bass/toms quiet vs the cymbals." Built an
   env-gated per-key family mute and measured per-family integrated LUFS in real tracks:
   - standard backbeat: hi-hats **26 dB under** kick+snare (inaudible);
   - Hey Jude: crash only **2 dB under** kick+snare (too loud), hats 19 dB under;
   - the ride measured near kick-level energy per hit (dominates ride tunes).
   Root: the sampled `DRUM_LEVEL` table is calibrated to *match the modeled kit*, so it
   inherited the model's hat-light / cymbal-heavy voicing. Every bus-level fix preserved
   the broken ratio — that's why (1)–(3) failed.

## The fix (0.19.2)

Applied in the drum mix loop so it scales the sampled AND modeled kits equally (parity kept):
- `kit_balance(key)` per-key trim: hi-hats ×4.5 (+13 dB), snare ×1.8, toms ×1.6 (they sat
  behind the kick), crash 1 ×0.5 / crash 2 ×0.68 / ride ×0.55 / china·splash ×0.68 / ride
  bell ×0.72 (loud accents pulled back).
- `DRUM_FORWARD = 2.0`: overall +6 dB nominal, which lands as an audible ~+3 dB after the
  limiter — the value Arthur picked off a rendered ladder.

Calibrated against Hey Jude family measurements (env-gated per-key mute + ch10-solo LUFS):
hats −33 → −22, crash −16 → −22, snare/toms brought to within ~2 dB of the kick.
