### Confirmed bugs (not taste)

1. **GM 4 / GM 5 electric pianos emit no pitch.** `Modal::new` documents its partials
   as `(freq Hz, amp, T60 s)` (`voices.rs:235`). Every other modal voice scales the
   ratio table by the key frequency (timpani `voices.rs:700` → `(f * r, amp, t)`;
   bells `:583`). `electric_piano_1` (`voices.rs:482`) and `electric_piano_2`
   (`voices.rs:510`) pass the **bare ratios** — so the modes run at 1–9 Hz,
   key-independent. Audible output = a 10 ms noise burst + the onset click.
   Arthur: *"just some thumps"* — literally correct.
   Hid because `f` IS still used (the noise bandpass), so no unused-var warning.
   Checked all 11 `Modal::new` call sites; only these two are wrong.

2. **The audition muted the choir.** `tracks/audition.py:57` sends CC70 = 0 in every
   slot reset; `engine.rs:1319` latches `vowel_authored = true` for ANY value incl. 0.
   So every choir slot spawned on the closed "mm" vowel. Arthur never heard an "aah".
   The same function's docstring explains it omits CC71/CC74 for exactly this class of
   trap — and then includes CC70.

3. **MM-BUG-KILN-00004** (already filed, Open, High, untouched): `BowedString` vibrato
   runs 16× too slow → dead flat. Default bank for GM 42/43. 46 + 42 committed MIDIs.

### The rig is unfair

Default and alt slots take registers from two unlinked tables (`programs.py:70` vs
`:157`). Computed roots: GM 43 main C4 vs alt E2 (**20 st apart**); GM 42 C4/E3 (8 st);
GM 44 C4/F#4 (6 st — Arthur heard exactly this). GM 48/49 are the SAME (fair) — so the
"alt better" signal there is real and points at the sample layer, not the model.
Also: a stale ALIAS table means 16 programs never render, incl. GM 89 (19 albums).

### Genuine voice defects (survive the rig)

- **GM 29/30 drive**: `engine.rs:341` `target = sag_target / env` — drive gain is
  INVERSELY proportional to the envelope, floored at 1.0 at the attack, slewing UP to
  4× through the decay. Backwards from a real amp. (My own first read — "no waveshaper
  at all" — was wrong: `DRIVE` has `grit: false`, but the *engine* has a Drive insert.
  The verify pass corrected me.)
- **GM 61 brass section**: `sampler.rs:664` has no arm for 61 → falls through `_ =>` to
  a **solo trumpet** sample. Plus every realism cue dialled down vs the trumpet
  (chiff 0.15 vs 0.35, attack 60 ms vs 30 ms, sampled transient × 0.6).
- **GM 10 music box** = the glockenspiel: same free-free bar series 1 : 2.76 : 5.40
  (`voices.rs:604-611`). A comb tooth is a *clamped* cantilever (≈1 : 6.3 : 17.6).
- **GM 47 timpani**: modal ratios are textbook-correct; the strike thump is LOUDER than
  the fundamental and the partials die in ~1 s (real: 3–8 s).
- **GM 64–67 saxes**: the drive knob is provably inert. A tanh on a two-level
  rectangular pulse maps each level to a fixed value → still a rectangle, same duty,
  same harmonic ratios; DC-blocked it is a pure gain. There is no harmonic-generating
  stage. (Conical-vs-cylindrical IS modelled correctly, via pulse duty.)

### Meta-finding: the oracle suite cannot see this class of defect

No pitch oracle exists anywhere — a voice emitting infrasound passed every gate for its
whole life. `bass_articulations_distinct` (`voices.rs:10805`) "proves" the basses differ
by asserting `black_box(2.4) < black_box(3.2)` — two compile-time constants, renders
nothing.
