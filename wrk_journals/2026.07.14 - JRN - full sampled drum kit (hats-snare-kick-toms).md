## Stage D — sourcing (commit 71d9ff6)

Parsed the pinned Virtuosity SFZ mappings (`Programs/mappings/mid/*.sfz` @
`9f04cf9a…`) before choosing anything. Two source shapes:

- `kick_snon` has TRUE round robins: 4 vel layers (hivel 31/63/95/127) × 4
  RRs — took the whole grid (16 files).
- snare_center (36 vl), snareoff_center (12), snare_crossstick (16),
  htom/ltom_center (16 each) are DEEP-velocity-layered with **no** RRs.
  Embedding all 36 snare layers would bloat the crate, so each target layer

  peak-normalizes to 0.9 (the synth applies velocity gain itself).
  Subset: snare 6×3 (source vl 4-6/10-12/16-18/22-24/28-30/34-36),
  snareoff 4×3 (all 12), sidestick 3×3, tomhi 4×3, tomlo 4×3.

40 MiB budget. The 109 existing cymbal WAVs regenerated **byte-identical**
(generator determinism confirmed by git status). Tail caps: kick/snare

## Stage E — routing (commit 7783494)

`SampledCymbal` → `SampledDrum` (same mechanism + a `repitch` factor).
Routing added: 35/36→KICK, 37→SIDESTICK (Virtuosity's cross-stick), 38/40→
SNARE, 42/44/46→HH_CLOSED/PEDAL/OPEN, toms repitched onto the modeled
ladder.

**Tom split deviates from the brief** (was: 41/43/45→LO, 47/48/50→HI).
With measured roots 113.5/181 Hz, key 45 (190 Hz) sits almost ON the rack
tom's root, so the minimal-stretch split is **41/43→TOM_LO,
45/47/48/50→TOM_HI**. Ratios: 0.88/1.23/1.05/1.33/1.62/1.94. The 50→1.94×
stretch is the steepest; it shortens the decay to ~0.42 s, which is
physically what a small high tom does — kept sampled, verified by the
ladder oracle (six distinct ascending pitches on table values).

Removed the old VSCO kick/snare `SampleOverlay` — with the full kit routed
it became unreachable, so the whole HitSample/hit_bank machinery went with
it (drums.rs wrap, sampler accessors, prewarm entries, its test).

Brush kit: its key map intercepts 35–46 first, so brushes keep brush
voices; toms/cymbals fall through to the sampled kit exactly as they fell
to the V3 models before.

Level calibration (parity with the replaced models at vel 100, RMS over
3 s): first run measured −6.2 dB (kick) to +9.0 dB (closed hat); the
DRUM_LEVEL table now lands all 21 keys within ±0.31 dB.

## Stage F — oracles, gate, proofs (commit 6c53938 = bump)

New oracles (all `#[cfg(feature = "embedded-samples")]`):
- `sampled_kit_routes_only_on_v3_brush_with_samples` — full routing seam +
  `--no-samples`/V1/V2 structural canary + brush interception.
- `sampled_kit_velocity_selects_layers_through_make` — soft vs hard picks a
  different take (a broken layer switch would render a scaled copy: same
  seed ⇒ identical jitter ⇒ scaled_diff ≈ 0; fails-first by construction).
- `sampled_drum_level_parity` — all 21 keys ±3 dB (measured ±0.31 dB).
- `sampled_toms_repitch_preserves_the_ladder` — 99.7/138.9/187.6/237.0/
  289.4/347.6 Hz vs table 100/140/190/240/293/352; ascending enforced.
- `sampled_closed_or_pedal_hat_chokes_open_in_engine` — GOTCHA: the naive
  "choked window quieter than open ring" fails for the PEDAL choker
  because the pedal chick's own body rings past 200 ms. The oracle now
  measures the RESIDUAL (choked-render energy minus choker-played-alone
  energy): 0.00000 for both chokers vs an open ring of 0.011 — the open
  hat is fully choked; an unchoked one would leave ~0.011 in the residual.
- `sampled_fast_closed_hats_do_not_machine_gun` — THE headline oracle:
  16 closed hats at 16th-note spacing through the engine. Fail-first is
  calibrated INSIDE the test: two same-seed/same-take voices render
  bit-identically and read NCC 1.000 (asserted >0.999); the engine path
  reads max pairwise NCC 0.705 (<0.97) and min same-take diff/rms 1.290
  (>0.4).

Gate: `cargo fmt --all` clean; `clippy --workspace --all-targets
-D warnings` zero (one let_and_return fixed); `cargo test --workspace
--release` 430 passed / 0 failed (stdin closed).
