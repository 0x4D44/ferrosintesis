# 2026.07.14 — JRN — Sampled cymbal kit, Stage A: sourcing pipeline + drumkit asset crate

Stage A of replacing the modeled cymbals with a sampled kit (per the
MetalPlate V4 / CC0-sourcing HLD): build the sourcing pipeline and the asset
crate only — no synth wiring (that is Stage B).

## What was done

- `tools/ferrosintesis-samples/prepare_drumkit.py` — sibling of `prepare.py`,
  reusing its `fetch`/`read_wav`/`resample`. Fetches 109 FLACs by pinned-commit
  raw URL: Virtuosity Drums (`sfzinstruments/virtuosity_drums` @
  `9f04cf9a734527edfbb0a4eee1f674e45bbf71bc`, `mid` mic set) for ride bow/bell,
  crash, sizzle crash, hi-hat closed/open/pedal/splash; Big Rusty Drums
  (`sfzinstruments/karoryfer.big-rusty-drums` @
  `f07ce00df34a46b6b08375be56fe116cf15782bc`, 18" china, stick, `oh` mic).
  FLAC decode shells out to ffmpeg (tool-time only, bit-exact, `pcm_s24le`);
  all audible processing (mono downmix, linear resample to 44.1 kHz, onset
  trim, tail caps 1.2/2.2/2.8 s, fades, peak-normalize 0.9) is stdlib Python
  mirroring `prepare.py`.
- `crates/ferrosintesis-samples-drumkit/` — new asset crate mirroring the
  orchestral one: 109 WAVs (15.63 MiB) embedded with `include_bytes!`, plus a
  typed `Bank` API (`RIDE`, `RIDE_BELL`, `CRASH`, `CRASH_SIZZLE`, `SPLASH`,
  `HH_CLOSED`, `HH_OPEN`, `HH_PEDAL`, `CHINA`; `wav()`, `pcm()`,
  `layer_for_velocity()`), with velocity splits parsed from the source SFZ
  mappings, not guessed. PROVENANCE.md + LICENSE-CC0 (verbatim, both repos'
  LICENSE files are byte-identical CC0 1.0 legal code).
- Workspace member + `.gitignore` negation added. Note: the existing ignore
  negations are per-crate explicit lines, NOT a `ferrosintesis-samples-*`
  wildcard — a new sample crate always needs its own line.

## Decisions & surprises

- Micset `mid`: the balanced mono-friendly middle position of the seven
  recorded; `oh` for the china as its closest perspective match.
- Virtuosity's `hh_splash` is a hi-hat pedal-splash, not a true splash
  cymbal, and has no velocity layers at the source (4 RRs, full range). It is
  still the kit's nearest GM-55 candidate; Stage B decides the mapping.
- Big Rusty's default branch is `main`, not `master`.
- Sources are 48 kHz stereo (Virtuosity) / 44.1 kHz stereo (Big Rusty).
- Left out: hh_half, hh_34, flat ride (bank kept lean; easy to add later by
  extending `BANKS` in prepare_drumkit.py).
- Per-layer natural loudness is discarded by peak normalization (bank-wide
  convention); the synth applies velocity gain, and `vel_hi` tables preserve
  the layer boundaries.

## Validation

`cargo fmt --check`, `clippy --all-targets -D warnings`, `cargo test` (5/5,
including a decode oracle over 4 banks: 44.1 kHz, peak 0.900, RMS 0.04–0.13,
durations as capped), `cargo build --release -p ferrosintesis-samples-drumkit`,
`cargo check --workspace` — all green. No version bump (new crate not yet
consumed by shipped code; Stage B's wiring bump covers the feature).
