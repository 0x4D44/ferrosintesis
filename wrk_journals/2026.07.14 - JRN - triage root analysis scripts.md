# 2026.07.14 — JRN — triage the root ad-hoc analysis scripts

**Mode:** cleanup (dev-only script removal — no shipped code, no version bump).

## Prompt

A prior agent noted six ad-hoc analysis scripts still sitting in the repo root
(`analyze_raw.py`, `census_opus.py`, `measure_raw.py`, `probe_ceiling.py`,
`val_u4.py`, `transcribe.py`) — none in the render path — and offered a cleanup or
scratchpad triage. Arthur asked me to do the triage cleanup.

## What I found

Read all six, traced every reference (an independent adversarial dependency sweep
confirmed the findings), and checked the docs that back them.

**Five are one-time loudness-measurement leftovers** from the now-shipped
normalization work (U4 per-track LUFS norm, U6 = the v0.16.0 loudness-normalized
catalog):

- `measure_raw.py` — renders all 104 album MIDIs raw (via the `raw_dump.rs` example),
  ffmpeg-measures each, writes `raw_loudness.csv`.
- `analyze_raw.py` — turns that CSV into the design-decision tables.
- `probe_ceiling.py` — one-shot probe that fixed the −4.5 dBTP WAV ceiling.
- `val_u4.py` — one-shot validation of the U4 per-track normalization.
- `census_opus.py` — ad-hoc whole-catalog opus loudness census (−18 LUFS / −1 dBTP).

Their method **and every finding** are durably captured in
`wrk_docs/2026.07.13 - CR - raw render loudness measurement.md`,
`wrk_docs/2026.07.13 - PLN - loudness normalization overhaul.md`, the matching JRN,
and `lessons_learnt.md` (the OPUS_TP_CEILING and normalize-loudness-iteration
lessons). The recommendation they informed — per-track LUFS normalization with a
native BS.1770 meter — shipped in v0.16.0. So the scripts are spent process tooling.

**`transcribe.py` is NOT a leftover** — the noting agent mis-grouped it. It is a
first-class, documented tool (the inverse of the render pipeline): `TRANSCRIBE.md`,
an HLD (`wrk_docs/2026.07.09 - HLD - opus to midi transcription tool.md`), a
`transcribe.local.json.example` config, dedicated `.gitignore` entries, and a
`--selftest` oracle. Kept.

## Decision (framework: at the repo root keep only documented tools + durable records; delete one-time process tooling)

- **Deleted** the five measurement scripts (`git rm`).
- **Kept** `transcribe.py` (documented tool) and `raw_loudness.csv` (the CR's cited
  evidence appendix — a record, not tooling; the CR and PLN reference it by name).
- **Scratchpad note** captures the one bit of forward value in the deleted set: a
  reusable whole-catalog post-encode loudness census (what `census_opus.py`
  prototyped) would be a useful QA oracle — but as a proper tool, not root clutter,
  and it is largely redundant with the shipped in-pipeline normalization + native
  BS.1770 meter.
