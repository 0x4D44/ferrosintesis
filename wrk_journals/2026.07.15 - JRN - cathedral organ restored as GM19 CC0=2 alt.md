## Investigation (3-agent workflow) — the load-bearing finding
The synth alt bank is a **one-bit switch**: engine.rs `s.alt_bank = (val != 0)` collapses
CC0 to a bool, and `altbank::make` dispatches by PROGRAM alone. So GM19 could host only one
alt (the legacy Leslie), and **The Ninth Bell reaches its organ via CC0=1** (96 notes) —
repointing that slot would change the album. Across all 114 corpus MIDIs the only CC0 values
used are {0, 1}, so **CC0=2 is free**. Chosen design: thread the real CC0 value through and
dispatch GM19 by bank (2 → cathedral, else legacy). The alternative (hang the cathedral off
an unrelated program's alt slot to avoid engine work) was rejected as a confusing hack.

## Mechanics that worked
- **reverb.rs** was pure-deletion in `baf8dce` and untouched since → `git diff baf8dce^ baf8dce
  -- reverb.rs | git apply -R` restored the whole CathedralReverb FDN cleanly.
- **engine.rs** == `baf8dce` exactly (no later commits) → reverse-applied ONLY the pure-deletion
  hunks (a CRLF-safe binary python hunk-filter; a text round-trip corrupts line endings and
  git-apply rejects it), restoring all machinery in place; then hand-rewired the MIXED hunks
  (predicate, fx_profile dry arm, bus branch, mix streams) to gate on CC0=2.
- **voices.rs** changed post-`baf8dce`, so the voice block was extracted from `baf8dce^` and
  spliced. GOTCHA: the 3484-4258 range over-ran into the drawbar `Organ` struct/impl (it sits
  AFTER `impl Voice for CathedralOrgan` in `baf8dce^`), duplicating it → deleted the dup.
- Threading: new `alt_bank_value: u8` on Strip + Active + CC0 handler + spawn; `altbank::make`
  gains a `bank` param; `cathedral_organ`/`organ_leslie_family`/`fx_profile` become bank-aware.

## Durable lessons
