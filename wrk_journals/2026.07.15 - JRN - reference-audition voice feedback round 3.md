## Outcomes — root causes (all evidence-grounded, measured)

- **40==41 identical:** both route through the SAME `violin_bank` onset at identical gain
  (voices.rs:10206/10248) → bit-identical first 380 ms (the strongest identity cue). They
  differ only in a too-subtle tail EQ (viola 6% darker; SC-55 makes it 33% darker via
  formant placement). Round-2's "give viola the violin bank" call caused this. Fix = a
  dedicated CC0 viola bank + darker BODY_VIOLA.
- **043 contrabass:** waveguide 1.8-1.95× too bright — inherits cello in-loop damping but
  has LESS output damping than the cello (backwards). Fix = darken (refl_sustain 2600→1400,
  add out_lp, lower body_f). Wolf-band keys 46-50 = separate parked defect.
- **046 harp:** octave-hollow — 2nd harmonic +5.7 dB OVER f0 (SC-55 −26.6). Flat-spectrum
  KS excitation + 400 Hz body peak on the octave. Oracle harp_46_shimmers REWARDS the
  defect. Fix = 1/n excitation tilt (harp-only field) + oracle recal.
- **047 timpani:** ZERO energy above 300 Hz (modal bank tops 2.245·f0, strike LP 300 Hz).
  No mallet thwack. Fix = bandpassed mallet strike 800-1500 Hz + canonical modes.
- **052/053/054 voice:** parallel narrow-Q formant bank carves notches BETWEEN formants
  (h3/h4 −21/−29 dB where refs PEAK); voiced too bright/solo. GM54 INVERTED (ours brightest,
  refs darkest) + an oracle pins it bright. Fix = dark GM54, glottal −6dB/oct tilt, widen Q,
  oracle recal.
- **056-061 brass holds:** frozen static sustain — centroid wander 2-13 Hz vs SC-55 88-191
  (7-75×); solo naturals have NO vibrato. Fix = shallow decorrelated modulator into L
  (reuses the flue-quick-win modulator).
- **064-067 sax:** "fuzz" = p⁴ rasp turbulence (~200× SC-55's broadband hash); "hollow" =
  duty-0.30 rectangle nulls h3. Fix = cut noise_base 4-6× (quick win) + fuller-harmonic body.
- **074-078 flue pipes:** "shaking sshsshssh" = a 50% breath AM locked to the pitch vibrato
  at 4.5-5.5 Hz = the ~4 Hz fluctuation-strength peak (voices.rs:6778). Flute escapes it
  because its breath level is quiet (masked). Fix = shallow decorrelated flutter off 4 Hz +
  breath trims (ONE line + a small LFO). Recorder even/odd inverted + oracle asserts h2≥h3
  backwards. Bottle over-noisy (Helmholtz redesign overshot).

## The LA-synthesis verdict (answering Arthur's hypothesis)

Half right. LA covers only the ONSET (brass holds render bit-identical with --no-samples).
So a missing sample fixes an IDENTITY/attack complaint (viola sameness, recorder identity,
timpani strike) but NOT a sustain/noise complaint — and most of round 3 is the latter,
i.e. cheap in-model bugs. The two most vivid complaints (flue sshsshssh, sax fuzz) are a
handful of constants, no samples needed.
