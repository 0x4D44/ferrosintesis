## DESIGN

Key simplification the measurements unlocked: **bake the loop offline, runtime =
plain modulo wrap.** Kills the "biggest structural gap" (Zone has no loop
metadata) — we never need it; `bank!`/`parse_wav`/`Zone` untouched. `LoopVoice`
~40 lines with its own Adsr(sustain=1.0) → correct released()/alive() by
construction. Drone = bass+tenor octave stack from the two real drone files,
key-relative by repitch. Model stays on the alt bank via the required 109 arm.

Self-flagged before review (crux): my doc justified "repitch preserves the seam"
via period-exactness, which is imprecise. The real reason: the baked seam is
waveform-CONTINUOUS (data[L-1]→data[0]), a property of the DATA, independent of
playback rate — so repitch preserves it trivially. The implementation
consequence the doc must state explicitly: the linear-interp neighbour must WRAP,
`hi = (floor(pos)+1) % L`, or the last sample of the loop interpolates against an
out-of-bounds / wrong neighbour and clicks every wrap. Will fix in the fold.

### KEY FINDING from testing the core bet against real data (shaped the design)
A self-correlation-search loop extractor — even a wide one — clears ρ>0.95 on only
~2 of 6 zones; chanter reed cycle-to-cycle variation accumulates over a self-cut
loop. **Upstream's SFZ loop points give ρ 0.98–1.00 (25/26).** So the design's
"do our own search, skip the SFZ" decision was REVISED (§9): parse the SFZ
`loop_start`/`loop_end`, use them, re-validate, self-search only the broken `D#5`.
This is why we test against real data before writing the code.

### Render-diff (§7.11): EMPTY BY CONSTRUCTION — not run in full, and why

so an album render-diff is definitionally empty. Contamination of OTHER programs is
impossible here: the only shared-path edit is splitting `64..=67 | 109 | 111` into
`64..=67 | 111` + a separate `109` arm — 64-67/111 call the identical `reed(...)`.
And the golden test PROVES the modeled 109 is byte-identical pre/post
(`--no-samples` == the pre-change golden hash, all 3 rates). So the full baseline-
build + 99×2 render (~20 min to confirm silence-vs-silence) is skipped as pure
duplication; the golden + full suite substitute. Flag if you want the full run.
