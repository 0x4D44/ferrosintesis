## Extraction — PROVEN (prototype ran clean)
SF3 = SF2 structure, samples stored as per-zone **Ogg Vorbis** in `smpl` (ifil 3.1).
- Parse RIFF `sfbk` → top-level `LIST sdta` (record `smpl` sub-chunk data byte offset) and
  `LIST pdta`. pdta fixed-width records: phdr 38, pbag 4, pgen 4, inst 22, ibag 4, igen 4,
  shdr 46. (Beware: my first list-walker bug treated the chunk SIZE as an absolute END —
  `end = off + size`.)
- Preset `bank==0 & preset==7` ("Clavinet", phdr[20]=preset u16, [22]=bank u16, [24]=bagNdx)
  → pbag → pgen gen oper **41** (instrument) → instrument **148**.
- Instrument 148 ibag → igen: gen **53** = sampleID, gen **43** = keyRange. 11 sample zones.
- **SF3 shdr `start`/`end` are BYTE offsets** into `smpl` (NOT sample frames) → each slice
  `smpl_data[start:end]` is one complete Ogg file → `ffmpeg -y -i z.ogg z.wav` → mono 44.1k PCM.
- 11 zones tile keyRange 0–108. Roots MIDI **[31,36,43,48,55,60,67,72,79,84,91]** = sounding
  G1,C2,G2,C3,G3,C4,G4,C5,G5,C6,G6. **Trust shdr originalPitch, NOT the sample name** (name
  octave is +1). Measured pitch matched originalPitch within +1..+12 cents. Name each dest
  WAV by sounding pitch.

## Bake — PROVEN (all 11 loop seams clean, ratio 2.0–3.2)
Decoded samples are ~0.2 s struck bodies with a sustain loop (sampleModes=1, startloop/endloop
in decoded frames; **clamp endloop to decoded length** — ~100-frame Vorbis padding). Bake:
1. `loop = seamless(x[sl:el], xf=160)` — crossfade the loop's tail into its head so repeats
   don't click (this fixed roots 31/48/79 which clicked at ratio 11–22 without it).
2. `out = x[:sl]` (attack) + repeated seamless loop → `1.6 s` total.
3. exponential decay from `sl` onward, **t60 register-scaled 2.4 s@root31 → 0.9 s@root91**
   (EAR-TUNABLE — no ears on this box), 50 ms end fade, peak-normalize 0.9, 16-bit mono 44.1k.

## Design (routing + voice)
- New MIT asset crate **`ferrosintesis-samples-clavinet`** (+ `NOTICE`) so core/orchestral
  stay pure-CC0. Add to `embedded_wav()` resolver + workspace members + a feature-gated dep.
- `sampler.rs`: `clavinet_bank()` (11 baked Zones via `bank!`) + a `ClavinetSampled` voice =
  `GongOneShot`'s cursor (baked buffer, `pos`/`step` linear-interp repitch) BUT multi-zone
  (`nearest(clavinet_bank(), key_freq)`) and WITH a note-off release fade (~60 ms damp — a
  clavinet mutes on key release, unlike the gong). Level = EAR-tunable const × `vel_amp`.
- `voices::make(7)`: `if samples { clavinet_sampled(...) } else { Pluck(&CLAVINET) }`.
- `altbank::make`: add `7 => voices::make(7, key, vel, sr, seed, false)` — mirrors the `109 =>`
  arm, so CC0≠0 forces the modeled clavinet.
