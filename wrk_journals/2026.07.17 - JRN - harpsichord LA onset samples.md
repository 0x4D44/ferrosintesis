# 2026.07.17 — JRN — harpsichord (GM 6) LA onset samples

## Task
Add an LA (Roland-D-50-style) sampled onset layer to the harpsichord (GM program 6),
which until now was a pure Karplus-Strong `Pluck` (`HARPSICHORD` preset) with no sample
layer. Companion clavinet (GM 7) work is parked pending an explicit licensing decision
(see "Clavinet" below).

## Sourcing (CC0)
A cross-verified research fan-out over the CC0 ecosystems (VCSL, VSCO-2-CE, FreePats,
Freesound-CC0, plus a licence map of the usual soundfonts) confirmed:
- **Harpsichord: multiple clean CC0 sources.** Picked **VCSL "Harpsichord, Unk"
  (Harpsi4)** — `github.com/sgossner/VCSL`, root `LICENSE` is full CC0 1.0 (added in
  commit `c1ea7bcc`). It ships a 5-octave FF–f''' harpsichord, 61 chromatic isolated
  single-note sustains, dry/close. Pinned SHA `c1ea7bcc3c7309650ab0da9d15c9cd1fbc4a4c7e`.
- **Clavinet: no clean CC0 source exists** (verified negative). VCSL/VSCO/FreePats have
  none; Freesound CC0 has only funk loops + synth-emulation single notes; real free
  clavinet sets are EULA-gated. MIT GM soundfonts (FluidR3/MuseScore) carry a real
  clavinet but are not CC0.

## Key finding — VCSL labels are an octave low
Probed 10 spanning zones before choosing the bank (repo lesson: verify actual audio /
true pitch, don't trust the name). Every VCSL Harpsi4 file measures ~2× its filename
label frequency (label C3 → 262 Hz = C4), confidence 0.91–1.00 — the same offset the
VSCO string sections have. So the destination bank is named by **sounding** pitch (like
`nylon_*`), each dest mapping to the octave-down source label, and the **measured** root
(not the label) lands in `sampler.rs`.

## Implementation (mirrors the nylon/steel plucked-LA pattern)
- `prepare.py`: `VCSL_REV` + `HARPSICHORD_URLS` (10 zones, sounding C2–F6 on a ~6-st C/F
  grid), `KEEP_FAM["harpsi"]=(0.9,0.30)`, `F0_RANGE["harpsi"]=(55,1500)`. Bake reuses the
  exact `trim_to_onset`/`measure_f0` path; `sample_output_path` auto-routes `harpsi` →
  orchestral crate. Surgical bake (family add is provably inert on the other 202 files;
  `git status` confirmed only +10 WAVs).
- Orchestral asset crate: +10 `include_bytes!`, `FILE_COUNT` 147→157, `EXPECTED_BYTES`
  9032142→9833422 (+801280).
- `sampler.rs`: `harpsichord()` bank + `harpsichord_bank()` with the measured roots.
- `voices.rs`: `LA_HARPSICHORD` const + program-6 `make()` arm now `LaVoice::wrap`s the
  Pluck when `samples`, exactly like GM24/25.

## Gain tuning
Started at the guitar's `LA_GUITAR`=0.42; `la_level_continuity` failed at C5 (key 72):
the sampled 50–150 ms window sat 2.9× above the model's own decay shape (a harpsichord's
high strings damp fast in the MODEL, but the real recording's body still rings). Dropped
to **0.28** (power-model boundary ~0.31), which meets the seam cap with margin; the quill
spike lives in the first 50 ms, before that window, so the attack character is kept.
