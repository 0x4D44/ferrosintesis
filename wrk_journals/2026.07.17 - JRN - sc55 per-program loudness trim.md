# 2026.07.17 — JRN — SC-55-referenced per-program loudness trim

## Task
Arthur asked whether all instruments are normalized to the same level. They are not —
answered that first, then (his choice) matched the SC-55mkII balance, conservative/damped.

## What I did
1. **Diagnosis (code).** Confirmed no per-program normalization: voice = `vel_amp*gain`
   (hand-tuned), mix strip = `volume*expr*at_gain*breath`, only global stage = whole-mix
   −18 LUFS. No `PROGRAM_TRIM`/level table anywhere.
2. **Measurement.** Built a 128-program probe MIDI (one sustained note per GM program,
   equal key/vel/CC), rendered dry + `--peak-normalize` (single linear scalar → exact
   relative dB; verified 0 clipped samples). Metric care: whole-note RMS for sustained,
   early-window RMS for decaying (peak too spiky, whole-note RMS penalizes fast decay).
   Register-robust (C3+C4).
3. **SC-55 reference.** Rendered the same probes via `mdmidiemu --synth sc55`. Compared
   each engine re its own median; delta = ferro − sc55, averaged over both keys.
4. **Trim table.** `gen_trim_table.py`: correction = −delta, sustained families only,
   0.70×, ±6 dB clamp, 1 dB dead-band → 48 programs. Implemented as
   `engine::PROGRAM_TRIM_DB` applied at the melodic strip (`g *= trim`, ch9 exempt).
5. **Verified**: containment (untouched bit-identical, corrected = trim ±0.5 dB glue),
   convergence toward SC-55 (residuals 5–6 → 1–2.5 dB), blast radius (only corrected-program
   albums change; a no-corrected-program album is bit-identical), full suite green, golden
   ch8 re-captured.

## Surprises / traps
- **First analyzer used the wrong note spacing** (1.5 s vs the true 1.25 s = 960 on + 240
  gap @ 120 bpm/480 tpq). The drift mislocated windows and produced bogus −99 dB reads that
  looked like dead instruments. Always derive the probe period from the tick math, not the
  intended seconds.
- **Whole-note RMS is not a fair loudness metric for decaying voices.** ferro guitars/
  plucked read −11..−20 dB "quiet" vs SC-55, but that's a *faster decay envelope*, not a
  level deficit; their attack early-RMS is close. Lifting their gain would blow out the
  attack. → excluded all struck/plucked/percussive from the trim.
- **The master bus-glue compressor is nonlinear**, so a per-channel trim doesn't reproduce
  exactly at the master — corrected programs land ±0.5 dB off their nominal trim in a solo
  probe. Expected, benign (the glue is "a dB or two of gentle movement").
- **`cmd | grep` masks cargo's exit code** — the backgrounded `cargo test | grep` reported
  exit 0 while cargo actually had 1 failure (golden). Read the grep'd `test result:` line,
  not the pipeline exit.
- Base moved to 0.21.15 (GM0 Salamander grand) while my local main clone lagged at 0.21.14;
  built the render-diff baseline from the branch base (302b6a6), not the stale main clone.
