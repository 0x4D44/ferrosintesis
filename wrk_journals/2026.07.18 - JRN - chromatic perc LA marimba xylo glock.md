## The bug (MM-BUG-KILN-00015, Severity Medium, payoff HIGH)

Chromatic percussion (GM 8-15) has no LA onset layer — pure `bell()`/`wood_bar()`/Pluck
models. Mallet-strike instruments are attack-dominated (the ear judges them almost entirely
by the strike transient), so an onset sample is the textbook onset-only win, structurally the
easiest (short one-shots, no sustain to reconcile). This branch does **batch 1** = the three
with a verified CC0 source; vibraphone 11 / tubular 14 / celesta 8 / music-box 10 have no VSCO
source and stay for a later batch.

## Design decisions (settled)

- **Source (VERIFIED present at the pinned rev):** VSCO-2-CE Percussion mallet subdirs, same
  `VSCO_REV = 440300901dfe9275fd84e0b7763af1f8443ae62e` prepare.py already pins. Each is a
  SINGLE flat dynamic layer (no p/f, no RR) — like nylon/steel/harpsi, so `LaVoice`'s vel_amp
  does the dynamics. File patterns + available notes (from `gh api` scout):
  - **Marimba (GM 12)** → `Percussion/Marimba/Marimba_hit_Outrigger_{N}_loud_01.wav`,
    N ∈ {F1,C2,G2,B2,F3,C4,G4,B4,F5,C6}.
  - **Xylophone (GM 13)** → `Percussion/Xylo/Xylo_Medium_{N}_ff_01_far.wav`,
    N ∈ {G3,C4,G4,C5,G5,C6,G6,C7}.
  - **Glockenspiel (GM 9)** → `Percussion/Glock/glock_medium_{N}.wav`, N ∈ {G4,C5,G5,G6,C6,C7}.
- **MEASURE every root — never trust the label.** Mallets are 2f-prone (struck bars have a
  strong 2nd/3rd partial) AND the transposing ones lie: glockenspiel sounds ~2 octaves ABOVE
  written, xylophone ~1 octave above. VSCO files are *usually* labelled at sounding pitch, but
  CONFIRM by measurement (prepare.py prints roots; hardcode the MEASURED value). Add each family
  to `TWO_F_STRONG` if a zone reads 2f (per the recorder/banjo/viola precedent), and name the
  dest by the MEASURED sounding pitch.
- **Struck → KEEP more of the sample.** Add `marimba`/`xylo`/`glock` to `KEEP_FAM` (like the
  plucked banks, ~0.9 s keep) so the strike + early ring is captured, crossfading into the
  modeled bar/bell decay. Fade window short (struck, like timpani `LA_TIMPANI=(0.50,(0.05,0.30))`).
- **Target crate = `ferrosintesis-samples-orchestral2`** (CC0; gitignore whitelist already
  covers it). `FAMILY_PACKAGE["marimba"|"xylo"|"glock"] = "...-orchestral2"`.
- **LA wrap over the EXISTING modal model** (`LaVoice::wrap`): GM 9 glock wraps `bell(...)`,
  GM 12 marimba + GM 13 xylo wrap `wood_bar(...)`. Do NOT replace the models — the sample is
  the onset, the model keeps the pitched decay (exactly like harp/timpani).

## The proven pipeline (per instrument — from the viola + 9-sweep journals)

1. `gh api "repos/sgossner/VSCO-2-CE/contents/Percussion/<Dir>?ref=$VSCO_REV" --jq '.[].name'`
   to confirm exact filenames.
2. `prepare.py`: add `<FAM>_URLS` dict (module-level, mirror `HARP_URLS`/viola `VIOLA_URLS`),
   `F0_RANGE["<fam>"]`, `FAMILY_PACKAGE["<fam>"]`, `KEEP_FAM["<fam>"]` (struck), maybe
   `TWO_F_STRONG`; merge `| <FAM>_URLS` into BOTH the `main()` fetch loop AND the `sorted(...)`
   union.
3. `python tools/ferrosintesis-samples/prepare.py --only=<fam>` → bakes WAVs into
   orchestral2/samples/, prints MEASURED roots. Record roots here; sanity-check vs expected
   mallet pitches (marimba C4≈262, xylo/glock sound higher — VERIFY the octave).
4. `sampler.rs`: `<fam>()` Zone bank (MEASURED roots) + `pub fn <fam>_bank()` + prewarm.
5. `orchestral2/src/lib.rs`: `include_bytes!` the new WAVs. (`FILE_COUNT` auto-updates; the
   `inventory_matches_packaged_wavs` test requires the SAMPLES list == the packaged files.)
6. `voices.rs`: wrap the GM 9/12/13 make() arms with `LaVoice::wrap(model, <fam>_bank(), key,
   vel, sr, LA_<FAM>.0, LA_<FAM>.1)`; add `LA_<FAM>` const (fade.1 < 0.90); add the program to
   `LA_PROGRAMS` + the fade-guard array; update testutil `sample_layer_engaged_at_probe_keys`.
7. Oracles: run `la_level_continuity`, `la_fade_ends_before_model_owned_window`, the modal
   pitch oracles for 9/12/13, `class_identity_ranges_hold` (the new class oracle — 8-15 are in
   the `keyboard+chrom-perc 0-15` DECAY range; an LA onset must NOT flip them to holding — it
   won't, the onset is short). Full `$null | cargo test --workspace </dev/null`. clippy/fmt.
8. **Render-diff** (report): baseline binary from `git merge-base origin/main HEAD`; render the
   ALBUMS MIDIs both binaries; EXPECTED diffs only on albums using 9/12/13; `--no-samples`
   bit-identical (confinement); non-9/12/13 album changing = contamination bug.

## Forks / risks

- **F-octave:** if a measured root disagrees with the expected sounding pitch by an octave,
  the sample is labelled at written (not sounding) pitch — rename the dest by the MEASURED
  sounding pitch (the modal model plays the WRITTEN key, so the LA sample must be repitched to
  the sounding pitch of that key; check how `LaVoice::wrap` maps key→sample and mirror timpani).
- **F-class:** if adding the LA onset flips a mallet's `sustain_db` above −10 (the decay
  ceiling in `class_identity_ranges_hold`), that's a real problem (the onset shouldn't hold);
  investigate — likely the fade window is too long. Do NOT relax the class range.
- If NO clean measured root for a zone (2f you can't resolve), drop that zone (keep the
  well-measured ones) and note it — like the viola/pipe single-zone precedents.
