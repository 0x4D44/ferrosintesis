# 2026.07.18 — JRN — Scrap the CC0 alt-bank voicings for GM40 (violin) & GM41 (viola)

## Why
Arthur was auditioning the CC0 alt bank against the default bank and reported that
GM40 and GM41 "main" (default, CC0=0) and "alt" (CC0≠0) sound the same. Investigation
(A/B render of a 2.5 s held note + staccato, default −18 LUFS normalization, samples on)
confirmed it and explained it:

| Program | main vs alt | why |
|---|---|---|
| GM40 violin | **−50 dB diff (inaudible)** | both banks build the same bowed model + the **same** `violin_bank` onset sample + same `LA_VIOLIN` gain/fade. The alt was a frozen copy of the default. |
| GM41 viola  | **−17 dB diff (subtle, attack only)** | same viola body in both; only the onset sample differs — default uses the **dedicated** `viola_bank` (MM-BUG-KILN-00005 fix), alt still used `violin_bank` as a proxy (strictly worse). |
| GM29/30 driven gtr | −2.6/−1.6 dB (very different) | by design: `DRIVE` (decaying) vs `DRIVE_LEAD` (sustaining). Left untouched. |

So the alt bank added nothing for GM40 and a worse proxy for GM41. Arthur: "scrap the
alt versions of GM40 & GM41."

## What changed (`crates/ferrosintesis/src/altbank.rs`)
- `make()`: split the old `40..=43 =>` bowed arm into an explicit
  `40 | 41 => crate::voices::make(program, key, vel, sr, seed, samples)` (fall through to
  the default voice) and `42..=43 => { …existing alt Bowed… }`. GM42/43 keep their alt
  Bowed set (a genuine alternative to the default cello/contrabass waveguide arco) — only
  40/41 were scrapped.
- New oracle `altbank_violin_viola_fall_through_to_default`: asserts alt `make(40/41)` is
  **byte-identical** to `voices::make(40/41)`. Pins the scrap — re-introducing a distinct
  alt-bank 40/41 voicing breaks it.
- Doc comments (module header, factory header, `render_make` doc, BW-O1, BW-O7) updated to
  say 40/41 now delegate to the default.

The frozen `Bowed` struct + `bowed_body`/`bowed_voice`/`BODY_VIOLA` are **kept** — they
still voice 42/43/44 in production and anchor the body-brightness gradient oracle
(`bowed_bodies_differ`, which renders `render_bowed(40/41/42/43)` directly). No dead code.

## Blast radius (verified, not assumed)
- MIDI scan of all 124 committed album/demo `.mid` files for any channel pairing CC0≠0
  with program 40 or 41: **zero committed albums**. One demo does —
  `demos/ferrosintesis_reference/midi/02 - Bass, Solo Strings, Ensemble, Brass.mid`
  (ch0, progs 40 & 41, CC0=1). Its render only improves/stays the same (default GM40 ≈ old
  alt GM40; default GM41 dedicated-viola onset > old violin proxy). Demo `.mid` untouched;
  its `.wav`/`.opus` are git-ignored build output.
- No committed album render changes → the render-catalog render-diff is a provable zero for
  this CC0-gated change, so it was not run (the direct MIDI scan is the stronger proof).

## Notes / possible follow-ups
- GM29 and GM30 share ONE voice as each other (`DRIVE` default / `DRIVE_LEAD` alt); what
  separates overdriven from distortion is only the program-keyed overdrive insert in
  engine.rs. Their main-vs-alt contrast lives in the note tail (held note reveals it), so
  short/staccato material makes them sound alike — that is not a bug.
- No version bump on the branch (integration owns the single bump).
