## The bug (MM-BUG-KILN-00005, Severity High)

GM 41 viola currently wraps `sampler::violin_bank(vel)` repitched (`voices.rs:10916`),
so the first ~380 ms (the onset the LA layer owns — the strongest identity cue) is
bit-shared with GM 40 violin. Measured: [0,120 ms) diffRMS/RMS = 0.059 (−24.6 dB) at
key 64. The perceptual oracle already flags `(40,41)` as an `EarPending` suspect defect.
Blast radius GM41 ~37 albums, GM40 ~51. `BODY_VIOLA` (`voices.rs:7229`) already darkens
the MODEL, but the SAMPLE is violin's. Fix = a dedicated viola onset bank.
