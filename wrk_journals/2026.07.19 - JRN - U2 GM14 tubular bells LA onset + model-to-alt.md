## Alt-bank wrinkle (design note for review)
GM14's `CC0!=0` slot was ALREADY a *different-instrument* alt — tam-tam (CC0=1) / recorded gong (CC0=2), a
deliberate round-3 choice (`altbank_gm14_gong_is_sample_derived`). Arthur's directive is "move the originals to
alt versions **of the same instrument**." So the pure tubular MODEL cannot use the plain `voices::make(.., false)`
arm (it collides with the tam-tam) — I gave it its **own graded bank, CC0=3**, via the GM14 `match (bank, samples)`
(pattern precedent: GM0 banks 1–4, GM19 banks 1–2). Net GM14 alts: CC0=1 tam-tam, CC0=2 gong, **CC0=3 pure tubular
model** (new). This is a small interpretation of the directive under a pre-existing constraint — flag for Arthur if
he'd rather GM14 not carry a separate model alt.

- **Oracle:** generalized `altbank_vibraphone_...` → `altbank_sampled_programs_preserve_pure_model_and_default_layers`,
  now a loop over `(program, key, alt_bank)`: `(11, 60, 1)` and `(14, 65, 3)`. Uses `render_make_bank` so each
  program's pure-model alt bank is exercised. (a) alt byte-identical on/off; (b) default diverges from the model
  in the attack window. Future units append their triple.
