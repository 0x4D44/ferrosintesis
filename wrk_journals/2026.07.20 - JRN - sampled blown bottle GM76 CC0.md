# 2026.07.20 — JRN — sampled blown bottle (GM 76), CC0 loop voice

## Trigger

The modelled blown bottle (WD11 Helmholtz) was persistently "too windy" by Arthur's ear.
Chasing the model to match the real reference (Roland SC-55mkII, rendered via the local
`mdsc55` emulator) proved a long grind — the jet-noise resonance + ring-past-release WERE
the wind. Arthur downloaded four CC0 Freesound bottle samples; measured + auditioned, he
picked **349867 "Blown Bottle Two"** (Terry93D, CC0 1.0). Decision: **use the sample,
abandon the modelled bottle** (the model stays only as the `--no-samples` fallback, the sax
pattern). "The sampled version is much better."

## What was built (mirrors the saxophone `SaxLoopVoice` exactly)

- **New crate `crates/ferrosintesis-samples-bottle`** (CC0-1.0): one 16-bit mono 44.1 kHz
  file `bottleloop_G3.wav`, root **205 Hz** (G3). `lib.rs` = `FILE_COUNT`/`SAMPLES`
  (`include_bytes!`)/`get() -> Option<&[u8]>` + parity tests. `README.md` + `PROVENANCE.md`
  (CC0; Freesound 349867 / Terry93D; SHA-256-pinned source).
- **Sample bake**: first blow of 349867 (the source has 3 blows), trimmed 0.45–2.10 s
  (attack swell → ~1.2 s plateau body), 3 ms fade-in, squared 60 ms fade-out, peak-norm 0.9.
  Committed source: `tools/ferrosintesis-samples/freesound-src/bottle_G3.wav`
  (SHA-256 `56421959…65fd`).
- **`sampler.rs`**: `bottle_loop_bank()` (single 205 Hz zone), `find_bottle_loop` (a copy of
  `find_sax_loop` re-windowed to the bottle's longer plateau: START 0.45–0.90, LEN 0.05–0.15,
  BODY_END 1.45), `BottleLoopVoice` (attack → looped plateau, same intrinsic vibrato/drift/
  breath as the sax, `kind()="bottleloop"`), `bottle_loop_voice()`, `BOTTLE_LOOP_GAIN = 0.65`
  (calibrated to ~parity: +0.2/+1.6 dB vs the model at keys 55/60).
- **`voices.rs`**: GM 76 dispatch — a `76 =>` arm above `72..=79` = sampled by default,
  `Wind::from_preset(wind(76), …)` (the Helmholtz model) as `--no-samples` / out-of-window
  fallback. Removed the dead LA-onset `76 =>` line and pruned the now-unused `LA_BOTTLE`.
- **Wiring**: workspace member, ferrosintesis feature `dep:` + `=0.1.0` path dep, the
  `embedded_wav` `.or_else` chain, the `.gitignore` un-ignore for the crate's WAV.
- **Provenance**: `crates/ferrosintesis/README.md` Wind row + CC0 crate list (embedded count
  365 → 366).

## Voicing / measurement

- Sample repitch window 0.5–2.05× of 205 Hz ≈ keys 48–67 (C3–G4); the demo bottle notes
  (C4/E4/G4, keys 60/64/67) all engage the sample. Above ~G4 the model fallback speaks.
- The sampled bottle is a clean pitched tone — held-note HNR **+24 dB** (vs the windy model's
  +4.6) — the "note, not wind" Arthur wanted.

## Oracles

- `bottle_loop_level_parity_and_flat` (keys 55/60): kind==`bottleloop`, raw dB band −2..+4,
  liveness CoV band 0.02..0.08 (measured 0.037), loop-wrap seam < 0.03 (measured 0.0064).
- `bottle_loop_pitch_integrity` (keys 48/55/60/67): pitch within 45 c (measured −24..+2 c).
- Pre-existing model oracles (WD-O12/O13) untouched and passing — the model is unchanged.
