## Change

Each voice's additive breath bed was cut (`voices.rs` WindPreset defs):

- **Whistle (78)** `breath` 0.30 → **0.16** (0.30 was a deliberate "make the air audible"
  raise in §2.8.5.2; Arthur's ear reversed it).
- **Ocarina (79)** `breath` 0.17 → **0.10**.
- **Shakuhachi (77)** `breath` 0.20 → **0.12**, muraiki >8 kHz shelf `breath_hi` 0.05 → **0.03**.

Pan-flute (75) untouched (approved as-is).

## Oracle re-targeting

The old bands were written to enforce audibility — the intent Arthur's ear overrode — so
they were re-targeted to the new measured levels (still meaningful, not gutted):

- **WD-O5** breath-fraction bands (measured after the cut): whistle 0.0174 → band (0.012,
  0.026); ocarina 0.0117 → (0.008, 0.017); shakuhachi 0.0291 → (0.020, 0.040). Ordering
  `rec < flute < pan < bottle` still holds untouched. The `shak > 3·flute` clause relaxed
  to `shak > 1.8·flute` (shak/flute is now ≈2.0× — still markedly airier).
- **WD-O4** muraiki shelf: shakuhachi 8–16 kHz fraction fell to 0.00765 (flute 0.00081,
  9.4×) with the `breath_hi` cut, so `shak >= 0.010` → `>= 0.006` and `>= 10·flute` →
  `>= 7·flute`. There is still a clear shelf, clearly above the flute.
