## Intent

Build the deterministic, testable core so the percussive re-derivation is one command once the
ear-gated timbre bugs are fixed: register-band probe, attack/body multi-window meter,
envelope+pitch-tilt+velocity guards, paired-difference anchor. **Out of scope:** the 6 timbre
bugs, the bass voice-gain fix, and applying any new trims (all ear-gated downstream).

## Key design decisions (see `wrk_docs/2026.07.21 - HLD - M-CAL v2 tooling implementation.md`)

- **No library change.** The envelope mismatch is visible in the existing 400 ms momentary
  block *trajectory* (onset-region max vs held-region max) — no sub-400 ms primitive, so the
  published crate is untouched.
- **Two windows (attack `[0,200)ms`, body `[400,900)ms`), not three.** The probe meters 1.2 s
  while holding 1.3 s to exclude the per-engine release; a tail window re-admits that variance.
  Attack-vs-body catches both named defects (GM28, GM33).
- **Register fix = per-family semitone transpose** of the 6-pitch-class set (basses −24, high
  pipes/perc +12), not sampler zone-roots; the per-key guard backstops residual fallback.
- **Guard is anchor-independent** (`Δattack − Δbody` cancels the common offset).
- **Provisional derivation only** — final numbers wait on the timbre bugs.
