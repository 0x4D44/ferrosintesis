# Journal — review of `crates/ferrosintesis-cli/`

Reviewed the complete assigned area at baseline `2d90376` using correctness,
security, performance/scale, reliability, maintainability, test-coverage, and
devil's-advocate lenses. Adjacent library/catalog source was read only to
confirm call contracts.

The pass confirmed three defects worth entering in the Open queue:

- `MM-BUG-KILN-00097` — output alias can replace the source MIDI;
- `MM-BUG-KILN-00098` — a 1–4 Hz WAV makes `calmeter` loop and grow memory;
- `MM-BUG-KILN-00099` — `measure_wav` ignores format and sample-rate metadata.

It also captured `MM-REQ-KILN-00032`: the CLI, catalog renderer, and raw
measurement renderer need one machine-checked default render profile. Current
values match, so this is Draft design debt rather than a bug.

The already documented unchecked numeric options and classic-RIFF size limit
remain unfixed and are recorded prominently in the CR report, but the
adversarial pass kept them report-only to avoid duplicating the 2026-07-18
review. Terminal-title controls, pre-roll clipping, malformed dev-tool
arguments, and sampled-twin compatibility were also kept out of the bug queue
because their demonstrated current impact was low or contract-limited.

No app, render, test, or exploratory harness was run. No shipped file was
changed. Git staging, commit, fetch, branch, push, and integration were left to
Deltic as required.
