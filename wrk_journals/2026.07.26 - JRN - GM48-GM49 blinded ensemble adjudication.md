## Intent

Decide whether GM48 String Ensemble 1 and GM49 Slow Strings have a perceptually
sufficient identity difference after their shared sampled onset hands over to the
model. This is the one human judgment deliberately left `EarPending` by the
perceptual-distinctness oracle.

## Probe

Codex generated four single-note MIDI probes and rendered each in a fresh process:

- probe keys 48 and 72;
- velocity 100;
- three-second held note plus 0.1 seconds of release tail;
- embedded samples enabled;
- reverb and echo disabled;
- each clip independently normalized to −18 LUFS with the normal −1 dBTP ceiling;
- A/B order randomized independently at each key.

The four WAVs are temporary testing artefacts under
`C:\Users\marti\AppData\Local\Temp\MM-BUG-KILN-00024-175b594`.
The answer key was withheld until Arthur returned the verdict.

Measured integrated loudness:

| Pair | A | B |
|---|---:|---:|
| key 48 | −18.00 LUFS | −18.00 LUFS |
| key 72 | −18.00 LUFS | −18.00 LUFS |

This removes overall loudness as a cue while retaining the real sampled-onset/model
handover. The two A/B orders are independent, so the same letter does not imply the
same program across registers.

## Decision trail

1. The ledger's existing 0.0602 tail score is evidence that numeric distinctness is
   unproven, not a perceptual verdict. A listening probe is required.
2. Dry, same-note, level-matched renders were chosen to isolate instrument identity
   from effects and gain.
3. Both oracle registers were retained because a distinction that exists in only one
   register is not a durable program identity.
4. No `TESTING-GUIDE.md` exists in this repository. No failure-state diagnostic pack
   applies to this planned perceptual adjudication.

## Result

Arthur's observation, verbatim:

> Is A GM48 and B GM49? I'm not sure what I'm listening for - the _A & _B
> samples sound pretty much the same to me (for both pairs)

Answer-key reveal:

| Pair | A | B |
|---|---|---|
| key 48 | GM49 Slow Strings | GM48 String Ensemble 1 |
| key 72 | GM49 Slow Strings | GM48 String Ensemble 1 |

The randomized orders happened to match at both registers. Arthur's tentative label
guess was inverted, but identifying the programs was not the task. The decision-bearing
observation is that neither pair exposed a clear identity difference. The same result at
both independent probe registers confirms the existing defect on the pinned build.

## Confirmed in code

`crates/ferrosintesis/src/voices.rs:strings` gives GM49 a velocity-scaled 0.45-second
base attack. At velocity 100 this is about 0.42 seconds. The shared sampled-onset
handover runs to about 0.40 seconds, so most of GM49's differentiating swell happens
under the common onset. After settling, GM48 and GM49 use the same five-player
`SawStack`; the remaining low-pass and release differences did not create a recognizable
identity in either blinded pair.

## Decision and handoff

MM-BUG-KILN-00024 moves from `Blocked` to `Open`. The autonomous fix must give GM49 a
durable Slow Strings identity that remains audible after the shared sample handover at
both probe registers. It must make the frozen tail-tier anti-clone oracle pass without
