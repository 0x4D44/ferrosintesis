# Smooth B1 piano sustain handoff

## 2026-07-26 — diagnosis and design

Arthur asked to replace the Yamaha B1 default piano's unnatural sustain shimmer
with the first alternate VSCO piano's better handoff mechanism.

Confirmed:

- Both banks use the same acoustic-piano model, CC64 handling, and felt-damper curve.
- VSCO's PCM is envelope-conditioned at bake time and uses the ordinary 180–450 ms
  complementary sample-to-model crossfade.
- B1 PCM is independently peak-normalised and uses a special runtime path: sample
  polarity inversion, early modeled overlap, 20 ms adaptive power/correlation
  compensation, and frozen crossfade weights on key-up.
- The special path fixed a measured dip/rebound but is the leading cause of the
  synthetic shimmer. Natural unison beating in individual B1 recordings may remain.

Design scope and acceptance criteria are in
`wrk_docs/2026.07.26 - HLD - smooth B1 piano sustain handoff.md`.

## 2026-07-26 — adversarial design review

Three independent reviewers covered conditioner math, runtime/audio behavior, and
reproducibility, then each refuted the combined finding set. All eight findings
survived all three checks; none was Critical.

The important correction is that the existing VSCO conditioner is not sufficient:
it rejects five actual B1 zones, becomes a constant gain before the handoff, and
cannot repair the B1's faster decay or changing negative phase correlation. The
design now uses a bounded B1 envelope through 450 ms and makes static-handoff
feasibility a measured implementation point. It will stop rather than restore
adaptive runtime gain if no static solution passes.

The review also found an existing reproducibility defect: `_bake_b1upright` accepts
the assigned retired soft pass. The implementation will reject anything other than
the exact 25-normal/27-hard inventory before writing.

## 2026-07-26 — external design review

One read-only Claude Opus pass found a Critical acceptance-test loophole: retiring
the B1 sample earlier would improve the modulation metric while erasing the recorded
piano identity. The design now pins both established fade windows and guards the old
first-180-ms waveform correlation and K-weighted level.

Useful Major findings also added a frozen pre-deletion baseline, independent layer
conditioning plus K-weighted seam calibration, high-entropy model seeds, separate
tail-gain and hiss bounds, and an output inventory derived from the clean committed
bank. The suggested calibration-enum rename was rejected as unrelated churn; B1
still needs its own calibration policy.

The one targeted critical-item re-review found that a sparse level fixture could
miss per-take attenuation and that signed waveform correlation contradicted an
allowed static polarity flip. The final identity guard covers all 52 zones and uses
absolute normalized correlation. The design is SELF-APPROVED; no unresolved
Critical finding remains.

## 2026-07-26 — implementation feasibility fork

The first static implementation removed the B1-only adaptive/frozen runtime path and
routed B1 through the ordinary sum-to-one piano wrapper. The bake now rejects the
retired soft layer and any inventory other than 25 normal plus 27 hard zones before
writing. It derives a smooth, bounded offline tail gain from the acoustic model's
expected power across randomized phases. Positive gain is reduced per zone when
needed to preserve 0.9 peak headroom; the first 180 ms remains sample-identical.

The proposed 3–4.5 Hz Tubular Bells metric was invalid. The pinned excerpt contains
140 note-ons in its first 35 seconds at exactly 250 ms intervals, so its 4 Hz peak is
authored articulation rather than an isolated shimmer measure. The misleading Rust
oracle and analysis script were removed before commit.

The raw B1 re-bake completed with the new inventory, identity, headroom, late-peak,
tail-gain, and high-frequency-energy guards. The ordinary runtime handoff then failed
the existing macro-envelope oracle at MIDI key 21, velocity 50, seed `0x13579BDF`:
3.09 dB rebound versus 0.52 dB in the bare model, above the 1.50 dB limit. The prior
adaptive implementation measured 3.40 dB on the same case, so offline conditioning
improved but did not solve it.

This is the design's declared architectural stop. A B1-only static constant-power
law is the smallest next experiment, but it is no longer an exact copy of the VSCO
alternate's sum-to-one mechanism. No alternate law has been implemented pending
Arthur's choice.
