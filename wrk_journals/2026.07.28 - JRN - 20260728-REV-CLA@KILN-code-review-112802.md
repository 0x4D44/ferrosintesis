# Review journal — ferrosintesis strings sample crate

Static review of `crates/ferrosintesis-samples-strings/` with independent
correctness, security, performance, reliability, maintainability, test-coverage,
and devil's-advocate lenses.

One defect survived adversarial verification: the public README rebake selects
32 of 40 assets, while the package summaries omit the same GM32 `pizzbass_*`
family. Raised `MM-BUG-KILN-00160` with a concrete metadata sweep and
source-derived oracle fix.

Static checks refuted current WAV corruption, duplicate assets, embedded/file
inventory drift, package-include omissions, dependency risk, and a meaningful
linear-lookup performance problem. Acoustic quality remained unverified because
this pass did not run the application, tests, sample generator, or exploratory
audio harness.

No requirement was minted: the durable oracle work is part of the confirmed bug
fix rather than standalone design debt.
