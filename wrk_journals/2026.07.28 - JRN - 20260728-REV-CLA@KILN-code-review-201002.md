# Review journal — VCSL Kawai sample crate

Static review of `crates/ferrosintesis-samples-vcsl-kawai/` with independent
correctness, security, performance, reliability, maintainability,
test-coverage, and devil's-advocate lenses.

Three Low-severity defects survived adversarial verification:

- `MM-BUG-KILN-00161` — the published provenance maps A2 and A#3 to the wrong
  upstream source labels;
- `MM-BUG-KILN-00162` — 16 deliberate logical aliases are stored and decoded
  as duplicate PCM, wasting 2,128,768 packaged bytes and 4,256,128 resident
  decoded bytes;
- `MM-BUG-KILN-00163` — Kawai's generic bake path has no family-scoped
  stale-output validation, while the source oracle mistakes Headroom's
  unrelated check for complete coverage.

Captured `MM-REQ-KILN-00164` for an independent, non-mutating Kawai rebake and
root/format oracle. Static checks found all 48 current WAVs structurally valid
and inventory-complete. Runtime routing, legal/package text, unsafe-code,
prewarm, and audio-hot-path concerns were refuted.

The application, package command, build, tests, generator, and exploratory
audio harness were not run. Upstream source/licence truth and acoustic quality
remain unverified.
