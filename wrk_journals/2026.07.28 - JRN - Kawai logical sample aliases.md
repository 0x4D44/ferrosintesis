# MM-BUG-KILN-00162 — Kawai logical sample aliases

The Kawai recipe exposed 48 logical layer/round-robin names, but VCSL supplies only
32 distinct source velocity payloads. Sixteen generated WAVs were byte-for-byte
copies, and `sampler.rs` decoded the two repeated layer pairs into separate banks.

The fix separates logical names from physical storage:

- `prepare.py` derives 32 canonical sources and 16 aliases from the full logical map.
- The packaged `ALIASES` manifest preserves every old exact lookup name.
- `gen_crate_lib.py` emits alias-aware lookup code and rejects undeclared duplicate
  physical payloads.
- `sampler.rs` returns the canonical decoded bank for both logical layer names.

The package shrank from 6,386,304 to 4,257,536 WAV bytes, saving 2,128,768 packaged
bytes. The focused regressions failed before the fix and passed afterward. A fresh
baseline/candidate render-diff over all 124 catalog MIDIs at 8 kHz reported 124 SAME,
0 changed, and 0 contamination, proving the cache-sharing change is audio-inert.
