# Kawai stale output inventory

MM-BUG-KILN-00163 showed that `prepare.py --only=kawai` could retain a WAV whose
source-table entry had been removed. The only validation in `main()` covered
Headroom, while the Rust source oracle modeled validation as an unscoped boolean.

The regression removes one entry from `KAWAI_SOURCES`, leaves that WAV in a
temporary packaged output, and proves the rebake fails before fetching, reading,
or writing. `main()` now validates `("kawai", KAWAI_SOURCES)` before using the
table. The Rust oracle also requires that exact family and expected-set pair;
negative controls reject an unrelated family and the wrong expected set.

Fail-before: `KawaiOutputInventoryTest` processed the remaining 31 Kawai sources
and raised no `ValueError`. Pass-after: 4 focused Kawai Python tests, all 22 Rust
inventory tests, formatting, and focused clippy pass.
