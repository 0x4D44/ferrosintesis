only 27 unique upstream velocity-layer payloads. Each zone repeated `pp_rr2` as
`mf` and `f_rr2`, and repeated `mf_rr2` as `f`.

the three redundant sampler constructors return the canonical decoded banks.

saving 3,592,296 packaged bytes plus three decoded-bank allocations.

decoded-bank pointer oracle failed. Pass-after: 3 source-derived Python tests,
3 asset-crate tests, the decoded-bank pointer test, 22 inventory tests,
