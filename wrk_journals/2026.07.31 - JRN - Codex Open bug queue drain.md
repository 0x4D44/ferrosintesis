# 2026.07.31 — Open bug queue drain

## MM-BUG-CRUCIBLE-00008 — catalog MIDI overlap oracle

The old oracle paired note timestamps inside each `MTrk`. It therefore missed
cross-track overlaps, same-tick on-before-off ordering, and overlaps when note
counts differed. Three adversarial controls reproduced those false negatives;
the existing balanced repeated-note control stayed clean.

A file-wide ordered lifecycle audit exposed a second cause in the committed
catalog. The copied album writers clamped simultaneous starts to zero-length
notes. Serialization then placed the off before both ons, leaving an orphan
off/on pair and making later re-strikes ambiguous. All 22 writer copies now
collapse simultaneous duplicate starts before clamping distinct re-strikes.
Regeneration removed 111 zero-tick note-on/off pairs from 26 committed MIDIs.
The only other MIDI event changes were three synchronized Burning Meridian
comment metadata updates already present in its generator source.

Every affected album was rebuilt before verification. All available composition
oracles passed. `cargo test -p render-catalog --test album_midi_overlaps` then
passed all four controls plus the full committed catalog.

## MM-BUG-CRUCIBLE-00009 — catalog discovery errors

Album discovery, recursive ownership discovery, and lyrics-sidecar validation
all flattened `read_dir` entry results. A directory could therefore yield one
valid path plus an I/O error and be treated as a smaller clean directory.

All three scans now share an injected directory-reader seam. Directory-open and
entry-read failures retain the directory path and propagate to the caller. Two
mixed success/error controls failed against flattening and pass with fallible
collection. `cargo test -p render-catalog` and focused all-target clippy pass.

## MM-BUG-CRUCIBLE-00010 — encoder preflight status

The encoder preflight treated every spawned `ropusenc --version` process as
usable, regardless of its exit status. An isolated-PATH control renamed a known
failing executable to `ropusenc`; the old helper entered discovery after its
nonzero exit.

Preflight now requires a successful status before running the discovery
continuation. Failures include the exit status and at most the final 200 stderr
characters. The fake-encoder control proves discovery stays untouched, and a
separate Unicode control pins tail bounding. Render-catalog tests and focused
all-target clippy pass.

## MM-BUG-CRUCIBLE-00011 — bounded encoder subprocesses

Both `ropusenc --version` and per-track encoding used `Command::output`, so a
stuck child held catalog discovery or a render worker forever. They now share a
captured-output runner that polls to a deadline, kills an expired child, and
waits for it before reporting a named timeout. Preflight has a 10-second limit;
each encode has a generous 30-minute limit.

The regression launches the test binary as a fake encoder that marks its start
and never exits. A one-second injected deadline returns only after a nonzero
reaped status is available, and the surrounding `TempWav` removes its file.
`cargo test -p render-catalog` and focused all-target clippy pass.
