## Worth remembering

**When a bug quotes exact numbers, check the numbers.** 00021 listed six bass WAVs
and their first PCM frames (-1248, +1647, -1053, -932, -7471, -1072). Reading frame
0 of all 13 committed WAVs at `bea209f^` and at trunk reproduced all six values
exactly and showed all six now 0, with the other seven unchanged at 0. That is a
stronger closure than any test result, and it took one short script.

**For an asset fix, prove what was NOT changed too.** The same script showed peak
amplitude identical (29490) in all six files and only 3-84 frames differing per
file — under 1.9 ms. That is what actually answers "does the de-click erase the
attack?", which the test can only assert on a synthetic fixture.

**Reverting half a coupled fix can make a test pass for the wrong reason.** 00019
changed both `cached_members_match` and `write_member_manifest`. Reverting only the
predicate would leave the new dict-shaped manifest unreadable by the old reader, so
every cache would miss and the regression would pass — green for a reason that has
nothing to do with the bug. Both had to go back together to reproduce the defect.
