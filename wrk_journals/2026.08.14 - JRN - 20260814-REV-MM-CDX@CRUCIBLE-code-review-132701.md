# Review journal — `crates/render-catalog/`

One bounded static review pass covered the complete crate: manifest, 1,590-line binary,
MIDI-overlap integration test, and argv goldens. Six focused reviewers and a devil's
advocate covered correctness, security, performance, reliability, maintainability, test
coverage, and implicit assumptions. The lead independently checked every surviving claim.

The pass confirmed one defect. The overlap oracle skips SysEx, while production treats GM
System On as a same-tick-prioritized hard reset that stops active voices. Filed
`MM-BUG-CRUCIBLE-00034` with a concrete reset-aware oracle fix and negative controls.

The subprocess pipe concern remains unverified because the accessible external encoder
source did not establish output volume. Worker-tally, job-count, symlink, and metadata
proposals were either already documented, operator-controlled, duplicate, or lacked a
current failure. No requirements were justified.

No application, build, test, render, encoder, or exploratory harness ran. Deltic owns git,
commit, coverage reconciliation, and integration for this pass.
