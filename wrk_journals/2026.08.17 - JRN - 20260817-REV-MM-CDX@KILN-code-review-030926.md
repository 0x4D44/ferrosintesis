# Review journal — MuseScore grand sample crate

Reviewed `crates/ferrosintesis-samples-musescore-grand/` after the 2026-08-16
WAV-to-FLAC migration. Six independent lenses and a devil's advocate covered
correctness, security, performance, reliability, maintainability, test coverage,
and implicit assumptions. The pass was static: no app, build, test, decoder,
generator, render, network lookup, or exploratory harness ran.

The committed 25-file FLAC bank is internally aligned by filenames, package
inventory, consumer zones, unique hashes, and STREAMINFO shape. The actionable
failures are in the published format contract and regeneration workflow:

- `MM-BUG-KILN-00253` — stale WAV package documentation;
- `MM-BUG-KILN-00254` — WAV-producing command leaves FLAC runtime bytes stale;
- `MM-BUG-KILN-00255` — direct per-zone publication is not bank-atomic;
- `MM-BUG-KILN-00256` — fixed shared decode intermediates race across worktrees.

Shared generator, decoder, onset-oracle, source-pin, and independent asset/root
verification findings were deduplicated against existing bugs and Draft
requirements. No new requirement was needed.
